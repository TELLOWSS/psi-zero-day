# 전체 화면 그래픽 정리

이번 범위는 SIGNAL BREAKER의 기존 제작 자산·캐릭터·맵 구조물을 연결한 표시 품질 개선이다. 본편 WATCH와 별도 분기이며 새 캠페인이나 게임 규칙은 추가하지 않는다. 모든 원화를 새로 제작했다거나 모바일 성능 검수가 끝났다는 의미는 아니다.

| 영역 | 변경 |
|---|---|
| 화면 선명도 | 실제 표시 크기와 devicePixelRatio에 맞는 캔버스 해상도. 높음 최대 2배, 균형 최대 1.5배, 낮음 1배. ResizeObserver로 집중 화면·레이아웃 변경에도 갱신. 좌표계는 기존 1100×620 유지 |
| 캐릭터·실착 미리보기 | 기존 WATCH 동작과 손 앵커를 유지. 미리보기 backing surface를 700×360으로 올리고 표시 크기는 유지. 실제 현장 원화 배경을 같은 미리보기에 사용 |
| 발사체 | 펄스의 밝은 충격 핵, 포획망의 육각 전개, 자력기의 양극 곡선, 미스트의 분산 입자, 앵커의 금속 갈고리, 스캐너의 회전 탐지 궤도. 궤적은 실제 탄환 기록과 위치를 사용 |
| 타격 | 실제 총구에서 방향성 발사 섬광, 전력 코어 타격 시 방사형 전기 균열. 공유 VFX 원화와 기존 재질별 색상 유지. 효과 저장 수와 입자 수 상한 유지 |
| 현장 분위기 | 폭풍 제어장 비, 집진 통로 분진 안개, 상하 명암. 저품질에서 추가 대기 효과 생략. 흔들림 감소에서는 이동하는 대기 효과 시간 고정 |
| UI | HUD·패널·버튼·설정 화면의 금속성 명암, 따뜻한 발사 버튼, 선택 장비의 청록 표시. 장식이 입력을 막는 레이어 추가 없음 |

## 검증

모드 테스트 31개, 캐릭터×장비 36개 조합, 6개 PC/태블릿/모바일 뷰포트 확인. DPR 2 실제 Chrome에서 해상도 상한·저품질 전환·정지 시간 보존·캐릭터 변경·발사를 확인. 700px 미리보기 backing 크기 검증. 타입 검사·production build·본편 회귀 검사는 작업 로그에 기록한다.

재현: `scripts/verify-graphics.cjs`, `scripts/verify-browser.cjs`, `scripts/verify-chapter.cjs` (이 문서 기준 public/signal-breaker-dev 하위). 고밀도 표시가 실제 휴대폰에서 적정한지는 실기기 FPS·발열 검수가 필요하다. 기본 저사양 품질 상한이 그 검수를 대신하지 않는다.
