# 엔딩 인물 연기·음성 준비 구현 — 2026-10-12

보스 해소가 현장을 바꾸고, 현장의 변화가 사람의 반응으로 이어지는 흐름을 강화한다. 기존 고화질 CG, PSI 게임 근거 기록, 다음 구역 징후와 수동 출발을 이어간다.

## 구현

CH-01·03에는 임준호 relief, CH-02에는 윤성호 appreciative, CH-04에는 강태식 supportive 실제 캐릭터 자산을 사용한다. 원본 파일을 복제·수정하지 않고 얼굴·상체 영역을 명시적으로 프레이밍한다. 대사 장면에만 등장해 짧게 정착하고, 미세한 호흡·무게 이동 후 퇴장한다. 움직임은 EndingPlayer 경과 시간을 사용해 정지·탭 숨김과 함께 멈춘다. reduced motion/low는 정적인 인물로 유지한다. 이미지 로드 실패는 인물 레이어만 숨기며 자막·건너뛰기·기록에 영향을 주지 않는다.

CH-05의 화자는 이름 없는 작업자다. 이를 임준호나 다른 인물로 바꾸지 않고 기존 현장 CG 속 작업자를 유지한다. 최종 SIGNAL RECEIVED → 오늘도 무사히 흐름을 보존한다.

human 장면에 1.5초를 추가했다. CH-01은 13.5초, CH-02~04는 15.5초, CH-05는 22.5초다. 이미 기록된 엔딩 version/identity/evidence를 변경하지 않아 기존 재감상 기록을 유지한다.

엔딩 전용 음성 슬롯 다섯 개와 재생 모듈을 연결했다. 후속 사용자 제공 녹음 5개가 연결됐으며 최종 청취 승인은 대기 상태다. 기존 음성을 다른 인물의 목소리로 붙이지 않는다. 정확한 화자·대사 ID, 실제 경로·SHA-256·길이가 확인되고 런타임 통합이 허용된 파일만 재생한다. 음성 재생은 보상·점수·PSI·게임 엔진 상태를 변경하지 않는다.

## 제작 범위와 다음 작업

이번 연기는 **기존 2D 캐릭터 자산의 상체 프레이밍 및 미세 움직임**이다. 음성 파일은 사용자가 제공한 원본을 후속 통합했다. 립싱크·손·머리·관절을 분리한 애니메이션이나 최종 음성 녹음 완료로 계산하지 않는다. 캐릭터별 손짓/시선 전환 및 CH-05 손을 드는 작업자 연기는 별도 실제 자산 제작 단계다.

현재 정확한 녹음 5개와 자산 연결은 완료됐다. 다음은 `ENDING_VOICE_RECORDING_SPEC_20261012.md`에 맞춘 인물 연속성·최종 청취 확인이다. 이어서 인물의 손짓/시선 프레임과 Android 실기기에서 오디오 포커스·안전 영역을 확인한다. 실제 PSI 프로그램 연동은 별도 단계다.

## 검증 경계

엔진 terminal fixture로 엔딩 진입·보상 유지·기록·재감상·수동 진행을 검사한다. 합성 QA 톤으로 파일 해시, 실제 Web Audio 디코딩/출력, 정지·재개·음원 정리·변조 거부를 검사한다. 이는 실제 대사 녹음이나 Director 청취 승인, Android 실기기 검증을 대신하지 않는다. 화면은 390×844, 844×390, 768×1024, 1920×1080에서 확인한다.
