# 엔딩 연출 고도화 — 2026-10-12 KST

사용자 승인 범위: 다섯 보스 클리어 엔딩의 연출 고도화. 기존 12 / 14 / 14 / 14 / 21초와 수동 출발 구조를 유지한다.

## 연출 의도

보스의 승패보다 **플레이어의 개입으로 회복된 현장**을 먼저 보여준다. 현장 구도 → 작업자의 짧은 반응 → 게임에서 확인한 PSI 근거 → 다음 현장 신호 순서다. 정적 이미지 전체를 흔들어 인물 애니메이션으로 계산하지 않는다.

| 스테이지 | 현장 회복 장면 | 사람 장면 | 다음 연결 |
|---|---|---|---|
| CH-01 | 분리된 보행로와 정리된 자재 | 임준호가 걸을 길을 확인 | 컨베이어의 불규칙한 금속음 |
| CH-02 | 이송 경계와 분리된 길 | 윤성호가 팀의 동선을 맞춤 | 자재 너머 분진 |
| CH-03 | 드러난 집진 통로 | 임준호가 상부 흔들림을 발견 | 장력선 |
| CH-04 | 받침목 위 하중과 느슨한 슬링 | 강태식이 함께 맞춘 순서를 확인 | 전력 연결부 |
| CH-05 | 앞선 네 현장 회상과 닫힌 전력 구역 | 작업자가 시작 전에 먼저 멈춰 확인 | SIGNAL RECEIVED → 오늘도 무사히. → 작전 선택 |

## 반영

- **장면별 세로 구도**: 고화질 원화의 피사체 위치를 직접 확인해 초점을 지정. CH-04 world는 원화 가로 위치 90%, human은 48%, memory는 78%. 마지막 CH-04 회상도 하중을 보여준다. 가로 화면은 현장 전체의 관계를 보존한다.
- **대사**: 화자 이름과 말 분리. human에서는 큰 챕터 제목과 PSI 근거를 감춰 사람의 말이 먼저 읽힌다. 기존 대사의 의미와 화자는 유지한다.
- **정보 리듬**: PSI 근거와 실제 현장 평가와의 구분 안내는 memory에서 함께 표시. hook은 다음 확인에 집중한다. 결과 화면에는 기존 저장 근거를 계속 표시한다.
- **마지막**: 네 현장의 회상 → 작업자의 확인 제안 → SIGNAL RECEIVED → 오늘도 무사히. 자동으로 다음 작전을 시작하지 않는다.
- **전환**: 자막의 짧은 등장과 기존의 낮은 카메라 드리프트. 일시정지·백그라운드 시 둘 다 멈춤. 저품질·모션 감소 설정은 정지 구도.
- **음향**: 기존 전투 음악을 멈춘 뒤 250ms 공간, 1.25초로 낮은 공기음과 부드러운 화음 진입. human에서는 화음 35%로 낮춤. 마지막 0.8초로 사라진다. 원본 절차 음향이며 성우·오케스트라 최종 녹음으로 주장하지 않는다. 전용 버스는 동시에 기본 4개 소스, memory 신호음 포함 최대 5개. 일시정지·숨김 시 무음, 종료·재감상 시 정리. 외부 샘플이나 신규 네트워크 음원은 없다.
- **오프라인**: 새 presentation 모듈을 전용 서비스워커 shell에 추가, v0.38.0-ending-direction. 원화는 기존 on-demand 캐시.

## 검증 범위

브레이커 Node 회귀, 전체 앱 회귀, typecheck/build와 브라우저 5개 스테이지 × 4화면(390×844, 844×390, 768×1024, 1920×1080)을 실행한다. 새 브라우저 검증은 world/human/memory/hook의 구도·자막·타이틀·근거 표시를 확인한다. 기존 저장 실패 재시도, 클리어 중 전투 정지, 재감상·새로고침 보상 중복 방지, 자동 출발 방지도 유지한다.

보스 종료 fixture로 연출 경계를 확인하는 검증이며, 완전한 전투 밸런스 플레이나 Android 실기기 검증을 대체하지 않는다. 실제 PSI 연동·점수·성우 녹음·인물의 프레임별 연기는 이번 반영에 포함되지 않는다. 최종 음향 청취와 Production Lock은 Director 검수 단계다.
