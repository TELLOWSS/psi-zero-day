# SIGNAL BREAKER — 캐릭터 총구/탄도 방향 동기화 개선
2026-10-11 · Source/Browser QA 범위. Android 실기기 승인 아님.

## 사용자 신고의 구현상 원인
- 발사체 물리 좌표는 기존부터 `Game.launchGeometry().muzzle`을 사용해 정확했다.
- 실제 플레이에서 사용하는 authored actor는 8방향 캐릭터 애니메이션을 선택하고, 일부 뒤쪽(후면) 스프라이트에서 무기보다 캐릭터를 뒤늦게 다시 그리는 방식이므로 무기 총구가 가려진 것처럼 보일 수 있었다.
- 자동조준으로 탄환이 발사된 직후 목표가 바뀌면 캐릭터의 포즈 방향이 그 탄환보다 먼저 바뀔 수 있었다.
- 이 보고의 원인은 코드 판독 및 예상 렌더링 동작 기준이며, Android 실기기의 재현 영상 프레임 분석 결과는 아니다.

## 구현
- 독립 `src/firing-pose.js`가 실제 `fire` 이벤트에 기록된 발사 방향·무기·시뮬레이션 시각을 관찰하며, 발사 후 **최대 115ms**만 그 벡터를 캐릭터 화면 포즈로 사용한다.
- 회피/이동 중에는 발사자 현재 위치에서 총구 위치를 다시 산정하지만 **실제 발사체 위치/궤적·게임 조준 벡터·명중/데미지·사격 속도·발사체 32개 상한은 절대 수정하지 않는다.**
- 뒤로 돌아 있는 캐릭터 스프라이트가 무기를 가려도 총구 끝의 짧은 컬러 배럴 표시를 캐릭터보다 위 레이어에서 그려 반대 방향의 발사로 읽히지 않게 한다. 높은 품질 설정에서만 비용이 증가하는 화려한 효과 대신 **상수 개의 Canvas stroke** 사용.
- stage setup/retry 시 pose 캐시 초기화, 기본 무기 + 신규 bankshot/resonance 컬러/캐릭터 도형 호환, script 및 service worker offline 캐시 업데이트.
- 음성/캐릭터/다른 게임용 공유 actor bundle을 직접 편집하지 않아 기존 EP01과 SURVIVORS 사용에 미치는 영향 최소화.

## 품질 검사
- 기존 5개 스테이지의 좌/우 탄환 총구 위치·방향 일치, 신규 주력 무기 2종, 조준 180도 급반전, 조작 중 사용자 이동, pose timeout, 잘못된 fire 이벤트·재시작 reset을 검사하는 테스트 추가.
- UI smoke에 신규 파일 로드 추가. 브라우저 네 화면 크기에서 실제 actor 좌/우 방향과 screenshot 파일 작성.
- 실제 기기에서는 auto ON, 이동 joystick, 조준 override, FIRE 동시 터치 상태를 재현하고 **총구 화염이 캐릭터 앞에 표시되는지** 영상으로 추가 검수해야 한다.
- 상업용 최종 무기 rig/실물 장착 자세, 프리미엄 장비 소재·이펙트·과금 가치 및 보스 5종 재미 검증은 계속 열린 과제.
