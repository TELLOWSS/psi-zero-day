# 메인화면 연결 및 운영 동기화 기준

사용자가 2026-10-10 GitHub·Vercel 운영 동기화와 메인화면 구성을 요청했다. 이 요청은 초기 인계서의 독립 개발·배포 금지 범위 이후의 명시적 통합/배포 승인이다.

운영 대상: TELLOWSS/psi-zero-day, main. 기존 Vercel 프로젝트 psi-zero-day (prj_W0pIPvmZkiP5mSi92LRxH7aw3PNa), 기존 운영 주소 psi-zero-day.vercel.app. 시작 운영 커밋 9f018f4de767dc4d4ce951bc9d8616e24186d354. 현재 변경은 이 커밋의 후속이며 다른 본편 작업 폴더의 미커밋 수정은 포함하지 않는다.

메인 제목 아래에 스토리/워치/브레이커/디펜스/도감 모드 선택을 배치했다. 워치와 브레이커는 실행, 스토리·디펜스는 기존 프리뷰로 연결한다. 브레이커 상세 진입 카드와 5작전·6장비·무보상 연습 안내를 추가하고 메인 복귀 링크를 제공한다. 모바일의 오래된 120px 공백과 플레이 카드 등장 애니메이션을 정리했다.

실행 경로는 /signal-breaker-dev/index.html이다. 개발 서버의 SPA fallback과 독립 HTML 파일을 혼동하지 않도록 명시 경로를 사용한다. 게임 저장은 기존 브레이커 전용 namespace이며 WATCH 저장/크레딧을 합치지 않는다.

검증: 본편 2,037개 통과/1개 제외, 브레이커 31개 통과, 타입 검사·production build. 실제 Chrome의 PC/모바일에서 메인 모드 선택 → 브레이커 실행 → 발사 → 메인 복귀, 화면 넘침 없음/JS 오류 없음 확인. scripts/verify-hub-entry.cjs는 환경변수 SIGNAL_BREAKER_HUB_URL로 운영 주소에도 같은 흐름을 재현한다.

브라우저 서버/정적 파일 응답/로컬 저장/화면 갱신을 검증한 정적 앱 흐름이며 신규 API·DB·서버 비밀키는 사용하지 않는다. 실제 모바일 발열·장비 미술 최종 판정은 운영 동기화 완료와 별개다. 배포 결과의 정확한 SHA·READY·운영 별칭과 운영 브라우저 검증은 동기화 후 확인한다.
