## 기록과 연출의 구분

CH-01의 source 관찰·차단·검증 기록과 기존 ch01-ending-v1 저장을 유지한다. CH-02~05는 source 시스템이 없으므로 observed/controlled/verified를 만들지 않는다. campaign-ending-v1은 엔진 won, 최종 wave, 올바른 보스 identity/resolved, 모든 보스 노드·회수 회로 해소, 잔류 신호 0을 요구한다. 컨베이어 최종 segment와 집진 최종 filterStage도 확인한다.

기록은 origin=game, measurementKind=simulated, externalSync=false다. sourceAssessment 및 네 미측정 지표는 unmeasured다. 컨베이어 차단·집진 압력 해소·장력 고정·전력 격리 횟수는 기존 엔진 카운터의 실제 값만 저장하며 0도 그대로 유지한다. 해당 개입을 모든 플레이어가 수행했다고 가정하지 않는다. 이미지의 현장 정리는 창작된 클리어 연출로, 실제 현장 확인이나 분진 농도·무전압 측정의 증명으로 해석하지 않는다. 운영 PSI API, 새 공식·임계치는 추가하지 않는다.

CH-04 마지막 Wave 대사는 ‘반입 혼선 추적’에서 ‘장비 연결부 전력 신호 확인’으로 정리해 엔딩과 다음 맵을 연결했다. 결과 화면의 현장 기억에는 각 작전의 다음 안내와 연결 대사를 표시한다.

## 이미지 제작과 전달

빌트인 imagegen 편집으로 각 기존 맵을 개별 참조했다. 공통 프롬프트: 원래 카메라·건축물·장비 위치·원근과 산업현장 재질 유지, 중앙 40%에 작업자와 핵심 변화, 텍스트·HUD·로고 없음, 동일 맵의 위험 해소 후 현장. 각 원본 PNG는 새 파일로 유지하고 아래 WebP를 프로젝트 자산으로 사용한다. 모두 1672×941. Production Lock 판정은 별도다.
