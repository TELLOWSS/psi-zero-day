## 공통 제작 지시

본문 대사만 한 번 읽는다. 따옴표, 화자 이름, 파일명, 지시문을 읽지 않는다. 깨끗한 한국어 dry voice, 음악·효과음·무전 필터·다른 사람 목소리·임의 문장 추가 없이 제작한다. 실제 인물이나 유명 성우를 모사하지 않는다. 임준호 두 대사는 동일한 화자 프로필을 사용한다. 기존 캐릭터의 승인된 목소리와 연속성을 청취 비교한다.

원본 권장 mono PCM WAV / 48kHz / 24-bit. 생성 도구의 원본이 다른 형식이면 원본을 보존하고 업샘플링으로 품질을 부풀리지 않는다. 시작·끝의 짧은 무음을 포함해 상한을 맞추며, 또렷함을 해치는 속도 조절로 맞추지 않는다. 실제 녹음이 더 길면 승인 후 human 장면을 다시 타이밍한다. 전체 엔딩은 25초 이하를 유지한다.

## 통합 계약

`src/ending-performance-content.js`의 정확한 `speakerId`, `lineId`를 기준으로 연결한다. `status: 'approved'`는 녹음 내용·화자·사용권·청취 확인 후에만 지정한다. voice에는 실제 `/assets/...wav|ogg|mp3` 경로, 원본 SHA-256, 디코딩 재생 길이, 동일한 speakerId와 lineId를 기록한다. 현재 다섯 슬롯은 `awaiting-recording`, `voice: null`이다.

런타임은 해시, 디코딩 길이(±80ms), 장면 안의 재생 여유를 확인한다. 늦은 다운로드가 human 시작에서 400ms를 넘기면 문장 중간에서 시작하지 않고 그 회차를 자막으로 유지한다. 일시정지·탭 숨김은 음원을 해제하고 재개 시 엔딩 경과 시간의 같은 지점부터 재생한다. 건너뛰기·종료·재감상 시작은 이전 음원을 정리한다. 음성 중 배경 음악과 현장 공기음을 낮춘다.

## 청취 확인

각 파일에 제작 도구/모델/화자 설정/생성 일자/사용권 근거/정확한 대사/길이/SHA-256을 남긴다. 한국어 발음과 인물 연속성, 문장 시작·끝, 클리핑, 모바일 스피커·이어폰에서 자막과의 일치, 배경 음향과의 균형을 확인한다. 자동 테스트의 합성 톤은 재생 기술 검증만 하며 실제 목소리나 청취 승인을 대신하지 않는다.
