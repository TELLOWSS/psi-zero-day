# SIGNAL BREAKER — CH-02 FLOW 2/5 과대 금속 오브젝트 판독성 개선

2026-10-11, 기준 GitHub main PR #183 (a596fd3f22f9). 본 변경은 게임의 전투 판정이나 스테이지 진행을 바꾸지 않는 아트 렌더링 보호 조치다.

## 근거
첨부 모바일 캡처에서는 CH-02 2/5 웨이브에 화면을 크게 가리는 금속 형상 및 밝은 곡선이 발견됐다. 기존 released hazard 아틀라스는 반경 r 물체를 직경 3.35r로 렌더링했다. 실제 판정 반경은 14/23/31이고, 확대 카메라에서는 비물리 시각물이 과장될 수 있다. **다만 캡처의 모든 금속 형상이 released hazard인지, 배경 리소스에 포함돼 있는지는 캡처만으로 확정할 수 없다.**

## 수정
- `PremiumArt.hazardVisualSize(q, camera.scale)` 를 추가하여 일반 위험물 이미지를 충돌 직경 `2r` 이상이되 통상 `2.35r` 이하, 화면 픽셀 직경은 충돌 상자 자체가 더 크지 않은 경우 최대 110px로 제한한다.
- 좌표/나이/속도/원본 이미지 원근을 조작하지 않는다. 금속·분진·전력·중량물 4종 모두 적용한다.
- 외곽 고정 크기의 충돌 표시 및 사전 경고용 점선 링으로 실제 위협 범위를 인식시킨다.
- 품질·움직임 옵션을 존중하며 새로운 이미지 파일을 추가하지 않는다.

## 테스트 계약
- 3개 반경 × 6개 확대비에서 이미지가 충돌판정보다 작아지거나 과도하게 커지지 않는지 검사한다.
- 재질 4종과 품질 3단계 및 Motion 옵션별로 아틀라스 호출은 1회이며 입력 게임 상태를 변경하지 않아야 한다.
- 390x844, 844x390, 768x1024, 1920x1080의 CH-02 FLOW 2/5에서 금속 위험물 포함/배경만 A/B 화면을 캡처한다. **배경-only 화면에도 거대한 금속 형상이 존재하면 이 수정만으로 문제가 해결됐다고 볼 수 없으며, 원본 배경 이미지 자산을 별도 점검해야 한다.**
- 기존 GitHub Actions 엔진/입력 회귀 및 전체 앱 회귀 통과 전까지 main 병합하지 않는다.
