# SIGNAL BREAKER 모바일 화면 품질 개선

작업 기준: 2026-10-11 첨부 모바일 화면.

화면 상단은 작전·웨이브·보호 상태를 간결하게 표시한다. 실제 보스 웨이브에만 보스명·방호 노드 상태·체력 게이지를 노출한다.

하단은 이동·FIRE·조준의 세 영역으로 구분한다. AUTO와 무기 선택을 중앙 조작 위로 배치하고 장치 버튼은 별도 한 줄로 표시한다. 연쇄 강화 버튼의 긴 문구는 짧게 줄인다.

클리어 화면은 점수와 핵심 성과, 작전 포인트, 다음 행동의 순서로 안내하고 기존 상세 기록 및 장비 정비 기능을 유지한다.

변경 범위는 화면과 표시 정보이며, 전투 물리와 보스 체력은 이번 PR에서 변경하지 않는다.

자동화는 모바일 세로/가로·태블릿·데스크톱의 보스 HUD 및 FIRE 버튼 위치, 클리어 UI를 검사한다. 실제 Android 사용성과 최종 자산 검수는 별도이다.
