# CH-01 전용 보스 / 2종 주력 무기 구현 검증 메모
2026-10-11 · SIGNAL BREAKER · Development QA (not Final Art / Android Production Lock)

## 범위
- 주력 장비 **반사 집중탄(bankshot)**: CH-02 해금, 실물 발사체 속도·간격·색·도형·절차적 사운드 구별. 방호판 반사 후 코어 명중 시 반경 110 월드 픽셀의 기존 코어 1개를 추가로 분리(추가 생성된 새 코어는 제외).
- 주력 장비 **공명 충격파(resonance)**: CH-03 해금, 느린 근거리 단발. 최초 명중 + 반경 95 월드 픽셀의 기존 코어 최대 2개 추가 분리.
- 두 무기는 기존 `pulse/net/magnet/mist/anchor/scan` 여섯 장비 삭제 없이 추가. 2슬롯/쿨다운/투사체 32개 상한/스테이지 장비 해금/저장 복원/자동조준/보스 노드 조작/PSI 3종 아이템 조합 유지.
- **CH-01 전용 보스(반입 혼선 제어기)**: 기존 공용 장비 스프라이트를 대체하는 고유 벡터 조형(강철 프레임, 경고 스트라이프, 스윙 기어, 셔터, 노드, 작업구역 경고선). 별도 색 변형이 아닌 전용 실루엣.
- 공격 주기: 진입 후 첫 7.5초, 이후 8.5초 간격. 발동 1.35초 전 현재 플레이어 X 좌표에 위험 통로를 고정해 예고하고, 회피하지 못하면 체력 1 감소. 피격 무적시간 준수. 반사탄으로 보스 약점을 맞추면 2 HP 피해, 일반 직격은 1 HP.
- CH-02~05는 기존 보스 코어 규칙을 보존. 고유 아트/기믹 4종 추가 제작은 **미완료**.

## 테스트 결과와 수용 조건
- PR #175에는 장비별 실제 탄도/효과, 단계별 잠금, 보스/릴레이 접근, 콤보, 화력 제한, 정확한 발사 출발점에 대한 결정적 테스트가 추가됨.
- PR #176에는 경고 사전 노출·회피·피격 무적·반사탄 공격·다른 스테이지 분리에 대한 결정적 테스트가 추가됨.
- 동일 입력 기반 보스 시뮬레이션 5 스테이지 × 3 시드 × 3 펄스 패턴 = **45회 모두 클리어**, 실패 0, 투사체 최고 32. 기존 골든과의 차이는 CH-01 2회 클리어 시간뿐; CH-02~05 결과는 완전 동일.
- 위 45회는 기존 기본 펄스 패턴의 자동화 시뮬레이션이며 **신규 두 무기의 사람 실플레이 승률, 모바일 터치감, 재미를 입증하지 않음**.
- 보스 경고 구역은 브라우저 390×844 / 844×390 / 768×1024 / 1920×1080 등 viewport QA에서 실제 캡처 검증 대상.
- 최종 승인은 Android 폰/태블릿 실기기에서 사격 방향과 상체 포즈, AUTO+이동+수동조준, 프레임/발열, 효과음 믹스, CH-01 보스 위험 경고의 가독성을 확인한 후 부여.
- 나머지 주력 무기 확장 목표(8개 계열), 나머지 4보스 고유화는 별도 제작 범위.
