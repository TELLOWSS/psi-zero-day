# SIGNAL BREAKER CH-04 장력 불균형 릴레이 — 4단계 부하 검증
2026-10-11 | 기준 main: PR #187

## 기존 문제
CH-04는 지정 순서대로 3개 릴레이를 열고 고정된 체력 6을 소진하면 끝나는 1회 전투였다. 기존 9개 자동 입력 평균 보스 구간은 약 9.9초였으며, 전용 장력 앵커를 쓸 기회가 적었다.

## 실제 수정
- `loadStage:1,maxLoadStages:4`, 매 단계 방호 릴레이 3개를 다시 공략하여 장력 코어를 노출하고 후속 부하 시험을 진행.
- 중간 3단계에서 `phase='rebalancing'`, 3.4초 재조정 뒤 다시 릴레이를 해제. 재조정 중 코어 피해 방지.
- **실제 장력 레일에 앵커탄을 명중**하여 장력선이 고정된 상태에서 재조정이 진행되면 최초 1회에 한해 재조정 시간을 **1.4초 단축**. 지속 시간 안에 단일 보너스만 적용해 악용 방지. 기존 파열 차단 및 고정 중 코어 2배 피해는 보존.
- 단계가 높아질수록 파열 예고 충돌 구간과 장력 경고가 확대되고 파열 간격이 점증적으로 단축. 미리 표시한 구역을 피하면 여전히 피해 없음.
- 보스 하단 상태 'LOAD TEST 1/4..4/4', 장력 보스 HUD, 새 기계 표면 손상 및 고유 부하 검증/앵커 보정/재가동 VFX/SFX. 현재는 절차적 Canvas 아트이며 영화급 Final Art가 아님.

## 검증 계측
- 고정 45개 자동 입력: **45회 모두 완료**, 최고 동시 탄환 **32개**.
- CH-04 9개 조합의 평균 보스 구간: **약 9.9초 → 45.1초**, 최단 27초, 최장 59.4초. CH-04 외 4개 스테이지의 replay 결과 불변.
- 위 시뮬레이션은 실제 사용자가 앵커를 얼마나 잘 활용하는지 측정한 것이 아니다. 자동 이동/자동 조준/고정 공격 패턴의 구조 검증 결과다.
