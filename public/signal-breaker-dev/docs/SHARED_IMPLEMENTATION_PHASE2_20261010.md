# 공유 캐릭터 선택 · 장비 손목 연결 2차

## 구현
- 기존 공유 원화 6명(주인공, 강태식, 윤성호, 이재훈, 임준호, 안전 감시원)을 선택 가능하게 연결했다. 새 원화 복제나 전원 선로딩은 하지 않는다.
- 준비/일시정지 화면에서 외형을 선택하며 능력치와 물리는 동일하다. 선택은 독립 저장 공간에 보관한다. 전투 중 변경하려면 정지 버튼을 사용한다.
- 변경 시 기존 표시 어댑터 참조를 해제하고 다음 플레이 프레임에서 선택 캐릭터만 준비한다. 게임 상태와 점수는 유지하며 HTML 선택 조작의 키 입력은 게임에 전달하지 않는다.
- 기존 장비 표시를 고정 화면 좌표에서 캐릭터의 실제 directionalSocket(wrist)와 actorTorsoPoint로 이동했다. 캐릭터별 보정과 보행/반동 변형을 동일하게 따른다. 두 장비의 기존 색상 구분은 유지한다.

## 검증
- 실제 Chrome에서 6명 모두 원화 로딩, 이동, 발사, 손목 좌표 반환과 정지 중 시간 유지 확인. 새로고침 후 선택 보존 및 JS/HTTP 오류 없음 확인.
- 독립 검사 11개 통과. 대원 변경 저장과 선택 입력의 발사 차단을 UI smoke 검사에 추가했다. 타입 검사와 Vite 빌드 통과. 기존 테스트 2037개 통과/1개 제외. 화면 크기 6종에서 화면 넘침과 JS/HTTP 오류 없음 확인. 준비/선택 화면과 강태식 손목 장착 화면은 저장소 루트 docs/qa/signal-breaker-20261010/actor-selection.png 및 actor-wrist.png에 보관했다.

## 남은 범위
손목 장착 연결은 전용 장비 원화의 완성을 뜻하지 않는다. 기존 간단한 장비 표시를 재사용했고, 캐릭터 원화에 그려진 기존 소도구 제거/가림, 손의 앞뒤 가림 보정과 장비별 총구 위치는 후속 작업이다. 엔진의 발사체 출발점(player.x, player.y-25)은 유지했으므로 시각 총구와 물리 출발점의 최종 일치는 아직 미완료다.

빠르게 여러 캐릭터를 바꾸면 진행 중 이미지 로딩은 브라우저에서 끝날 수 있다. 참조 해제는 즉시 메모리 반환 보장이 아니며 캐릭터별 메모리 상한/실기기 발열은 아직 미측정이다. UI 이름은 기존 이름을 사용했으며 새로운 별칭을 임의 창작하지 않았다. 배포와 본편 연결은 하지 않았다.
