# SIGNAL BREAKER — CH-04 장력 릴레이 보스 구현/검증
2026-10-11 | 개발 시제품; Android 실기기 및 상업용 Final Art Lock 미완료

## 게임 메커니즘
- CH-01 위치 추적 → CH-02 컨베이어 정지 → CH-03 집진 압력 배출과 구별되는 CH-04만의 **장력선 파열 감시 / 앵커 고정**.
- 보스 등장 후 첫 파열 시점 약 2.8초, 파열 예고 1.35초. 작업자 X=440~885 위험 통로 표시. 예고 동안 장력 앵커를 실제 흔들리는 레일에 적중시켜 잠그면 예정 파열이 취소되며 다음 경고는 6.6초 후. 미조치 시 파열, 이후 7.9초 간격 반복.
- 파열 시 위험 통로 내 작업자 1HP 감소, 피격 무적시간 적용. 통로 외부 이동 회피 가능. 앵커 자동 작동 없음. 강제로 장력선을 잠글 필요 없이 기본 펄스로도 보스를 격파 가능.
- 보스 릴레이 3개는 **번호 순서**대로 기본 펄스/반사 집중탄/공명 충격파로 해제. 앵커로 레일을 묶은 상태에서는 개방 코어에 2HP, 그 외에는 1HP. 보스 최대 HP=6. 안정화와 노드 공격은 독립된 플레이어 행동.
- 장력선 발사체가 실제 rail collider에 적중했을 때 앵커를 가동하는 기존 코드 경로에서 보스 차단 판정이 즉시 발생함.
- 외형: CH-04 전용 와이어 드럼, 이중 도르래, 추, 중앙 장력 코어, 경고등과 고정 상태 레이블. 기존 세 보스 실루엣 재색칠 아님. 절차적 짧은 경고·제어 성공·파열 SFX 및 경량 VFX.

## 검증 근거
- CH-04 8개 엔진 테스트: 독립 identity, 사전 경고, 정지 차단, 실제 rail projectile collision, 피격/무적, 안전 통로 외부 회피, 노드 순서와 약점 보너스, 타 스테이지 격리, 일시정지/해결 상태.
- 5개 CH × 3시드 × 3발사스타일 = **45회 결정적 입력 재현: 45/45 클리어, 최고 동시 발사체 32**, CH-04 경고 12/파열 8/장력 앵커 차단 4. 결과 변경은 CH-04 5건이며 다른 CH-01/02/03/05 값은 그대로.
- 390×844 / 844×390 / 768×1024 / 1920×1080 브라우저 시나리오: 보스 예고, rail 앵커 실탄 명중, 차단 반응 캡처 확인 대상으로 추가됨.
- 위 자동화 성공은 실제 인간 플레이 밸런스, Android 조작 방향/진동/발열, 상업용 최종 아트·사운드 수준을 입증하지 않음. 그런 항목은 Production QA 별도 처리.
