# SIGNAL BREAKER — CH-05 복합 전력 제어기 최종 보스
2026-10-11 · 개발 기준선 · Android/Final Art Production Lock 이전

## 최종전 플레이 문법
CH-01 이동 경고, CH-02 벨트 정지, CH-03 미스트 압력 배출, CH-04 장력 앵커 고정 다음에 **CH-05 복합 전력망 위험을 분석·격리**하도록 구성한다. 이전 4개 보스를 재색칠하거나 단순히 체력만 늘린 보스가 아니다.

- 전력 제어기는 3개 지역(월드 X=370, 750, 970)을 차례로 활성화한다. 공격 1.4초 전 활성 구역을 시각·텍스트·음향으로 예고하고, 공격 시 표시 구역에 남아 있는 플레이어만 HP 1 감소(피격 무적 적용). 위험 구역 밖으로 이동하면 일반 무기로도 공략 가능.
- **수동 회로 격리:** 실제 `scan` 필드를 보스 근처에 발사해 적용해야 한다. 예고 시작 **이후** 스캔을 수행해야 해당 경고를 취소한다. 오래된 스캔 상태를 이용한 자동 차단은 허용하지 않음. 안전 조치는 항상 플레이어 행동에 의존한다.
- 스캔 적용 후 3.7초 동안 약점 분석 상태. 보스의 번호 순서대로 3개 릴레이를 펄스 계열 무기로 해제하고 노출된 전력 코어를 타격하면 스캔 유효 중 2HP, 그 외 1HP. 스캔만으로 코어 HP는 줄지 않음.
- 체력 7 중 **3 이하**부터 2단계 과부하. 위험 구역 폭 증가(반폭 128→164), 다음 공격 간격 단축(7.7→5.8초), 밝아지는 경고등/후광과 새로운 패턴음 발생.
- 보스가 격파되면 경고/공격 생성이 중단되고 기존 CH-05 완료 → 결과 보상 → 수동 스테이지 선택/장비 정비 흐름이 그대로 적용된다.

## 테스트와 해석
- 단위 테스트: 3개 위험 구역, 예고·방전·회피·무적, 경고 이후 스캔 차단, 사전 스캔 차단 금지, 릴레이 순서, 스캔 중 2HP, 체력 기준 2단계 전환 및 위험 폭, 다른 4개 보스 격리, 일시정지/격파 후 무발생.
- 자동 입력 결정적 검증: 5개 CH × 3시드 × 3펄스 프로필 = **45/45 클리어**, 실패 0, 최고 동시 투사체 32; CH-05 전력 예고 10회, 실제 방전 5회, 스캔 격리 4회, 2단계 진입 9회. 기존 CH-01~04 재현 결과 불변, CH-05 4개 항목만 기준값 변경.
- 브라우저 390×844 / 844×390 / 768×1024 / 1920×1080 뷰포트에서 경고 구역, 스캔 격리, 2단계 연출을 캡처하는 자동 검증 추가.
