# SIGNAL BREAKER · CH-03 집진 보스 다중 필터 전투 검증
2026-10-11 | 기준 main PR #184 4a3b5521d376

## 목적
기존 CH-03 추출기 보스는 개발 자동 입력 9회에서 평균 약 11.2초만에 종료되어 미스트에 의한 압력 배출을 학습하거나 공략할 기회가 제한됐다. 일반 CH-02의 5중 금속 장갑을 복사하는 대신, 집진 설비의 **필터 1~4단계 / 배출·세척 / 다음 필터 장착**을 독자적인 보스 리듬으로 구현한다.

## 실제 코드
- 보스에 `filterStage:1,maxFilterStages:4,purgeUntil:0,purgeMistBonus:false`를 유지하고 4번째 필터까지 각 필터 방호 노드 재개방 → 집진 코어 피해 → 필터 배출 단계 → 새 필터 전환.
- 배출 단계는 기본 3.4초이며, **플레이어가 집진구에 미스트를 맞히면 1회 한정 1.5초 단축**. 이때 기존 미스트 압력 배출 방어 효과도 유지.
- 배출 중에는 일반 공격의 보스 체력 감소 차단. 집진 보스의 압력 사전 경고/분출 자체는 여전히 동작하므로 방어 행동과 이동의 가치를 유지.
- 별도의 필터 상태 HUD, 필터 오염/교체 표현, 배출·세척·재가동 VFX/SFX 추가.
- CH-01/02/04/05 엔진 규칙·게임 저장 구조·AUTO/수동 진행·일반 위험물 시야 규칙 변경 없음.

## 재현 결과
- 고정 입력 45개 시나리오: 45/45 클리어, 최대 동시 탄환 32.
- CH-03 9개 조합 평균 보스 구간 **11.2초 → 35.0초**, 최소 23.1초~최대 43.4초. 필터 교체 이벤트 27회.
- CH-01/02/04/05의 기록은 변경되지 않았고 고정 시뮬레이션의 결과 차이는 CH-03 9개 기록에 국한됐다.
- 이는 자동 입력에서의 함수 동작 검증이며 **실제 Android 난도·45~90초 목표 달성·상업 수준 아트 최종 승인 결과는 아님**.

## 품질 게이트
- 4개 필터를 각각 다시 공략하고 끝 필터 이후에만 승리하는지, 미스트 배출 시간 단축의 1회 제한, 계속되는 압력 공격, 4개 외부 챕터 영향 없는지 단위 테스트.
- 390x844, 844x390, 768x1024, 1920x1080 브라우저에서 필터 2/4 전환·미스트 개입·재가동의 실제 캡처.
