# SIGNAL BREAKER — CH-02 컨베이어 과부하 보스 검증 메모
2026-10-11 | Development milestone | NOT final Android/art lock

## 플레이 차별화
- **CH-01:** 추적 X 위치를 잠그고 경고한 다음 수직 낙하 구역을 회피하는 전투.
- **CH-02:** **공정 장치 자체의 과부하**가 위험 원인. 컨베이어를 정지시켜 위험 자체를 차단하거나 벨트 위험 구역 바깥으로 회피한다. 정지 상태에서 노출 코어를 타격하면 **2HP**, 작동 중에는 **1HP**. 이 선택은 사용자 조작에 의한 장치 제어이며 자동 안전조치가 아니다.
- 스테이지 진입 후 보스 등장 약 **1.0초** 시점부터 1.6초 경고(보스 기준 첫 2.6초, 이후 8.8초 간격). 빨간 과부하 띠, HUD 경고, 기계 장치 경고음이 동기화된다. 원래 장비의 사이클은 1→0(정지)→-1→1.
- CH-02 전용 벡터 실루엣: 가로형 구동 프레임, 두 개의 구동 풀리/벨트, 압력 센서, 개폐 코어, 주황 경보등, 정지 상태 표기. CH-01 보스 실루엣을 재사용하지 않는다.
- 공격 차단은 **경고 중 벨트 정지**, 일반 회피는 **월드 X 340~860 밖으로 이동**. 공격 지점/시간, 상태 전이, 피격 무적은 엔진에서만 판정한다.
- 공격/차단 이벤트에 서로 다른 절차적 사운드와 이펙트 적용. 모바일/PC 화면의 하단 HUD에 짧은 한국어 경고 별도 노출.

## 영향/회귀 검증
- CH-01, CH-03, CH-04, CH-05 전투 규칙은 바꾸지 않음. 이미 반영된 신규 무기 2종과 기존 6개 장비, 32투사체 상한, 자동 사격·수동 선택·기록 저장 유지.
- 테스트: 경고 시작/대역, 즉시 정지에 따른 공격 차단, 과부하 피격 및 무적, 위험 구역 이탈, 정지 시 약점 배율, 다른 보스와 격리, 일시 정지 시 시간 고정.
- 기존 5 스테이지 × 3시드 × 3발사 패턴 = **45회 전체 클리어**, 최고 동시 투사체 32, 과부하 경고 9회/실행 6회. 피격으로 CH-02의 2회에서 체력 1 소모; **CH-01/03/04/05 시뮬레이션 기록은 변화 없음**.
- 고정 재현 기반 테스트는 플레이어 손맛/공략 밸런스/접근성을 입증하지 않음. 실제 Android 및 390×844/844×390/768×1024/1920×1080 시각 결과 확인 필요.
- 스테이지별 **고유 최종 이미지/장치 반응/최종 음향 믹스**는 Production Lock 이전 추가 품질 작업 대상.
- 다음 순서: CH-03 분진 집진 보스 → CH-04 장력 릴레이 → CH-05 복합 전력 보스.
