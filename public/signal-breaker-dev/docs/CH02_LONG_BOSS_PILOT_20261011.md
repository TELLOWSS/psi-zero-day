# SIGNAL BREAKER CH-02 장갑 파괴형 보스 1차 고도화

기준: 2026-10-11 모바일 실플레이 캡처 및 GitHub 기존 엔진.

기존 CH-02 보스는 9회 고정 입력 기준 평균 약 8.6초로 종료됐다. 그래서 장갑 5단계, 단계 사이 2.6초 재가동, 단계별 손상 스크래치·경고 구역 확대·구동 소리·파괴 효과를 추가했다. 약점은 매 단계 3개의 방호 노드를 파괴해야 다시 노출된다. 벨트 정지에 따른 공격 차단과 2배 약점 피해를 유지한다.

1차 자동 재현 9회: 9회 모두 클리어. 보스 구간 평균 31.3초, 최단 18초, 최장 40.7초. 전투시간 45~90초 목표는 아직 미달이며, 자동 입력 조건에서는 정지 조작을 사용하지 않아 인간 공략·재미 검증으로 해석해서는 안 된다. 다섯 챕터 45회 재현 모두 클리어, 기존 CH-01/03/04/05 기록 불변, 동시 투사체 상한 32개.

브라우저 검증에서 CH-02 과부하 경고/정지, 첫 방호 코어 파괴 이후 장갑 재가동, 2단계 재진입 화면 캡처를 추가했다. Android 실제 조작 및 상업 수준의 보스 모델/애니메이션은 별도 검수다. 기존 우선 구현 UI와 다른 보스 규칙·스테이지 수동 진행은 유지한다.

다음 과제: 장갑 단계별 고유 공격과 전용 기계 아트 보강, 빨리 종료되는 연쇄 빌드에 대응하는 리듬 조정, CH-01/03/04/05로 검증한 패턴을 순차 확장.
