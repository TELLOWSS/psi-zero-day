# SIGNAL BREAKER — 모바일 세로 보스전 카메라 프레이밍 개선

2026-10-11. PR #185 CH03 필터전 고도화의 390x844 GitHub Actions 캡처를 육안 검수하면서 확인된 가독성 문제.

## 문제
- CH03 보스전 세로 화면은 메인 집진 보스가 화면 **오른쪽 바깥에 치우쳐** 본체/약점과 압력 경고 영역이 함께 읽히지 않았다.
- `updateCamera`는 플레이어와 **첫 번째 미해제 노드 하나**를 기준으로 줌 범위를 선택해, 보스 본체까지 화면 안에 들어온다는 보장이 없었다.
- 브라우저 QA 통과는 해당 구도의 품질 승인과 동일하지 않다.

## 수정
- 일반 웨이브는 기존 카메라, 보스가 실제로 출현했을 때만 `SignalBreakerBossCamera.frame` pure helper를 사용한다.
- 세계좌표 기준 플레이어 주변 좌우 50px, 보스+노드가 포함하는 최대 143world 폭을 목표로 가용 세로 화면의 줌/스크롤을 정한다.
- 최대한 보스 전체 실루엣을 화면에 넣으며, 매우 좁은 320px 화면에서는 충돌 방지와 조작을 위해 플레이어·보스 **중심 가시성**을 먼저 보장한다.
- 카메라만 변경한다. 체력, 탄도, 조준, 히트박스, 스테이지, 저장 데이터는 수정하지 않는다.
- 390x844 CH03 필터 보스/압력 경고 장면의 본체·플레이어 동시 가시성을 브라우저에서 검사하고 캡처한다.

## 완료 조건 및 미완료
- Node 프레이밍 테스트 및 Browser QA 390x844, tablet portrait, landscape, PC; 전체 앱 회귀 통과 후 merge.
- 이 수정만으로 고해상도 최종 보스 모델, 모든 공격 경고의 모바일 가독성, Android 두손 터치, 상업용 영화적 연출이 완성된 것은 아니다.
