# 장비·총구·실제 발사 정합 3차

## 적용
기존에는 손목 장비의 시각 끝점, player.y-25에서 생성되는 발사체, player.y에서 계산하는 방향이 달랐다. 순수 엔진 launchGeometry()가 공통 그립(player.x, player.y-25), 위쪽 발사 제한, 단위 방향, 총구(그립에서 방향으로 22px)를 확정한다. 발사체·읽기 전용 예측·발사 이벤트가 같은 결과를 사용한다. 실제 출발점은 종전보다 22px 앞이다. 캐릭터별 능력이나 발사점 차별은 두지 않는다.

표시 어댑터는 실제 손목에서 공통 총구까지 기존 장비의 길이/각도를 맞춰 표시한다. 원화가 제공하는 손/도구 가림 영역은 기존 몸통 변환으로 투영해 원화를 다시 그려 장비 위에 표시한다. 반동 포즈가 총구의 물리 기준을 바꾸지 않는다. 발사 입자/녹음 이벤트도 실제 총구에서 발생한다. 원화 준비 동안 사용하는 기존 정지 후보의 총구 캡과 섬광도 동일 기준을 사용한다.

공유 어댑터를 앱 셸 캐시에 포함하고 버전을 0.5.2로 변경했다. HTTPS 오프라인의 모든 캐릭터/음원 지원이 완성됐다는 의미는 아니다.

## 검증
독립 검사 12개 통과. 새 검사에서는 두 장비, 플레이어 좌/중앙/우 위치, 좌/우/낮은 목표 18 조합에서 예측 첫 점·실제 발사체·발사 이벤트의 위치와 방향 일치, 읽기 전용 연산의 상태 불변을 확인한다. 기존 방호판 반사 예측과 실제 충돌 비교도 통과했다.
실제 Chrome에서 6명×2장비×좌우 조준의 화면 총구 좌표와 엔진 총구 일치 및 JS/HTTP 오류 없음 확인. 타입 검사와 Vite 빌드 통과. 기존 회귀 테스트 2037개 통과/1개 제외.

## 한계와 다음
전용 장비 원화 제작은 이번에 하지 않았다. 기존 간단한 장비 표시를 재사용했고 원화에 포함된 소도구의 제거/교체, 실제 손의 개별 관절 구동, 그립 방향별 원화, 캐릭터별 손가림의 육안 최종 승인과 모바일 실기기 검증은 남아 있다. 손목에서 공통 총구까지 길이 변화가 있으며 장비별 신체/관절 원화가 최종적으로 필요하다. 이 단계는 발사 정합의 기능 수정이며 최종 원화 품질 완료가 아니다.
다음은 방호판/전자석/컨베이어의 장치 상태와 시각·음향 연결이다. 본편/배포 연결은 하지 않았다.
