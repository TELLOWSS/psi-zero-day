CH-01~05의 human 장면에 사용자가 제공한 정확한 대사 파일을 연결했다. 원본 바이트·PCM 형식·속도는 그대로 보존했다. source 매니페스트의 미해결 speakerId/lineId/경로를 기존 localization 및 엔딩 계약과 대조해 매핑했다.

## 통합 상태

`runtime-integrated-pending-listening` / `integrationAuthorized: true`로 실제 재생을 연결한다. `finalListeningApproved: false`, `usageRightsVerified: false`를 그대로 유지한다. 사용자 제공 및 런타임 통합은 최종 청취/사용권 승인으로 바꾸지 않는다. 별도의 승인값을 추측하지 않았다.

실제 자산은 `/assets/survivors/voice-ending-v1/`에 저장했다. 상세 출처·해시·길이·메타데이터·측정은 `content/signal-breaker-ending-voice-v1-ingest.json`, 배포 측 매니페스트는 같은 음성 폴더의 `voice-manifest.json`에 있다. 대사 내용은 제공 exactDialogue와 localization을 대조했다. 독립 ASR 또는 실제 귀로 듣는 최종 청취 인증은 수행하지 않았다.

## 재생과 검증

엔딩 시작 때 파일을 준비하고 정확한 human 장면에서 한 번만 재생한다. 스테이지·화자·대사 ID·SHA-256·디코딩 길이·장면 길이를 확인한다. 음악과 현장 공기음은 음성 중 낮아진다. 정지·탭 숨김은 음원을 해제하고 엔딩의 같은 지점부터 재개한다. 음성 종료와 엔딩 시간 경계 모두 완료로 처리해 마지막 부분의 반복을 방지한다. 건너뛰기·재감상·종료에서 이전 음원과 버퍼를 정리한다.

서비스 워커 v0.40.0은 5개 WAV를 설치 시 캐시한다. 실제 브라우저에서 5개 원본의 해시·디코딩·음성 출력, human 시점, 정지·숨김·재개, 종료 후 반복 없음, 재감상·보상 유지, 네트워크 차단 후 5개 해시와 실제 디코딩을 검증했다. 합성 톤 시험도 해시 불일치 거부를 유지한다. 이는 최종 청취 승인이나 Android 실기기 검증을 대신하지 않는다.

다음 제작은 인물 음색 연속성과 문장·발음·호흡·배경 혼합의 최종 청취, 특히 CH-05 원본의 최대 진폭 구간 확인이다. 그 뒤 손짓·립싱크와 Android 오디오 포커스를 확인한다. 실제 PSI 연동은 별도 단계다.

## 회귀 검사에서 함께 수정한 화면 문제

음성 자산 경로가 SURVIVORS Art 검사도 실행해, 기존 착용 미리보기의 가로 화면 재생 조작이 잘리는 문제를 재현했다. 음성 추가 전과 같은 CSS의 고정 최소 너비가 화면 높이에 따른 이미지 축소를 막았다. 작은 가로 화면에서는 이미지 너비를 남은 높이에 맞추고 최소 너비를 해제했다. 기존 캔버스·조작 영역 잘림 검사는 그대로 유지한다.

이어진 인물 동작 검사는 수동으로 나열한 소스에서 import를 제거해 현재 렌더러의 의존 파일을 누락했다. 기존 빌드 도구로 실제 렌더러와 의존 파일을 함께 묶도록 검사 준비만 수정했다. 7명 전원의 idle/walk/run/brace/action 및 실제 픽셀 변화 판정은 유지한다.

8방향 장비 점검의 고정 장면도 direction만 바꾸고 fittingPose의 visualAngle을 그대로 두어 같은 방향을 반복했다. 두 방향값을 일치시켜 실제 8방향을 검증하며, 방향별 픽셀 차이·발 접지 판정은 유지한다. 두 수정은 검사 입력에 한정하며 게임 렌더러를 바꾸지 않는다.

LZ 고정 장면 검사는 엔진이 빌드의 공유 청크로 이동하면서 예전 UI 파일명에 대한 포착을 잃었다. 동일한 엔진 update 계약을 자바스크립트 청크에서 찾아 포착한다. 현재 계약에 맞춰 Wave 2 보급 정지를 실제 순찰 재개 버튼으로 완료한 뒤 보스 해소 고정 장면을 설정하고 회수 구역의 자동 시작을 기다린다. 플레이어를 구역 오른쪽에 두며, 실제 엔진 재생을 기다리는 조건과 LZ 안팎 시간·화면 판정은 유지한다. 이는 자연 보스전 클리어 증거가 아닌 기존 고정 장면 검사의 복구다.

모바일 홈 검사는 기존 MODE_SELECT_V11 화면을 예전 인물 중심 화면으로 판정해, 의도적으로 숨긴 인물과 첫 화면 아래의 카드에서 실패했다. 현재 레이아웃에서는 실제 모드 카드 원화의 로딩·영역 일치, 스크롤 후 출발 버튼 접근, 모든 버튼/링크의 폭·높이, 기록 순서, 미리보기 잠금 및 실제 게임 진입을 검사한다. 예전 레이아웃에 대한 인물 alpha 판정은 유지한다. 홈 화면 디자인을 변경하거나 실패 판정을 제거하지 않았다.
