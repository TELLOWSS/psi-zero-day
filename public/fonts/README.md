# PSI UI Font Distribution

Self-hosted, unmodified fonts. No runtime CDN or third-party font request.

- Pretendard Variable 1.3.9: https://github.com/orioncactus/pretendard/releases/tag/v1.3.9
  Binary distribution: https://cdn.jsdelivr.net/npm/pretendard@1.3.9/dist/web/variable/woff2/PretendardVariable.woff2
  License: Pretendard-LICENSE.txt (SIL OFL 1.1).
- Black Han Sans Regular: https://github.com/google/fonts/tree/main/ofl/blackhansans
  License: BlackHanSans-OFL.txt (SIL OFL 1.1).
- Chakra Petch Bold: https://github.com/google/fonts/tree/main/ofl/chakrapetch
  License: ChakraPetch-OFL.txt (SIL OFL 1.1).

Body: Pretendard. Major titles only: Black Han Sans. Instrument numerals: Chakra Petch.
Font display is swap; system fallbacks remain available during loading.
