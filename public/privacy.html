PSI : ZERO DAY 개인정보처리방침

시행일: 2026년 9월 15일

본 방침은 현재 배포 중인 PSI : ZERO DAY의 오프라인 우선 버전을 기준으로 작성되었습니다. 향후 로그인, 분석, 광고, 클라우드 저장 또는 외부 SDK가 추가될 경우 실제 데이터 처리 방식에 맞게 본 방침을 먼저 갱신합니다.

1. 처리하는 개인정보

현재 버전의 PSI : ZERO DAY는 게임 이용을 위해 이름, 전화번호, 이메일 주소, 위치정보, 연락처, 사진, 광고 식별자 또는 계정 정보를 필수로 수집하지 않습니다.

2. 게임 진행 데이터

게임 진행 상태와 선택 결과 등 저장 데이터는 사용자의 기기 또는 브라우저 로컬 저장공간에 저장될 수 있습니다. 현재 버전에서는 해당 저장 데이터를 개발자 서버로 전송하거나 계정과 연결하지 않습니다.

3. 네트워크 및 제3자 서비스

현재 게임 핵심 플레이에는 사용자 계정 로그인, 광고 네트워크, 행동 분석 SDK 또는 클라우드 세이브가 필요하지 않습니다. 앱 배포 플랫폼과 운영체제 자체에서 처리하는 기술 정보는 각 플랫폼의 정책이 적용될 수 있습니다.

4. 권한

현재 버전은 핵심 게임 플레이를 위해 카메라, 마이크, 연락처, 정확한 위치정보 등의 민감한 기기 권한을 요구하도록 설계되지 않았습니다. 향후 기능 추가로 권한이 필요해질 경우 목적과 처리 방식을 사전에 고지합니다.

5. 보유 및 삭제

게임 진행 데이터는 사용자의 기기 로컬 저장공간에 보관됩니다. 사용자는 앱 데이터 삭제, 앱 제거 또는 브라우저 사이트 데이터 삭제를 통해 해당 로컬 데이터를 삭제할 수 있습니다.

6. 아동의 개인정보

현재 버전은 아동의 개인정보를 별도로 수집하도록 설계되지 않았습니다. 향후 대상 연령이나 서비스 기능이 변경될 경우 관련 법령과 플랫폼 정책에 맞게 별도 보호조치를 검토합니다.

7. 방침 변경

게임 기능, SDK, 네트워크 기능 또는 데이터 처리 방식이 변경되는 경우 실제 동작과 일치하도록 본 개인정보처리방침을 수정하고 시행일을 갱신합니다.

8. 문의

개인정보 관련 문의는 Google Play 스토어 등록정보에 표시된 개발자 연락처를 통해 접수할 수 있습니다.
