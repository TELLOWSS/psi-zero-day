# Episode 01 Art Inbox

This directory is an intentionally temporary GitHub ingest surface.

Drop one of the exact contracted archives here and commit it to `main`:

- `PSI_ZERO_DAY_EP01_FINAL_BACKGROUNDS_WEBP.zip`
- `PSI_EP01_PERFORMANCE_WAVE01_GITHUB_READY.zip`

GitHub Actions verifies the archive byte count and SHA-256, extracts only the contracted WebP files, runs the relevant production checks and Episode 01 visual regression, updates the runtime manifests, then removes the ZIP from the repository in the bot commit.

Do not rename or recompress either archive. A modified archive is rejected before extraction.
