# SIGNAL BREAKER 그래픽·게임성 고도화 기획 / 구현 기준

## 목표와 검토 범위
현장 배경·장비·HUD의 금속 질감과 비교해 낮은 수준으로 보이는 요소를 기존 플레이 화면에서 분리한다. 캡처 88814의 중복 안내 정리는 유지한다. 입문 1~5는 배울 수 있는 난이도를 보존하고, EP02 6~10에서는 기존 목표를 수행하는 행동이 짧은 전투 기회로 연결되도록 한다. 새 버튼·새 상점·복잡한 제작표는 추가하지 않는다.

## 그래픽 감사와 원화 제작
| 요소 | 현재 확인 | 적용할 개선 |
|---|---|---|
| 발생원 | Ψ 문자와 원형 도형이 사실적인 현장·산업 장비와 이질적 | 안테나·청록 수신 코일·주의등이 있는 산업용 신호 비콘 |
| 화력 부품 | P 문자와 단순 다각형 토큰 | 보호 케이지·금속 단자·청록 에너지 셀 |
| 강화 충전 | C 문자 토큰 | 구리 코일·호박색 충전 캐패시터 |
| 신호 워치 | W 문자 토큰 | 코발트 광학 삼각 센서·금속 하우징 |
| 배경·6종 장비·보스 | 이미 실제 원화와 부품 움직임을 사용 | 해당 자산을 유지하고 작은 보급 부품의 재질 수준을 맞춤 |

내장 ImageGen으로 한 개의 투명 2×2 아틀라스를 제작한다. 셀 순서는 발생원/화력/충전/워치이며 원화의 알파를 유지해 WebP로 패킹한다. 코드가 존재하는 원화 위치만 읽는다. 작은 아이템은 30~34 월드 단위, 발생원은 약 46단위로 표시해 적 충돌 판정과 위험 구역을 가리지 않는다. 숫자·보상·상태는 HTML과 기존 상태 표시로 유지한다. 이미지에 글자를 새기지 않는다.

## 게임성: 신호 체인을 방호 기회로
현재 EP02에는 각 작전당 한 번 수행하는 선택 목표가 있다. 반사 3회, 벨트 과부하 차단, 분진 3개 해소, 장력선 고정, 경고 전력망 스캔이다. 이 목표의 기존 충전 보상에 **즉시 1.5초 방호 창**을 더한다.

- 기존 조작을 정확하게 활용하면 한 번의 짧은 안전 시간을 얻는다. 이를 이동·재조준·아이템 회수에 활용한다.
- 적 체력·무기 상성·진화 요구 조건은 유지한다. 긴 무적이나 자동 클리어 기능으로 만들지 않는다.
- 작전당 한 번만 지급한다. 반복 충돌·같은 목표 재수행·정비 재개·저장 복원으로 재발급하지 않는다.
- 이미 피격 후 무적 시간이 더 길면 줄이지 않는다. 방호 시간이 끝나면 기존 피격 규칙으로 돌아간다.
- 일반 1~5에는 적용하지 않는다. 유료 모듈 없이 모든 EP02 플레이어가 같은 방호 보상을 받는다.
- 화면에는 신호 체인 완료와 충전·방호 보상을 짧게 표시하고, 플레이어 주변의 방호 반응으로 구분한다. 별도 전투 버튼은 만들지 않는다.

## 검증과 판단 기준
변경 전/후에 동일한 45개 숙련 입력 실행을 비교한다. 잘못 고른 상성·맞는 상성·진화 조합을 구분해 보상의 효과와 장비 선택의 필요성을 확인한다. 이 수치는 사람의 승률이라고 표현하지 않는다. 입문·연속 작전 입력 골든은 보존한다. 보급 원화의 네 셀 실제 렌더, 로딩/오프라인 포함 여부, 작은 휴대폰의 안내·입력 영역·시야를 브라우저에서 검증한다. 방호 획득/만료/중복 지급 방지와 이전 체크포인트 복원을 순수 엔진 테스트로 확인한다. 전체 테스트·타입·빌드·CI 통과 후 GitHub 및 운영 Vercel의 실제 파일을 비교한다.
