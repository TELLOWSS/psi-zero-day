# 캐릭터 이미지 연결 검증 · 2026-10-14

## 기준과 발견 사항

사용자가 올바른 기준으로 지정한 **시그널워치 → 순찰 요원** 탭의 초상을 기준으로 확인했다. 실제 파일을 열어 얼굴·나이·안전모·작업복·소품을 대조했고, 화면의 이름과 이미지 URL도 검증했다. 캐릭터 원화 생성이나 바이너리 덮어쓰기는 하지 않았다.

| 인물 | 잘못 사용되던 이미지 | 확정된 기준 이미지 |
|---|---|---|
| 강태식 | `assets/episode01/hires/kang-taesik-portrait.webp` — 다른 얼굴·수염·작업복 | `assets/episode01/characters/kang-taesik-portrait.webp` — 주황 안전모·조끼, 콧수염 |
| 윤성호 | `assets/episode01/hires/yoon-sungho-portrait.webp` — 흰 안전모·다른 얼굴·태블릿 | `assets/episode01/characters/yoon-sungho-portrait.webp` — 노란 안전모·갈색 작업복, 결속 작업 소품 |
| 임준호 | `assets/episode01/hires/lim-junho-portrait.webp` — 흰 안전모·다른 나이와 얼굴 | `assets/episode01/characters/lim-junho-portrait.webp` — 노란 안전모·녹색 조끼·무전기 |
| 구형 윤성호 프로필 | `assets/survivors/director_yoon_hero.jpg` — 다른 얼굴·작업복 | 순찰 요원 기준의 윤성호 초상 |

메인 동료 화면은 실패할 때만 올바른 기본 초상을 쓰는 구조였다. 잘못된 hires 파일 자체가 정상 로드되어 이미지 오류 처리가 작동하지 않았다. 고해상도 우선 헬퍼가 현재 승인된 캐릭터 초상을 반환하게 수정했다. 파일명에 hires가 있다는 이유로 다른 인물의 이미지를 우선하지 않는다. 자산 resolver의 캐시 버전 쿼리도 보존한다.

## 적용한 화면

- 메인 화면 작은 **동료** 아이콘을 누른 뒤 나오는 동료 8인 카드 및 선택한 인물 상세.
- 메인 챕터 기록의 인물 상세와 본편 기본 대화 초상: 동일한 공통 헬퍼를 사용하므로 함께 교정.
- 시그널워치 준비 화면 캐릭터 배너: 강태식·윤성호 및 구형 별칭 프로필의 다른 외모 연결 교정. 임준호 배너는 이미 올바른 기준 초상이었다.
- 배너는 `contain`으로 전체 이미지를 보존하여 얼굴·안전모가 크롭 때문에 잘리지 않도록 조정.
- 모바일에서 글자가 숨겨지는 메인 동료 아이콘에도 접근 가능한 이름을 부여.

구형 캐릭터 ID의 저장 호환과 게임 능력은 유지했다. 기존 hires 파일과 구형 배너 원본은 이력 및 외부 참조를 위해 삭제하지 않았으며 운영 캐릭터 초상/배너 경로에서 제외했다. 배경용 `hires/night-pour-hero.webp`는 캐릭터 초상이 아니므로 그대로 사용한다.

## 나머지 자산 대조

8인 기본 초상과 지도용 전신, 현재 연결된 표정·퍼포먼스 이미지, 플레이어 성장 초상을 대조했다. 18개 초상/표정/퍼포먼스 파일에서 캐릭터를 서로 바꿔 연결한 추가 사례는 발견하지 않았다. 표정과 작업 자세의 차이를 다른 인물로 간주하지 않았다. 시그널브레이커의 6인 선택 카드는 올바른 지도용 전신을 사용하며 이름과 캐릭터 ID 연결을 확인했다. 동작 이미지는 이전 캐릭터 성장 검증에서 6인 실제 로딩 및 오프라인 교대를 확인한 기존 승인 자산을 유지한다.

## 검증

회귀 테스트는 동료 8인의 기본/상세 초상 일치, 잘못된 세 우선 경로의 재등장 방지, 워치 6인 및 구형 별칭의 선택 초상/배너 일치를 확인한다. 전체 테스트 2,062개 통과, 기존 1개 건너뜀. TypeScript 검사와 production 빌드도 통과했다.

브라우저에서는 세로 390×844, 가로 844×390, PC 1440×900에서 동료 8인의 카드와 상세 이미지를 실제 디코딩하고, 워치 6인의 선택 초상·선택 후 배너 및 브레이커 6인의 전신 경로를 검증했다. 이미지 이름뿐 아니라 실제 원화도 대조했다. 실제 화면 증거는 `docs/qa/character-identity-20261014/`와 `docs/qa/character-identity-20261014.json`에 보관한다.
