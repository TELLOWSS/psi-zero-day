# 안전감시단 착용 아트 1차 통합

## 범위 및 승인 상태

대표 캐릭터 `safety_monitor`의 `voice_lens`, `shock_mantle`, `inspection_wing`만 독립 착용 아트로 교체했다. 신규 능력, 유료 결제, 엔진 밸런스 변경은 없다. 사용자 요청에 따른 런타임 적용/검수 단계이며 전 캐릭터의 cinematic production lock이 아니다. 앞서 생성한 전신 합성 후보를 런타임 캐릭터로 대체하지 않고 원본 캐릭터에 독립 장비를 합성한다.

## 합성 계약

- 원본 캐릭터의 불투명 경계를 기준으로 정규화한 소켓을 사용한다. 투명 여백과 발바닥 피벗 변화에 영향을 받지 않는다.
- 도킹 레일은 캐릭터 뒤, 무전/보호 모듈은 캐릭터 앞에 그린다.
- 캐릭터의 원본 장갑/태블릿 영역을 다시 앞에 합성해 장비가 손을 덮지 않도록 한다.
- 몸통/장비는 동일한 리그 위상, 피격 반응, 동작 이동량, 좌우 반전을 사용한다. 해당 캐릭터의 리그를 그대로 사용하며 새로운 애니메이션 프레임을 제작했다고 주장하지 않는다.
- 다른 공식 캐릭터에 검수되지 않은 소켓을 임의 적용하지 않는다. 기존 표시를 유지한다.
- 새 아트가 로드된 장비에 한해서 기존 범용 상품형 장비 표시를 제거한다. 누락/로드 실패를 최종 착용 자산으로 계산하지 않는다.
- 점검 드론은 기존 드론 래스터를 유지하고, 도킹 구조는 새 자산을 사용한다. 대표 캐릭터의 드론 표시 크기를 24로 줄이고 orbit을 34로 조정했다. 이는 표현 크기이며 실제 억제 거리 180을 변경하지 않는다.
- 보호막 상태등은 실제 shield/feedback에서 읽는다. 실제 보호막 원형 표시도 인물 크기에 맞춰 정렬했다. 보호막 충전 규칙은 그대로다.
- 선택한 캐릭터에 필요한 자산만 로드한다. 이미지 및 알파 경계 스캔을 캐시해 상품 미리보기 변경마다 반복하지 않는다.

## 검증

전체 테스트 1175 통과 / 1 skip. 타입 검사, prebuild 포함 빌드 및 최종 Vite 빌드 통과. 단독 장착/3종 동시 장착/해제, 앞뒤 레이어 분리, 미지원 캐릭터 거부, 좌우 반전/피격/몸통 동기화 테스트 추가.

실제 브라우저: 무전 단독, 보호 모듈 단독, 3종 동시 장착, 390x844 모바일 미리보기와 좌우 이동 중 전투 스크린샷을 확인했다. 모달 clientWidth/scrollWidth 모두 356. 장비 3종의 알파 픽셀 및 실제 캔버스 표시 확인. 브라우저 오류 없음. 테스트 장비는 독립 브라우저 세션에만 지갑 fixture로 주입했으며 실제 구매 검증으로 간주하지 않는다.

## 남은 제작

이 3종의 착용 구조를 다른 공식 캐릭터의 체형별로 실측/검수한 뒤 확장한다. 프레임별 케이블 변형, 독립 드론 도킹/출격 애니메이션, 무전 송신 동작과 정밀한 방향별 피격 연출은 다음 제작 항목이다. 단일 2.5D 레이어 합성을 방향별 프레임 납품 완료로 계산하지 않는다.

사운드는 기존 관현악 후보를 유지했다. 새 장비 착용/도킹/보호막 효과음은 이번 작업에서 제작하지 않았다. 다음 사운드 제작에서 실제 음원과 사용권/루프/동시발음 검수까지 진행해야 하며, 합성 비프음으로 오케스트라 완성을 대신하지 않는다.
