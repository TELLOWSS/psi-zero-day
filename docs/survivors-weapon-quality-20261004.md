# 장비 그래픽·효과음 개선

기존 발사→실제 명중→소멸 이벤트와 승인된 장비 외형을 유지하며 표현을 보강했다. 빔 재질에 분절된 고휘도 코어를 더하고 분말 밀도를 개선했다. 명중점에는 입력 방향을 따른 짧은 접촉 파편을 적용하며 치명 반응은 개수를 늘린다. 근로자 계도에는 파편을 적용하지 않는다. 혼잡·모션 감소 설정에서는 추가 파편을 생략한다. 피드백 풀 64개 제한을 유지한다.

10개 장비, 3개 단계에 대해 작동음·압력·재질 질감·잔향을 한 PCM 버퍼에 합성하고 캐시한다. 기존 단일 오실레이터보다 서로 다른 장비의 음색과 여운을 구분한다. 거리 감쇠를 더해 먼 효과가 가까운 명중음을 덮는 것을 줄인다. 기존 24음원 제한, 우선순위, 사용자 음량·음소거·BGM 덕킹을 유지한다. 근로자 계도음은 장비와 관계없이 동일한 차분한 확인음이다.

이 작업은 절차적으로 제작한 효과음 개선이며 최종 현장 녹음·성우·영화급 사운드 인증은 아니다. 기존 음악 후보와 음성은 유지한다. 실제 Android 스피커·이어폰 청감 및 최종 아트/사운드 승인에는 별도 검수가 필요하다.

검증: typecheck/build 통과. 4개 화면 크기에서 실제 게임 시작·HUD·정지/재개 및 구성된 혼잡 피드백 검증 통과. OfflineAudioContext로 실제 production 경로 렌더링 시 최대 24음원, 음소거 0음원, 혼잡 피크 0.17395. 이전 스토리 UI 8건 결과를 재사용하고 음성 출력은 이번 코드로 다시 렌더링했다. MP3 샘플은 공통 배율 12로 청취용 증폭했으며 런타임 볼륨과 다르다.

전체 회귀 재검증: 207개 파일 / 1,114개 테스트 통과.
