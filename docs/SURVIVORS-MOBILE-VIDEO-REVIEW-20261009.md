1. 일반 착용 미리보기에서도 발사·분사·궁극기 자세의 활성 구간에 선택한 장비의 기존 발동 원화와 연출을 표시한다. 실제 장비별 색상·서명을 재사용한다. 정지·모션 감소에서는 발동 연출을 진행하지 않는다. 새로운 능력·피해·전투 판정을 만들지 않는다.
2. 모바일 세로 화면에서 착용 영역을 패널 가용 폭까지 확대한다(상한 340px). 화면 비율과 전신 구도를 유지하며, 가로 화면의 낮은 높이에 맞춘 기존 작은 미리보기는 유지한다.
