## 세계관 충돌과 구체적 대안

| 항목 | 현재 | A: 격리·차단·대피형 (권장) | B: 추상 위험신호형 |
|---|---|---|---|
| 드럼통 | 유폭으로 주변 위험물/적 제거 | 발화 전 짧은 경보 → 통제선 전개 → 작업자 대피 → 위험원 격리. 유폭 보상/별 조건을 통제 기여로 바꿔야 함 | 실물 드럼통은 비전투 환경물로 남기고 별도의 비인간 위험 신호를 소거 |
| 근로자 | 탄환 충돌·HP·넉백 | 무전/지시가 도달하면 작업을 멈추고 보호구/동선을 복구. 내부 HP를 위험 잔량으로 해석하려면 텍스트/소리/동작을 함께 바꿔야 함 | 공격 대상은 추상 신호, 근로자는 별도 NPC. 엔진 대상 구조 변경 범위가 큼 |
| 중장비 | 무력 제압·파괴의 쾌감 | 접근 예고 → 작업반경 통제 → 비상 정지/회수. 실제 절차를 정답 버튼 하나로 축약하지 않음 | 장비 옆 위험 아이콘만 제거, 장비 움직임과 인과가 약해질 수 있음 |

A는 기존 자동 대응·위치 선정·성장을 살리면서 상위 안전 하한선에 맞춘다. 다만 표현 변경만으로 충분하지 않고 별 조건·환경 기믹·효과음까지 함께 변경해야 한다. B는 공격 오해를 줄이지만 사람/현장을 함께 읽는 체감과 구현 비용에서 불리하다. 2026-10-03 Director 응답으로 A를 확정했다. 드럼통 폭발·자기 피해·폭발 탄환을 제거하고 격리·주변 위험 해소로 대체했다. 사람·중장비 넉백은 지시 수신·일시정지로 대체했다. 양중 구역은 경고 중 지시 신호가 도달해야 통제·점수가 발생한다. 통제 없는 낙하 위험으로 사람을 유인해 점수를 얻는 경로를 제거했다.

## 연출 검수

Q03에서 동작 줄이기 시 흔들림·피격 비네트·반전 플래시를 제한했다. 사람·중장비의 넉백은 제거했으며 기존 히트스톱·성장 수치·캐릭터/맵 제작 방향은 유지했다. 반복 안전통로 라벨을 한 번으로 줄이고 격리 완료 링·안전통로로 이동하는 기존 근로자 스프라이트를 연결했다. 이 기존 렌더 보정은 최종 아트 제작/승인이 아니다. 접지·8방향 동작·최종 배경 교체·전후 실기기 trace는 남아 있다.
