# SIGNAL BREAKER 보스 기계 동작·피격 손상

기준: PR #194 운영 커밋 c8dc8e9e. 기존 5종 Production 원화를 유지하는 2D 분할 렌더링.

## 플레이 변화

| 보스 | 원화 내부 동작 | 실제 상태 반영 |
| --- | --- | --- |
| 반입 차단문 | 양쪽 셔터 이동·잠금축 회전 | 약점 노출 시 개방, 위험 예고 시 동작 가속 |
| 컨베이어 | 양쪽 구동축 반대 방향 회전 | 실제 벨트 방향에 따라 역회전 |
| 집진 장치 | 팬 회전 | 미스트 통제 시 회전 감속 |
| 장력 드럼 | 와이어 권선의 미세 진동·유압 관절 회전 | 실제 장력 고정 동안 정지, 예고 시 진동 증가 |
| 전력 장치 | 차단기 접점 이동·측면 구동부 회전 | 약점 노출 시 접점 분리 |

회전각은 시뮬레이션 시간 차이를 누적한다. 방향·속도 변경 때 각도를 다시 계산해 튀는 현상을 방지한다. 엔진 객체별 WeakMap에서 렌더링 시계만 관리하며 HP, 공격·충돌·약점, 보상·저장에는 쓰지 않는다.

갑옷·필터 단계와 현재 HP로 금속 하우징에 누적 긁힘을 표시한다. 다음 단계에서 HP가 회복돼도 손상이 이어지고 새 보스는 초기화된다. 실제 bosshit 이벤트에만 0.24초 국소 명중 반응이 발생한다. 전체 화면 섬광은 추가하지 않는다.

이미지 1장과 최대 4개 부품 마스크를 재사용하며 매 프레임 새 이미지·캔버스·픽셀 버퍼를 만들지 않는다. 약점 위치와 본체 외곽 크기는 그대로다. 일시정지 중 회전각은 유지되고 움직임 감소에서는 기계 애니메이션·명중 섬광이 정지한다. 노출·손상 표시는 유지한다.

## 검증

- Node 브레이커 198개 통과. 엔진 무변경·원화 재사용·분할 draw 수 제한, 역회전 연속성, 장력 고정, 미스트 상태, 누적 손상, 피격 만료·정지·초기화 검증.
- 전체 앱 2,039개 통과(기존 1개 skip), typecheck 및 production build 통과.
- 1920×1080, 844×390, 390×844, 768×1024 × CH-01~05: 보스 픽셀 변화·일시정지·움직임 감소·실제 HP 표시·콘솔 검증.
- 브라우저 검사는 실제 앱 진입 후 보스 상태를 고정하는 fixture 검사다. 자연 보스전 완주 또는 Android 실기기 성능 측정으로 계산하지 않는다.
- 독립 캔버스에서 보스만 렌더링하여 배경·UI 움직임과 분리된 픽셀 변화와 움직임 감소 시 픽셀 동일성을 검증한다.
- 기존 오프라인 자산 구성은 유지하고 서비스워커 캐시를 v0.43.0-boss-articulation으로 갱신한다.

## 미술 판정·다음 검수

이번 범위는 기존 최종 원화의 부품 마스크 애니메이션과 절차적 금속 손상 표현이다. 독립 관절 원화·다단계 파손 이미지·3D 리깅 제작 완료로 계산하지 않는다. 고화질 후보가 실제 전투에서 자연스럽고 약점이 잘 읽히는지 Director 검토가 남는다. Android 실기기 입력·프레임시간·메모리는 실제 장치에서 확인해야 한다.
