# 디펜스 그래픽 검증·구현 — 2026-10-15

## 확인 결과와 구현

공개 기본 훈련 `ramp-01`에는 단순 SVG 장비 16종·위험체 6종이 기존 HD 현장 배경 및 별도 장식물과 혼용돼 있었다. 시그널 브레이커의 금속·조명·장비 표현과 차이가 컸고, 지원 동료 선택에서도 얼굴 위주 잘림과 긴 여백이 캐릭터 인지를 방해했다.

이번 변경은 색상만 조절하지 않고 실제 래스터 자산을 새로 제작해 런타임에 연결했다.

- 장비 4계열 × L1/L2/L3A/L3B = 16종. 관측 접시·광학 헤드, 고정 드럼·앵커, 단발·다발 방출부 등으로 계열과 분기를 구분한다. 상점·설치 장비·진화 트리에서 같은 이미지를 쓴다.
- 비인간 산업 위험체 6종: 일반·고속·장갑·군집·은폐·최종 위험. 근로자를 공격 대상으로 표현하지 않는다.
- 현장 전투판과 출전/허브/결과용 키아트 2종. 호박색 현장 조명, 청록색 원경, 황색 장비·흑철·구리의 재질을 시그널 브레이커 기준으로 맞췄다.
- 지원 선택은 시그널 워치 순찰 요원의 승인된 강태식·임준호 전신 및 초상을 재사용한다. 실제 지원 효과·시간·재사용 시간을 한글로 표시한다. 구현된 두 지원 기능에 대응하며 신규 능력을 임의로 만들지 않았다.
- 경로 흐름, 접지 그림자, 실제 공격 재사용 시간에 연결된 계열별 방출 이펙트, 타격/해소 연출을 보강했다. 움직임 줄이기 설정도 반영한다.
- 공개 기본판의 옛 장식물 중첩을 제거하고, 입구·출구·설치 지점을 비워 판독성을 유지했다. 세로·가로·PC에서 카드와 자원을 조정했다.

새 자산 24개의 합계는 2,216,972바이트다. 22개 투명 스프라이트는 368×368이며 투명 여백을 둔다. 장비 아틀라스를 기계적으로 등분하면 안테나가 잘리는 문제가 있어 실제 오브젝트 경계를 검수하고 추출 좌표를 개별 기록했다.

## 검증 범위

PC·세로·가로에서 일반 UI로 추천 구매/진화/지원/웨이브 시작을 진행해 각각 10웨이브 승리, 보호막 20을 확인했다. NORMAL/SWIFT/ARMORED/SWARM/VEILED/BOSS가 실제 출현한 기록과 최종 위험/결과 화면을 저장했다. 자동 플레이는 시간 가속을 사용하며 적 삭제·자원 주입·승리 상태 주입은 하지 않는다.

5개 화면 크기에서 선택/배치/진화/정지/재접속, 가로 넘침 없음, 설치 지점 정렬 오차 2px 미만을 확인했다. 브라우저에서 24개 이미지 디코딩, 정식 캐릭터 경로, 4계열 상점 연결, 옛 장식 중첩 제거, 움직임 줄이기를 별도 검사했다. 자산 해시·투명 가장자리·16개 장비/6개 위험체 고유 경로도 회귀 검사한다. 최종 검사 수치는 [verification.md](qa/defense-premium-20261015/verification.md)에 기록한다.

## 보존한 규칙과 남은 확인

이번 변경에서 순수 엔진의 피해·가격·10웨이브·경로·8개 패드·저장/해금 규칙은 바꾸지 않았다. `ramp-01`을 사용하는 공개 훈련/이벤트에 새 아트를 연결하며 다른 비공개 현장의 기존 아트를 모두 교체한 것으로 보고하지 않는다. 이벤트별 제목과 브리핑도 유지한다.

실제 Android 저사양 기기의 GPU/발열/장시간 성능, 사람의 타격감 평가, Director의 최종 이미지 승인과 기존 상업 출시 권리 감사는 별도 확인 대상이다. 단위 검사나 데스크톱 Chrome 화면 크기 에뮬레이션이 이 항목을 대체하지 않는다. 빌드의 기존 500kB 초과 청크 경고는 남아 있다.
