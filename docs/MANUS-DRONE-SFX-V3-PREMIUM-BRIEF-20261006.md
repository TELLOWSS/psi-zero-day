# MANUS PRODUCTION BRIEF — PSI DRONE SFX V3

## Goal

Create a **luxury-grade industrial drone sound identity** for PSI : ZERO DAY.

Do NOT create a finished sci-fi laser shot.

The previous approach failed because one baked “drone shot” tried to contain everything and sounded generic.  
This version must be produced as **separate dry sound layers** that can be mixed dynamically in the game.

The result should feel like:

**high-end inspection robotics + premium camera gimbal mechanics + compact BLDC motor + magnetic actuator + controlled electromagnetic impulse + very short air displacement**

The drone is an expensive safety/inspection machine, not a weapon.

## Absolute rejection list

Reject and regenerate any output that resembles:
- arcade “pew”
- laser zap
- Star Wars-style energy gun
- gunshot / rifle transient
- missile launch
- toy quadcopter
- cheap servo whine
- retro UI beep
- musical synth note
- long electronic tail
- huge cinematic boom
- exaggerated sub-bass
- harsh 2–6 kHz whistle

No music, voice, dialogue, ambience or combined demo reel.

Create **one isolated sound per requested file**.

## Required source format

Prefer:
- WAV
- 48 kHz
- 24-bit
- dry
- close perspective
- mono unless explicitly noted
- no baked reverb
- no leading silence
- clean tail
- no clipping

If Manus cannot provide this exact format, use the highest-quality original format actually supported. Do not fake format claims.
