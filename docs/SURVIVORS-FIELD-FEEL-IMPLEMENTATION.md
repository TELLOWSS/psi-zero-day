# 현장을 정리하는 쾌감 — 구현 기록

2026-10-09 / 작업본 `psi-zero-day-animation-20261007`

목표는 익숙한 현장의 재질과 장비 무게를 알아보는 재미, 공격이 먹힌다는 확신, 주변 위험을 정리한 뒤의 해방감이다. 기존 무기별 발사 준비·반동·궤적에 실제 피해량과 몬스터의 종, 마지막 타격 사실을 연결했다.

## 전투에 반영한 내용

| 계열 | 적용 |
|---|---|
| 운반 장비 | 지게차 제동, 굴착기 내려앉음, 철근 진동, 호스 잔류 흔들림 |
| 낙하 자재 | 잔해 조각별 붕괴, 형틀 패널 접힘, 강관 시간차 낙하, 덕트 찌그러짐 |
| 누출 설비 | 밸브 회전·감압, 팬 감속, 누출부 봉합, 매니폴드 구간별 소등 |
| 일반·마지막 타격 | 확정 피해만 반응, 마지막 타격의 긴 재질 잔향과 큰 접촉 반응, 제한된 효과 풀에서 우선 표시 |
| 현장 변화 | 통제한 자리의 짧은 정리 흔적, 실제 확보 구역의 바닥 조명 변화, 주변 위협이 사라지면 짧은 해소 안내 |
| 접근성 | 설정 탭의 화면 흔들림·타격 섬광 독립 조절, 저장·복원, 기존 음량 믹서 유지, 시스템 동작 줄이기 준수 |

작업자에게는 기존 계도·확인 연출을 유지한다. 누출 장비에는 폭발을 추가하지 않는다. 낙하 자재를 통제했을 때의 마무리는 마지막 낙하 높이에서 이어지고, 운반 장비는 확정 이동 방향을 유지한다. 시각 파편은 충돌이나 추가 피해를 발생시키지 않는다.

몬스터별 PCM 타격음은 기존 절차적 사운드 경로를 확장했다. 12개 재질의 음높이·잔향·압력·무게와 마지막 타격을 구분한다. 이 소리는 실장비 녹음이나 청감 최종 승인본이 아니다. 녹음 기반의 기존 무기 발사음과 계도음은 유지한다.

## 구조와 성능

엔진은 확정 접촉의 `targetId / species / appliedDamage / finishing`과 통제 완료의 종·반경·동작 스냅샷을 전달한다. 표현 계층은 이를 소비하며 점수·전투 규칙·시뮬레이션 난수는 변경하지 않는다.

마무리 16개, 접촉 24개, 정리 흔적 32개로 제한한다. 마무리는 1.15초, 접촉은 0.32초, 흔적은 12초 뒤 사라진다. 정지·일시정지 시에는 진행하지 않는다. 래스터는 기존 스프라이트 아틀라스를 재사용하며, 오디오 버퍼 캐시는 128개로 제한한다. 지면 조명 캐시는 기존 상한을 유지한다.

## 검증

- 전체 회귀: 1,778개 통과, 1개 건너뜀.
- 추가 검사: 실제 투사체의 일반·마지막 피해 영수증, 12종 고유 사운드, 작업자 보호, 효과 상한·만료·정지, 동작 줄이기, 설정 파싱.
- PC 1440×900 / 모바일 390×844: 실제 충돌 경로에서 콘크리트·철근·가스 설비의 마지막 타격 확인, 설정 저장·재진입 복원, 페이지 오류·가로 넘침 없음.
- 12종 마무리 렌더와 동작 줄이기 비교 화면: `artifacts/material-feel/`.

브라우저 검사는 테스트용 적·투사체를 배치해 실제 엔진 충돌과 표시를 확인한다. 자연 진행 전체의 난이도나 현장 경험자의 스트레스 해소 효과를 입증하는 검사는 아니다. 해당 체감은 현장 사용자 플레이와 청감 검수로 평가한다.
