# NEW-PSI 메인·궁극기·현장 공정 통합 개선

## 1. 목표와 적용 범위

공식 상위 브랜드 NEW PSI를 사용자가 요청한 표기 **NEW-PSI**로 메인과 안전모에서 일치시킨다. PSI 원본 방패·동심원 눈은 유지한다. 기존 50개 시그널 워치 구역의 공정 정체성, 물리 배치, 준비 도면, 전투 중 상태 확인을 연결한다. 신규 캠페인이나 실물 자산 대신 쓰는 임시 그래픽은 추가하지 않는다. 이 작업은 기존 현장 구성의 구현 개선이며, 모든 현장의 최종 아트·재미·교육 검수를 완료했다는 판정은 아니다.

## 2. 메인 구성

- 배경과 분리되는 약한 반투명 밝은 받침, 얇은 테두리와 블러로 원본 파란 방패를 살린다. 로고 자체의 바깥은 투명하다.
- 로고 오른쪽에 NEW-PSI → ZERO DAY의 2단 제목을 둔다. 반복되는 별도 NEW PSI 표기는 제거하고 한국어 부제와 슬로건의 기존 흐름을 유지한다.
- 모바일은 받침과 제목을 함께 축소하고 인물의 얼굴·안전모를 가리지 않게 한다. 가로·세로 전용 원화에 NEW-PSI 안전모 인쇄를 각각 적용한다.
- 원화는 built-in image_gen 편집, 런타임은 버전 있는 v6 WebP 두 장이다. 원본과 프롬프트/해시를 보존하며 다운로드는 각 500KB 이내다. 자세한 프롬프트는 `branding/NEW-PSI-ART-PROMPTS-20261017.json`에 기록한다.

## 3. 궁극기 안내 정책 변경

기존 `SIGNAL-WATCH-ULTIMATE-ONBOARDING-20261017.md`의 ‘건너뛰면 다음 순찰에서 재안내’를 대체한다. 학습 일시정지는 **stage_01에서 아직 안내를 보지 않은 경우 한 번만** 허용한다. 발동하거나 보관을 선택한 뒤 재도전·새로고침해도 다시 강제하지 않는다. stage_02~50에서는 미사용 사용자여도 일시정지 안내를 하지 않는다. 일반 완충 표시·효과음·F/터치 발동은 모든 구역에서 유지한다.

v1 실제 사용 이력은 호환하고, v2 안내 표시 이력은 안내를 여는 순간 저장한다. 저장소가 거부되면 현재 컴포넌트 세션에서 한 번만 보인다. 브라우저 데이터 삭제까지 영구 보존하는 서버 저장은 추가하지 않는다.

## 4. 현장·공정 구성

기존처럼 네 장애물이 대부분 같은 위치에 놓이던 배치를, 현장 8종의 명시적인 배치 자료로 교체한다. 물류 / 굴착·지하 / 골조 / 양생 / 설비 / 기존 구조·리모델링 / 고소·상부 / 마감·인계다. 모든 기존 구역이 정확히 한 종류에 속하며 현장 내 위치 편차와 기존 통제 대상과의 간섭 해소로 50개 배치가 구별된다.

기존 고품질 바닥·기둥·엄폐물·잔재 자산을 그대로 사용한다. 바뀐 배치는 실제 이동, 돌진 충돌, 시야와 발사체 차폐, 잔재 정리 및 이동 경로에 적용된다. 그림만 바뀐 스킨이 아니다. 성능을 위해 구역당 기존과 같은 4개 장애물을 유지한다. 중앙 진입·탈출 통로, 시작 위치, 맵 경계와 기존 통제 대상 발밑은 비운다.

메인의 **현장·공정** 화면은 10개 기존 프로필 모두에 작업면 이미지, 진입·작업·인계 흐름과 연결된 순찰 구역을 제공한다. 선택 카드에도 해당 구역의 실제 이미지를 사용한다. 새 이미지로 오해될 합성 장식이나 미구현 공정을 추가하지 않는다. 잠긴 구역은 기존 해금 조건을 표시하고, 열린 구역만 해당 준비 화면으로 연결한다. 완료한 구역을 골라도 자동으로 다음 구역으로 바뀌지 않게 일회성 진입 요청을 소비한다. 저장된 해금·별 기록은 바꾸지 않는다.

기존 대표 디펜스 맵 4종(순타 굴착, 역타 하부, 리모델링, 데이터센터)은 플레이 준비로 연결한다. 리모델링·데이터센터의 기존 검증 선행조건은 유지한다. 나머지 프로필은 연결된 순찰을 제공하며 아직 없는 전용 디펜스를 완성했다고 표시하지 않는다. 이전의 개발 게이트/맵 제작 대기 문구는 실제 제공 범위와 진입 조건으로 교체한다.

준비 화면의 **현장·공정 도면**은 선택 구역의 실제 바닥 위에 엔진이 만든 장애물과 실제 통제 위치를 표시한다. 진입 → 작업 → 인계의 짧은 작업 흐름과 번호별 통제 대상을 함께 읽을 수 있다. 일시정지 화면에서는 같은 도면이 현재 지형 HP와 실제 위험 상태를 받아 정리된 잔재·경고·격리 상태를 보여 준다. 임시 중지는 완료로 잘못 표시하지 않으며 재가동 가능성을 알린다. 이동 중 새 대형 패널은 추가하지 않는다.

## 5. 검증과 한계

단위 검증: 50개 구역 누락·중복 없음, 서로 다른 물리 배치, 경계 내 4개 장애물, 중앙 통로와 통제 대상 여유, 추적 경로 접근 가능, 기존 충돌/차폐/정리 회귀, 스테이지 1·한 번 안내 정책, 새 원화 실제 디코딩·해시·크기·다운로드 예산을 확인한다.

실행 검증: 메인 7개 해상도에서 로고·제목·모드 진입·얼굴/안전모 노출을 확인한다. 궁극기 5개 해상도에서 실제 발동과 재안내 억제를 확인한다. 대표 현장들은 준비 도면과 실제 전투·일시정지 도면 좌표를 비교한다. 완충 및 구역 해금은 명시적인 QA fixture이며 자연 진행이나 사람의 학습 성공률을 증명하지 않는다.

Android 실기기, 초보자 관찰, 전체 50개 구역의 장시간 난이도·최종 아트 감상 검수는 별도의 사람 평가가 필요하다. 기존 공정/현장별 완성도는 이 구현 결과를 바탕으로 계속 판정하며 자동 테스트만으로 Production Lock하지 않는다.
