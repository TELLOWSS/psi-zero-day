# 생존 모드 자연스러운 움직임 구현 기준

## 목적과 현재 진단

몸, 발, 손에 든 도구, 착용 장비가 같은 동작의 원인에 반응해야 한다. 흔들림의 양을 늘리는 것만으로 자연스러움을 만들 수 없다. 게임의 이동 속도·충돌·발사 판정은 유지하며 실제 이동과 실제 발사 이벤트를 표현의 원인으로 사용한다.

현재 보행은 실제 이동 거리로 진행되고, 발사 반응도 실제 발사 이벤트를 따른다. 그러나 달리기 기준 145에서 보폭이 순간적으로 바뀌며, 출발·정지의 보행 혼합은 선형이다. 몸 기울기는 속도만 따라가므로 급정지의 무게 이동이 없고, 좌우 전환에서 장비 스프링이 초기화된다. 이 네 가지를 먼저 수정한다.

## 이번 구현 순서와 수치

1. 이동 거리 기반 보행은 유지한다. 벽에 막혀 실제 이동이 없으면 보행 주기를 진행하지 않는다. 렌더링 간격이 아니라 초당 이동 속도로 미세 이동을 판정한다.
2. 보폭은 속도 130~180 구간에서 smoothstep으로 걷기 54에서 달리기 66까지 연결한다. 주인공의 원화 보행은 기존 두 걸음당 거리 112를 유지한다. 세로 이동 투영은 기존 접지 계산을 유지한다.
3. 보행 활성도는 100ms 동안 증가·감소하며 출력에 smoothstep을 적용한다. 발과 몸의 보행 변형이 시작과 끝에서 급하게 꺾이지 않게 한다. 정지 중 주기를 임의로 진행해 가짜 걸음을 만들지 않는다.
4. 몸의 무게 이동: 실제 수평 속도를 75ms 시간 상수로 추종한다. 실제 속도와 추종 속도의 차이로 출발·제동 관성을 만들되 추가 기울기는 ±0.012, 전체는 ±0.047 이내로 제한한다. 발사와 피격 반응은 기존 실제 이벤트·우선순위를 유지한다.
5. 장비: 몸 부착점은 유지하고 회전만 관절별 스프링으로 제한한다. 몸의 관성에 반응하고, 좌우 전환 시 회전·각속도를 좌표계에 맞게 반전하여 월드 공간의 흔들림을 보존한다. 정지하면 원위치로 수렴한다. 시뮬레이션 시간이 같으면 움직이지 않는다.
6. 시간이 되감기거나 몸 샘플이 500ms 이상 끊기면 이동 추론을 재시작한다. 장비 스프링은 기존 250ms 재시작 기준을 유지한다. 순간이동을 긴 보폭으로 해석하지 않는다. 감소된 모션 설정은 장비 흔들림을 끈다.

## 발 접지와 원화 제작 기준

이번 보간 개선은 완전한 접지 잠금을 의미하지 않는다. 기존 리그의 접지 다리 계산과 8방향 원화를 사용한다. 정지 과정에서 두 발을 실제 바닥 위치에 고정하려면 방향별 접지·통과·착지·정지 포즈와 각 프레임의 발 좌표가 필요하다. 없는 동작을 늘이거나 몸 전체를 크게 회전하여 대신하지 않는다.

다음 원화 제작의 승인 기준: 모든 캐릭터의 같은 신체 비율·PPE·장비 부착점, 8방향 각각 좌우 접지/통과/착지, 출발과 정지의 양발 지지, 45/90/180도 회전의 중심발, 이동 중 발사 상체, 피격 후 회복. 프레임마다 발바닥·골반·어깨·손·가슴/등/허리 장비 소켓과 앞뒤 가림 영역을 기록한다. 접지 다리의 월드 위치가 미끄러지지 않는지 이동 거리와 비교한다. 현재 주인공 이외 캐릭터는 기존 원화 리그를 사용하므로 완전한 8방향 신규 작화 완료로 보고하지 않는다.

## 검증과 합격 기준

- 30/60/120Hz 동일 경로의 보행 주기 일치. 같은 시간의 재샘플에서 몸·장비 상태 일치.
- 속도 145 경계에서 보폭의 불연속 없음. 출발·정지 혼합의 시작/끝 완만함.
- 급정지 제동 반응이 제한 범위 안에서 발생하고 정지 1초 뒤 충분히 수렴.
- 좌우 전환에서 장비의 월드 회전 보존. 각 관절의 기존 제한 범위 유지.
- 벽 충돌·순간이동·시간 되감기에서 가짜 보행 없음. 발사 중 보행 주기 유지.
- 실제 장착 미리보기와 실제 전투에서 PC·모바일 화면을 확인한다. 숫자 테스트 통과만으로 최종 아트 품질을 확정하지 않는다.

최종 시각 승인에는 연속 동작의 Director 검토가 필요하다. 코드 개선과 원화 제작 잔여 항목을 분리하여 보고한다.

## 이번 반영 검증 기록 (2026-10-09)

출발/제동/보폭 연결/시간 재시작/좌우 관성 보존을 반영했다. 장비는 샘플 구간의 고정 목표에 대한 감쇠 스프링을 해석적으로 계산한다. 고정 목표에서 30/60/120Hz 결과 일치를 검증했으며, 시간에 따라 변하는 목표의 완전한 프레임 독립성까지 주장하지 않는다.

전체 테스트 1,840개 통과, 1개 기존 skip. 타입 검사와 프로덕션 빌드 통과. 별도 5203 테스트 서버에서 1440×900, 390×844, 844×390 화면의 착용 미리보기와 실제 전투를 실행했다. 무료 무전기와 유료 통신 장비 3종의 같은 아틀라스 사용, 측면/뒷면, 미리보기 저장소 불변, 이동/정지/좌우 전환, 페이지 오류 없음을 확인했다. 모바일 화면 검증의 이동 입력은 자동화 키보드이므로 실제 두 손가락 터치 조작성 검증과 구분한다.

검증 결과: `artifacts/natural-motion-tests.log`, `natural-motion-build.log`, `natural-motion-browser.json`. 연속 PC 검토 영상: `artifacts/natural-motion-pc.webm`. 현 렌더링의 화면과 영상은 검토 자료이며 캐릭터별 신규 회전 원화나 접지 잠금의 최종 승인을 대신하지 않는다.
