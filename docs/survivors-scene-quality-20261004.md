# 슈팅 화면 전체 조명·접지감·HUD 개선

기존 Production 바닥·캐릭터·장비 아트를 보존하며 화면의 합성 품질을 개선했다. 전체 바닥에 따뜻한 작업 조명과 차가운 외곽 색을 통일하고, 현재 활성 투광기 위치에 조명 풀을 배치했다. 조명은 바닥 위, 캐릭터·드롭·위험 경고 아래에 그린다. 전장 외곽만 낮은 농도로 어둡게 하며 경고는 어둡게 처리하지 않는다.

장비의 긴 그림자와 접촉 그림자, 승인 캐릭터의 공통 반그림자로 접지감을 보강했다. 기존 rig·보행·발 접촉을 유지한다. HUD의 금색 외곽광·강한 그림자를 줄이고 금속성 패널, 단색 체력계, 차분한 시간·경험치 계기로 정돈했다. 승인된 전체 바닥 맵이 로드되면 레거시 격자 중복을 생략한다.

정적인 조명은 절반 해상도 캔버스에 굽고 최대 8개만 캐시한다(원시 RGBA 약 10MB). 비가시 드롭·일반 위험의 렌더링만 생략하며 엔진 시뮬레이션은 그대로 실행한다. 경고 중인 위험과 보스는 생략하지 않는다. 충돌·스폰·대미지·난이도·저장·스토리는 유지한다.

검증은 1·7·10·20 맵의 실제 초반 플레이를 390×844, 844×390, 1440×900에서 확인한다. 해금 저장은 검증 fixture이며 자연 진행 클리어가 아니다. 장면 스크린샷은 일시정지 이전 플레이 화면이다. 전체 회귀와 typecheck/build 결과, 실제 브라우저 렌더 오류·HUD 영역·정지/재개를 확인한다. Android 실기기 FPS 및 최종 상업 그래픽 품질 판정은 포함하지 않는다. 인화물 드럼통과 분전반은 내장 image_gen으로 생성한 새로운 production 후보 바이너리로 교체했다. 프롬프트·출처는 `content/art/survivors-scene-props-20261004.json`에 기록했다. 기존 원·사각형 마커를 제거하고 64/68px 장비 아트를 배치하며 경고·HP·차단 확인 표시는 유지한다. 외곽의 굵은 16px 테두리는 4px로 줄여 현장 배경을 드러냈다. 전체 최종 아트 Lock 판정은 별도다.

최종 검증: 207개 파일 / 1,114개 테스트, typecheck/build 통과. 4개 맵 × 3개 화면 크기 = 실제 초반 플레이 12건의 HUD·일시정지·재개 통과, 렌더 오류 0건. 새 WebP 두 파일의 알파 채널 유지 확인.
