# 도감·동료 안전모 보수 — 2026-10-17

## 수정

이전의 ‘래스터 파일 연결 확인’만으로는 원화 품질과 투명 배경을 충분히 검증하지 못했다. FG109는 3,972바이트의 기존 평면 도해가 남아 있었고 일부 자산은 투명 채널이 있어도 장비 내부 틈에 밝은 배경이 남았다.

- `restoration-v4` 19종: 동선 교차부·동바리·타설·해체·밀폐공간·임시전기 등 7종을 실제 장비/현장 맥락으로 제작하고, 게이트·계단·비계·측정기·무전기 등 12종의 배경과 내부 틈을 보수했다.
- FG109는 차량·보행 동선이 겹치는 **교차부**를 실제 포장·표시·물리적 구획으로 표현했다. 기존 오버레이 계약에 따라 원화 안에 차량과 사람을 중복으로 구워 넣지 않았다. 움직이는 차량이나 보행 시뮬레이션을 새로 구현했다고 주장하지 않는다.
- `FieldGuide.tsx`에서 v4→v3→기존 승인 원화 순으로 선택한다. 118항목 중 v4 19 / v3 60 / 기존 39개가 사용된다. v3 원본 61개를 삭제하거나 과거 잠금 해시를 고치지 않았다.
- 동료 8명의 초상 8·지도 전신 8·감정 표현 8, 총 24 production 슬롯에 공식 방패와 NEW-PSI 안전모 표식을 적용했다. 원래의 얼굴·안전모 색·직무 소품을 기준으로 편집했다.
- 앱의 asset ID와 저장 상태를 유지하고 presentation resolver에서 버전 경로로 교체한다. 동료 목록, 본편, Watch 준비 화면, Guard의 인물 이미지 및 Breaker 선택/엔딩 이미지에 연결한다.
- Breaker에 필요한 새 원화 8개를 오프라인 프리캐시에 추가하고 release manifest를 다시 계산했다.

## 검증의 범위

19종 모두 흰색/짙은 바탕에 실제 알파로 합성해 확인했다. 채널 통계는 잘못된 배경을 자동으로 승인하는 기준으로 사용하지 않았다. 이미지 모서리 알파, 실제 치수·해시·썸네일과 118개 라우팅을 별도로 검사했다.

도감은 320×568, 390×844, 568×320, 844×390, 1440×900에서 118개 이미지를 decode하고 검색·분류·빈 결과·원화 확대·Escape·포커스 복귀를 확인했다. 390px에서는 v3/v4 합집합 79개 상세 원화를 실제로 열었다. 동료는 390×844, 844×390, 1440×900에서 8명 목록·상세, Watch 6명 선택·대표 이미지, Breaker 6명 선택을 확인한다. 실행 결과는 `docs/qa/field-helmet-repair-20261017/`에 보관한다.

전투용 다방향 애니메이션 시트 전체와 주인공 성장 단계의 별도 PNG는 이 24슬롯 교체에 포함하지 않았다. 이들까지 같은 신규 표식으로 확장할 때는 손·도구 소켓과 프레임 좌표를 보존하는 별도 검수가 필요하다. 이 작업을 모든 애니메이션 프레임 교체로 보고하지 않는다.

NEW-PSI 원화는 실제 화면에 통합된 최종 후보이며, 해시 검증이 Director의 최종 미술 감상 승인을 대신하지 않는다. Android 실기기 QA는 별도다.
