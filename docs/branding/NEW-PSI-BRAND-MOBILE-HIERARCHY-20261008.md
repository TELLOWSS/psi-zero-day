# NEW PSI 모바일 인물·행동 위계

B1 후속. 기존 승인 대표 인물/정체성/원화를 유지하고 표시 구성만 개선한다. 세로 원화 R1이나 새 로고를 운영에 넣는 작업이 아니다.

## 변경

- 실제 시그널 워치 진입을 read-only 해금/준비 중 요약보다 먼저 배치한다. 요약은 단순 상하 경계의 정보 영역이며 별도 부유 카드가 아니다. 값·기능은 그대로다.
- 폰세로에는 기존 player-map.webp를 제목 그룹 내부에 별도 표시한다. 다른3명을 모바일 첫 화면에 추가하지 않는다. PC/태블릿 기존4인 그룹, 낮은 폰가로의 기존 간소화는 유지한다.
- 화면 전체 고정 좌표 대신 제목 그룹 기준으로 얼굴·PPE·태블릿·전신을 배치한다. 한글 제목/부제 폭과 주 행동 간격을 보장한다. 인물 이미지는 클릭을 가로채지 않는다.
- 폰세로의 준비 중 버튼은 제목/잠금 표시/프리뷰 동작을 유지하고 반복 설명을 접는다. 실제 플레이 버튼의 설명과 프리뷰 내부 전체 안내는 남긴다.
- 새 저장 키, 장비/피해/해금 규칙, 기존 음성·원화 파일, 후보 승인 상태를 바꾸지 않는다.

## 검증과 한계

- DOM 회귀에서 행동 영역이 상태 요약보다 앞에 있음을 확인하고 canonical4인/모바일 동일 파일/실제 플레이 callback/디펜스 프리뷰 잠금을 검사한다.
- 집중22건, 전체1,762건 통과·1건 제외, 타입/prebuild/build 통과. 마지막 작은 CSS 간격/추가 슬롯 변경은 후속 focused/type/build/browser 검사와 원격 CI로 별도 확인한다.
- `tests/verify-brand-mobile-hierarchy.mjs`: PC1440x900/태블릿1024x768/폰390x844·360x640·320x568·430x932/가로844x390·740x360, 일반/reduced16경로. 실제 decoded player-map의 alpha32 외곽을 contain 렌더링 좌표에 투영하고 한글 제목/부제·행동 버튼과 교차를 검사한다. CTA 첫viewport·44px·숨김 요약의 DOM 순서·프리뷰 잠금·실제 준비 화면 진입도 확인한다.
- 첫 시안의 숨김 CSS와 큰 폰430의 인물/CTA 겹침을 실제 캡처·계측으로 발견해 수정했다. 정상으로 보고하거나 검사만 느슨하게 만들지 않는다.
- 최종 로컬16경로 모두 통과: 동일 player-map URI, 폰세로 alpha 영역/제목/부제/버튼 비중첩, CTA 첫viewport/44px, 요약 위계, 디펜스·스토리 프리뷰 잠금, 실제 준비 진입, 넘침/오류 없음. 390/430 폰세로 최신 PNG 직접 확인. 9개 실제 슬롯4viewport 감사 및 최종 집중22/타입/Vite build도 통과.
- DOM/알파 경계는 그림자 전체나 주관적 인물의 몰입도/접지/아트 완성도 점수가 아니다. 실제 휴대폰 주소창·발열·긴 플레이·Director 최종 화면 승인은 별도다.
- R1은 별도 후보/HOLD다. 이 기존 원화 UI 배치를 새 원화 파일 승인으로 확대하지 않는다.
