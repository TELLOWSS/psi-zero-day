# NEW PSI 브랜드 경험 명세 v0.1

상태: Director 검토용. 아래 화면·문장·자산 규격은 제안이며 운영 미적용.

## 1. 하나의 경험을 연결하는 원칙

**관찰 -> 준비 -> 대응 -> 확인 -> 회복 -> 기록.**

메뉴 이름, 색, 소리, 움직임을 이 흐름에 연결한다. 장르를 새로 만들거나 점수·저장 규칙을 바꾸는 명세가 아니다.

## 2. 화면별 연출 계약

| 화면 | 첫 시선 | 주 행동 | 남겨야 할 감정 | 구현 주의 |
|---|---|---|---|---|
| 타이틀 | 작품명 + 주인공 + 실제 현장 | 현재 플레이 / 실제 저장 이어하기 | '이 현장에 들어가고 싶다' | 준비 중 모드 설명이 메인 경험을 압도하지 않음 |
| 작전 준비 | 선택한 구역과 주인공 | 시작, 장비·음성 확인 | 자신 있는 출발 | 선택과 실제 엔진 시작 인자를 일치시킴 |
| 장비실 | 장착한 몸과 보유 PSI | 비교, 구매, 수리, 장착 | 도구를 준비하는 만족 | 미리보기와 실제 소유·장착·효과를 분리 |
| 전투 | 현장 + 주인공 + 현재 위험 | 이동, 회피, 통제 | 이해 가능한 긴장과 손맛 | UI보다 예고·대상·동선이 우선 |
| 성장 선택 | 선택 전후의 정확한 효과 | 강화 또는 진화 선택 | 다음 대응이 기대됨 | 표시값과 실제 계산 일치 |
| 결과 | 실제 완료/중단 + 획득 PSI | 다음 구역 준비 / 재준비 | 해소와 다음 행동의 명료함 | 기록·보상을 새로 계산하지 않고 엔진 사실 표시 |
| 기록 | 실제 달성한 사실 | 확인·다음 작전 선택 | 플레이의 흔적 | 존재하지 않는 회수·인명 결과·관계 변화를 만들지 않음 |

## 3. 화면 구성의 구체안

### 타이틀

- 현장 원화는 배경 장식이 아니라 사람·장비·동선이 함께 보이는 공간이다.
- 작품명과 '오늘도 무사히'를 한 그룹으로 읽히게 한다. 한글 감정 문구와 영어 시스템명이 경쟁하지 않는다.
- 실제 저장이 있으면 현재 플레이의 이어가기 정보가 우선한다. 저장 여부 판단은 기존 저장소/도메인 경로를 사용한다.
- 시그널 워치는 플레이 가능한 첫 행동, 준비 중 모드는 한 단계 낮은 목록으로 구분하는 안을 검토한다.
- 초점·호버는 작은 경계·명암 변화로 통일한다. 계속 움직이는 외곽선과 네온 스캔으로 시선을 분산시키지 않는다.
- 자동 소리 시작이나 반복 진입 연출로 시작 버튼을 기다리게 하지 않는다.

### 작전 준비

- 구역명, 현장 원화, 선택 캐릭터의 얼굴·도구, 실제 장착 장비가 일치한다.
- 큰 숫자와 같은 크기 제목을 여러 줄 쌓지 않는다. 구역 -> 주인공 -> 장비 상태 -> 시작 순서다.
- 난이도와 음성은 실제 선택 상태가 분명한 분절 컨트롤을 유지한다.
- 보유 장비의 위험한 내구도는 알려주되 구매나 완벽한 조합을 시작 조건으로 만들지 않는다.
- 음성의 실제 선택·저장·미리듣기 지원 여부를 먼저 확인하고, 존재하지 않는 미리듣기 버튼은 기획 승인만으로 표시하지 않는다.

### 장비실

- 권장 표시명 후보: **PSI 장비실**. 상품마다 '프리미엄'을 반복하여 품질을 주장하지 않는다.
- 보유 PSI와 수리 예정 금액을 스크롤 중에도 확인한다.
- 실제 착용 몸을 중심으로 하며 상품 그림을 인체에 임시로 붙이지 않는다.
- 상세에는 역할, 실제 효과, 현재 대비 변화, 내구도, 구매/수리 후 잔액을 순서대로 둔다.
- 설치·착용 위치와 발동 모습으로 장비 차이를 보여준다. 색만 다른 상품 그림으로 구분하지 않는다.
- 희귀도는 이미 존재하는 분류를 사용한다. 새 등급·확률·무료 재화/유료 재화 분리는 추가하지 않는다.
- 파손은 소유권을 잃는 처리가 아니다. 현재 승인된 '사용 불가, 수리하면 복구' 규칙을 그대로 표시한다.
- 버튼은 익숙한 아이콘과 명확한 행동으로 구성하고, 낯선 아이콘은 이름을 제공한다.
- 반복 상품만 카드로 표현한다. 섹션을 떠 있는 카드로 만들거나 카드 안에 또 카드를 넣지 않는다.

### 전투

- 신호와 통제의 실체가 우선이다. 진화 이펙트도 예고·체력·방향을 가리지 않는다.
- 발사체 하나의 발사·충돌·소멸을 하나의 시간축으로 연결한다.
- 금속은 국소 스파크와 제동, 파편은 중량과 낙하, 가스는 압력·분산으로 구분한다.
- 작업자 안내에는 기계 파괴용 스파크를 사용하지 않는다.
- 기본형, 강화형, 진화형은 구조·궤적·재질·짧은 리듬에서 달라진다. 실제 판정 범위보다 훨씬 큰 공격처럼 보이게 하지 않는다.
- 보호막은 흡수한 순간, 소진, 복구가 구별된다. 대기 중 큰 빛 구체로 캐릭터를 가리지 않는다.
- 실제 HP 감소가 없는 차단 타격은 피해 타격과 구분한다. 예외 규칙은 엔진에 남고 UI가 새 피해를 만들지 않는다.

### 결과와 회복

- 첫 정보는 작전 결과와 획득 PSI, 두 번째는 핵심 기록, 세 번째는 다음 행동이다.
- 캐릭터의 짧은 안도 동작·음성 후보는 실제 완료 상황에서만 재생한다.
- 실패는 실망을 부풀리는 큰 붉은 연출보다 원인과 재준비 경로를 보여준다.
- HP 0을 실제 인명 사고·부상·사망으로 단정하는 문구는 별도 사실/콘텐츠 검증 없이 추가하지 않는다.
- 마지막 구역은 다음 구역이 존재하는 것처럼 표시하지 않는다. 기존 엔진/해금 규칙에서 행동을 도출한다.
- 보상·장비 마모·선택 맵은 기존 한 번 정산 경로를 유지한다.

## 4. 문장 사전 후보

기존 문자열을 즉시 교체하는 목록이 아니다. 해당 사실이 실제로 발생하는지 확인한 뒤 localization ID에 연결한다.

| 상황 | 권장 표현 후보 | 사실 조건 |
|---|---|---|
| 주인공 소개 | 신호를 놓치지 않는 현장 안전관리자 | 승인된 역할, 새 능력 약속 아님 |
| 시작 | 작전 시작 | 실제 준비 완료 상태 |
| 무전/장비 조치 성공 | 통제 확인 | 실제 엔진 성공 이벤트 |
| 작업자 조치 | 안전 안내 전달 | 작업자 대상의 실제 조치 |
| 핵심부 개방 | 핵심부 개방 · 접근 통제 | 실제 보스 상태 |
| 장비 착용 | 장착 완료 | 저장/현재 장착 성공 |
| 장비 수리 | 수리 완료 · 장착 상태 확인 | 실제 수리 성공, 장착 여부 별도 |
| 포인트 부족 | PSI 부족 · 현재 잔액 확인 | 가격과 잔액의 실제 차이 |
| 파손 | 파손 · 수리로 복구 가능 | 내구도 0, 소유권 유지 |
| 실제 저장 실패 | 기록을 저장하지 못했습니다 | 저장 함수 실패, 재시도 지원 확인 |
| 지도 로딩 실패 | 현장 지도를 불러오지 못했습니다 | 실제 지도 로딩 실패 |
| 완료 | 작전 완료 | 실제 victory/정산 완료 |
| 실패 | 대응 중단 · 다시 준비 | defeat. '사고 발생' 대체 여부는 Director 확인 |
| 다음 행동 | 다음 작전 준비 | 실제 해금/다음 구역 존재 |
| 마지막 구역 | 작전 기록 확인 | 해당 기록 화면 지원 여부 확인 |

새 버튼이나 화면이 필요한 문장은 지원되지 않으면 사용하지 않는다. '안전 확보', '전원 무사', '인명 피해 없음'은 엔진이나 승인된 서사에 근거가 있을 때만 쓴다.

## 5. 인물별 톤의 제작 원칙

- 현장 안전관리자: 짧고 명료한 판단, 동료에게는 온기. 허세·조롱·과도한 구호 제외.
- 강태식: 기존 베테랑 반장 설정과 체격·손동작 유지. 미승인 사투리를 추가하지 않음.
- 윤성호: 기존 철근반장 역할과 소품 유지. 강태식의 음성과 실루엣을 복제하지 않음.
- 이재훈: 실행과 일정 조율의 구체성. 냉담한 악역으로 임의 변경하지 않음.
- 임준호: 신입의 관찰·질문이 드러나되 사고를 내는 웃음거리로 만들지 않음.
- 최민석·서정민·오승재: 승인된 직군·소품·책임 범위를 먼저 확인하고 추가 대사는 별도 서사 승인.

인물별 대사 제작은 기존 성우 팩을 검토한 뒤 별도 납품 명세로 진행한다. 신규 음성의 화자·모델·파일·대본·사용권을 기록하며, 생성 도구명만으로 새 음원 사용권 확인을 대체하지 않는다.

## 6. 실제 최종 후보 제작용 프롬프트

아래 프롬프트는 승인 이후 제작용이다. 현재 자산을 생성·교체했다는 의미가 아니다.

### BR-ART-01 대표 원화

```text
NEW PSI : ZERO DAY의 승인된 캐릭터 기준과 실제 현장 배경을 참조하여 공식 키 아트 후보를 제작한다. 대표 여성 현장 안전관리자의 얼굴, 흰 안전모, 청색 안전조끼, 반사띠, 태블릿과 기존 체형을 정확히 유지한다. 실제 플레이와 연결되는 건설현장 공간에 사람, 장비, 작업 동선과 하나의 읽을 수 있는 위험 신호를 배치한다. 긴장은 상황에서, 자신감은 자세에서, 따뜻함은 동료 사이의 거리에서 표현한다. 기존 2.5D 디오라마의 인물 비율과 재질을 유지하며 캐릭터만 실사풍으로 바꾸지 않는다. 로고와 한글은 이미지 안에서 생성하지 않고 편집 단계에서 합성할 여백을 확보한다. 얼굴·손·도구를 가리지 않는다. 과한 네온, SF 갑옷, 날아다니는 건설장비, 근거 없는 대형 무기, 피·신체 파괴, 실제 회사 로고, 가짜 문자를 넣지 않는다. 런타임 최종 후보이며 참고용 포스터와 구분하여 프레이밍을 검수한다.
```

납품 규격은 기존 Production slot의 실제 크기·포맷·크롭 계약을 조사한 후 확정한다. 16:9/세로/모바일 가로를 별도 승인한다.

### BR-MOTION-01 주인공 걷기와 장비 발동

```text
현재 승인된 인물 원화, 실제 방향별 프레임, 발바닥 피벗, 어깨·흉부·등판·허리 소켓 계약을 먼저 조사한다. 얼굴·PPE·태블릿 손·체형을 유지한다. 발이 교차하는 중간 동작의 좌우 발 순서와 무게 이동을 보완하고 이동 방향이 바뀌어도 발바닥 피벗이 튀지 않게 한다. 무전, 보호 장비, 드론은 몸의 앞뒤 가림과 케이블 연결을 유지하는 독립 레이어로 제작한다. 발사·흡수·소진·재충전·스캔은 실제 엔진 이벤트에만 반응한다. 새 공격 능력이나 수치를 추가하지 않는다. 결과물은 작은 실제 전투 크기, 피팅, 모든 방향, 모바일에서 승인하며 한 장의 생성 이미지로 리깅 완료를 선언하지 않는다.
```

### BR-AUDIO-01 짧은 브랜드 사운드

```text
NEW PSI : ZERO DAY의 브랜드 사운드 최종 후보를 제작한다. 현장의 짧은 무전 확인, 실제 장비 잠금의 단단한 촉감, 따뜻한 음악의 해소를 하나의 짧은 인상으로 연결한다. 긴 광고용 오프닝, 군사 경보, 과한 트레일러 강타, 기존 상용 게임의 음형 모방은 제외한다. 음성·현장 위험 경고와 주파수·시간상 경쟁하지 않게 한다. 시작용과 실제 작전 완료용을 구분하고 임의 성공을 암시하지 않는다. 무손실 마스터, 웹용 납품본, 루프가 아닌 끝맺음, 화자/모델/도구 정보와 게임 공개 배포 사용권 기록을 함께 납품한다. 반복 진입 시 피로도와 휴대폰 스피커에서의 식별성을 청취 검수한다.
```

## 7. 엔지니어링 연결 계약

- 새로운 정책 문서는 승인 전 런타임에 import하지 않는다.
- 명칭·문장은 localization을 통해 적용한다. 기존 ID·저장 데이터·경로 이름을 외형 브랜딩 때문에 바꾸지 않는다.
- 엔진은 실제 결과를 소유하고 UI는 이름·원화·소리·순서만 표현한다.
- 실제 자산의 로딩 실패를 준비 중 아트나 임시 그림으로 숨기지 않는다.
- 캐시된 원화와 제한된 이펙트 풀을 유지하고 per-frame 이미지/필터 할당을 늘리지 않는다.
- 현재 프레임·자산 계약과 테스트를 조사한 뒤 필요한 최소 변경만 구현한다.
