## 형태와 납품

- 열린 직각 현장 경계 + 떨어진 신호 막대. 완료 체크/방패/인증 배지를 넣지 않는다. 삼각 재생 형태를 사용하지 않는다.
- 작품명 `NEW PSI : ZERO DAY`를 그대로 유지한다. NEW PSI가 주 계층, ZERO DAY가 작품 계층이다. 한글 부제 `오늘도 무사히`는 기존 UI 텍스트로 유지하며 새 이미지 속에 추가하지 않았다.
- 편집 소스 SVG3개, 자체 포함 폰트가 있는 ink/chalk 기본/낮은 가로 워드마크 SVG4개, 독립 심벌 SVG2개, 각 투명 PNG6개를 docs에 보존한다. 명시적으로 승인된4개 SVG만 public으로 동일 바이트 복사하며 Git LF 고정으로 OS 체크아웃에 의한 승인 SHA 변경을 막는다.
- 기존 Chakra Petch Bold 파일을 변형 없이 내장했다. 같은 OFL 원문을 납품 폴더에 보존하고 파일/hash를 JSON에 기록한다. 이것은 상표 조사나 Director 승인과 별개다.
- `scripts/materialize-brand-wordmark-candidate.mjs`가 소스/폰트로 납품을 생성하고 해시를 기록한다. PNG는 실제 SVG의 브라우저 래스터 출력이다. 소스 글자는 편집 가능한 text이며 패스 윤곽 문자 납품으로 주장하지 않는다.
