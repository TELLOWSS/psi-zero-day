- 첫 수정은 상단 LZ 안내에 현재 플레이어에서 실제 LZ 좌표로 향하는 8방향 화살표와 한국어 방향을 추가한다. 내부 진입 후 기존 사수/진행 표시로 돌아온다. 밖에서는 진행 막대를 숨겨 좁은 화면의 방향 문구 공간을 확보한다.
- 범위155/15초/피해/보상/저장 규칙은 변경하지 않는다. world pointer도 유지한다. 거리의 단위를 임의로 미터라고 표시하지 않는다.
