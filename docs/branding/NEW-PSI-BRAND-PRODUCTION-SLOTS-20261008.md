## 납품 및 승인 단위

1. 현재 원본 얼굴/PPE/도구를 참조한 최종 후보 원본과 무손실 편집본을 보존한다. 로고/가짜 문자를 원화에 굽지 않는다.
2. 런타임 납품은 실제 슬롯에 맞춘 WebP/투명 인물 파일로 구분한다. 동일 원화의 서로 다른 크롭도 파일명·원본/납품 hash·적용 슬롯을 기록한다.
3. 밝음/어두움·단색·16/32/48px 아이콘·PC/폰세로/폰가로/태블릿 실크기 비교본을 Director에게 제시한다. 자동 확대/파일 존재를 시각 승인으로 대체하지 않는다.
4. 얼굴·손·태블릿·동선·예고가 살아 있는지, 준비 중 기능의 위계가 현재 플레이보다 강해지지 않는지 검수한다. 현재 숨겨진 폰 인물 슬롯은 별도 구성 판단이 필요하다.
5. 생성 도구/모델/원본·편집본·납품본/사용권 확인 주체/검수자/승인 날짜/범위를 남긴다. 명시적 파일 승인 전 런타임 교체하지 않는다.

## 재현 가능한 조사

- `scripts/audit-brand-production-slots.mjs`는 4viewport의 실제 DOM URI/디코딩 크기/object-fit/object-position/visibility/box를 계약 JSON과 대조한다. 로컬 납품 파일 크기/hash를 기록하고 뷰포트 간 identity drift를 검사한다.
- 출력: `artifacts/brand-production-slots/report.json`, 4개 full-page PNG. 공개 운영 조사4경로 통과, 폰세로 캡처 직접 확인.
- hash는 로컬 납품본의 hash다. 원격 파일 bytes 대조·제공자 약관·인물 알파 경계·픽셀 기반 시각 품질·실기기 검수는 이 검사에 포함하지 않는다.
- 숨겨진 인물은 hidden으로 기록하며 pass는 슬롯 파일/연결 일치만 뜻한다. B2 전체 완료나 미승인 후보의 운영 승격을 뜻하지 않는다.
