# 작전 이야기·보급 활용 안내 구현 기록

작성: 2026-10-10. 기준 커밋: `d358641e`. 사용자 후속 “이어서 진행”에 따라 애착·반복 플레이 기획의 첫 작전 흐름을 로컬 구현했다. 본 문서의 구현 범위는 새 직업·성장 공식·장기 경제 조정과 구분한다.

## 구현된 경험

작전 준비에서 선택한 6명 각각의 관점, 이번에 남길 선택 목표, 해당 인물의 가장 최근 인계 기록을 보여준다. 현재 구역에 돌진 카트나 통제 설비가 없으면 실제 가능한 목표로 바꾼다. 정리 가능한 지형은 현재 엔진과 같은 배치 함수를 통해 확인한다. 목표는 이야기 관점의 제안이며 기존 별·보상·작전 성공 조건을 추가하지 않는다.

성공·실패 결과 모두 통로 정리·돌진 제동·통제 구역의 실제 수를 표시한다. 수행한 행동과 남은 확인 사항을 구분하고, 다음에 시험해 볼 조합을 캐릭터별로 제안한다. 다른 인물이나 다른 구역의 기록을 이번 작전 성과로 표시하지 않는다. 재대응 결과의 저장·갱신은 기존 버전 1 인계 저장소를 사용한다. 별도 친밀도 저장소를 추가하지 않았다.

시범은 기존 STAGE 12 철근 반입·배근 구역이다. 작전 준비의 “퇴근 전에, 이 길만은” → 기존 현장 진술·판단 사건 → 첫 정비 무전 → 두 번째 정비 무전 → 이번 작전 인계로 연결한다. 무전은 실제 보급 정지 중에만 표시한다. 상세 기록은 접어 둘 수 있고 중앙 전투 팝업을 추가하지 않는다. 기존 승인 인계 CG·대화·진로 관심 선택은 기존 조건을 유지한다.

보급 카드는 구매 전후 실제 변화의 첫 수치를 바로 보여주며 전체 수치는 상세 보기에서 확인한다. 체력·적용 상한으로 변화가 없는 경우 구매 전에 안내한다. 현재 보유한 활용 장비와 미보유 추가 후보를 구분한다. 이 후보는 필수 재료나 세트 보너스가 아니다. 카트·낙하·가스 등 해당 구역 위험에 맞는 활용 안내를 제공한다. 구매 비용과 적용 함수는 기존 그대로다.

## 흐름 검증

사용자 경험: 캐릭터·구역 선택 → 작전 준비와 저장된 인계 확인 → 기존 현장 판단 대화 → 정지한 보급의 무전·효과 확인 → 재개 → 결과 인계 저장·표시.

| 경계 | 검증 결과 | 근거 |
|---|---|---|
| 캐릭터·구역 → 선택 목표 | 6명과 존재하지 않는 카트 목표의 대체 확인 | `tests/survivors-operation-story.test.tsx` |
| 저장 → 기억 표시 | 인물·구역 구분, 잘못된 데이터 제외, 읽기 중 변경 없음 | 같은 테스트·기존 인계 저장 회귀 |
| 보급 → 무전 | STAGE12 두 실제 보급 정지에서 표시 | `artifacts/operation-story/report.json` |
| 읽기 → 전투·저장 | Escape/P 입력과 상세 열기에도 전체 상태·저장값 불변 | 같은 보고서 |
| 실제 카운터 → 결과 | 실패 결과에서도 확인한 행동의 수 저장·표시 | 같은 보고서·새 단위 검사 |
| 보급 설명 → 적용 | 보유/미보유 구분·상한 안내·실제 변화 수치 | 보급 관련 단위 검사·`artifacts/supply-preview/report.json` |

브라우저 조건: PC 1440×900, 모바일 세로 390×844, 모바일 가로 844×390. 6명 × 성공/실패 × 3화면의 **36개 소스 표시 조건**과, 실제 앱에서 STAGE12 준비·기존 판단 대화·보급 두 번·실패 결과 저장을 확인했다. 36조건은 컴포넌트 fixture이며 자연 전투 완주가 아니다. 실제 앱 검사도 구역 해금·웨이브 시계·최종 카운터를 QA에서 지정했다. 새로고침·애착·현장 경험자의 반응을 자연 플레이로 검증했다고 계산하지 않는다.

브라우저 예외·console error 없음. 표시 fixture는 가로 넘침 없음을 확인했고 실제 보급은 세 화면에서 눈으로 확인했다. 별도의 기존 보급 구매 검사도 세 화면에서 각 8종, 총 24회 구매를 수행해 적용 수치·상한·중복 구매 방지·잔액을 확인했다. 첫 검사 fixture의 favicon 요청 오류는 fixture에 명시적인 favicon을 추가해 수정했다. 다음 검사는 기존 STAGE12의 8초 판단 사건을 건너뛰어 재개 확인이 멈췄으므로, 기존 대화를 먼저 끝내는 순서로 검사 흐름을 수정했다. 제품의 기존 판단 사건을 삭제하거나 자동 통과시키지 않았다.

전체 회귀: **1,933개 통과 / 1개 기존 건너뜀**, 타입 검사 및 프로덕션 빌드 통과. 전체 로그는 `artifacts/operation-story-tests.log`, 빌드 로그는 `artifacts/operation-story-build.log`. 기존 큰 청크 경고는 남는다. 브라우저 시각 자료는 `artifacts/operation-story/`에 있다.

React 검토: 목표와 결과는 순수 조회 결과로 계산하고 새 효과나 프레임 구독을 추가하지 않았다. 기록은 준비 화면에서 한 번 읽어 자식에 전달한다. 무전은 정지한 보급에서만 읽으며 전투 루프를 늘리지 않는다. 기존 버전·검증·상한이 있는 로컬 저장소를 사용하고 새 외부 API·환경 변수는 필요하지 않다.

## 남은 기획 범위

후속 요청으로 다음 작전의 통로 변화와 실제 모드 행동 연계를 추가했다. 아래 문단은 최초 구현 시점의 범위이며, 현재 상태는 `SURVIVORS-HANDOFF-WORLD-BRIDGE-IMPLEMENTATION-20261010.md`를 따른다.

다음 작전에서 실제로 달라지는 통로·배치 상태, 장비별 성과를 분리한 조합 회고, 구매까지 작전 수와 수리비를 실측한 경제 조정, 본편·디펜스의 실제 참고 기록 연결은 이번 구현에 포함되지 않았다. 스토리·디펜스 프리뷰의 준비 참고 안내를 유지한다. 새 직업·진로 공식, CG·음성 추가 제작은 기존 별도 계약을 따른다.

실제 현장 경험자와 초보자의 역할·시너지 이해, 다음날 캐릭터 기억, 실제 휴대폰의 읽기·조작 검수는 외부 관찰 대상이다. 자동 검사로 애착·몰입 향상을 입증하지 않는다. 이번 로컬 변경은 이전 배포와 구분하며 GitHub/Vercel 재동기화는 별도 기록한다.
