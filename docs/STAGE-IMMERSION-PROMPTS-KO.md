# 다음 제작 단계 실행 프롬프트

## 현재 반영 범위

- 기존 20개 스테이지를 공정에 맞는 15종 배경에 연결했다. 새 배경은 12종이다.
- 후반으로 갈수록 마감재·설치 표시·설비 표기가 정교해진다. 초반 화질을 낮추는 방식은 아니다.
- 모바일 상점은 목록, 피팅, 현재 장착으로 분리했다. 구매와 장착은 기존처럼 별도 동작이다.
- 독립 착용 아트 3종을 기본 캐릭터 6명의 몸통에 맞췄다. 모든 프리미엄 장비의 아트가 완성된 것은 아니다.
- 오케스트라 후보곡은 유지하고 개별 사운드 볼륨을 추가했다. 최종 녹음·마스터링 완료를 뜻하지 않는다.

## 1. 같은 장소의 공정 변화

PSI ZERO DAY의 기존 Survivors 스테이지 05/09/10/19와 06/08을 개선하라.
현재 배경, 실제 위험 설비 위치, 작업 목표를 먼저 읽어라. 같은 장소를 공유하되
설치 전, MEP 설치, 시운전, 전원 격리 상태가 케이블 연결·설비 가동 표시·작업구역
정리 상태로 구분되게 제작하라. 색만 바꾸는 변형은 금지한다. 중앙 전투 공간의
가독성, 실제 이동 경계, 경고 범위를 유지하라. 설치물의 충돌이 필요하면 순수
engine/domain에 규칙과 테스트를 먼저 추가하라. 배경 그림만으로 가짜 장애물을
만들지 말라. 390px 모바일과 데스크톱에서 이동 중 캡처를 검토하고 결과를 기록하라.

## 2. 나머지 프리미엄 장비의 착용 제작

현재 survivors-store의 16종 장비와 survivors-wearable-art의 3종 아트를 비교하라.
미완성 장비를 신체 부착형, 휴대형, 배치형, 동행형으로 분류하고 우선순위를 정하라.
캐릭터 원본의 얼굴·체형·소지 도구를 유지한 독립 투명 아트를 제작하라. 캐릭터별
부착점, 앞뒤 가림, 이동·피격 시 몸통 추종, 활성/소진 상태를 구현하라. 캐릭터 옆에
작은 아이콘만 띄우는 것을 착용 완료로 계산하지 말라. 실제 엔진의 장비 효과와
연결하고 소유·장착·미리보기 저장 상태가 분리되는 테스트를 유지하라.

## 3. 드론 도킹과 출격

inspection_wing의 독립 도킹 레일과 실제 동행 드론을 읽어라. 준비, 도킹, 출격,
추적, 복귀의 시각 상태를 실제 장비 준비도와 대상 상태에서 도출하라. 공격 범위나
억제 범위를 애니메이션 때문에 늘리지 말라. 도킹 중에는 몸에 붙고 출격 시 레일에서
분리되며 복귀 시 자연스럽게 접합되게 하라. 정지 이미지나 시간만으로 가짜 공격
성과를 보여주지 말라. 저사양 모바일과 reduced-motion에서도 상태를 구분해야 한다.

## 4. 영화급 오케스트라와 현장 음향

현재 7종 orchestral candidate와 Music/SFX/Voice/Ambience 믹서를 읽어라.
음악은 현장 진입, 압박, 중대 위험, 개입, 진화, 성공, 실패의 감정 흐름으로 설계하라.
동기화 가능한 오케스트라 스템과 정확한 반복 구간을 납품하고, 곡 전환의 호흡을
플레이 사건에 맞춰라. 무전·경보는 음악 위에서 명료하게 들려야 한다. 굴착장,
고층 바람, 양생 히터, 서버 냉각, 야간 펌프의 실제 환경음을 낮게 배치하고 장비별
접촉음·재질음을 녹음하라. 휴대폰 스피커, 이어폰, 연속 전투에서 피로도와 피크를
검토하라. 사용 권한, 파일 해시, 승인 상태를 기록하라. 합성 개발 효과음이나
후보곡을 최종 승인 자산으로 재표기하지 말라. 최종 음악 제작 도구나 원본이 없으면
부족분을 명시하고 자동 생성했다고 주장하지 말라.

승인을 구분한다. 각 단계의 미완성 항목을 다음 작업에서 바로 실행할 수 있게 남긴다.
