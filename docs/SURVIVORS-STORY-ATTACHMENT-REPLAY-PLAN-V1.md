# 오늘도 무사히 — 캐릭터 애착·현장 서사·반복 플레이 기획 v1

작성: 2026-10-09. 상태: 사용자 요청에 따른 설계 제안. 아래 새 서사·보상·저장 규칙은 아직 구현하지 않았다. 현재 그래픽 업데이트 배포와 구분한다. 수치와 대사는 검증할 초안이며 확정된 세계관 설정이 아니다.

## 1. 플레이어에게 남길 감정

“내 일을 알아주는 게임이다. 내가 이 현장을 조금씩 바꾸고 있다. 이 사람들과 다음 작업도 해보고 싶다.”

핵심은 조작의 시원함, 장비 조합의 발견, 동료에 대한 관심, 현장에 남는 흔적이다. 오랫동안 몰입할 수 있되 종료 시점에도 성취가 닫혀야 한다. 플레이 시간을 억지로 늘리는 연속 접속 손실, 시간 한정 구매 압박, 끝없는 저확률 반복은 쓰지 않는다. 다음 플레이는 놓친 보상에 대한 불안보다 새 판단과 조합을 시험하고 싶은 기대에서 시작한다.

## 2. 현재 게임에서 이어갈 기반과 빈틈

현재는 6명 캐릭터, 공정별 위험과 보스, 장비 성장·진화, 보급 선택, 정리 선물·보너스 구간, 작전 인계 기록, 시그널 워치, 스토리·디펜스 프리뷰가 있다. 새 메뉴를 늘리기보다 이 연결점을 먼저 강화한다.

작전 준비의 캐릭터별 글은 이미 역할과 최근 인계를 설명한다. 그러나 본편의 실제 분기나 디펜스 보너스까지 연결된 것은 아니다. 현재 `survivors-operation-brief-ko.json`의 “준비 참고용” 안내를 실제 연계가 구현되기 전 삭제하지 않는다. `survivors-campaign20-ko.json`의 공정·무전·성공/잔여 위험 문구를 우선 서사 원재료로 쓴다.

| 현재 경험 | 강화할 경험 | 구현 위치 원칙 |
|---|---|---|
| 장비 구매 후 역할 설명 | 선택 캐릭터가 오늘 맡은 문제·내 목표·지난 결과 | 기존 작전 준비 |
| 웨이브마다 보급 | 이번 조합이 어떤 위험을 해결하는지 설명 | 기존 보급 카드 |
| 점수와 완료 | 내가 확보한 통로와 다음 팀의 반응 | 기존 결과·인계 기록 |
| 반복 스테이지 | 같은 공정에서 다른 동선·조합·통제 판단 | 기존 작전 선택 |
| 준비중 모드 프리뷰 | 동일 기록의 의미를 설명하는 연결 문구 | 기존 프리뷰, 준비중 상태 유지 |

## 3. 슈팅의 이야기 문법

슈팅은 위험을 사람처럼 죽이는 서사가 아니라, 과장된 위험 형상을 통제하고 현장을 회복시키는 액션으로 정리한다. 일반 위험 해소는 장비 회수·분진 흩어짐·압력 안정·전원 차단처럼 재질에 맞게 닫는다. 작업자는 구조·대피·지원 대상이다. 실제 사람으로 읽히는 위험에는 피해 묘사 대신 보호·노출 해소 표현을 사용한다.

한 작전의 구조는 **인계 → 작은 이상 → 통제·조합 선택 → 위험의 원인 확인 → 마지막 대응 → 퇴근 인계 → 다음 작업의 신호**다. 설명은 플레이 사건에 붙인다. 긴 교육 글을 전투 도중 읽게 하지 않는다.

### 첫 시범 작전: “퇴근 전에, 이 길만은”

기존 골조·철근 반입 구역 중 하나를 시범 대상으로 선정한다. 새 대규모 캠페인이나 지도 제작을 먼저 시작하지 않는다.

1. 작전 준비: 다음 철근팀이 쓸 통로와 반입 장비 동선이 겹친다. 선택 캐릭터의 역할과 선택 목표 하나를 보여준다.
2. 첫 웨이브: 이동·사선·위험 예고를 익히며 통로 한 곳을 확보한다. 무전은 가장자리의 한 줄로 나온다.
3. 첫 보급: 통로 확보형, 돌진 제동형, 회수형 조합을 비교한다. 전투는 멈춰 선택을 보장한다.
4. 중간 변주: 확보한 통로가 실제 우회 선택에 도움이 된다. 미확보 상태에도 더 돌아가는 대안이 남는다.
5. 마지막 대응: 기존 돌진·양중 위험의 예고를 읽고 제동 또는 회피·통제한다. 원인을 다르게 보게 하는 짧은 무전으로 앞 사건과 연결한다.
6. 결과: 확보한 통로, 제동 횟수, 남은 재확인 항목을 구체적으로 보여준다. 성공을 실제 완전 안전 보증으로 표현하지 않는다.
7. 다음 신호: “내일은 위쪽 반입 동선도 확인 부탁합니다.”처럼 다음 관심사를 한 가지 남긴다.

대사 초안: 임준호 “아까 비운 길, 다음 팀도 그쪽으로 가면 되죠?” / 강태식 “길만 치운 게 아니네. 이제 신호가 보인다.” 같은 기록을 선택 캐릭터·관계 관점에 맞춰 다르게 보여준다. 구현 시 발화 상황·인물 말투 검토 후 localization text_id로 옮긴다.

## 4. 6명에게 애착을 만드는 방향

새 과거사·가족관계·트라우마는 임의로 확정하지 않는다. 현재 직무와 말투를 중심으로 작은 행동과 반복되는 반응을 만든다. 역할별 목표는 선택형이며 진행을 막지 않는다.

| 캐릭터 | 기억될 행동 | 선택형 작전 목표 | 관계가 보이는 결과 예시 |
|---|---|---|---|
| 안전관리자 | 말을 듣고 중지·재개 근거를 남김 | 서로 다른 통제 수단을 활용 | 다음 팀이 재개 전 확인할 항목을 남김 |
| 강태식 | 작업반과 이동 순서를 챙김 | 통로·차폐 활용 | 작업반이 확보된 우회로를 사용 |
| 윤성호 | 결속·자재의 작은 차이를 알아봄 | 낙하 반경 밖에서 작업면 확보 | 다음 반입 위치를 알아보기 쉽게 인계 |
| 이재훈 | 도면과 실제 설치를 비교 | 열린 시야에서 감시·제동 | 계획과 다른 구간을 다음 팀에 표시 |
| 임준호 | 작은 이상을 먼저 말함 | 예고를 읽고 보고·우회 | 다음 작전에서 보고에 먼저 답하는 동료 |
| 안전감시자 | 무전·출입 경계를 유지 | 겹친 작업반경 분리 | 다음 팀이 신호 지점을 기준으로 배치 |

애착은 숫자 호감도보다 “내가 한 일을 기억하는 반응”으로 먼저 만든다. 첫 보고, 첫 통로 확보, 같은 조합 재사용, 실패 후 재대응에 각각 짧은 반응을 둔다. 반복 대사는 최근 재생 목록으로 피하고, 긴 이야기는 전투 밖 기록에서 다시 볼 수 있게 한다.

장비는 몸에 붙는 위치와 행동까지 기억되게 한다. 무료·유료 모두 외형·발사·타격·진화·해소의 연결을 갖추고 미리보기와 전투를 일치시킨다. 유료 장비가 캐릭터의 핵심 이야기나 최선의 결말을 독점하지 않는다.

## 5. “한 판 더”를 만드는 네 가지 순환

| 시간 범위 | 즐거움 | 플레이어가 확인할 증거 |
|---|---|---|
| 수초 | 발사·재질별 타격·정확한 제동 | 시각/소리/반동의 짧고 선명한 응답 |
| 한 웨이브 | 위험을 읽고 조합을 바꿔 성공 | 선택했던 장비의 효과가 실제 상황에 등장 |
| 한 작전 | 내 역할로 현장을 회복 | 통로·잔여 위험·동료 인계 변화 |
| 여러 작전 | 새로운 운영 방식과 인물 관점 발견 | 조합 기록·역할별 기억·현장 비교 |

작전 길이는 기존 실제 클리어 분포를 먼저 측정한다. 짧은 순찰 5~8분, 표준 작전 10~15분은 설계 목표다. 무한 반복 모드를 핵심 진행에 강제하지 않는다. 긴 도전은 웨이브 경계에서 안전하게 저장·종료할 수 있는지 별도 저장 계약을 검증한다.

### 조합 발견을 읽히게 만들기

보급 카드에는 장비 그림, 내 캐릭터 착용 부위, 지금 달라지는 효과, 현재 장비와의 시너지, 다음 위협 대응을 한 화면에 담는다. 보유하지 않은 조합은 “필요 장비”, 충족된 조합은 “현재 작동”으로 구분한다. 실제 엔진 효과가 없는 단어를 시너지로 표시하지 않는다.

조합 설계 예시는 ‘넓은 통제 + 빠른 회수’, ‘돌진 제동 + 안전 거리 확보’, ‘감시 범위 + 사각 통제’다. 정확한 장비 조합은 기존 weapon/store ID 및 효과 계약과 대조해 확정한다. 게임이 추천하는 이유는 “현재 돌진 위험이 많아 제동 후 회수하기 좋습니다”처럼 상황으로 설명한다.

작전 종료에는 이번 조합의 성과 1~2개와 다음 시험 제안 하나를 남긴다. 무조건 동일한 정답 조합을 추천하지 않는다. 자유 시험장은 무료/유료 및 진화 단계를 구매 없이 비교할 수 있는 현재 미리보기 기반을 활용한다.

## 6. 성장·보상·보너스 구간

기본 성장에서는 초반 목표 장비가 보이도록 구매 가격과 예상 작전 수를 함께 안내한다. “좋은 선택을 했는데 수리비 때문에 오히려 후퇴했다”는 경험을 막는 것이 우선이다. 기존 크레딧 정산·수리·장애물 선물·보너스 보상을 조사한 뒤 수치를 조정한다.

초안 목표: 기본 장비 첫 구매 2~3회 표준 작전, 첫 핵심 진화 경험 3~5회. 이것은 확정 경제 수치가 아니다. 초보·숙련 실제 수익과 실패율을 측정해 맞춘다. 실패해도 이미 확정한 정리·회수 보상을 중복 없이 보존하는지 확인한다.

보너스 구간은 짧고 명확한 스트레스 해소가 된다. 기존 보너스 구현에 맞춰 회수·정리·안전한 연속 해소를 활용하며 대량 점수·풍부한 작은 파편·경쾌한 소리를 준다. 실제 위험을 무시해 달려드는 행동이 더 이득인 구조는 피한다. 기초 장비로도 보상 목표를 달성할 수 있게 한다.

장기 보상은 수치 인플레이션보다 캐릭터 작업 배지, 장비 외형 단계, 조합 기록, 현장 전후 기록을 우선한다. LIFE ARCHIVE는 현재 승인 범위인 엔딩·CG·주요 기록 해금을 유지한다. 별도 친밀도·PSI·Dark Path 공식을 임의로 도입하지 않는다.

## 7. 현장을 기억하게 만드는 변화

장애물 정리 흔적, 통제선, 회수된 설비, 다음 팀의 동선 같은 소수 상태를 결과와 다음 작전에 연결한다. 전후 비교는 같은 시점·카메라로 보여주고 무의미한 장식 변화와 실제 결과를 구분한다.

다음 작전 변경은 사전 안내한다. 길을 정리했으면 우회로가 넓어지고, 재확인 사항이 남았으면 선택 목표가 이어진다. 한 번 실패했다는 이유로 다음 작전이 계속 어려워지는 누적 벌점은 두지 않는다. 다시 확인하면 기록을 갱신할 수 있어야 한다.

실패 기록에도 “무엇을 읽었고 다음에 어떻게 대응할지”를 담는다. 예: 돌진 예고를 본 시점, 막힌 우회로, 제동을 쓰지 못한 이유. 사용자를 훈계하거나 실제 업무 능력을 평가하는 문구는 쓰지 않는다.

## 8. 스토리·디펜스와의 연계 계약

슈팅에서 얻은 기록은 본편의 답이나 실제 증거를 자동 생성하지 않는다. 스토리에서는 관찰해야 할 위치·역할별 질문·참고 인계로 활용한다. 본편의 실제 증거 획득과 판단은 본편에서 수행한다.

디펜스에서는 확보한 동선·감시 사각을 배치 참고로 보여준다. 영구 공격력·난이도 보너스를 바로 지급하지 않는다. 실제 연결은 모드별 승인과 domain/engine 계약이 갖춰진 뒤 구현한다. 현재 준비중 프리뷰를 본편 출시로 표시하지 않는다.

공유 기록 초안: `recordVersion`, `characterId`, `stageId`, `objectiveId`, `securedRouteIds`, `controlledHazardKinds`, `unresolvedChecks`, `completionState`. 저장은 로컬 우선이며 기록 수 상한·중복 정산·버전 마이그레이션·재도전 갱신 규칙을 먼저 정한다. React UI는 기록을 읽고 보여주며 규칙을 소유하지 않는다.

모드 연결 선택의 5항목 검토:

| 항목 | 시범 작전 적용 |
|---|---|
| 안전 하한선 | 위험 반경과 노출 통제를 낮추지 않음 |
| 현장 진술 | 반장·철근 작업자의 동선 관찰을 듣고 확인 |
| 관계·공정 압박 | 다음 반입과 작업반 이동이 겹치는 상황 |
| 선택 비용 | 통로 정리에 시간·장비 선택 기회 사용 |
| 지연 결과 | 다음 팀 인계와 재확인 위치에 기록이 남음 |

## 9. 몰입을 지키는 화면·소리 규칙

전투 중 중앙 팝업을 늘리지 않는다. 무전은 가장자리 한 줄, 중요 위험은 현장 위치의 예고로 표시한다. 텍스트가 읽히는 동안 조작을 요구하지 않는 구간을 쓴다. 보급·설정·상세 기록을 열면 안전하게 정지한다.

성장 효과는 장비마다 발사 1차 실루엣, 재질 접점, 해소 잔상으로 구분한다. 경고 색과 보상 색을 구분하고, 혼잡 시 장식만 줄인다. 공격 판정·위험 예고를 화질 때문에 숨기지 않는다. 모바일에서는 버튼 도달 거리, 손가락 가림, 한 손 이동과 액션을 먼저 검수한다.

사운드는 정비소의 잠깐 잦아든 소리, 무전 시작음, 작업 종료의 짧은 음악처럼 상황을 기억시키는 동기를 만든다. 기존 음원 품질·권리·기기별 중첩을 검토한 뒤 연결한다. 불쾌한 경보를 보상 획득음처럼 반복하지 않는다. 효과 강도·동작 감소·음량은 기존 설정과 공유한다.

## 11. 검증할 질문과 측정

현장 경험자와 게임 초보를 나누어 소규모 관찰한다. 첫 플레이 뒤 “내 캐릭터가 누구였나, 오늘 무엇을 해결했나, 내 장비가 왜 도움이 됐나, 다음에는 무엇을 해보고 싶은가”를 묻는다. 다음 날에는 기억나는 사람·장면·행동을 확인한다. 이는 아직 수행하지 않은 검증 계획이다.

초안 합격 목표: 관찰 참여자의 80%가 역할과 목표를 설명하고, 70%가 실제 시너지 하나를 설명하며, 절반 이상이 다음에 시도할 조합이나 캐릭터를 자발적으로 말한다. 소표본 비율을 전체 사용자 효과로 일반화하지 않는다. 플레이 시간만으로 몰입을 판정하지 않는다.

경제는 첫 구매까지 작전 수, 실패 후 순수익, 수리비 비중, 보너스 대비 본편 보상 비율을 비교한다. 전투는 장비 선택 분포, 죽음 직전 예고 인지, 통로 정리 활용을 본다. 관측은 우선 동의한 로컬 테스트 기록으로 하고 새 외부 분석 백엔드를 도입하지 않는다.

기술 회귀: 일시정지 중 피해 없음, 저장 후 기록 복구, 중복 정산 방지, 보상 설명과 실제 효과 일치, 모바일 버튼·가림, 6명 장비/동작 공유, 낮은 화질의 경고 유지. 취향과 애착은 자동 테스트 통과로 대체하지 않는다.

## 12. Director 검토 항목

시범 작전의 정확한 기존 stage ID, 캐릭터 대사의 최종 말투, 인간형 위험 해소 표현, 보상 목표 수치, 본편/디펜스 연결 범위를 확정한다. 본 문서는 구현 가능한 초안과 검수 기준을 제공하며 아직 승인되지 않은 설정을 제품에 반영하지 않는다.

## 13. 인물 성장·진로 서사 확장 (2026-10-09)

스테이지별 후속은 [50개 구역·6명 성장 서사 연결](SURVIVORS-STAGE-CHARACTER-ARC-PLAN-V1.md)에서 기존5개 장과 인물별 관점을 대조한다. 첫 시범 stage_12는 제안이며 확정 stage ID가 아니다. 기존 요원별 기록과 본편3단계 원화 계약을 우선하며 별도 성장 시스템을 중복하지 않는다.

사용자는 여러 작전에서 어떻게 성장했는지에 따라 인물의 진로와 단계별 모습을 보여주는 육성 서사를 요청했다. 기존 직무와 정체성은 유지하면서 경험·판단·인계가 전문성 및 다음 역할로 이어지는 구조를 제안한다. 전투 레벨·장비 진화와 장기 인물 성장은 분리하며 추가 전투 조작이나 반복 접속 벌점을 만들지 않는다.

상세 명세는 [인물 성장·진로 서사 확장](SURVIVORS-CHARACTER-GROWTH-NARRATIVE-PLAN-V1.md) 참조. 기존 시범 작전에 대표 인물의 성장 사건 하나를 연결한 뒤 단계 이미지와 진로별 후일담을 검수한다. 6명 전체의 직업 트리·원화·새 저장 공식을 동시에 구현하지 않는다. 직업명·성장 임계치·대사·최종 원화는 검토 대기이며 Career/Dark Path/PSI 미확정 공식 및 Episode 01 제작 게이트를 유지한다.

## 14. 작전 흐름 구현 (2026-10-10)
