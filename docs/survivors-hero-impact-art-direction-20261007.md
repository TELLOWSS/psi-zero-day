# 주인공 몰입과 타격감 개선 기획

## 목표

주인공의 판단과 행동이 화면에서 읽혀야 한다. 발사 직후 몸이 반응하고, 실제 명중 위치에서 재질이 반응하며, 소리와 카메라가 같은 순간을 강조한다. 현장 안전관리자가 위험을 통제한다는 게임의 정체성과 위험 예고의 가독성을 유지한다.

## 이번 구현

1. **주인공의 행동**: 실제 발사 각도를 기록한다. 정지 중에는 명령을 내리는 방향을 바라보고, 이동 중에는 이동 방향과 발 접지를 유지한다. 반동은 발사 방향의 반대쪽으로 2.4px 이내 이동하고, 짧은 상체 기울기와 피격 압축을 장비에도 동일하게 적용한다.
2. **공격 원화**: 기존 인물의 얼굴, 안전모, 조끼, 작업복, 태블릿과 실루엣을 유지한 8방향 무전 명령 원화를 추가한다. 준비와 회복은 기존 자세로 연결하고, 행동 진행률 12~56%에서 새 명령 자세를 사용한다. 이동 중에는 보행을 보존한다.
3. **타격의 위계**: 일반 명중, 진화 무기, 치명타 순으로 충격을 구분한다. 같은 업데이트의 발사보다 확정된 강한 명중이 카메라 충격을 우선 소유한다. 거리가 멀어지면 충격이 줄어들고, 120~140ms 재발동 간격과 지수 감쇠로 연속 흔들림을 억제한다.
4. **광원과 실루엣**: 무기 색의 접촉광을 주인공의 실제 알파에만 합성한다. 주변 현장과 위험 예고에는 영향을 주지 않는다. 광량은 최대 24%, 짧게 감쇠하고 재사용 캔버스로 처리한다. 피격은 짧은 따뜻한 반사광과 몸의 압축으로 구분한다.
5. **밀도와 재질**: 가까운 명중 위치마다 하나의 강조 효과를 선택한다. 일반 화면은 6개, 혼잡 화면은 3개로 제한한다. 중복 치명타의 흰 코어와 금색 충격파를 제거하고 기존 무기 색과 금속·파편·증기의 최종 래스터 자산을 유지한다. 작업자 확인과 차단에는 전투 파편을 생성하지 않는다.
6. **소리**: 기존 녹음 자산을 우선 사용한다. 치명타 녹음은 5% 낮은 피치로 무게를 부여한다. 기존 절차적 보조음에는 짧은 저역 압력과 접촉음을 추가한다. 작업자 확인음과 발사음은 이 강조의 대상이 아니다.

## 최고 품질로 확장하는 제작 방법

- **캐릭터 원화 완성**: 같은 캐릭터 모델을 기준으로 8방향 보행·무전·분사·몸 보호·회피를 각각 8~12프레임 제작한다. 모델/리깅에서 렌더링한 일관된 원화는 AI 생성 프레임의 얼굴·손·장비 오차를 줄일 수 있다. 얼굴과 장비의 위치를 프레임별로 검수한다.
- **재질과 조명**: 캐릭터·장비의 노멀/방향별 조명 패스를 미리 렌더링하면 젖은 바닥, 안전모, 반사 조끼와 금속 장비의 광원 반응을 높일 수 있다. 추가 패스는 실제 모바일 비용을 측정한 후 도입한다.
- **주인공의 성격**: 위험 발견, 통제 성공, 보호구 소진, 보스 대응에 맥락에 맞는 짧은 연기와 무전을 제작한다. 같은 대사를 반복하지 않고 빈도와 우선순위를 관리한다. 새 대사·성우 녹음·표정 연기는 별도 콘텐츠와 음성 제작이 필요하다.
- **강한 순간의 연출**: 보스의 실제 무력화나 위험 통제 완료에 한정해 짧은 회복 자세와 음향 여백을 배치한다. 매 타격마다 화면 전체를 번쩍이거나 컷인을 반복하지 않는다. 실제 플레이 결과가 확인된 이벤트를 기준으로 설계한다.
- **플랫폼 품질**: PC에서는 선명한 고해상도 원화와 재질 효과를 유지하고, 모바일에서는 같은 핵심 자세·접촉광을 유지하며 주변 파편 수와 중복 효과를 줄인다. 물리 Android 기기의 프레임 시간, 발열, 메모리를 별도 측정한다.

## 품질 판정

실제 게임 플레이에서 주인공과 위험 예고가 동시에 식별되어야 한다. PC, 모바일 세로·가로에서 원화의 방향과 접지, 공격·피격의 반응, 효과 밀도를 확인한다. 일시정지는 같은 프레임을 유지하고, 모션 감소는 카메라 충격과 접촉광을 제거한다. 전체 테스트, 타입 검사, 빌드와 브라우저 캔버스 검증을 완료한다.

## 브라우저 검증 결과

1440x900, 390x844, 844x390에서 8방향 명령 자세가 모두 구분되고 접촉광의 알파 외부 유출은 0이었다. 실제 게임의 발사·명중 이벤트와 일시정지 프레임 고정을 확인했다. 장비 미리보기는 추가로 667x375와 568x320까지 보행·공격·모션 감소·비활성 정지·저장 상태 유지·가로 넘침 없음 검증을 통과했다. 이는 브라우저 기술 검증이며 물리 모바일 성능과 최종 미술 승인을 대체하지 않는다.

## 자산 출처

새 원화는 내장 이미지 생성 도구로 기존 `player-walk-eight-v1.png`와 `player-command-v2.png`를 참조해 제작한다. 최종 프롬프트는 기존 여성 안전관리자의 인물·복장을 고정하고, 2열 4행의 동일 크기 셀에 동·남동·남·남서·서·북서·북·북동 방향의 무전 명령 자세를 요청했다. 배경은 실제 투명 알파이며, 전신·안전모·부츠가 셀 안에 들어가도록 요청했다. 원화의 기술 검증은 최종 미술 승인과 구분한다.
