# 시그널 브레이커 게임성 확인검증·개선

2026-10-13 / `0.53.0-gameplay` / 이전 배포 `898b6e80`

최신 종합 기획서 v4.5와 기존 10개 작전을 기준으로 선택의 의미, 재도전 학습, 진행 안내, 저장 복원을 검증했다. 기존 그래픽 개선은 [그래픽 검증 기록](SIGNAL-BREAKER-GRAPHICS-AUDIT-20261013.md)에 정리되어 있다. 구매 가격·판매 플랫폼은 미정이며 결제는 연결하지 않았다.

## 발견·구현

| 문제 | 구현·검증 |
|---|---|
| EP01 연속 작전이 첫 튜닝을 자동 적용하여 선택을 건너뜀 | 신규 작전 기본값을 직접 선택으로 변경. 연속 작전의 보급·전투 규칙을 보존하면서 구간 사이에 기존 후보를 선택. 준비/일시정지 설정에서 자동 선택을 켤 수 있음 |
| 저장된 선택을 재접속 시 자동으로 건너뛸 가능성 | 체크포인트에 자동 선택 여부 저장·검증. 직접 선택은 같은 후보를 복원. 이전 버전 체크포인트는 기존 자동 진행 유지 |
| EP02 모든 구역의 초기 프레임이 전격으로 고정 | 기존 재질 대응에 맞춰 CH-03은 전격, 나머지는 레이저 권장. 준비 화면에 추천 이유를 안내하고 다른 프레임 선택 유지 |
| 장갑/보스 HP를 줄이는 중에도 정체 안내 가능 | 보스 HP·설비 단계·장갑 합계·발생원 처리 진행을 정체 판정에 포함. 실제 6초 정체 시 이동 안내 유지 |
| 제한시간 실패 직전 예고 부족 | EP02 구간 남은 8초에 한 번 안내. 튜닝 중 시간 정지, 기존 제한시간 수식 유지 |
| 실패 후 단계 공통 조언만 보여 직접 피격 원인 학습 부족 | 5개 설비 공격의 실제 피격 원인을 기록하고 회피/보조 장비 안내 연결. 무적 중 공격은 원인 기록을 덮지 않음. 제한시간 실패에는 이전 피격 조언보다 기존 진화/잔여 신호 조언 우선 |
| 수동 장비 선택으로 자동 전환이 꺼져도 이유 불명확 | OFF 상태와 일시정지 설정에서 다시 켜는 방법 안내 |

체력·보스 HP·보상량·제한시간·기존 진화 조건을 조정하지 않았다. `lastDamage`는 현재 시도의 진단 정보이며 구간 체크포인트에 과거 피격 기록을 추가하지 않는다. 재시작·복원 시 초기화된다.

## 재현 가능한 검증

- 엔진 테스트 262개 통과. 신규 8개는 실제 첫 구간 완료 후 선택, 구간 시간 정지, 체크포인트 호환/오염 거부, 자동 선택, 진행 판정, 피격 원인, 제한시간 경고, 권장 프레임을 검사한다. 보스 HP/장갑/마감 시각을 배치한 일부 단위 테스트는 진단 fixture이며 전투 승률 근거가 아니다.
- EP01 실제 입력 100회: 5개 작전 × 5개 시드 × 자동/첫/중간/마지막 후보. 100회 완료, 실패 0, 상한 도달 0. 실제 후보만 선택하며 강제 완료·생명 보충·임의 최대 특성 없음.
- EP02 실제 입력 45회: 잘못 맞춘 프레임 0/15 완료, 맞춘 프레임 10/15 완료, 진화 적용 15/15 완료. 구역 재질과 진화가 결과에 영향을 주는 기존 규칙 확인. 동일 조작 정책의 결과이므로 사람의 난이도·선택 가치 평가로 해석하지 않는다.
- 신규 계정 12개: 초기 5P와 가이드 3P, 실제 획득 보상만으로 10개 작전을 완료. 총 142회 시도 중 완료 120, 실패 16, 360초 상한 도달 6. 같은 시드 최대 3회 재도전. 상한 6회는 정지형 정책의 CH-03이며 이동을 포함한 재도전으로 완료했다.
- 브라우저 360×640, 844×390, 1440×900: 실제 첫 구간 완료, 선택 중 시간 정지, 새로고침 후 같은 후보 복원, 마지막 후보 적용·다음 구간 진입. 별도 실제 설정 클릭으로 자동 진행 확인. 스크린샷을 열어 세로 선택 화면을 검토했다.
- 전체 캠페인 브라우저 검사: 세 방향에서 10개 작전의 실제 입력, 엔딩 후 보상, 강화·소켓, EP02 전환, 저장·재접속·엔딩 아카이브를 검사한다. 최종 실행 결과는 `docs/qa/signal-breaker-gameplay-20261013.json` 참고.
- root 테스트·타입 검사·빌드·배포 자산 검사 결과도 같은 JSON에 기록한다. 시뮬레이션 상세 로그/스크린샷은 로컬 `artifacts/gameplay-*`에 보존한다.

## 남은 사람의 검증·기획 판단

1. 실제 초보 플레이어가 튜닝 차이를 이해하고 보스 경고를 학습하는지, 10개 작전의 반복감과 재미를 평가해야 한다. 자동 입력 성공은 구매 전환·리텐션의 증거가 아니다.
2. 기획의 일반 구간 60–75초, 보스 90–120초와 현재 웨이브/작전 단위의 관계는 Director 확인이 필요하다. 단순 HP 증가로 시간을 채우지 않았다.
3. 현재 재도전에서도 완료 웨이브 1P 보상은 기존 규칙대로 지급된다. 같은 웨이브 보상의 중복 금지 여부는 기존 기획이 불명확하므로 보상 경제를 임의 변경하지 않았다. 특성 총 상한 31P 유지.
4. 실제 Android/iOS 기기의 프레임 시간·발열·터치 손가락 가림은 물리 기기 검증이 남는다. 브라우저 viewport 검사는 기기 FPS 측정이 아니다.
5. 가격·유료 제공 범위·판매 플랫폼 결정과 사람의 구매 가치 평가가 남는다. 현재 작업으로 첫 결제 발생을 주장하지 않는다.
