# 안전모 원근 및 현장 화면 고도화

## 원인과 변경

메인 v6의 안전모 인쇄는 글자·방패가 넓고 정면을 향해 보여 기울어진 인물과 안전모의 곡면에 맞지 않았다. 가로·세로 두 원화를 각각 편집해 인쇄 크기를 줄이고 방패 축과 글자 기준선을 안전모 패널/챙의 기울기에 맞췄다. 먼 쪽은 원근에 따라 좁아지고 곡면의 명암을 따르도록 요청했다. v6 파일은 보존하고 v7로 연결한다. 각도·곡면 적합성은 확대 육안 검토 대상으로, 픽셀 해시만으로 검증했다고 판정하지 않는다.

현장·공정 화면은 평면 전투 바닥을 대표 이미지로 사용해 현장의 크기와 공종을 충분히 보여주지 못했다. 신축(기초·골조·반입), 기존 구조 리모델링(임시지지·접합), 데이터센터(설비·전원·시운전)의 시네마틱 원화 3종을 새로 제작해 10개 프로필의 유형별 카드와 상세 이미지에 연결했다. 장면은 현장 분위기 원화이고 실제 배치와 구별된다. 연결된 순찰 바닥은 별도의 ‘실제 순찰 배치 도면’으로 열어 확인한다. 순찰 해금과 대표 디펜스의 선행조건은 유지한다.

## 현장도감

- 메인과 같은 재질·조명 계열의 신축 현장 배너, 공정 탭, 검색과 결과 수를 배치한다. 설명서 버튼을 헤더 안으로 옮겨 도감 그리드의 잘못된 셀 배치를 해소한다.
- PC는 목록/상세 2열, 모바일 세로는 가로 품목 목록/큰 상세 원화로 읽는다. 작은 가로 화면은 페이지 스크롤을 허용해 설명과 버튼에 도달할 수 있게 한다.
- FG 번호·품목명·관찰 포인트로 전체 공정을 검색한다. 결과가 없을 때는 이전 품목을 계속 표시하지 않는다.
- 기본 원화를 크게 표시하며 ‘원화 크게 보기’는 브라우저 modal dialog를 사용한다. 초점 유지, Escape 닫기와 원래 버튼으로의 초점 복귀를 검증한다. 목록 이미지는 지연 로딩한다.
- 118개 항목을 파일 실사한 결과, 기존 연결은 실물 원화 **57개**, 기존 벡터 도해 **61개**다. 존재하지 않는 계획 경로를 이미지로 요청하지 않으며 기존 도해와 관찰/근거 텍스트를 유지한다. 61개 항목을 새 실물 원화로 제작했다고 보고하지 않는다. 이번 신규 제작은 안전모 2종 보정과 현장 장면 3종이다.
- 기존 UI의 ‘계도력 +15%’ 효과 문구는 구현 근거가 확인되지 않아 관찰 포인트 설명으로 교체했다. 게임 수치나 법적 근거 원문을 바꾸지 않는다.

## 자산·검증

생성 도구: built-in image_gen. 정확한 프롬프트는 `branding/FIELD-STUDIO-PROMPTS-20261017.json`, 원화는 `public/assets/branding/home-new-psi-v7` 및 `public/assets/field-studio-v1`, 크기·파일 해시는 각 런타임 manifest에 기록한다. 원본 PNG는 생성 도구 저장 위치에 보존한다. WebP 변환 외 합성은 하지 않는다.

회귀 테스트, 타입 검사, 프로덕션 빌드와 실제 브라우저에서 검색·공정 전환·57개 이미지 디코딩·61개 도해 유지·모달 확대/닫기·초점 복귀·모바일 넘침·10개 현장 프로필 이미지 및 진입을 확인한다. Android 실기기, 사람의 미술 평가, 61개 도해의 개별 실물 원화 제작은 자동 실행 검증과 구별되는 후속 제작/평가 범위다.

실행 결과: 전체 테스트 2,204 통과 / 1 skip, 이후 검색창 접근성 이름 보정 관련 2개 후속 검사 통과. 타입 검사·정규 빌드·최종 번들 통과. 메인 7개 해상도, 도감 5개 해상도, 현장·공정 3개 해상도 × 10개 프로필 실행 통과. 큰 청크 경고는 기존대로 남는다. 도감의 법적 근거 텍스트는 이 그래픽 작업에서 재검토하거나 갱신하지 않았다.

확대 비교는 `docs/qa/helmet-perspective-20261017`의 가로/세로 before-after 이미지다. 왼쪽 v6, 오른쪽 v7이며 동일 위치를 잘라 비교했다. 제품 이미지 편집은 image_gen, 이 비교본은 육안 검토용 크롭이다.
