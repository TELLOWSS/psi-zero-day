# PSI RPG 원화 적용 1차

기획서 G0A의 기존 화면 적용부터 진행한다. 진입 키아트, 작전 로비의 현장 운영실 배경, 장비실 연구 작업대 배경, 크레딧 영역 협업 메달을 원본 이미지로 연결한다. 텍스트와 조작 요소는 DOM으로 유지한다. 현재 장비실의 장비 구매 기능에 연구 배경을 적용하며, 영구 연구 기능이 구현되었다고 표시하지 않는다.

원본 PNG는 생성된 최종 후보를 그대로 사용한다. 장비실 이미지는 화면을 열 때 로딩되고 오프라인 설치 캐시에 포함한다. 원본 크기 최적화와 미술 최종 검토는 후속 항목이다. 전투 배경과 투사체, 충돌, 성장 수치에는 변화가 없다.

후속 순서: 저장 계약 → 조작원 성장 → 영구 무기 연구 → Signal Watch 검증 기록 연계. 신규 성장 기능의 완료 여부는 실제 구현 및 테스트 결과로 기록한다.
