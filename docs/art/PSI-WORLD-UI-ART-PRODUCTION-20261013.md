# PSI 세계관 원화와 UI UX 이미지 제작 계획

2026년 10월 13일 | 전체 RPG 기획의 필수 제작 항목 | PR 204 연계

## 1 제작 목표

게임 화면을 읽는 동안에도 NEW PSI 현장 안에 있다는 감각을 유지한다. 원화는 세계·사람·공정의 변화와 캐릭터 성장을 전달하고 UI 이미지는 관측·연구·대응이라는 역할을 구분한다. 기지, 연구, 정비, 전투, 엔딩이 같은 소재와 광원 언어를 공유해야 한다. 최종 원화를 실제 화면에 연결하는 것을 완료 기준으로 삼고 임시 도형이나 콘셉트 이미지를 적용 완료로 계산하지 않는다.

## 2 공통 미술 기준

- PSI의 현대 한국 건설현장, NEW-PSI ZERO SITE 01, 사람의 제보와 사고 전 신호를 중심으로 한다.
- 콘크리트·아연도금 강재·보호 케이블·회로·관측 장비의 실제 소재를 사용한다. 네이비·그래파이트·절제된 청록 신호와 황색 작업등을 연결한다.
- 사람의 피부·작업복·안전모는 기존 승인 원화의 얼굴과 비율을 유지한다. 새 원화에서 타 인물로 바꾸지 않는다.
- 위협은 위험 신호다. 인물을 공격 대상으로 표현하지 않고 군사 시설·마법 성채·재난 폭발을 기본 세계 이미지로 쓰지 않는다.
- 공정·계절·기상별 원화 변형은 확정한 게임 상태와 일치시킨다. 날씨 그림만 바꾸어 실제 위험 변화가 구현된 것처럼 표시하지 않는다.
- 위험과 사선의 대비가 배경보다 높아야 한다. 시네마틱 밀도는 가장자리·원경에 배치하고 핵심 입력과 HUD 뒤는 복잡도를 줄인다.
- 타 게임·브랜드·작가를 모방하는 프롬프트, 무단 사진·음원·캐릭터 참조를 사용하지 않는다. 사용권·시각 품질·실행 검증을 별도로 기록한다.

## 3 전체 화면별 자산 목록

| 화면 또는 대상 | 필수 원화 | UI UX의 목적 | 처리 상태 |
|---|---|---|---|
| 세계관 진입 | 현장 전체 키아트, 가로·세로 대응 | 사람과 공정이 성장하는 장소의 첫 인상 | 1차 가로 원화 제작 |
| 공통 기지 | 현장 조정실, 외부 현장 연결 배경 | 이어하기·다음 작전·성장 진입 | 1차 가로 원화 제작 |
| 무기 연구 | 연구 작업대, 프레임·부품 상세 원화 | 영구 연구와 작전 진화의 차이 | 1차 연구실 배경 제작 |
| 캐릭터 성장 | PLAYER 성장 단계의 장비·작업복 변형 | 얼굴을 유지한 성장의 체감 | 승인 원화 참조 후 별도 제작 |
| 동료와 기록 | 기존 인물의 대화·제보·회복 표정 | 관계와 현장 결과의 감정 | 기존 자산 대조 후 필요 컷 제작 |
| 능력 트리 | 관측·협업·경로 제어 9개 기능 아이콘 | 이름과 기능을 시각적으로 연결 | 기존 아이콘과 중복 확인 후 제작 |
| 연구·정비 카드 | 산업용 카드·노드·선택·잠금 부품 | 경로·선행 조건·현재 선택 판독 | 1차 UI 부품 아틀라스 제작 |
| 장비 상세 | 8개 도구와 4개 조합의 부품 이미지 | 장비 역할과 조합의 물리적 차이 | 기존 장비·발사체 원화 우선 재사용 |
| 전투 | 5개 현장과 상태 변화, 보스·손상 단계 | 발생원과 조치 결과를 공간에 표현 | 기존 원화·부품 애니메이션 고도화 |
| 워치 연계 | 같은 현장의 관측·대응 상태 이미지 | 같은 사건임을 인식하고 확인 상태 구분 | 사건 ID와 공정 매핑 후 제작 |
| 엔딩 | 5개 현장 회복 컷과 인물 반응 | 사람·현장·기록으로 클리어 보상 표현 | 기존 회복 원화 검토 후 보강 |
| 상점 | 외형 상품의 실제 적용 미리보기 | 구매 전 모습·효과·제약 확인 | 상품 확정 후 실 화면 기반 제작 |
| 스토어·홍보 | 키아트·아이콘·대표 장면 | 작품의 실제 경험과 브랜드 전달 | 상용 권리·상표 확인 후 별도 납품 |

신규 자산 수는 기존 원화의 재사용·수정·교체 판정 후 확정한다. 현재 4종을 전체 라이브러리 완료로 계산하지 않는다. 같은 사건·인물·현장의 정체성이 이어지도록 자산 ID와 상태 변형을 묶어 관리한다.

## 4 1차 제작물

| ID | 용도 | 화면 규칙 | 현재 납품 범위 |
|---|---|---|---|
| PSI-WORLD-01 | 세계관 진입과 대표 장면 | 16:9, 중앙 인터페이스 여유, 공정과 동선 | 독립 생성 가로 원화 |
| PSI-BASE-01 | 공통 기지 | 현장 밖 공정이 보이는 조정실, UI용 저대비 공간 | 독립 생성 가로 원화 |
| PSI-LAB-01 | 무기 영구 연구 | 실제 부품·작업대의 질감, 노드 배경 공간 | 독립 생성 가로 원화 |
| PSI-UI-PARTS-01 | 카드·선택·능력 노드 장식 | 실제 투명도, 문구 없는 부품, 기능별 실루엣 | 3×2 부품 아틀라스 |

새 배경을 기존 전투에 강제로 덮어쓰지 않는다. WORLD는 진입, BASE는 신규 기지, LAB은 신규 연구 화면의 슬롯에 연결한다. UI 부품은 숫자·글자·잠금 이유를 대신하지 않으며 실제 버튼은 접근 가능한 입력 영역을 갖는다.

## 5 인터페이스 적용 규칙

가로 기지의 주요 행동 영역 뒤는 저대비 공간을 사용한다. 연구 화면은 노드와 연결선을 DOM 또는 코드로 배치하고 원화는 공간과 소재를 전달한다. 모바일 세로는 핵심 현장이나 장비가 잘리지 않도록 별도의 구도 또는 검증한 크롭을 납품한다. 단순 확대와 잘라내기로 현장 맥락을 없애지 않는다.

이미지에 명칭, 수치, 가격, 연구 조건, 버튼 글자를 구워 넣지 않는다. 동일 폰트 체계와 로컬라이제이션 ID를 유지한다. UI 프레임은 9-slice 적용 가능 영역을 측정하고 카드 높이는 내용에 따라 늘어난다. 장식의 크기와 클릭 영역은 분리하고 모바일 입력은 44px 이상으로 유지한다.

선택·잠금·비활성은 테두리·아이콘·텍스트를 함께 사용한다. 배경 전체와 대형 구조물을 반복 이동시키지 않는다. 충돌과 무관한 원경 레이어의 작은 움직임과 신호 광원만 사용하고 UI 내용과 전투 판정은 흔들리지 않게 한다. 움직임 감소에서는 불필요한 패럴랙스·진동·번쩍임을 끈다. 색약·저품질 설정에서도 위험 유형·약점·사선은 남긴다.

## 6 제작과 납품 구조

원본, 런타임 WebP 또는 PNG, 크롭·슬라이스 메타데이터, 실제 프롬프트, 제작일과 도구, 해시, 사용권 증빙, 미술 승인, 화면 슬롯을 묶는다. 배경은 원본 비율을 유지하고 투명 부품은 알파를 보존한다. 변경은 새 버전 파일로 저장하며 승인 자산을 덮어쓰지 않는다.

배경은 기기별 리사이즈와 WebP 변환 후 검수하며 1장당 200~900KB를 최초 최적화 목표로 둔다. 품질을 해치는 고정 용량 제한으로 사용하지 않는다. 현재 화면의 이미지부터 로드·디코딩하고 다음 화면은 유휴 시간에 준비하여 메뉴 진입을 막지 않는다.

이미지의 일관성 확인 → 가로·세로 구성 → 원화 제작 → 작은 화면 검토 → 런타임 변환 → 화면 연결 → 오프라인 캐시 → 실기기 검증 순으로 진행한다. 파일을 만들었다는 사실과 운영 화면 적용을 구분한다. 권리 미확정 자산은 확인 또는 독립 제작 교체를 완료한 뒤 상용 납품한다.

## 7 완료 기준

- 세계관 키아트·기지·연구·성장·전투·엔딩이 같은 PSI 작품으로 읽힌다.
- 공식 인물의 얼굴·역할·장비가 유지되고 성장의 차이가 명확하다.
- 이미지 뒤의 한국어·수치·노드·사선이 PC와 모바일에서 읽힌다.
- 위험과 발생원, 조치 후 정지 상태, 손상 단계가 구별된다.
- 이미지 로딩과 디코딩이 끝난 뒤 연출 시계가 시작되고 오프라인에서도 유지된다.
- 원화·폰트·코드·음향의 상용 이용 근거가 자산별로 남는다.
- 기술 검증과 Director 미술 판정을 모두 기록한 뒤 실제 적용 완료로 표시한다.

## 8 현재 실행 범위와 환경 제한

1차는 원화 4종과 전체 제작 계획을 만든다. 생성 이미지는 최종 자산 후보이며 가로·세로 크롭, 9-slice, WebP 변환, 오프라인 캐시, 실 화면 연결은 런타임 환경이 연결된 뒤 검증한다. 로컬 실행 환경의 연결이 끊긴 상태이므로 현재 단계에서 게임 적용이나 Vercel 배포 완료를 주장하지 않는다.

## 9 1차 납품 파일과 확인 결과

- PSI-WORLD-01: `public/signal-breaker-dev/art/psi-rpg-world-v1.png`, 1672×941 PNG, 2844052 bytes.
- PSI-BASE-01: `public/signal-breaker-dev/art/psi-rpg-base-v1.png`, 1672×940 PNG, 2351646 bytes.
- PSI-LAB-01: `public/signal-breaker-dev/art/psi-rpg-lab-v1.png`, 1672×941 PNG, 2149849 bytes.
- PSI-UI-PARTS-01: `public/signal-breaker-dev/art/psi-rpg-ui-parts-v1.png`, 1536×1024 PNG, 2345439 bytes.

UI 아틀라스는 1536×1024 RGBA, 3×2 구성이다. PNG 픽셀을 디코딩해 투명 픽셀 868,545개(55.22%), 바깥 모서리와 상단 카드 3개 중심의 alpha 0을 확인했다. 9-slice 경계와 가로·세로 실 화면은 별도 검증한다. 배경 3종의 장면·구도·PSI 소재와 UI 6부품을 시각 확인했다. 기존 캐릭터와 전투 엔진을 변경하지 않았다.

실제 프롬프트와 생성·보정 이력은 [원화 제작 기록](PSI-WORLD-UI-ART-PROMPTS-20261013.md)에 남긴다. 전체 라이브러리·게임 연결·Vercel 운영 적용 완료로 계산하지 않는다.
