# 메인화면 그래픽 개선 — 2026-10-16

## 표시 정리

시그널 워치·가드의 LIVE와 브레이커의 PLAY는 고정 문자열이며 서버 접속, 실시간 인원, 업데이트, 진행도와 연결되지 않았다. 세 카드에서 제거했고 사용하지 않는 PLAY 번역 키도 정리했다. 숨겨진 기존 현장 미리보기의 LIVE SITE 표시는 실제 기능인 현장 미리보기 이름으로 바꿨다. 스토리의 준비중 표시는 이용 가능 여부를 정확히 알리므로 유지했다.

## 그래픽과 화면 구성

내장 **image_gen**으로 메인화면 전용 최종 후보 이미지를 제작했다. 어두운 야간 배경에서, 빗물에 젖은 새벽 현장·크레인·도시 전경과 현장을 바라보는 안전관리자가 보이는 장면으로 교체했다. 새 인물의 설정·이름·서사를 추가하지 않았다. 로고·텍스트·버튼은 실제 UI로 합성하고 이미지에 새겨 넣지 않았다.

- 최종 자산: [site-at-dawn.png](../public/assets/branding/home-v2/site-at-dawn.png), 1672×941, 2,658,971 bytes. 생성 원본을 그대로 복사했다.
- 생성 방식과 최종 프롬프트 전문: [hub-key-art-prompt-20261016.json](./hub-key-art-prompt-20261016.json). CLI/API 대체 경로는 사용하지 않았다.
- PC는 네 게임을 같은 크기의 커버 카드로 배치해 개별 그래픽을 크게 보여준다. 각 장비 게임의 기존 최종 이미지를 재사용하고 제목·설명·화살표·음영을 통일했다.
- 모바일 세로는 장면의 안전관리자가 보이도록 배경의 초점을 조정하고, 카드 우측 이미지를 보존한 한 열 목록으로 표시한다. 중간 너비와 가로 모바일은 두 열로 표시한다.
- 오늘도 무사히 제목을 별도로 드러내고 기존 NEW PSI : ZERO DAY 워드마크와 메시지를 유지했다. 기록·동료·도감·설정·음악 기능은 보존했다.
- 배경의 자동 확대와 오래된 스캔·입자 장식을 꺼서 화면이 안정적으로 보이게 했다. 카드 이동·확대는 움직임 감소 설정과 사용자의 연출 OFF를 존중한다.
- 상단 메뉴 버튼과 음악 버튼의 터치 영역을 최소 44px로 맞췄다.
