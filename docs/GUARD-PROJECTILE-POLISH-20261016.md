# 시그널가드 발사체 그래픽 개선 — 2026-10-16

## 확인한 문제와 적용

기존 네 무기는 경로 전체를 긋는 선, 작은 원형 탄환, 같은 원형 명중·별 모양 파편에 의존했다. 무기의 재질·질량·발사 방식 구분이 약하고 큰 원형 피격 표시가 적을 덮었다. 동적으로 추가되는 SVG 발사 애니메이션은 문서의 시작 시간에 묶여 실제 발사 때 재생되지 않는 경우도 확인했다.

- PULSE: 금속 탄체와 황금색 잔광, 짧은 충돌 파편.
- BURST: 무거운 주황색 탄체, 화면 위쪽으로 솟는 곡사, 폭발 파편과 낮게 퍼지는 잔연.
- CONTROL: 청록색 에너지 탄체, 전기성 충돌과 느리게 사라지는 잔광.
- SENSOR: 가늘고 빠른 보라색 광학 탄체와 작은 정밀 명중 효과.

네 장비 모두 발사광 → 이동 탄체 → 명중 → 잔광을 분리했다. 투명 PNG의 재질·입자 디테일을 사용하며, 기존 경로 전체의 선과 원형 탄환을 시그널가드에서 교체했다. 기본 원형 피격 표시를 제거하고 적의 밝기 변화를 낮춰 재질 효과와 겹치지 않게 했다. SVG 이동은 각 발사체가 실제 DOM에 추가될 때 시작한다.

## 전투 의미와 모바일 표시량

엔진의 실제 발사·명중 이벤트, 타격 좌표, 피해량, 해결 여부를 읽는다. 지연 공격은 발사 때 가짜 피해·명중을 표시하지 않고 IMPACT 이벤트에서 표시한다. 실제 IMPACT에서 발사광을 다시 재생하지 않는다. 관통 공격은 마지막 실제 피격 대상까지 이동한다. WAVE는 기존 엔진의 실제 진행 반경 표현을 유지한다. 피해 계산·판정·저장 구조는 바꾸지 않았다.

동시 그룹 24, 이동 탄체 12, 발사광 8, 명중 재질 12, 해결 아틀라스 4, 피해 숫자 8을 상한으로 둔다. 보스와 주 대상의 명중을 우선한다. 효과는 최대 650ms 뒤 제거하고 일시정지·화면 숨김 때 정리한다. 움직임 감소 설정에서는 이동·발사광·잔연을 숨기고 절제한 정적 명중과 숫자를 남긴다. 첫 발사 전에 전투 준비 화면에서 자산을 미리 디코딩한다.
