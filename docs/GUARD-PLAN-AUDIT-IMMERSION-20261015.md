# 시그널 가드 — 기획 구현 감사와 전장·타격감 고도화

## 판단

P0/P1/P2의 6작전·6인 기본 능력·24장비 상태는 구현되어 있지만, 이전 상태를 기획 전체의 완성으로 볼 수는 없었다. 이번에는 현 제작 범위에서 누락된 표현·진화 선택·시연·전장 가독성을 보완했다. 12작전 전체, P3 매듭 보스, 동료 개인 특화, 최종 미술·실기 승인은 여전히 후속 범위다.

## 확인된 결함과 수정

이전 L4 몸체는 128px로 표시하면서 발사 원점은 108px를 가정해 몸체와 빛의 시작이 어긋날 수 있었다. L4 원점 목록도 없어 공통 좌표로 처리됐다. 이제 24상태가 각각 보정된 좌표를 사용한다. 착탄 프레임의 발사 섬광/여행 탄환, 복수 경로의 잘못된 보조선, 진행 파동의 전체 반경을 접촉 위치에 다시 그리는 표시도 수정했다.

효과 그룹의 정리 타이머가 새 공격마다 갱신되어 이전 그룹이 오래 남을 수 있었다. 이제 그룹별 유효시간을 관리한다. 피해 숫자는 실제 접촉을 근거로 최대8개만 표시한다. 도크를 열고 닫거나 효과가 사라지는 과정에서 엔진 틱·피해·자원·쿨다운을 바꾸지 않는다.

## 검증

- 전체 회귀 **2,143 통과 / 기존 1 건너뛰기**, TypeScript 검사·전체 배포 빌드 통과.
- 기존 정상 구매 기반 18개 지하×동료 완주와 36개 기초×추천 방향×동료 검사가 유지된다.
- 신규 **8최종×6동료=48개 실험실 조합**은 실제 구매·진화·지원 명령, 저장 복원 후 같은 프레임 결과, 정지 불변을 검사했다. 이를 48개 정규 캠페인 완주나 사람의 재미 검수로 표현하지 않는다.
- L4 4계열×5편성×A/B를 같은 조건에서 비교. 확인/제어 시간은 여러 대상에 대한 합계이므로 전투의 실제 경과시간이나 새 버프가 아니다.
- PC·세로·가로의 지하 3작전씩 **9회 실제 UI 완주**. 결과 보호막은 각 프로필에서 GD-04 13 / GD-05 14 / GD-06 20으로 기존과 일치했다.
- 1440×900 PC 전장 면적은 기존 기준 화면 약41%에서 **67.97%**, 390×844 세로는 **72.35%**로 확대. 짧은 가로는 상하 도크 대신 측면 조작으로 추가 조정했다.
- 5개 크기(1440×900, 390×844, 844×390, 320×568, 568×320)에서 무료 미리보기·취소·명시 확정·자원 부족 차단·L4 시연의 실제 저장 payload 불변을 검증.
- 모든 완주 프로필에서 가로 넘침·페이지 오류 없음. SVG 패드/HTML 터치 중심 오차는 2px 이내.
- 개발 서버의 자동 갱신과 준비 단계의 비동기 저장 revision을 기능 변경으로 오인하지 않도록 고정 빌드와 실제 저장 payload로 재검증했다.

재현 명령: `npm test`, `npm run typecheck`, `npm run build`. 브라우저: `scripts/play-guard-immersion.cjs`, `scripts/check-guard-immersion.cjs`. 로그는 `artifacts/guard-immersion-final-{tests,build}.log`, 화면·요약은 `docs/qa/guard-immersion-20261015/`.

## 남은 제작/Director 검수

P3 6작전과 매듭 보스/최종 결말, 후속 개인 특화는 별도 제작 범위다. 현재 자료의 역사적 기획 스냅샷을 런타임 완료 목록으로 사용하지 않는다. 기존 최종 후보 자산과 공급 음원을 기반으로 개선했으며, 새로운 최종 원화·녹음음원·상업 이용 권리·사람의 최종 승인을 추가 취득했다고 보고하지 않는다. 실제 Android 성능·20분 발열/메모리·이어폰/스피커 청취·초보자 플레이 관찰은 남아 있다.
