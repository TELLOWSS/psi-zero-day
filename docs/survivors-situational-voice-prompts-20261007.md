# 시그널 워치 상황별 음성 제작 기획과 프롬프트

상태: **제작 제안 / Director 청취 승인 전 / 런타임 미연결**. 아래 대사는 기존 설정을 바꾸는 확정 콘텐츠가 아니다. 먼저 P0 12개를 제작해 모바일 스피커에서 청취하고, 같은 화자 프로필로 P1을 확장한다. 현재 승인된 `director-shout-voice-v1.mp3`와 본편 voice lock은 그대로 유지한다.

## 연기 방향

주인공 `player`는 현장 안전관리자다. 침착하고 관찰력이 있으며, 위험 순간에도 알아들을 수 있게 짧게 말한다. 동료를 꾸짖거나 적으로 취급하지 않는다. 싸움의 승리보다 위험을 읽고 사람을 지켰다는 보람이 중심이다. 얼굴 원화와 어울리는 성인 여성 중음역을 **제안**하되, 최종 목소리·연령감은 Director가 승인한다. 과장된 애니메이션 고음, 상시 고함, 성우/유명인 모사, 기존 인물 목소리의 무단 복제는 사용하지 않는다.

## 생성 도구 공통 프롬프트

아래 공통 프롬프트 뒤에 각 작업 카드의 지시를 붙인다. 한 번에 한 파일만 생성한다. A/B는 각각 독립 파일이며 같은 화자를 고정한다. 도구가 화자 ID/시드를 지원하면 첫 승인 파일의 ID를 이후 모든 작업에 유지한다.

```text
한국어 게임 캐릭터의 단일 음성 대사를 생성한다. 화자는 현장 안전관리자인 성인 여성이다. 안정적인 중음역, 명확한 한국어 발음, 단정하고 자연스러운 현장 무전 말투. 같은 화자의 음색을 모든 파일에서 유지한다. 본문 대사만 정확히 한 번 읽는다. 지시문, 파일명, A/B 표시는 읽지 않는다. 설명, 음악, 효과음, 무전 잡음, 반향, 다른 화자, 임의의 문장 추가는 금지한다. 원본은 깨끗한 dry voice로 출력한다. 문장 시작과 끝을 자르지 말고 앞 0.10초, 뒤 0.20초의 짧은 무음을 둔다. 과도한 숨소리나 웃음은 넣지 않는다. 실제 인물이나 유명 성우의 목소리를 모사하지 않는다.
```

## P0: 먼저 제작할 12개

### 01. 작전 시작: A/B 각 1개

```text
파일: PSI_V_PLAYER_START_A_v01.wav
연기: 침착한 준비 완료. 결의는 있지만 과장하지 않는다. 1.4~2.2초.
대사: 현장 확인. 안전 동선부터 확보합니다.
```

```text
파일: PSI_V_PLAYER_START_B_v01.wav
연기: 짧은 호흡 뒤 자신 있게 시작. 1.3~2.0초.
대사: 순찰 시작합니다. 위험부터 확인하죠.
```

### 02. 체력 위험: A/B 각 1개

```text
파일: PSI_V_PLAYER_LOW_HP_A_v01.wav
연기: 살짝 숨이 찬 상태지만 판단은 또렷하다. 1.0~1.7초. 비명 금지.
대사: 잠깐, 안전한 쪽으로 이동합니다.
```

```text
파일: PSI_V_PLAYER_LOW_HP_B_v01.wav
연기: 무리하지 않겠다는 자기 판단. 단호하고 빠르게. 0.9~1.6초.
대사: 거리를 확보하고 다시 대응합니다.
```

### 03. 운반차 돌진 경고: A/B 각 1개



## 재생 설계: 자산 제작 후 별도 구현

| 상황 | 실제 트리거 | 우선순위 | 반복 제한 / 만료 |
| --- | --- | --- | --- |
| 시작 | ready → playing 완료 | 40 | 작전 1회 |
| 체력 위험 | HP 비율이 30% 아래로 실제 하강 | 90 | 40% 이상 회복 후 재무장, 20초 간격 |
| 운반차/낙하/가스 | 가까운 실제 위험이 warning 단계에 진입 | 100 | 위험 ID+경고 주기 중복 제거, 유형 8초 간격, 1초 뒤 만료 |
| 핵심부 개방 | boss core interlocked → exposed | 70 | 보스 페이즈당 1회, 1초 뒤 만료 |
| 대표 위험 통제 | 보스 encounter가 secured로 확정 | 80 | 보스당 1회 |
| 클리어 | engine victory와 결과 확정 | 85 | 작전당 1회, 최종 맵에는 A의 '다음 작전' 문구 사용 금지 |
| 작업자 안내 | worker feedback의 성공 확인 | 25 | 12초 간격, 같은 대상 1회 |
| 장비 진화 | 실제 장비 진화 획득 | 55 | 장비당 1회 |
| 지원 요청 | requestSupport가 실제 성공 | 50 | 성공 요청당 1회, 8초 간격 |
| 재준비 | defeat 후 플레이어가 재준비 선택 | 35 | 선택당 1회 |

게임 공식·HP 임계값을 바꾸지 않는다. 30/40%는 제안된 **음성 큐 판단 기준**일 뿐이다. 주인공 음성은 player 선택 시에만 사용하며 다른 캐릭터의 음성으로 대체하지 않는다. 50번 맵 최종 클리어는 '현장 안전 확인. 작전을 마칩니다.'를 별도 녹음하거나 승인된 B 중 맞는 문장만 사용한다.

Voice는 동시 1개다. 위험 경고는 낮은 우선순위 대사를 짧은 페이드로 중단할 수 있다. 경고를 뒤늦게 줄줄이 재생하지 않는다. pause/levelup/cutin/결과에 들어가면 전투 큐를 비우고 재개 시 재생하지 않는다. 기존 소장 샤우팅과 본편 대화가 Voice를 점유하면 낮은 우선순위 큐를 버린다. 대사 중 Music은 약 -5dB, 지속 SFX는 약 -3dB를 제안하되 위험 경고음을 가리지 않도록 청취 조정한다. 원화/자막/음성은 같은 사실 이벤트를 사용한다.

## 전달 규격과 청취 검수

- 원본 권장: mono WAV, 48kHz, PCM 24-bit. 도구가 MP3만 지원해도 원본 그대로 전달하고 재인코딩으로 손실을 늘리지 않는다.
- 최종 게임용 OGG/MP3 변환과 무전 EQ는 통합 단계에서 처리한다. 생성 때 필터·잡음을 굽지 않는다.
- 권장 true peak -1dBTP 이하. LUFS는 짧은 문장마다 기계적으로 강제하지 않고 공통 기준 파일에 청감 레벨을 맞춘다. 클리핑·강한 노이즈 게이트·워블을 확인한다.
- 글자를 읽는 느낌, 말끝 삼킴, '핵심부/통제/양중/측면'의 불명확한 발음, 화자 음색 변화가 있으면 재생성한다. 위 길이는 목표이며 또렷함을 희생해 맞추지 않는다.
- 모바일 스피커와 이어폰에서 보행·전투 SFX·음악을 함께 들으며 경고를 알아들을 수 있는지 검수한다.
- 파일별 화자 ID, 도구/모델, 생성 일자, 사용권, 승인 여부를 함께 기록한다. 승인 후 SHA-256을 기록해 manifest에 연결한다. 제작 파일이 없는 동안 URI와 PRODUCTION_APPROVED 상태를 추가하지 않는다.

## 선택적 캐릭터성 확장

P0/P1 이후에만 강태식 등 **기존 캐릭터의 정식 화자 설정**으로 짧은 동료 응답을 제작한다. '관리자님, 동선 비웠습니다.'처럼 실제 확인 사실을 말하고, 맡지 않은 보직·사투리·인물 관계를 새로 확정하지 않는다. 우선 24개 주인공 파일만으로 반복감과 이해도를 검증한다.
