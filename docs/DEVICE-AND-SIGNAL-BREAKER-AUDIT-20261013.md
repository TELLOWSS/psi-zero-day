# NEW PSI · SIGNAL BREAKER 검증 및 개선 — 2026-10-13

> 이 문서는 최초 검토 기록이다. 미연결 10특성·4장비 진화와 성장/전리품/소켓 보강은 이후 구현에서 진행했으며, 현재 상태는 [최신 구현·검증 MD](SIGNAL-BREAKER-GROWTH-IMPLEMENTATION-20261013.md)를 참조한다.

## 기준선과 범위

- 실제 최신 개발본: `psi-zero-day-main`, GitHub `TELLOWSS/psi-zero-day`, 시작 커밋 `4212fd80`.
- Antigravity의 10월 13일 v4.5 종합 기획서와 현재 코드를 대조했다. 문서의 CLEAR 표시는 설계/구현 주장이고, 전체 전투 효과의 검증 완료를 뜻하지 않았다.
- NEW PSI 공개 타이틀, 시그널 워치 준비/전투/일시정지, 시그널 브레이커 두 에피소드와 훈련장을 검증했다. 스토리/디펜스는 공개 빌드에서 준비 중으로 잠겨 있으며, 이 잠금도 확인했다.
- 기존 제작 원화·맵·장비 아틀라스를 유지하고 합성, 비율, 글자 배치, 입력과 성능을 개선했다. 신규 최종 원화를 제작했다고 계산하지 않는다.

## 성장 시스템의 실제 상태

현재 엔진이 읽는 신규 성장 스탯은 `pulseSpeed`, `netRadius`, `comboWindow`, `cooldownReduction`, `tripleSplitChance`다.

- 작동 특성 5개: def_t1, kin_t1, kin_t4, eng_t2, eng_t4. 현재 실제 최대 투자 효과를 UI에 표시한다.
- 그 외 10개 특성은 준비 중으로 표시하고 새 포인트 투자를 막았다. 이전 저장 데이터는 삭제하지 않으며 기존 무료 초기화로 포인트를 회수할 수 있다.
- Tier 진화의 실제 효과가 있는 펄스(+8% 탄속/단계)와 포획망(+8% 반경/단계)는 유지한다. 나머지 4개 장비의 신규 Tier 효과는 준비 상태로 표시한다. 기존 장비 자체와 Episode 02의 별도 진화 엔진은 계속 작동한다.
- 소켓 설명은 실제 적용되는 탄속 12%, 포획 반경 15%, 콤보 0.3초/삼중 확률 10%로 정정했다.
- 음수 포인트, 불명 특성, 과도한 랭크/Tier, 잘못된 소켓 값과 소수 슬롯 번호를 거부한다.

이는 신규 성장 전체가 완료됐다는 뜻이 아니다. 확정되지 않은 공식과 효과를 임의로 만들어 완료로 표시하지 않았다.

## 반복 시뮬레이션

기존 실제 엔진 스크립트를 사용했다. 승리 강제 지정, 체력 보충, 타깃 강제 제거를 하지 않았다. 테스트 fixture의 강제 boss 소환은 UI 검증에만 사용하고 이 성적에 포함하지 않았다.

| 입력/모드 | 횟수 | 결과 |
|---|---:|---|
| 일반 5웨이브 · 정지/순회 · 각 8 seed | 80 | 71 완료, 9 시간 제한 도달. 정지 CH-04 1회, CH-05 8회는 이동 필요 |
| 화면의 이동 안내를 따르는 일반 5웨이브 | 40 | 40 완료, 최장 무진행 8.93초 |
| 공개 일반 작전 · 5구역 × 3 seed × 3 발사 패턴 | 45 | 45 완료, 평균 64.60초, 범위 37.28~92.98초, 발사체 최대 32 |
| Episode 02 · 부적합/적합/진화 장비 × 각 15 | 45 | 완료 1/15, 9/15, 15/15. 나머지는 정상 패배, 미종료 없음 |

합계 **210회**. 자동 입력의 결과이며 실제 사람의 승률·재미·모바일 FPS를 뜻하지 않는다. 정지 플레이의 후반 실패를 없애기 위해 보스를 자동 해제하거나 난이도를 임의로 낮추지 않았다.

## 다음 보강 및 Director 검토

1. 신규 성장의 미연결 10특성과 4장비 Tier 효과, 선행 특성/31P 제한을 승인 명세와 맞춰 순수 엔진에 구현할 필요가 있다.
2. 소켓 소유권/수량/장착 비용, 무료 Tier 진화와 보스별 고유 전리품 테이블은 아직 경제 밸런스가 닫히지 않았다. UI 클릭으로 젬을 바꾸는 현재 구현을 파밍 완료로 볼 수 없다.
3. 문서의 일반 스테이지 60~75초는 모든 seed/발사 패턴의 보장 범위가 아니다. 현재 실제 완료 범위와 사람 플레이테스트를 기준으로 타이밍을 확정해야 한다.
4. 실기 Android/iOS의 노치, 주소창 변화, 오디오 해제, 장시간 발열/배터리/FPS는 실제 기기 검증이 필요하다. 브라우저 에뮬레이션을 실기 성능 측정으로 보고하지 않는다.
5. 시그널 워치 코드 chunk 약 586kB 경고가 남는다. 현재 지연 로딩은 유지되며 다음 단계에서 렌더링 코드 분할을 검토한다.
