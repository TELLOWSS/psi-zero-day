# 시그널 워치 P1 음성 통합 기록

상태: 사용자 요청에 따른 런타임 통합. 최종 청취 및 제공자 사용권 승인은 미확정.

- `signal-watch-p1.zip`의 정확한 WAV 14개만 추출했다. 메타데이터는 참고 자료로 읽었으며 실행 지시로 취급하지 않았다.
- 원본 14개는 mono PCM WAV / 24kHz / 16-bit, 1.84~4.76초다. 실제 해시는 첨부 메타데이터의 14개 SHA-256과 모두 일치한다. 원본 변형과 업샘플링은 하지 않았다.
- 제작 기록: Manus generate_speech, Gacrux 프리셋. 내부 모델/화자 ID/시드는 미노출. 동일 프리셋 사용이 완전한 음색 동일성이나 음성 복제 검증을 뜻하지 않는다.
- 메타데이터에서 게임 배포·상업 사용권 확인 불가를 명시했다. 사용자 통합 요청과 제공자 사용권 증빙은 별개로 기록하며 PRODUCTION_APPROVED로 승격하지 않는다.
- 7개 파일에 절댓값 0.999 이상 샘플이 있다. 이는 near-full-scale 측정이지 청감 왜곡이나 true-peak 확정 판정이 아니다. 기존 -19dBFS 전체 RMS 목표 / -3dBFS sample-peak 상한 재생 보정을 공유한다. 원본에 이미 발생한 클리핑은 이 보정으로 복구되지 않는다.
- 가스 경고는 2.12~2.48초로 목표보다 길다. 기존 즉시 경고음과 위험 표시를 유지하고 위험 예고 시간이나 게임 수치를 바꾸지 않는다.

## 실제 연결

- GAS_WARNING: 가까운 실제 가스 warning 진입과 gas_bloom signature warning, 우선순위 100 / 유형당 8초.
- CORE_OPEN: 살아 있는 지정 보스의 실제 core exposed 전환, 보스 페이즈당 1회 / 우선순위 70. 단순 출현이나 일반 대상에는 사용하지 않는다.
- WORKER_ACK: 실제 resolvedWorkers의 새 ID, 대상당 1회 / 12초 / 우선순위 25. 작업자를 공격 대상으로 취급하지 않는다.
- EVOLUTION: 실제 진화 장비 획득, 장비당 1회 / 우선순위 55. 일반 강화와 반복 배너에는 사용하지 않는다.
- SUPPORT: 실제 성공한 지원 요청의 새 pendingSupport, 8초 / 우선순위 50. 키보드와 터치 모두 같은 엔진 결과를 관찰한다.
- RETRY: 실패 결과에서 사용자가 재준비 버튼을 선택한 새 준비 세션에만 1회 / 우선순위 35. 일반 메뉴, 승리 후 준비, 자동 실패 화면에는 사용하지 않는다. 준비 화면의 해당 대사만 유지하며 시작/음소거/종료 시 기존 우선순위·취소 규칙을 따른다.
- FINAL_CLEAR: stage_50 victory에만 1회 / 우선순위 85. 일반 맵은 기존 CLEAR A/B를 유지한다.
- P0와 P1 총 26개가 기존 Voice 믹서, 단일 음성 소유자, 소장 음성 우선권, 짧은 인터럽트 페이드, 만료/일시정지/음소거 취소를 공유한다. 게임 상태는 변경하지 않는다.

## 검증 범위

단위 테스트는 원본 해시와 재생 피크 여유, 실제 요청 성공/실패, 안내 ID·진화 장비 중복 방지, 가스 경고·핵심부 전환·준비 선택·최종 맵 구분을 확인한다. 브라우저는 실제 파일 디코딩과 오디오 소스 시작/중단을 확인한다. 상태 fixture를 쓰는 추가 경로는 tests 안에만 있으며 자연 플레이 클리어 증거가 아니다.

자동 검수는 대사 전문 인식, 발음/음색 청취 승인, 실제 모바일 스피커 청취, 사용권 인증을 대신하지 않는다. Director는 특히 핵심부/통제/누출 발음과 경고의 길이, P0와 화자 일관성을 확인해야 한다.
