# OMEGA PROTOCOL — 디아블로 이모탈 기준과 제작 방향 (2026-11-14)

## Director 지정 기준

기준 게임은 **디아블로 이모탈**이다. 단일 화면에서 적만 제거하는 형식이 아닌, 쿼터뷰 카메라로 배경을 지나 이동하며 전투·이벤트·보스·보상을 경험하는 액션 RPG의 완성도를 목표로 한다. OMEGA는 가상 오염 산업단지 Q-17, 은백색 AIRA, SF 총과 검, 감염 작업자·폭주 기계·구조 임무라는 독자 정체성을 유지한다. 전투는 수동 기본이며 자동 사격은 선택이다. 디아블로의 콘텐츠나 미술·명칭을 복제하라는 뜻으로 해석하지 않는다.

## 공식 자료에서 확인한 기준

- [Blizzard PC 조작 설명](https://news.blizzard.com/en-us/article/23797159/making-diablo-immortal-for-pc): 마우스·키보드와 WASD, 특정 기술을 쓰며 이동할 수 있는 조작 및 키 재설정. 이 내용은 공식 설명이며 모든 기술이 이동 중 사용 가능하다는 뜻은 아니다.
- [Blizzard 접근성 설명](https://news.blizzard.com/en-us/article/23805083/making-a-game-for-everyonediablo-immortals-accessibility-features): 모바일 기술 버튼 위치 조정과 컨트롤러 조작 재설정 지원.
- [Blizzard 출시 소개](https://news.blizzard.com/en-us/article/23787371/diablo-immortaltm-a-new-plane-of-hell-opens-for-mobile-and-pc-on-june-2): 월드를 탐험하고 여러 지역을 통과하는 액션 RPG 구성. 이 자료는 출시 당시 설명이다.
- [Blizzard 베타 설명](https://news.blizzard.com/en-us/article/23734271/diablo-immortal-closed-beta-overview): 던전 탐험, 장비 획득 및 성장의 중요성. 이 자료는 개발 당시 설명으로 현재 모든 수치·시스템의 증거는 아니다.

## OMEGA에서 검증해야 할 차이

| 기준 | 현재 확인된 상태 | 완료 조건 |
|---|---|---|
| 현장 통과·탐험 | 현재 15개 내부 노드가 구역 경계에서 필드를 전환한다. 완전한 심리스 맵은 아니다. | 하나의 대표 구역에서 카메라 추적, 여러 공간의 연속 이동, 전경/중경/후경, 가림·출구·전투를 실제 조작으로 확인하고 확대한다. |
| 수동 전투 | 검수판에서 J/터치 수동 발사와 선택형 자동 사격이 동작한다. PC 마우스 월드 조준은 이번에 연결했다. | 이동 중 조준·사격·회피·검 연계를 실제 표적과 장애물에 대해 검증한다. 모바일 독립 조준, 손맛과 무기 원화는 미완이다. |
| 실재감 있는 배경 | AI 2D 원경과 개별 이미지 후보를 배치했으나 실제 입체 건물이나 정확한 가림·충돌을 보장하지 못한다. | 건축 구조와 높이·시점·광원·접지·앞뒤 가림이 일치하는 하나의 플레이 가능한 현장을 검수한다. |
| 인물·적 모션 | 여러 방향의 원화와 감염체 후보가 있으나 동작 연속성·방향·접지·비율이 미완이다. | 이동·총·검·피격·회피를 각 방향의 독립 원화와 실제 입력에 맞춰 검수한다. |
| 버튼·조작 | 검수판 버튼, 수동·자동 선택이 존재한다. Android 실기기·독립 조준·버튼 위치 변경은 미검증 또는 미구현이다. | PC/모바일 실기기에서 이동과 공격 동시 조작, 가독성·반응·배치·성능을 확인한다. |
| 보스·성장 | 실제 보스 HP와 기초 경고, 일부 강화가 있다. 완성된 고유 보스 페이즈·성장 트리는 미완이다. | 패턴 예고→회피→약점 반격→보상까지 실제 게임에서 확인한다. |

비교 게임과 동등하거나 그 이상이라는 평가는 지금 할 수 없다. 같은 조건의 실제 플레이 영상, 화면 크기, 기기 성능, 조작 지연과 사람의 시각·손맛 검수를 함께 확보해야 한다. 해당 목표를 구현 우선순위로 삼으며 별도의 제작·QA 게이트를 생략하지 않는다.
