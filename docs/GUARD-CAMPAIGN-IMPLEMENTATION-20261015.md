## 타워 시연과 추천

시연은 별도의 run을 정상 Build/Upgrade/StartWave 명령으로 만든다. L3A/B를 실제 장착하지 않아도 비교할 수 있다. 일반·장갑·군집이 섞인 같은 시험 흐름에서 실제 누적 대응을 표시한다. 본게임 자원·배치·진행·저장에 쓰지 않는다. 기본 시연은 최대 12초, 닫기/화면 숨김 시 정지한다. 동작 줄이기 설정에서는 실제 6초 판정을 한 번 계산한 정적 결과를 표시한다.

이번에는 혼합 시험 흐름을 제공한다. 기획의 개별 위험체 선택식 시험장과 L4 시연은 후속 범위다. 추천은 파의 실제 출현 간격·타격 횟수·진입점 대응 지연을 고려하도록 가드에 한정해 보강했다. 기존 모드 추천 규칙은 유지한다.
