# 슈팅 순찰 안의 반복 위반 사건과 장비 사운드

2026-10-04. 구현·브라우저 검증 완료 / Android 실기기·최종 성우·녹음 자산 검수 미완료.

## 이번 플레이

Stage 11~14에서 같은 가상 근로자 민재의 상황을 이어간다. 순찰 시작 후 2초에 현장 무전과 짧은 신호음이 나오고, 8초 이후 실제 진행 중 사건을 확인할 시점에 현장을 일시정지한다. 레벨업 화면이 먼저 열리면 그 선택을 완료한 뒤 사건으로 이어진다. 명명된 근로자의 보고 위치에는 기존 승인 근로자 자산을 사용한다. 이 근로자는 충돌·피격·점수 대상이 아니다.

현장에서 반복 위반 관리에 쓰는 삼진아웃을 이 작품의 현장 규칙으로 적용했다. 실제 회사·현장·근로자의 기록을 사용하지 않았다.

| 구역 | 확인한 사실 | 조치와 다음 기록 |
|---|---|---|
| 11 | 턱끈 잠금장치 결함 | 교체·재확인, 경고 0회, 반장 지급품 점검 인계 |
| 12 | 사용 가능한 안전통로를 이해했는데 통제선 침범 | 확인된 첫 경고, 동선·이해 재확인 |
| 13 | 다른 시점의 독립된 재위반 | 누적에 맞는 최종 경고, 책임자 동행·고지 |
| 14 | 사실과 기존 확정 경고를 대조 | 실제 세 번째일 때 현장 출입배제, 대체 인력 교육·동선 인계 |

각 판단 전에 근로자 진술 / 장비와 교육 이해 / 기록과 책임자 확인을 열어야 한다. 장비 결함을 경고로 세지 않고, 같은 사건을 재도전으로 중복 누적하지 않는다. 늦은 구역을 저장 해금으로 직접 시작했을 때 이전 경고를 만들어내지 않는다. 불확실하면 경고 확정은 유보하되 위험작업에서 배제하고 합동 재검토한다. 심각한 위험을 세 번째까지 기다리는 구조가 아니다.

판단 중에는 시뮬레이션과 조작을 멈춘다. 결정을 마치면 중단 시점부터 순찰을 재개한다. 출입배제·재검토 상태인 민재를 후속 구역에 반복 위반자로 다시 등장시키지 않는다. 작업 배제와 대체팀 인계는 이후 무전, 다음 구역 준비 화면, 결과 화면, 재접속 저장 기록에 남는다. 처벌 횟수에 점수·크레딧을 지급하지 않는다. 대체팀 교육은 이야기의 인계 결과이며 아직 별도 인력 배치 시뮬레이션으로 구현하지 않았다.

## 사운드 변화

기존 발사체 사실 큐에서 장비별 시작·실제 접촉·잔여 효과의 음향을 연결한다. 무전의 필터링된 잡음, 소화기와 극저온의 다른 분사 대역, 드론 지시광, 전기 아크, 차단 장비, 라바콘 접촉을 구분한다. 근로자에게 전달된 지시는 짧은 확인음으로 처리한다. 기존 발사음·명중음과 중복 재생하지 않는다.

이 효과는 절차적 Web Audio 사운드다. 현장 실녹음 또는 최종 영화급 음향으로 표시하지 않는다. 이미 확보한 음악 후보와 소장 음성의 권리·승인 상태는 유지한다.

- 24개 동시 음원과 우선순위 유지, 장비·단계별 짧은 재생 간격 제한.
- 혼잡 시 소멸 장식을 생략하고 접촉 반응 우선.
- Master 압축기로 중첩 피크 완화, 빠른 어택과 부드러운 감쇠.
- Music 음량과 덕킹 Gain을 분리. 덕킹·일시정지 뒤 사용자 음량이 100%로 덮이는 버그 수정.
- 중첩 경보의 덕킹 시간을 연장하고, 대화 중 음악을 낮춘다.
- 사실 확인·기록·판단 유보·출입배제에 다른 짧은 확인음 사용. 출입배제를 승리 팡파르로 처리하지 않는다.

## 검증

- npm test: 205개 파일 / 1,089개 테스트 통과.
- npm run typecheck 및 최종 npm run build 통과.
- 모바일 390×844 / 844×390: 실제 UI에서 네 구역의 무전·판단·재개 8건 검수 통과. 사실 확인 전 확정 버튼 비활성화, 경고 0→1→2→3, 저장된 출입배제 인계 확인.
- 재현을 위해 20구역 해금 저장 fixture를 사용했으며 실제 플레이·선택을 진행했다. 자연 해금 달성 증거로 부르지 않는다.
- 실제 production 사운드 코드를 OfflineAudioContext에서 렌더링. 동시 음원 최대 24, 음소거 뒤 0, 혼잡 출력 peak 0.3903로 검사 통과. Android WebView 실기기·스피커 청취 판정은 아니다.
- 마지막 음량·여운 보정 뒤 전체 회귀·빌드를 재실행하고 음향만 재렌더링했다. report의 uiEvidenceReused는 변경 없는 앞선 8건 UI 증거를 유지했다는 뜻이다.

근거: `qa/accountability-audio-20261004/report.json` 및 두 실제 캡처. `scripts/verify-survivors-accountability-audio.mjs`로 재현한다. 일반 실행은 전체 검사이며 `PSI_AUDIO_ONLY=1`은 기존 성공 보고서가 있어야 음향만 다시 검사한다.

`equipment-contact-preview.mp3`: 무전 → 소화기 → 드론 → 극저온 → 테슬라 → 차단 장비 → 라바콘, 각 0.5초. 실제 렌더러 출력으로 만들었다. 프리뷰 전체만 하나의 공통 Gain으로 보정하여 들을 수 있게 했으며 게임 내 Gain 설정이나 자산 승인 상태를 바꾸지 않는다.

## 남은 품질 게이트

Android 실기기의 혼잡·발열·음량과 BGM/현장음/장비/대사 통합 청취, 새 사건의 성우 연기와 현장 녹음, 대체 인력 인계를 실제 인력 배치로 확장할 때의 디렉터 검토가 남는다. 단독 전투 스토리를 더 확장하기 전에 이 네 사건의 몰입도와 음향을 플레이 영상에서 검수한다.
