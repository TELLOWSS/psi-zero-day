# 메인 중복 정리 · PSI 투명 마크 · 가드 전술 선택 고도화

작성: 2026-10-17. 이번 적용 범위는 기본 메인 화면과 시그널 가드 6개 스테이지다.

## 메인 화면

별도 '시그널 가드 · 작전 준비' 버튼은 가드 모드 카드와 같은 작전실로 연결돼 중복이었다. 별도 버튼을 제거하고 가드 카드를 첫 순서에 배치했다. 세로 모바일에서는 카드가 첫 화면 안에 들어오도록 소개 영역 높이를 조절했다. 작은 가로 화면은 스크롤로 카드를 선택한다.

마크 자체는 투명 SVG였으나 CSS가 흰 받침을 그렸다. 받침을 제거하고 파란 방패와 흰 눈은 보존했다. 남색 PSI 글자는 어두운 배경용 밝은 글자 변형으로 제공한다. 기존 원형·밝은 배경용 파일은 보존했다. 캐릭터 원화와 안전모의 마크는 변경하지 않았다.

## 플레이 점검 후 구현

기존 조준은 '출구 가까운 순'과 '체력 높은 순'뿐이었다. 지원 코어가 방해를 예고하는 상황에서도 플레이어가 이를 우선 처리하도록 명령할 선택지가 부족했다.

1. 가드 6개 스테이지에 **수동 '위협 우선'**을 추가했다. 예고·방해 중인 지원 코어 → 보스 → 탐지된 은폐 신호 → 출구 가까운 순으로 조준한다. 기본 설정은 기존 FIRST다.
2. 후보는 기존 탐지·사거리 판정 이후 정렬한다. 은폐를 무시하거나 사거리를 늘리지 않는다. 가까운 일반 신호보다 위협을 먼저 처리해 누수가 생길 수도 있다. 플레이어가 타워별로 선택한다.
3. 기본 공격, L4 분석/조준 및 연속 공격의 정렬을 같은 순수 엔진 함수로 통일했다. 발사된 L4 연속 공격은 발사 당시 조준 방식을 저장하며 저장·복원 후에도 유지한다.
4. 준비 화면의 파 정보에 **현재 배치 점검**을 넣었다. 실제 설치 장비의 기본 공격 범위와, 은폐 신호가 오는 경로의 탐지 범위를 표시한다. 장비가 겹친 구간은 중복 계산하지 않는다.
5. GD05의 두 진입 경로는 각각 평가한다. GD06 W5 전환 파는 바뀔 경로를 미리 평가한다. 기존 수동 전환 확인은 유지한다.

범위 수치는 약 20단위 간격의 구간 표본을 길이로 가중한 경로 비율이다. 화력·공격 속도·지원 버프·실제 처치 능력을 예측하는 수치가 아니다. 준비 점검은 읽기 전용이며 건설·자원 소비·자동 시작을 실행하지 않는다.

## 검증 및 경계

- 전체 테스트 **2,183개 통과**, 기존 1개 skip. 타입 검사와 npm run build 통과. 최종 문구/화면 번들도 별도 빌드했다.
- 실제 첫 공격 대상이 FIRST/STRONG/THREAT에서 달라지는지, 사거리 밖·미탐지 후보 제외, L4 후속 공격, 도중 저장·복원, 구형 FIRST 저장 및 비가드 콘텐츠의 THREAT 거절을 검증했다.
- 배치 범위 공백, 겹침의 합집합 계산, 두 경로 및 W5 경로 전환을 검증했다.
- 기존 정상 예산의 18가지 GD06 설계·동료 조합 회귀와 기존 캠페인 검증이 통과했다. 모든 상황에서 위협 우선이 승리를 보장한다는 뜻은 아니다.
- 메인 7개 화면에서 중복 버튼 제거·로고 투명·가드 진입·워치/브레이커 진입·스토리 안내를 확인했다.
- 전투 6개 화면에서 배치 점검, 직접 위협 모드 선택, 자원 유지·선택 저장, 실제 코어 예고·방해, 정지 중 시간 보존, 오프라인 수동 재배치로 해제를 확인했다.
