# 시그널 가드 모바일 최적화 기획

작성 기준: 2026-10-16, 운영 기준 커밋 c32276c3.

## 문제와 목표

현재 390×844 준비 화면의 맵은 약 315×525px입니다. 장비를 선택하면 맵이 다시 작아지고, 하단의 구매 취소·설명·타기팅·판매 뒤로 강화 트리가 밀립니다. 320×568에서는 상·하단 정보의 비중이 높아 312×187px 맵 주변에 여백이 남습니다. 가로 화면도 상단 정보 줄이 전장의 높이를 소모합니다.

목표는 전장을 안정적으로 유지하면서 조작할 때 필요한 정보만 여는 것입니다. 세로를 주 사용 환경으로 최적화하고 가로 화면도 지원합니다.

## 화면 설계

| 상태 | 상단 | 중앙 | 하단 |
|---|---|---|---|
| 준비·파 사이 | 보호막·자원·웨이브 / 정지 / 메뉴 | 전체 경로와 배치 지점 | 추천 배치 / 파 정보 / 파 시작 |
| 전투 | 같은 위치의 핵심 수치 | 전체 경로, 경고와 대응 | 동료 지원 / E-STOP |
| 일시정지 | 정지 상태 표시 | 맵 유지 | 전술 정보 / 전투 계속 |
| 장비 선택 | 수치 위치 유지 | 맵을 축소하지 않고 하단·우측 패널을 겹침 | 맵으로 / 전투 계속 또는 배치 완료 |
| 파 정보 | 수치 위치 유지 | 전장 위에 정보 패널 | 다음 파 진입 정보·설계 방식·전환 확인 |

- 세로 화면은 정보 줄과 조작부를 한 줄로 줄입니다. 맵의 가로/세로 표현은 실제 전장 영역에서 더 크게 표시되는 쪽을 선택합니다.
- 가로 화면은 맵이 상단 수치 아래 높이를 모두 사용하고, 오른쪽에 파 정보와 조작부를 둡니다.
- 메뉴에서 배속·음소거·안내 다시 보기·작전실 복귀를 제공합니다.
- 배치 패널은 전장을 재배치하지 않습니다. 닫기는 맵으로 돌아가고, 전투 재개는 별도 동작으로 명확히 구분합니다.
- 선택 지점은 패널의 가로 목록에서도 바꿀 수 있게 합니다. 높이가 350px 이하인 가로 화면은 같은 기능을 헤더의 선택 상자로 제공합니다. 작은 맵의 원을 정밀하게 누르지 않아도 됩니다.

## 장비 패널의 정보 우선순위

1. 선택 지점과 현재 장비, 구매 되돌리기.
2. 현재 단계에서 연결되는 다음 강화 후보와 비용.
3. 선택 후보의 실제 수치 변화·확인.
4. 접힌 대상 설정·판매, 전체 분기, 장비 실험.

판매를 강화보다 먼저 누르게 하지 않습니다. 다음 후보만 기본 표시하고 전체 분기와 잠긴 단계도 펼쳐 확인할 수 있습니다. 기존 강화 판정·가격·환불·전투·해금 규칙은 유지합니다.

## 구현 순서

1. 모바일 표시 상태와 전장 크기 관찰을 UI 계층에 추가합니다.
2. 상단·하단·정보 패널을 상태별로 구성합니다.
3. 선택 패널을 겹침 방식으로 바꾸고 강화 트리의 모바일 보기를 추가합니다.
4. 화면 회전·작은 화면·노치 영역·스크롤·키보드 초점을 검증합니다.

## 합격 기준

- 390×844 준비 화면에서 기존 대비 실제 맵 면적 20% 이상 확대를 목표로 합니다.
- 장비 선택 전후 맵의 크기와 터치 좌표가 유지됩니다.
- 핵심 버튼과 지점 선택 목록의 터치 영역은 최소 44×44px입니다.
- 준비·전투의 주요 조작에 페이지 스크롤이 필요하지 않습니다.
- L1 장비 선택 시 다음 강화 후보를 첫 화면에서 확인할 수 있습니다.
- 닫기·정보 열기·일시정지·화면 회전은 자원·타워·저장된 진행을 임의로 바꾸지 않습니다.
- 320×568, 360×740, 390×844, 430×932, 568×320, 844×390와 데스크톱 회귀를 확인합니다.

검증 결과는 별도 결과 문서에 기록합니다. 실물 휴대폰의 조작감 검증은 브라우저 에뮬레이션과 구분합니다.
