# Q06 — 사용자·Android 검수 기록지

현재 사람/실기기 항목은 전부 NOT_RUN. 진행자가 실제 관찰한 기록과 기기 정보를 입력한 뒤에만 PASS로 변경한다.

세션 정보: 날짜 / 빌드 commit / Android 모델·OS / 화면 해상도 / 오디오 출력 / 검사자 / 사용자 식별번호(이름 불필요).

| 대상 | 검사 절차 | 기록 | 현 상태 |
|---|---|---|---|
| 신규 사용자 1~5 | 설명 없이 시작 → 첫 이동/자동 대응 → 첫 강화 → 주요 위험 예고 → 결과의 원인 설명 | 각 사용자 성공/오해/시간/코멘트. 5명 중 4명 목표는 초안 | NOT_RUN |
| 터치 | joystick deadzone·취소·두 손가락·이동 중 궁극기·회전 | 의도치 않은 이동/버튼 충돌 여부, 영상 | NOT_RUN |
| 포커스 | 이동 중 홈 이동·알림·통화·화면 잠금 → 복귀·재개 | 이동 입력 잔류와 시간 점프 여부 | NOT_RUN |
| HUD | 360×800 / 390×844 / 844×390 / 1440×900, 긴 한국어·최대 숫자, 콤보/경보/진화/궁극기/선택/결과 | 겹침/잘림 스크린샷 | NOT_RUN |
| 청취 | 헤드폰·실제 휴대폰·소형 스피커 10분, 유선/Bluetooth 구분 | 피로/loop click/스템 drift/지연, 출력별 실제 평가 | NOT_RUN |
| 무화면 큐 | 경보/피격/개입/승패를 화면 없이 구분 | 사용자별 정답·혼동 | NOT_RUN |
| 무음 | 모든 중요 위험을 화면만 보고 인지 | cue 누락/늦은 이해 | NOT_RUN |
| 성능 | 대표 기기 10분 플레이, p95 프레임/입력 반응/메모리·context·voice 샘플 | raw trace 첨부. 60fps, p95 20ms, 입력 p95 100ms는 초안 | NOT_RUN |
| 저장 | 승패 후 재실행·손상 JSON 복구·오프라인 재실행 | 중복 보상/해금·별 불일치/진행 손실 여부 | NOT_RUN |

브라우저 재검증: `npm run build` → `npm run preview -- --host 127.0.0.1 --port 4173` → 별도 터미널에서 `node scripts/verify-survivors-browser.mjs`.
Playwright 및 Chromium이 설치되어 있어야 한다. 필요하면 PSI_PREVIEW_URL / CHROME_BIN / CODEX_PRIMARY_RUNTIME_NODE_MODULES를 설정한다. 자동 smoke가 PASS여도 성장·진화·궁극기·승패 전체 자연 플레이와 사람 검수를 대신하지 않는다.
