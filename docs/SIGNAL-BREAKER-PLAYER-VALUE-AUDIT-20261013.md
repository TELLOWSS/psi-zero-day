# 시그널 브레이커 첫 플레이·완주·구매 가치 점검

2026-10-13 / 릴리스 `0.50.0-player-journey`

사용자 결정: **판매 방식·가격 미정. 플레이 완성도와 구매 가치부터 개선하며 실제 결제는 연결하지 않는다.** 기준은 승인된 종합 기획서 v4.5와 현재 10작전·15특성·6장비 런타임이다. 새 캠페인·현금 경제·상점 가격을 임의로 추가하지 않았다.

## 확인한 사용자 여정과 구현

로비 → 조작 교본 → 출발 준비 → 이동·조준·발사·발생원 통제 → 보스 → 회복 엔딩 → 전리품 → 개조·소켓 → 다음 작전 → EP02 진화 → 10작전 완주 → 재접속 → 현장 기억 재생을 검증했다. 이 게임은 브라우저 안의 순수 엔진과 로컬 저장을 사용하며 이 여정에 결제 API나 서버 데이터베이스는 없다.

| 확인한 문제 | 구현한 개선 | 구매 가치와의 관계 |
|---|---|---|
| 로비의 주요 시작 버튼이 준비를 건너뛰어 안내·성장 선택을 놓침 | 로비의 모든 출발 경로가 준비 화면을 연다. 전투는 명시적 시작 뒤 진행한다 | 첫 판에서 조작을 이해하고 장비를 선택할 기회 |
| 교본이 실제 기본 AUTO 조작 및 도구 역할과 다름 | 이동·직접 조준·AUTO의 역할, 미스트/앵커/스캐너와 발생원 관찰→차단 순서 정정 | 잘못된 안내로 생기는 실패 감소 |
| 가만히 있는 설정은 집진 보스에서 장시간 막힘 | AUTO가 이동·회피를 대신하지 않음을 준비·교본에 명시. 기존 이동 안내 유지, 실패에는 상태별 대응 방법 제공 | 자동발사에 맡겨야 하는 게임으로 오해하지 않도록 설명 |
| 모바일 준비창이 작은 캔버스 기준으로 배치되어 위쪽이 잘림 | 준비/결과 오버레이를 뷰포트 기준으로 배치하고 스크롤·고정 시작 행 적용 | 세로·짧은 가로 화면에서 읽기와 시작 가능 |
| 보스 전리품 타이머가 엔딩 도중 모달을 열어 연출을 가림 | 보상은 작전 완료 때 확정, 전리품 창은 엔딩 완료/결과 보기 뒤 표시 | 완주의 감정적 보상과 성장 보상을 각각 볼 수 있음 |
| 보스 전리품 지급이 유실 가능한 시각 이벤트 큐에 의존 | 실제 `won`과 보스 `resolved`를 검증해 지급, 기존 seed 중복 방지 유지 | 알림 누락으로 성장 보상을 잃지 않음 |
| 실패 화면에서 다음 구역 설명을 보여주고 재설정 경로가 약함 | 실패 원인/현재 조건에 맞는 한 가지 대응과 장비·조작 재준비 버튼 제공. 실패에는 다음 구역 설명 제거 | 재도전의 목적과 바꿔야 할 행동 명확화 |
| 전리품의 용도 및 결과 복귀 버튼이 모호함 | 부품→Tier, 젬→호환 장비를 설명하고 결과→개조 바로가기 추가. 버튼을 ‘결과와 다음 작전 보기’로 변경 | 얻은 보상을 다음 판의 변화로 연결 |
| EP01 마지막에서 EP02 연결이 약하고 재접속 기본 선택이 항상 CH01 | 10작전 진행과 다음 미완료 작전 CTA, EP01 완주→EP02 준비, 재접속 때 미완료 구역 선택 | 남은 콘텐츠와 진행 방향을 이해할 수 있음 |
| 집중 모드의 전역 footer 숨김 때문에 로비의 엔딩/복귀/장비실 메뉴도 숨겨짐 | 게임 footer와 캠페인 하단 메뉴의 표시 범위를 분리 | 완주한 엔딩을 실제로 다시 볼 수 있음 |
| 숙련 목표가 현재 판에만 존재하고 빗나간 탄의 반사도 달성으로 집계 | 성공한 작전의 목표 달성을 기록에 누적 보존. 실제 반사 적중으로 집계, 로비에 숙련 n/3 표시 | 새 장비·다른 경로로 다시 도전할 이유 |
| 성장 저장 실패를 콘솔에서만 처리 | 저장 성공 여부 반환, 성장 메뉴의 실패 표시/저장 재시도. 완료 저장 확인에 성장 저장도 포함 | 진행 보존에 대한 신뢰와 실패 복구 경로 |
| CP ‘구매’가 현금 결제로 오해될 수 있음 | 첫 작전 완료로 얻는 게임 내 크레딧이고 현금 결제가 없음을 명시 | 현재 제공하는 기능을 정확히 설명 |

성장 데이터 저장 실패 시 현재 세션 상태를 유지하며 재시도한다. 저장이 끝나기 전 새로고침·브라우저 종료 시 보존을 보장하지 않는다. CP 지출은 성장 저장 확인 후 본 기록을 쓰도록 순서를 정리해, 성장 저장 실패 때문에 CP 차감만 기록되는 경로를 막았다. 브라우저 데이터 삭제와 다른 기기로의 이동에 대한 안내도 추가했다.

## 처음부터 끝까지 시뮬레이션

최대 성장 장비를 미리 넣는 검사와 분리하여 **새 계정 12개**를 만들었다. 시작 5P와 교본 3P만 사용하고 웨이브/작전 보상으로 투자하며, 획득한 부품과 젬으로만 개조/장착한다. 이동·조준·발사·장비 전환·발생원 통제·정비/진화는 엔진 명령을 사용한다. 승리 상태 주입, 체력 보충, 스테이지 건너뛰기를 하지 않는다.

| 프로필 | 계정 | 시도 | 승리 | 패배 | 360초 제한 도달 | 10작전 완주 |
|---|---:|---:|---:|---:|---:|---:|
| 처음에는 이동하지 않고, 실패/제한 도달 후 이동 안내 반영 | 6 | 82 | 60 | 16 | 6 | 6 |
| 처음부터 이동·위험 회피·프레임 상성 안내 반영 | 6 | 60 | 60 | 0 | 0 | 6 |
| 합계 | 12 | 142 | 120 | 16 | 6 | 12 |

첫 작전 성공 시간은 약 **52.8~61.4초**, 10작전의 성공한 전투 시간 합계는 약 **8.4~9.6분**이다. 후자는 패배·360초 제한 시도·메뉴·교본·엔딩 시간을 제외한다. 6개 제한 도달은 무이동 CH03 시도이며 승리로 세지 않았다. 제한 도달 뒤 이동을 사용하는 재도전은 완료했다. 이동을 무시해도 자동으로 보스를 깨도록 바꾸거나 승리 조건을 완화하지 않았다.

이는 결정론적인 입력 봇 결과이다. 사람의 첫 플레이 승률, 재미, 체류 시간, 결제율 또는 장치 FPS로 해석하지 않는다. 안내를 읽은 사람이 실제로 이동·진화를 이해하는지는 사람 플레이테스트가 필요하다.

## 실제 브라우저 검증

- 새 브라우저 저장소로 **360×640 세로 / 844×390 가로 / 1440×900 PC**에서 각각 10작전을 완료했다. 전투는 일반 엔진 명령을 가속 입력하며 실제 앱의 이벤트·완료 처리·저장·모달을 실행했다.
- 교본 +3P 1회, 명시적 준비→시작, EP02의 화면상 프레임/진화 선택, 전투 승리, 엔딩 준비/이미지 표시, 엔딩을 가리지 않는 전리품, 획득 부품으로 실제 펄스 Tier2 개조와 보유 젬 장착을 확인했다.
- 다음 에피소드, 완주 10/10, 저장된 10개 기록, 재접속 성장 복원, 엔딩 다시 보기의 보상 미지급, 결과 화면 가로 넘침과 JavaScript 예외를 검사했다.
- 별도 8개 뷰포트 회귀는 조작 도달성·회전·모달 정지·렌더 픽셀 제한·훈련장 분리까지, 성장 UI 3개 화면 회귀는 소켓/재료·훈련장 Tier·저장을 검사한다.
- 기존 현장·도구·보스·회복 장면 자산을 실제 로드하고 대표 스크린샷을 확인했다. 엔딩을 가리는 보상 창과 잘린 준비 패널을 고쳤다. 새 원화나 placeholder를 제작하지 않았으며 전체 원화의 최종 아트 승인으로 계산하지 않는다.
- 본편 **2,059 테스트 통과 / 1 skip**, 브레이커 **254 테스트 통과**, 타입 검사·빌드 통과. 본편 대형 번들 경고는 기존 상태로 남아 있다.
- 릴리스에는 신규 순수 요약 모듈을 포함한 **98개 자산 해시**를 기록한다. 배포 뒤 공개 주소의 동일 자산 바이트를 확인한다.

검증 코드: `public/signal-breaker-dev/scripts/simulate-player-journey.cjs`, `verify-player-journey.cjs`, `tests/player-journey.test.cjs`. 실행 증거: `artifacts/player-journey-20261013/`. 커밋에 포함하는 요약: `docs/qa/player-value-audit-20261013.json`.

다음 상업 검증에서는 무료게임 위주 이용자에게 시작 버튼만 알려주고 첫 판을 관찰한다. 최초 이동·발생원 통제·첫 개조를 스스로 할 수 있는지, 중단한 지점과 이유, 완주 뒤 재플레이 선택과 자발적인 구매 의향을 기록한다. 판매 가격이 없으므로 결제 전환율 목표를 임의로 만들지 않는다. 결제 의향을 강제 설문 응답이나 실제 결제로 간주하지 않으며, 이번 구현이 ‘무료 유저를 실제 유료 구매자로 전환했다’고 주장하지 않는다.

새 기상·공법·DLC·B2B 콘텐츠는 현재 구매 가치 검사에 포함된 구현이 아니다. 이번 범위는 기존 승인된 캠페인의 이해·진행·성장·완주·재방문 품질이다.
