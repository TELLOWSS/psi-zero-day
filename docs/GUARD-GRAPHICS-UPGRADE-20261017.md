# Signal Guard — 지원 코어 그래픽 개선

작성: 2026-10-17 / 범위: GD06의 지원 코어와 대응 시각 정보.

## 화면 검토와 구현

기존 지원 코어는 일반 ARMORED 장비와 같은 스프라이트를 사용했다. 작은 점선 원과 글자만으로 특수 역할을 구분해야 했고, 장비 중심까지 그어진 경고선과 대상 위의 큰 ×가 장비 외형을 덮었다.

- 독립된 안테나 패널, 무한궤도, 황색 보호 범퍼가 있는 전용 산업용 코어 원화를 생성해 적용했다. 기존 현장의 조명과 금속 재질에 맞췄다.
- 일반 신호보다 큰 78 단위 스프라이트를 쓰며, 체력 막대를 상단으로 옮겨 안테나와 겹치지 않게 했다. SPENT 이후에도 동일한 물리 장비 외형을 유지한다.
- 경고 연결선은 코어와 대상의 외곽에서 끝난다. 어두운 밑선으로 현장 위 대비를 확보하고 얇은 신호선으로 대상 관계를 표시한다. 두 장비가 너무 가까우면 연결선은 생략한다.
- 대상 SENSOR에 남은 시간 눈금과 초 표시를 추가했다. WARNING은 황색, ACTIVE는 연홍색이며 상단의 한국어 설명도 유지한다.
- 코어의 이름표는 화면 가로 범위 안으로 보정한다. 작은 가로 화면의 진입 지점에서 잘리던 이름표를 실제 캡처로 확인해 수정했다.
- 세로 화면에서 스프라이트와 이름표를 역회전해 읽는 방향을 유지한다.

## 자산 및 생성 기록

- 생성 방식: **내장 image_gen**, 투명 배경.
- 최종 프롬프트: [GUARD-PRESSURE-ART-PROMPT-20261017.json](branding/GUARD-PRESSURE-ART-PROMPT-20261017.json)
- 게임 자산: [support-core.webp](../public/assets/defense/guard-pressure-v1/support-core.webp)
- 자산 계약: [guard-pressure-art-v1.json](../content/defense/guard-pressure-art-v1.json)
- 384 × 384, alpha 보존, **53,450 bytes**. 원본을 sharp로 축소 및 WebP 변환했으며 실제 투명도·이미지 디코딩·SHA-256을 검증했다.

상태는 FINAL_CANDIDATE_RUNTIME_INTEGRATED다. 자동 검증을 시각적 Production Lock이나 Director 최종 승인으로 계산하지 않는다.

## 검증

- 최종 전체 테스트: 2,172개 통과, 기존 1개 skip (신규 그래픽 계약 3개 포함).
- npm run typecheck / npm run build 통과.
- 320×568, 390×844, 568×320, 844×390, 768×1024, 1440×900의 실제 브라우저에서 전용 자산 디코딩, 경고, 실제 탐지 방해, 시간 눈금, 일시정지, 수동 재배치, 오프라인 상태에서 재배치 후 해제, 가로 넘침과 JS 오류를 확인했다.
- 6개 화면의 모션 감소 설정과 추가 390×844 일반 모션 설정을 확인했다. 모션 감소에서는 선 애니메이션을 제거하며 일반 모션에서는 일시정지 시 멈춘다.

## 적용 경계와 검토 항목

전투 수치·판정·이동 경로·경제·저장 형식은 변경하지 않았다. 기존 저장의 pressure 비활성 상태에도 새 코어를 생성하지 않는다. 오프라인 검증은 이미 로드한 게임에서의 대응 동작이며 새로고침 후 전체 오프라인 설치 검증을 뜻하지 않는다.

이번 개선 범위는 GD06 지원 코어다. 전체 게임의 모든 원화·발사체·메인 화면을 교체했다고 주장하지 않는다. Android 실기기 성능, 사람의 플레이 감각, 최종 미술 승인은 별도 검토가 필요하다.
