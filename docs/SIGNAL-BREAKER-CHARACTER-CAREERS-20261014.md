# 시그널 브레이커 — 추천 성장 · 캐릭터 전문화 · 가로 몰입 화면

## 이번 요청과 적용 범위

2026-10-14 사용자가 요청한 초보자 추천, 시각적 성장 경로, 가로 화면 가림 개선, 캐릭터 선택, 캐릭터별 세계관과 테크트리를 운영 브레이커에 구현했다. 기준은 Master Design Principles, Gameplay Doctrine, 2026-10-13 PSI RPG 상세기획 및 기존 운영 성장 구현이다. RPG 상세기획의 미구현 경험치·연구 증거 경제 전체를 새로 도입하지 않고, 현재 운영 중인 웨이브 포인트·31P 한도·보유 부품·젬·작전 진화 조건에 연결했다.

## 처음 시작하는 사람의 흐름

1. 로비의 **캐릭터 선택 · 추천 성장**을 연다. 준비 화면에서도 같은 메뉴를 연다.
2. 상단에서 현재 인물과 추천 특성, 효과, 비용 1P, 적용 후 등급을 확인하고 **추천 특성 1P 적용**을 누른다. 자동으로 재산을 소비하지 않는다.
3. 기본 방호의 첫 특성 5등급까지 생존 여유를 확보한다. 이후 해당 인물의 전문 계열을 우선한다. 다른 계열은 자유롭게 투자하고 무료 초기화할 수 있다.
4. 다음 구간 튜닝은 회수·연쇄 유지·장비 여운 순서로 현재 제시된 선택 중 추천을 표시한다. 현장별 기본 프레임과 작전 중 진화도 기존 엔진 조건 안에서 추천한다.
5. 장비 탭에는 실제 보유 부품 또는 호환 젬으로 적용 가능한 추천만 표시한다. 개조는 부품 1개, 장착은 기존 젬 재고를 사용한다.

여러 등급의 특성 설명은 최고 등급 기준이며 등급당 효과를 균등 배분한다는 설명을 함께 표시한다. 추천은 클릭할 때마다 다시 계산하고, 포인트가 없거나 한도에 도달하면 소비 버튼을 만들지 않는다.

## 캐릭터와 세계관

신호는 사람을 공격 대상으로 바꾸는 설정이 아니다. 같은 현장의 동료가 자기 경험으로 위험 신호의 흐름을 제어한다. 공식 이름·직무·별칭과 기존 여섯 캐릭터의 실제 아트를 재사용한다. 아래 전문화는 브레이커 게임 내 능력이며 실제 자격이나 본편 Career 수치가 아니다.

| 인물 / 경로 | 경험에서 이어지는 기술 | 해당 계열 5 / 9 / 15P 달성 시 고유 효과 |
|---|---|---|
| 안전관리자 / 현장 지휘 · 방호 | 신호 읽기 → 대응 여유 → 팀의 호흡 | 연쇄 +0.1초 / 방호 반사 허용 +5% / 보조 장비 쿨다운 -4% |
| 강태식 / 버팀목의 기술 · 방호 | 버팀목 → 흔들림 통제 → 현장의 리듬 | 반사 감쇠 5% 감소 / 방호 반사 허용 +5% / 연쇄 +0.2초 |
| 윤성호 / 철근의 공진 · 키네틱 | 방향 읽기 → 공진 정렬 → 분리의 기술 | 탄속 +4% / 충격량 +5% / 넉백 반경 +12 |
| 이재훈 / 사각의 설계 · 공학 | 사각 탐색 → 동선 설계 → 정밀 배치 | 전자석 반경 +4% / 포획망 반경 +5% / 보조 장비 쿨다운 -4% |
| 임준호 / 첫 신호의 발견 · 공학 | 작은 징후 → 함께 회수 → 신호 연결 | 연쇄 +0.1초 / 포획 한도 +1 / 전자석 유도력 +5% |
| 안전감시원 / 통제선의 수호 · 방호 | 접근 통제 → 확산 억제 → 통제선 유지 | 방호 반사 허용 +4% / 위험 방출 지연 +4% / 반사 감쇠 6% 감소 |

고유 기술은 해당 계열 투자량을 채우면 순서대로 활성화되고 실제 전투 엔진의 기존 효과 계산에 더해진다. 기술 상태를 활성/미활성, 투자량/조건, 연결 화살표로 표시한다. 공통 전문화 3개 계열에는 5개 단계별 투자 등급·완료·다음 투자·선행 조건을 표시하며 위에서 아래로 연결한다. 장비는 1→4단계 이름을 연결하고, 작전 진화는 프레임→조합→확산/집중→최종 강화 경로와 구간·부품 조건을 표시한다. 외부 게임의 이미지나 UI 자산은 가져오지 않았다.

## 저장과 교대

- 기존 저장 키를 유지하고 schemaVersion 3으로 확장한다. 기존 공통 투자 내역은 안전관리자 경로에 보존한다. 타 인물은 독립 투자로 시작한다.
- 획득 포인트 한도와 장비·젬·부품·보상 중복 방지는 공유한다. 캐릭터마다 같은 획득 한도 내에서 자신의 투자 내역을 기억한다. 캐릭터 교대나 초기화로 포인트·부품·젬을 지급하지 않는다.
- 작전 중 캐릭터 교대는 잠근다. 로비와 새 작전 준비에서 교대한다. 현재 인물의 외형과 전투 능력이 일치한다.
- 저장 실패 시 특성 투자·초기화·교대·개조·소켓 장착은 이전 값으로 되돌린다. 저장 오류 안내와 재시도는 기존 화면에 유지한다.
- 훈련은 캐릭터 ID·투자 프로필까지 복제한 임시 관리자에서 처리하고 원본 성장 저장에 반영하지 않는다.
- 초상만 저장하던 방식의 누락을 수정해 여섯 인물의 실제 동작 이미지 67개도 서비스 워커 설치 캐시에 포함한다. 기존 PNG 원본 총 98.2MiB가 최초 설치 시 추가 다운로드·저장 대상이다. 이후 캐릭터 교대는 오프라인에서도 가능하다. 실물 모바일 배포 전 이 초기 용량과 설치 시간을 측정하고, 원본 좌표·투명도·동작 품질을 보존하는 자산 압축은 별도 최적화 대상으로 남긴다. 이미지 스타일이나 바이너리를 임의로 변경하지 않았다.
