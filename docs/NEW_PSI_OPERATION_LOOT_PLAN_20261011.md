# NEW-PSI — 게임의 첫인상·현장 개성·아이템 성장

2026-10-11 · 기존 마스터 바이블의 현장·팀·신호 관찰 방향과 현재 다섯 구역을 유지한다.

## 이번에 구현한 방향

접속하면 저장된 작전의 중간 강화 패널 대신 SIGNAL BREAKER의 작전 화면을 먼저 보여준다. 다섯 현장의 기존 고품질 배경, 사건의 궁금증, 고유 기믹과 목표를 선택해서 미리 볼 수 있다. 잠긴 현장도 미리보기는 허용하되 출동에는 기존 해금 조건이 적용된다. 이어하기는 보조 버튼이고 새 작전 시작이 주 행동이다. 사용자가 시작하기 전에는 전투 시간이 흐르지 않는다. 플레이 중 작전 선택을 열면 일시정지되고, 복귀로 같은 작전을 계속할 수 있다.

| 현장 | 개성 | 다음 행동을 만드는 궁금증 |
|---|---|---|
| 첫 반사 | 반사 궤적과 동료의 발생원 통제 | 같은 자리에서 왜 계속 신호가 생기는가 |
| 이동 반입 | 움직이는 완충 장치와 벨트 | 바뀐 동선에서 어떤 사선이 열리는가 |
| 집진 통로 | 분진 안정화와 게이트 타이밍 | 눈앞의 분진이 어느 구역에서 왔는가 |
| 장력 릴레이 | 하중 고정과 순서 | 전달되지 않은 변경이 어디를 흔드는가 |
| 반입동선 혼선 | 전류와 순서형 보스 | 앞 구역의 신호가 어떤 약점으로 연결되는가 |

기존 최종 배경 이미지를 그대로 사용한다. 신규 저해상도 배경이나 임시 시각물을 만들지 않는다. 창작 대사 75개와 3개 이야기 흐름, 자동 강화와 다음 구역 연결은 앞선 개선을 유지한다. PSI는 Proactive Safety Intelligence — 사고 전 신호를 모아 다음 위험을 먼저 읽는 안전지능이다.

## 아이템 습득 규칙

새 연속 작전에서 외피가 아닌 내부 위험까지 두 번 해소할 때마다 아이템 하나를 떨어뜨린다. 순서는 P → P → C → W로 반복해 무작위 운보다 플레이 성과로 성장을 예상할 수 있게 한다. 외피만 깨거나 같은 위험을 중복 처리해서는 보상을 얻지 못한다.

| 아이템 | 획득 효과 | 플레이에서 느끼는 변화 |
|---|---|---|
| P / 화력 조각 | 3개마다 LV.2, LV.3까지 성장 | 펄스 확산탄과 더 짧은 발사 간격 |
| C / 충전 모듈 | 작전포인트 +20P | 40P로 6초 연쇄 강화, 14초 재사용 대기 |
| W / 시그널워치 | 5초 위험·약점 표시, 3개 연결 | LV.2 이상에서 장비 조합의 자동 보조 사격 |

아이템은 떨어진 뒤 가까운 범위(세계 좌표 220)에서 플레이어를 향해 회수된다. 멀리 있는 아이템은 바닥으로 내려오며 8초 뒤 소멸한다. 움직여 다가갈 이유를 만들되 정밀한 픽셀 맞추기를 요구하지 않는다. 한 화면에 최대 20개, 투사체 32개를 유지한다. 중간에 선택창이나 획득 확인창은 없다.

워치 조합은 펄스와 회수망 / 미스트 / 자력 유도 / 앵커 / 스캔을 연결한다. 회수망은 4번째 펄스마다, 나머지는 6번째마다 보조 효과나 실제 보조 투사체를 발생시킨다. 워치만 얻으면 바로 강해지는 것이 아니라 화력 LV.2와 워치 3개가 함께 필요하다. HUD에서 화력의 다음 조각과 워치 연결 수를 확인할 수 있다.

남은 아이템은 웨이브와 같은 순회의 다음 구역으로 이어진다. 경계 저장에는 아이템 위치·나이·유형과 워치 수를 제한해서 기록한다. 오래된 저장의 새 항목은 0과 빈 목록으로 복원한다. 한 순회를 마치면 성장과 포인트를 재구성해 계속 새로운 빌드를 만든다. 짧은 모드·실험실·기존 저장의 일반 강화 규칙은 유지한다.

## 계속 한 판 더 하고 싶게 만드는 아이디어

1. **눈앞의 작은 목표:** P 한 개만 더, 40P 충전, 워치의 마지막 연결이 동시에 다음 행동을 만든다. 현재 구현했다.
2. **성과가 만드는 폭발 리듬:** 외피 분할 → 종류별 위험 동작 → 재해소 → 아이템 회수 → 확산탄과 조합 사격으로 다음 위험을 처리한다. 현재 구현했다.
3. **풍경과 공격법이 바뀌는 순회:** 다섯 현장의 배경과 기믹, 자동 연결, 짧은 무전으로 같은 화면의 반복을 줄인다. 현재 구현했다.
4. **다음 제작 후보 — 워치 예고 해소:** 다음 등장 위치를 짧게 먼저 보여주고 그 경로를 읽은 해소에 별도 시각 보상을 주는 시스템. 아직 구현하지 않았다. 실제 플레이에서 기존 표시와 겹치지 않는지 먼저 확인한다.
5. **다음 제작 후보 — 현장별 피날레:** 마지막 위험의 재질·장비 조합에 맞춰 분진이 걷히고 장력이 풀리는 장면을 강화한다. 기존 보스·회수 연출은 유지하며 새 피날레 자산은 이번 범위에 포함하지 않았다.

게임을 자주 끊는 팝업과 선택창은 넣지 않는다. 플레이 성과와 즉시 보이는 변화로 재미를 지향하며 시간 압박형 출석 보상·유료 무작위 획득은 이번 설계에 포함하지 않는다. 한 시간의 지루함이나 스트레스 해소는 사람 플레이 검증 대상이며 시뮬레이션으로 입증하지 않는다. 상업적 적법성이나 상표 사용권 전체를 이 변경으로 보증하지 않는다. 타 게임의 이름·아트·음악·화면 표현을 신규 복제하지 않았다.

## 확인 결과

로컬 규칙·회귀 테스트 89개 통과. 드롭 순서와 화면 한도, 근거리 회수와 멀리 있는 아이템의 낙하, 일시정지, 중복 획득 방지, 실제 보조 투사체, 경계 저장과 잘못된 저장 거부를 확인했다.

## 실제 플레이에서 판단할 것

첫 30초에 무엇을 할지 이해하는지, P/C/W를 쉽게 구분하는지, 두 번 해소한 결과가 획득으로 연결된다고 느끼는지, 조합의 마지막 워치를 기다리는 재미가 있는지 확인한다. 15·30·60분에는 구역 반복·대사 반복·손의 피로·원하는 때 쉴 수 있는지 평가한다. 그 결과로 다음 후보를 선택한다.
