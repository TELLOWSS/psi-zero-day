# 현장정비 보급소 정리

현장 장비 화면과 맞춘 어두운 청록색과 안전 황색을 사용한다. 현재 순찰 장비를 먼저 보여주고, 각 보급 카드에 실제 효과, 연계 장비 이미지와 이름, 활용 이유, 상세 설명, 가격을 배치한다. PC는 두 열, 모바일은 한 열이며 재개 버튼은 하단에 고정한다. 부족한 보급품도 설명을 읽을 수 있도록 카드 전체를 흐리게 하지 않는다.

연계는 현재 보유한 기본·진화 장비를 먼저 표시한다. 보유하지 않은 경우 ‘미보유 추천’으로 구분하며, 별도 세트 보너스·진화 해금으로 오해하지 않도록 안내한다. 공격 배율, 치명타 확률, 회복량 등 설명은 실제 적용식에 맞췄다. 노즐의 범위·지속시간 증가나 안전화의 피해 감소를 표시하지 않는다. 구매 효과와 가격은 유지한다.

보급품 아트는 built-in image_gen으로 제작한 4×2 투명 아틀라스를 사용한다. 생성 프롬프트는 SUPPLY-ART-PROMPT.md에 기록한다. 게임 내 연계 장비 이미지는 기존 장비 아트를 재사용한다.

검증: 기존 전체 테스트 1,780개, 추가 연계 추천 테스트 2개, 타입 검사와 빌드. PC·모바일 두 보급의 전투 정지, 명시적 재개와 설정 공유를 브라우저에서 재검증한다. 화면 기록은 artifacts/safe-supply에 저장한다.
