# 오늘도 무사히 - 인물 성장·진로 서사 확장 v1

작성: 2026-10-09. 사용자 성장 서사 요청에 대한 설계 제안. 기존 애착·현장 서사·반복 플레이 기획의 확장이다. 승인된 안전관리자 STAGE 12 CG/A·B 두 문장은 로컬 시범 연결됐다. 다른 신규 직업명·공식·임계치·대사·원화는 아직 초안이다. 항목별 상태는 `SURVIVORS-GROWTH-IMPLEMENTATION-STATUS-20261009.md`를 따른다.

## 1. 방향

후속 조사에서 본편 `content/episode01/character-growth.json`의 initial/focused/skilled와 시그널 워치의5장·요원별 성장 기록을 확인했다. 아래 네 장면은 새 상태 enum이 아니라 서사 구조다. 기존3단계와 후일담으로 매핑하며 중복 성장 저장이나 자동 모드 공유를 도입하지 않는다. 50개 구역과6명 연결은 [스테이지·인물 성장 연결](SURVIVORS-STAGE-CHARACTER-ARC-PLAN-V1.md)을 따른다.

추천한다. 핵심은 전투 수치의 증가가 아니라 **내가 함께 일한 사람이 어떤 사람으로 성장했는지 보이는 것**이다. 육성 게임의 선택-경험-성장-진로 구조에서 착안하되 참고 작품의 캐릭터·직업·세계관·아트·UI를 복제하지 않는다. 현장의 인물과 위험을 읽는 게임이라는 현재 정체성을 유지한다.

작전 중 레벨·장비 진화는 기존 한 판의 성장이다. 여러 작전에 걸친 인물 성장과 혼합하지 않는다. 기존 6명의 직무와 경력을 지우고 모두 신입부터 다시 시작시키지 않는다. 임준호에게는 처음 익숙해지는 과정, 숙련 인물에게는 전문성 확장과 후배에게 넘기는 경험처럼 각기 다른 시작점을 준다. 캐릭터를 플레이어가 소유·통제하는 대상이 아니라 자신의 판단과 반응이 있는 동료로 그린다.

## 2. 가벼운 선택, 깊은 결과

전투 조작은 늘리지 않는다. 작전 전 선택 목표 하나, 종료 후 짧은 대화 또는 인계 선택 하나를 기존 화면 안에 배치한다. 매 작전마다 둘 모두를 강제하지 않고, 선택 없이 기본 흐름으로 진행할 수 있게 한다. 성장 확인은 결과 화면의 한 장면으로 닫고 상세 기록은 전투 밖에서 연다.

흐름: 역할 목표 -> 실제 대응 -> 종료 인계 -> 동료의 기억 -> 성장 장면 -> 다음 역할 제안. 플레이어가 지나친 선택과 결과의 근거를 함께 보여준다. 예: '빠른 처리' 점수만으로 지도자가 되는 대신, 통로 확보 기록과 확인된 동료 인계, 중요한 선택 장면이 함께 이어진다.

관찰·전문기술·협업·회복/인계는 서사 분류 후보다. 숨겨진 점수표나 실무 능력 평가가 아니다. 실제 계측되지 않는 책임감·용기·신뢰를 전투 횟수로 자동 단정하지 않는다. 같은 적 반복 처치, 유료 장비 구매, 접속 일수는 진로 결정의 근거로 삼지 않는다.

## 3. 네 성장 장면

| 단계 후보 | 이야기 변화 | 이미지 변화 | 플레이어에게 보여줄 근거 |
|---|---|---|---|
| 현재의 나 | 기존 인물의 현재 역할과 고민 | 승인된 기본 인물 유지 | 현재 역할·작전 목표 |
| 나만의 방식 | 반복 경험에서 자기 판단을 말함 | 표정·자세·도구 사용의 안정감 | 서로 다른 작전의 실제 기록 |
| 책임의 확장 | 다른 팀과 조율하거나 후배에게 설명 | 관계 장면·작업 배치·차분한 동작 | 확인된 인계와 이야기 선택 |
| 선택한 길 | 다음 전문 역할을 스스로 선택 | 진로별 대표 장면과 후일담 | 선택의 인과 요약·미래 관심사 |

단계는 연령, 외모 우열, 계급장 수, 반짝임 강도로 표현하지 않는다. 같은 인물의 얼굴·체형·PPE와 핵심 도구를 유지한다. 단계 수와 도달 조건은 아직 미확정이며, 기존 Career/Dark Path/PSI 공식을 대신하지 않는다.

## 4. 진로는 보상 순위가 아니라 살아온 방식

안전관리자 시범 진로 후보: 현장 통제 전문, 작업 조율·멘토링, 위험 조사·개선. 명칭은 세계관 검토 후 확정한다. 각각 통제 판단의 명확함, 동료와의 인계, 원인을 재확인하는 경험을 중심으로 서로 다른 좋은 후일담을 제공한다. 특정 진로만 최강 공격력·최선 결말을 독점하지 않는다.

한 차례 실수나 대응 중단으로 영구 진로를 잠그지 않는다. 실패 후 재확인과 회복도 의미 있는 경험이다. 같은 작전 재도전을 성장 파밍으로 무한 누적하지 않는다. 둘 이상의 방향이 가능하면 플레이어가 비교 후 선택하며, 성장 기록을 보여주고 자신의 길을 재검토하는 기회를 설계한다. 강제 초기화·유료 변경·접속 중단 벌점은 없다.

이재훈에게는 계획과 현장 조율, 윤성호에게는 기술 전수처럼 기존 직무 안의 확장부터 다룬다. 모든 캐릭터가 동일한 직업 트리를 공유하지 않는다. 실제 자격증·승진·법적 권한 획득을 게임 성과로 보장하는 표현은 쓰지 않는다.

## 5. 이미지 제작 계약

먼저 한 인물의 한 성장 사건만 시범 제작한다. 첫 후보는 기존 대표 안전관리자이며, 최종 선정은 Director가 확정한다. 6명 전체의 여러 진로와 전투 아틀라스를 한 번에 만들지 않는다.

초기 범위는 기본 인물 재사용, 중간 성장 대표 이미지 2장, 진로 대표 이미지 3장으로 최대 신규5장인 제안이다. 현재 단계 초상·결과의 성장 장면·기록 다시보기에서 공유한다. 전투 스프라이트는 유지하고, 이후 승인된 의상/도구 변화가 필요할 때 별도 소켓·8방향·보행·가림 계약을 검증한다. 정지 CG를 여러 장 만든 것을 전투 애니메이션 완성으로 계산하지 않는다.

제작 브리프 템플릿:

`기존 승인 reference와 인물 ID / 얼굴·체형·PPE·핵심 도구의 불변 조건 / 이전 장면 / 이번 실제 사건 / 인물의 자발적 판단 / 달라진 자세·표정·관계 / 배경 공정 / 동일 카메라·색·광원 기준 / 변경 금지 목록 / 표시 슬롯·안전 크롭 / 승인 상태와 파일 SHA`

예시 초안: 같은 안전관리자가 확보한 반입 통로 옆에서 다음 팀과 인계 항목을 함께 확인한다. 단독 영웅 포즈나 훈장 대신, 듣는 표정에서 설명하는 표정으로 변화한다. 출입 경계와 PPE를 유지하며 화면에 읽기 어려운 문자를 이미지로 굽지 않는다. 이는 생성 프롬프트 방향이며 최종 장면·원화 승인이 아니다.

각 자산은 초상/성장 CG/전투 파일을 구분해 manifest에 출처·reference·생성 도구·사용권·SHA·Director 승인·표시 위치를 기록한다. 후보는 문서 영역에서만 검수하고 미승인 파일을 public/runtime에 연결하지 않는다. 정체성·손/도구·PPE·크롭·모바일 가독성을 파일 단위로 승인한다.

## 6. 기록과 시스템 경계

현재 실제 필드/생산 경로/추정 금지와 STAGE 12의 연결 게이트는 `SURVIVORS-GROWTH-EVENT-CONTRACT-V1.md`에 대조한다. 현재 aggregate handoff는 시간순 선택 로그가 아니므로 기존 기록만으로 진로 조건을 소급 만들지 않는다.

기존 인계 기록에서 실제 있는 사실만 참조한다. 추가 후보 필드는 characterId, chapterId, eventId, sourceRecordId, choiceId, unlockedSceneIds, chosenPathId, schemaVersion이다. 이는 저장 계약 제안이며 실제 저장 키·마이그레이션·Career 수치 도입 승인이 아니다.

추가 구현 전 사건 ID와 재도전 갱신·중복 처리·저장 실패 재시도·6명 분리·기존 저장 복구를 정의한다. 동일 사건을 다시 재생하거나 결과 화면을 새로고침해 성장/보상을 중복 지급하지 않는다. 구매·수리·정산과 독립시킨다. 원래 지갑·인벤토리·클리어·작전 중 레벨을 바꾸지 않는다. 규칙은 domain/engine, 저장은 app, UI는 읽기와 선택 전달만 담당한다.

새 성우 음성은 최종 대사와 화자·사용권·청취 승인 후 연결한다. 먼저 텍스트의 인과와 말투를 검수하며 기존 음성을 새 사건의 대사처럼 임의 재해석하지 않는다. LIFE ARCHIVE의 기존 엔딩·CG·주요 기록 해금 범위를 활용하되 준비 중 본편이 출시됐다고 표시하지 않는다.

## 7. 작은 시범의 순서

1. 기존 시범 작전 '퇴근 전에, 이 길만은'과 실제 인계 필드 대조. 대표 인물·사건·선택2안·근거 기록·대사·성장 장면을 문서로 확정한다.
2. 공식/임계치 없이 한 사건의 before/after 기록과 다시보기를 제안하고 Director 승인 후 구현한다. 처음에는 하나의 좋은 변화만 검증한다.
3. 승인된 기본 이미지와 텍스트로 흐름을 검증하고 신규 성장 원화 후보5장의 파일 검수를 별도로 수행한다. placeholder를 운영에 넣지 않는다.
4. 저장 회귀·PC/모바일·자연 플레이 확인 후 승인 범위만 배포한다. 변화의 원인을 플레이어가 설명하는지 관찰한다.
5. 시범이 성립한 뒤 진로 선택 장면을 연결한다. 나머지 인물과 새 캠페인은 Episode 01 게이트와 별도 승인을 따른다.

완료 기준: 왜 성장했는지 실제 근거가 보이고, 선택을 건너뛰어도 플레이가 막히지 않으며, 실패/재도전/새로고침/저장 오류에서 진로와 보상 중복이 없다. 같은 인물로 인식되는 원화, 각 진로의 고유 후일담, 모바일 읽기·닫기·다시보기, 실기기 검수를 확인한다. 테스트 성공만으로 애착이나 몰입 향상을 입증하지 않는다.

## 8. 확정이 필요한 결정

사용자는 첫 시범 안전관리자, STAGE12 CG 정확 파일, 안전관리자 두 인계 문장을 직접 승인했다. 후속 '현장 통제 전문 / 작업 조율·멘토링 / 위험 조사·개선'의 방향 구체화에 이어 정확한 세 문장·전투 밖 표시·선택 변경 가능 별도 저장을 직접 승인했다. 로컬 연결과 검증 결과는 `SURVIVORS-PLAYER-NARRATIVE-DIRECTIONS-V1.md`에 정리했다. 이 승인을 새 원화·음성·능력치·보상·직업·진로 공식 승인으로 확대하지 않는다.

대표 인물과 첫 사건, 진로 명칭/세계관, 되돌아보기 정책, 성장 조건/공식, 새 저장 계약, 이미지5장 범위, 최종 대사·파일·청취 승인은 별도 결정이다. 이번 요청은 기획 확장 근거이며 위 미확정 수치를 임의 구현하거나 최종 파일 승인으로 계산하지 않는다.
