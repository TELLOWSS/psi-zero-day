# 시그널 브레이커: 사용자 피드백 6항목 적용

2026-10-14 / `0.56.0-mobile-usability` / 이전 배포 `a16712ff`

| 사용자 피드백 | 확인 원인·적용 |
|---|---|
| 1. 작은 세로 이동 패드·자율성 | 최종 세로 스타일이 패드를 56px로 축소. 104px로 확대하고 겹치던 좌우 보조 버튼은 세로에서 숨김. 자유 패드/고정 패드 선택 추가. 반경 밖 드래그 시 기준점이 따라오고, 원형 데드존과 비례 입력으로 미세·대각선 드래그 처리. 왼쪽 아레나 하단의 자유 터치 영역 확대, 조준과 이동 두 손가락 입력 허용. 고해상도 캔버스에서 자유 패드가 작게 그려지던 좌표도 CSS 픽셀 기준으로 수정 |
| 2. 출발 준비·연결 그리드의 이질감 | 현장 사진을 유지하고 준비 버튼·선택 배지·스테이지 모달을 금속색/황동색 계열로 통일. 과도한 청록 네온 글로 제거. ‘연결’ 대신 ‘작전 준비/선택한 작전/작전 선택’ 표기. 세로 카드 2열 배치 |
| 3. 다음 작전 준비 후 초기화면 복귀 불가 | 준비·정지·완료·실패·튜닝 선택에 ‘브레이커 홈’ 추가. 전투 화면의 메인 버튼도 브레이커 홈으로 변경. 구간 선택 창에서 직접 홈으로 이동 가능. 홈에서 준비/완료/실패/튜닝/정지 상태로 돌아갈 수 있고, 준비/결과/튜닝 화면에서는 Escape도 홈 복귀 |
| 4. 하단 고정 새 작전 시작의 가림 | 로비 footer의 sticky 고정을 해제하여 페이지 내용 뒤에 자연스럽게 배치. 현장 이미지 아래 작전 준비 버튼으로도 접근 가능 |
| 5. 세로 아이콘만 표시 | 작전·가이드·훈련·특성·정지를 11px 한글로 표시. 작전/구간/점수/방호 정보도 한글화. 발사와 자동발사 상태를 한글로 표기. 기존 접근성 이름과 44px 터치 영역 유지 |
| 6. 중앙 자동 팝업의 몰입 방해 | 보스 자동 등장 카드 대신 짧은 설비 안내. 큰 중앙 복구 패널·전체 화면 격자를 간결한 한글 안내로 교체. 토스트·라디오·도움말의 불투명 배경/그림자 완화, 포인터 통과 유지. 집중 강화의 화면 가장자리 밝기도 낮춤. 사용자가 여는 준비·튜닝 선택 창은 실제 선택을 위해 유지 |

새 패드는 **기존 지면 좌우 이동**을 조작한다. 시그널 워치와 비슷한 자유 터치 감각을 보강했지만 캐릭터를 상하로 날리거나 물리·속도·충돌·난이도를 변경하지 않았다. 선택 방식은 로컬 설정에 저장되며 새 보상·경제·이미지 자산은 추가하지 않았다. 기존 원화의 최종 visual lock 판정과 구분한다.

## 검증

- standalone 테스트 271개 통과. 새 순수 입력 테스트: 데드존·비례 속도·대각선·긴 드래그 기준점 이동·반전·고정 기준점·잘못된 좌표 중립 처리. 기존 UI smoke의 가짜 DOM을 실제 사용 API에 맞춰 갱신하고 위치 의존 선택자를 제거.
- root 테스트 2,059개 통과·기존 1 skip. 타입 검사·빌드 통과. 총 통과 2,330개.
- 320×568, 390×844, 844×390, 1440×900에서 실제 UI 클릭과 Chrome 신뢰된 터치 입력: 커진 패드, 대각선 이동, 두 손가락 이동/조준, 손 뗀 뒤 이동 정지, 준비→홈→준비, 구간 창→홈→준비, 전투→홈→재개, 비고정 footer, 한글 표시, 투명 안내 검사. 작은 세로·긴 세로의 합성 화면을 열어 검토.
- 8개 viewport UI/UX 회귀 검사 통과. 세 방향에서 실제 입력으로 10작전·엔딩·보상·강화·저장·재접속 완료. 다음 작전 준비에서 홈 복귀 후 준비 재접속도 추가 검사.
- 실제 첫 구간 완료·저장 복원 후 튜닝→홈→튜닝: 같은 후보와 정지된 시간 유지. 별도 피격 진단 fixture에서 실패→홈→실패→선택 유지 재도전 준비 검사. 피격 fixture는 인간 승률 근거가 아니다.
- 서비스워커 캐시·릴리스와 100개 자산 해시 갱신. 세부 결과: `docs/qa/signal-breaker-six-usability-20261014.json`; 로컬 로그·이미지: `artifacts/usability-*`.

실제 휴대폰의 엄지 가림·잡는 자세·패드 감각, 안내 투명도의 실외 가독성은 사람과 물리 기기 확인이 남는다. 이번 검사는 자동 입력/viewport 검증이며 실제 기기 FPS·재미·구매 전환을 측정하지 않는다.
