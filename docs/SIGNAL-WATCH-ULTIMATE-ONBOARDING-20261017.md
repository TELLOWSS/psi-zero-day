# 시그널 워치 궁극기 발견·첫 사용 개선

## 문제와 목표

기존 버튼은 ‘소장 샤우팅’과 READY로 표시되고 모바일에서는 이름이 숨겨졌다. 충전 경로를 플레이 전에 알기 어려웠으며, Space가 충전 전에는 회피, 완충 후에는 궁극기가 되어 같은 입력의 결과가 달랐다. 초보자가 궁극기를 알아보고 직접 한 번 사용하도록 시작 안내 → 충전 확인 → 첫 사용 체험을 연결한다.

## 적용한 흐름

1. 기본 작전 브리핑에 사자후 궁극기의 효과, 위험 통제·안전 기록 수집에 따른 충전, F/화면 버튼 조작을 소개한다.
2. 전투 중에는 모바일에서도 ‘궁극기 · 사자후’, 충전 백분율과 수집 안내를 표시한다. 완충되면 버튼 테두리·색과 준비 완료 문구가 바뀌며 짧은 두 음으로 알려 준다. 기존 음소거와 효과음 믹서를 따른다.
3. 아직 사용 이력이 없는 플레이어의 첫 완충 때만 일시정지 안내를 연다. 레벨업, 상점, 다른 일시정지, 보스 도입 연출 중에는 연기한다. 안내 중 시뮬레이션은 정지한다.
4. ‘지금 사자후 발동’/F는 실제 엔진 발동을 실행한다. ‘충전 보관 · 순찰 계속’/Escape는 에너지를 유지하며 재개한다. 동일 순찰에서 재촉하지 않는다. 건너뛰었다면 다음 순찰에서 다시 배울 수 있다.
5. 실제 발동 성공 후에만 버전 있는 로컬 사용 이력을 저장한다. 저장소 접근이 거부되어도 현재 세션은 계속된다. 숙련 사용자는 완충 알림만 받는다.
6. 궁극기는 F/화면 버튼, 회피는 Space/Shift(기존 C도 유지)로 분리한다. 궁극기의 충전량, 통제력, 기존 연출과 피해 규칙은 바꾸지 않는다.

## 접근성과 검증

안내는 처음 발동 버튼에 초점을 주고 두 행동 사이에 키보드 초점을 유지한다. touch 이벤트는 이동 조이스틱으로 전달하지 않는다. 짧은 가로 화면은 안내 내부에서 스크롤하여 두 행동에 도달할 수 있다. 일반 일시정지창은 중복 표시하지 않는다.

단위 검증은 실제 최대 충전량에 따른 백분율, 잠긴 버튼, 안내 초점·Escape/F, 저장소 오류, 엔진 정지 중 시간/충전 유지와 실제 발동 소모를 확인한다. 브라우저 검증은 1440×900, 390×844, 320×568, 844×390, 568×320에서 시작 브리핑 → 첫 안내 → 보관 → 회피 → F/터치 발동 → 이후 완충 시 재중단 없음까지 확인한다. 브라우저의 완충은 명시적인 QA fixture이며 자연 충전 속도나 초보자의 실제 성공률을 증명하지 않는다.

자동화는 Android 실기기 검증이나 사람의 음질·재미·학습성 승인을 대신하지 않는다. 후속 플레이 관찰에서는 첫 완충 이후 발동까지 걸린 시간, 안내 건너뛰기 이유, 모바일 전투 시야를 평가한다. 별도 사용자 추적·서버 분석 시스템은 추가하지 않는다.
