# 시그널 브레이커 — 진화 검증·그래픽 마감·전투 선택 개선

2026-10-15 사용자 요청. 최신 무기/동작 검토와 EP02 진화 기획·EP03 공세 기획 및 상위 게임 원칙을 기준으로 현재 기능을 보강한다. 현장 위험 신호를 해소하는 게임이며 사람을 공격 대상으로 만들지 않는다.

## 진화 메커니즘

- 조합 진화는 기본 5부품(촉매 모듈 4), 전문화는 9부품+2구간 완료, 최종 진화는 14부품+3구간 완료. 부품은 누적 확보 기준이며 소비하지 않는다. 확산/집중은 이번 작전에서 한 경로만 고른다.
- 기존 명중 처리는 **발사 후 보조 장비를 전환한 상태**를 읽었다. 이제 실제 발사체에 저장된 계열·조합·전문화·최종 상태를 사용한다. 이미 발사한 조합탄은 유지되고, 조합 보조 장비를 뺀 뒤 발사한 탄은 기본 계열로 나간다. 다시 장착해도 기본탄에 과거에 없던 진화를 붙이지 않는다.
- 저장 검증에 집진 현장의 안정화 장비 제약이 빠져 있었다. 정규 진화가 허용하지 않는 프리즘/특이점 조합을 해당 현장의 저장 복구에서도 거부한다. 정상적인 폭풍/플라즈마 및 기존 합법 저장은 유지한다.
- `canEvolve`로 실제 엔진과 정비 UI의 선택 조건을 합친다. 실제 부품·완료 구간을 읽는 `progress`는 읽기 전용이다. 기존 레거시 진단용 발사체 API는 유지한다.

## 전투 선택의 개선

정비에서 조건을 충족하면 **추천 진화 + 추천 튜닝으로 다음 구간**을 한 번에 선택할 수 있다. 버튼에 선택할 진화 이름이 보이며 명시적으로 눌렀을 때만 실행한다. 자동으로 부품을 소모하거나 다른 경로를 덮어쓰지 않는다. 개별 진화/튜닝 선택과 진화를 보류하고 진행하는 선택도 유지한다. 추천 진화 노드를 우선 포커스해 초보자가 기회를 놓치지 않도록 한다.

전투의 기존 한 줄 안내 영역에 다음 진화의 부품/구간 조건 또는 필요한 보조 장비를 표시한다. 보스 경고·급강하·시간 제한은 진화 안내보다 우선한다. 새 중앙 팝업이나 전투를 가리는 패널은 추가하지 않는다. EP03의 실제 공세·역할·해소 증폭 규칙과 기존 영구 경제는 유지한다.

## 그래픽 ‘마지막 2%’의 방향

현재 승인된 현장·캐릭터·위험체·발사체 원화를 사용한다. 새 원화를 생성했다고 기록하지 않는다. 실제 피해 사건의 표현 품질을 높이는 데 집중한다.

- 장갑이 실제로 0이 되는 순간에만 짧은 청록 노출 링과 흩어지는 6개 장갑 조각을 그린다. 이미 벗겨진 장갑은 중복 파괴 효과를 만들지 않는다.
- 폭풍의 청색 번개 / 특이점의 녹색 연결·이동 고리 / 프리즘의 보라색 평행 사선 / 플라즈마의 주황색 접점 고리를 구분한다. 실제 손상된 목표 사이에서만 연결하고 최종 진화의 선 굵기를 한 단계 높인다.
- 승인된 위험체 원화에 절제된 입체 명암과 작은 하부 그림자를 더한다. 충돌 크기와 원화 셀 크기는 그대로 유지한다. 장갑에는 어두운 전체 트랙을 깔아 남은 호를 배경에서 읽기 쉽게 한다.
- 진화 선택 성공은 인물 주변의 짧은 장착 링으로 표현한다. 화면 전체 섬광·추가 카메라 흔들림·장시간 불투명 효과는 만들지 않는다.
- 효과 상한 low 8 / balanced 16 / high 28, 최대 수명 0.55초 유지. low는 명암/추가 광선을 줄이고, 줄인 동작은 장식 조각·흐름 고리를 생략한다. 위험 경고와 실제 데미지는 품질 설정에 영향을 받지 않는다.

## 검증 방법과 제한

새 순수 회귀는 4조합의 실제 발사→보조 장비 변경→명중 효과, 기본탄에 소급 진화 금지, 누적 부품/구간 게이트, 제한을 우회하는 저장 거부, 실제 장갑 0 사건, 조합별 연결 메타데이터와 효과 상한을 검증한다.

브라우저 전체 여정은 신규 계정으로 세로/가로/PC에서 15작전씩 진행한다. 일반 이동·조준·발사·장치 명령과 실제 UI의 추천 진화/튜닝 버튼을 사용하며 강제 승리·체력·시드·부품 수정은 하지 않는다. 빠른 엔진 시간 진행은 자동 검증용이며 사람의 손맛이나 초보자 성공률의 증거로 해석하지 않는다. 오프라인 검증의 과거 완료 기록 fixture는 해금용이며 첫 구간 전투/저장/이어하기는 실제 진행으로 확인한다.

릴리스: `0.62.0-evolution-clarity`. 캐시 자산 179개, 추가 이미지/음원 다운로드 없음. 실물 Android의 발열·프레임률과 주관적 그래픽 완성도는 후속 플레이 리뷰 항목이다.
