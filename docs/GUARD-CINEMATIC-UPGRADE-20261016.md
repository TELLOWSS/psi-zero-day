# Signal Guard 그래픽·몰입 개선 — 2026-10-16

## 연출 방향과 구현

산업 현장의 따뜻한 작업등과 차가운 방어 신호를 대비시키고, 실제 공격 → 접촉 → 해소의 순서를 읽을 수 있도록 구현했다. 화면 전체를 반복해서 흔드는 대신 장비의 짧은 반동, 보정된 발사구 충전등, 실제 대상 위치의 파편과 피해, 짧은 해소 섬광을 사용한다. 적은 종류별 부유·진동 주기가 다르며 보스의 장갑과 실제 고정 상태를 별도 표식으로 표시한다.

새 실제 알파 자산은 built-in image_gen으로 생성·수정했다. 프롬프트 원문은 `docs/guard-cinematic-image-prompts-20261016.json`, 생성 원본 경로와 해시는 `content/defense/guard-cinematic-v1.json`에 기록했다. 최종 후보인 8프레임 아틀라스는 `public/assets/defense/cinematic-v1/signal-resolve-atlas.webp`이며 229,470바이트다. `scripts/ingest-guard-cinematic-assets.mjs`는 원본을 균등 셀과 투명 여백으로 정규화한다. 사용자의 최종 아트 승인을 의미하지 않는다.

실제 해소에만 400ms 애니메이션을 표시한다. 동시에 공격 그룹 24개, 해소 스프라이트 4개, 피해 숫자 8개, 전장 조명 2개로 제한한다. 정지·숨김 시 공격 효과를 정리하고 움직임 줄이기 설정에서는 정적 전투 정보가 남는다. 엔진의 피해·자원·점수·승패 규칙은 연출 계층이 변경하지 않는다.

전투 중 전장을 우선하도록 도크를 압축하고 짧은 가로 화면은 조작부를 측면에 배치했다. 장비 선택 시 상세 전술 화면을 제공한다. 무료 진화 미리보기와 별도 비용 확정, L4 비교 실험실, 실제 경로 기준 출구 경고, L4 발사 원점 및 음향 보완은 `docs/GUARD-PLAN-AUDIT-IMMERSION-20261015.md`에 항목별로 기록했다.
