# 후면 보행 다리 늘어남 수정 — 2026-10-09

사용자 영상 `KakaoTalk_20261009_125756721.mp4`의 약 64초 장면에서 이동 중 다리 늘어남을 확인했다. 기존 접지 보정의 허용 이동량은 캐릭터 높이 74px의 45%(33.3px)였다. 하체가 약 40%(29.6px)인 원화에 이런 보정을 적용하면 발을 지면에 남겨두는 동안 다리 영역을 과하게 늘릴 수 있었다. 이 문제는 원화에 긴 다리가 그려진 것이 아니라 렌더링 변형의 허용 범위에서 발생했다.

## 구현

- 원화의 발과 하체 시작점을 기준으로 허용 길이를 계산하고, 변형된 다리 길이를 원화의 108% 이내로 제한한다. 좌우 이동도 캐릭터 높이의 12% 이내로 제한한다.
- 제한이 적용된 실제 발 위치를 접지 추적기에 다시 기록한다. 이전의 도달할 수 없는 월드 접점을 계속 끌고 가지 않는다. 게임의 캐릭터 좌표·이동속도·충돌·입력은 바꾸지 않는다.
- 몸, 부츠 및 빛 효과가 같은 보정 발 위치를 재사용한다.
- 두 발의 가로 좌표가 같은 경우에도 하체의 왼쪽·오른쪽 영역을 서로 다른 다리로 배정한다. 기존에는 두 다리 모두 왼쪽 영역을 선택할 수 있었다.

## 재현·검증

`tests/verify-survivors-leg-proportions.mjs`는 브라우저에서 실제 캐릭터 원화와 게임의 동일한 렌더러를 사용한다. 6명×8방향×전진/후진의 96조합을 초당 320px 이동으로 재현한다. 수정 전 대조군은 테스트 브라우저에서만 길이 제한을 우회하며 제작 파일을 되돌리지 않는다. 각 프레임의 하체 시작점-발 거리를 원화의 같은 거리와 비교한다. 수치는 모델의 기하학적 길이 비율이며 픽셀 단위 전신 해부학 측정으로 계산하지 않는다.

- 수정 전 대조군 최대: 플레이어 2.127, 강태식 2.077, 윤성호 2.085, 이재훈 2.125, 임준호 2.155, 안전감시자 2.221.

- 브라우저 픽셀 검사: 발 좌표가 겹치는 경우에도 하체 양쪽의 픽셀이 보존되는지 확인한다.
