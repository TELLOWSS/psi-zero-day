# 2-B / 2-C 검증 및 부분 적용

컨베이어 가동·운전·정지·성공 마무리와 실제 표적 타격음 5개를 적용했습니다. WAV 원본을 그대로 보관합니다. 운전음은 성공 이벤트의 1.3초 구간으로 사용하며 지속 운전 루프라고 표시하지 않습니다. 방출음은 컨베이어에 대응하는 물리적 포획/방출이 없어 보류하고, 데모는 감상용으로 제외했습니다.

ZIP의 중앙 디렉터리 오프셋이 실제 데이터 위치와 다릅니다. 로컬 헤더를 별도로 검사하여 원본 크기와 CRC가 모두 맞는 항목만 복구했습니다. 음악 groove만 검증됐고 full_mix/tension/base는 DEFLATE 오류, special은 로컬 헤더를 찾지 못했습니다. 음악의 합산·정렬 검증이 불가능하여 음악 교체는 하지 않았습니다.

복구된 8개 오디오는 Chrome Web Audio로 디코딩했습니다. 컨베이어 7개에는 디코드 샘플 full-scale 초과가 없었습니다. 시작/종료의 급격한 경계는 기존 DC 제거·3ms/25ms 페이드와 재생 엔벌로프로 처리합니다. 주관적 청취와 음악성 확정은 별도입니다. 제작 README는 numpy 합성이라고 명시하며 AI 모델 생성이나 청취 완료로 표시하지 않습니다.
