# 메인 화면 PSI 원형 마크·안전모 표기·캐릭터 연출 개선

작성: 2026-10-17.

## 요청과 적용

첨부된 브랜드 화면을 확인했다. 기준은 **오른쪽으로 높아지는 비대칭 파란 방패, 흰색 동심원 눈과 중앙 원, 하단 PSI 상호**다. 첨부 자료에 없는 법인명은 만들지 않고 PSI를 사용했다.

- 기본 메인 로고의 종전 NEW PSI 심볼 대신 첨부 마크의 형상을 벡터로 재현해 연결했다. 원본 벡터 파일을 받았다는 의미는 아니다.
- 원래 로고의 파란색·흰색·남색 PSI 글자가 밤 배경에서도 읽히도록 밝은 바탕 위에 표시한다. 게임 부제 ZERO DAY는 마크와 분리했다.
- 메인 상단 상호도 PSI로 표시한다. 사이트 전체의 공식 게임명, 기존 파비콘과 다른 장면의 브랜드 파일을 일괄 교체하지 않았다.
- 가로·세로 원화의 주연 안전모에 PSI 방패 마크와 PSI 상호를 곡면·원근·조명에 맞춰 넣었다.
- 추가 요청에 따라 성인 주연의 눈빛, 입술, 얼굴 조명과 몸의 흐름, 작업복의 허리·힙 핏을 더 관능적으로 다듬었다. 기존 주연의 인상, 현장 동작, 안전모, 조끼, 장갑, 전체식 안전벨트의 가슴·허리·다리 스트랩을 유지했다.
- 작은 세로 화면은 제목의 가로폭을 줄여 얼굴과 안전모 마크를 가리지 않게 했다. 가로 화면은 배경 시작 위치를 조정해 상단 조작부가 안전모 마크를 덮지 않게 했다.
