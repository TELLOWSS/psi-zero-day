## 구현

최종 무기는 광역/근거리/설치/집중 사격의 역할을 유지하면서, 등장 지점까지 공격이 이어지는 문제를 제한했다. 적 체력이나 모든 난이도를 일괄 높이는 방법은 사용하지 않았다.

| 진화 무기 | 이전 | 변경 |
|---|---|---|
| 위성 방송 | 수명 2.2초, 관통 99, 간격 1.1초 | 수명 0.52초(약 302 거리), 관통 3, 간격 1.4초 |
| 냉각 분사 | 16발, 수명 0.8초, 관통 99 | 12발, 수명 0.55초, 관통 3 |

| EMF 방벽 | 1.2초 간격, 15초 잔류, 관통 99 | 2.4초 간격, 6초 잔류, 관통 6 |
| 헌터 드론 | 무제한 탐색, 0.22초 간격, 1.2초 탄환 | 탐색 260, 0.4초 간격, 0.38초 탄환 |

기본 드론 탐색은 300, 무전 탐색은 450이다. 투광등 기본 범위는 70+레벨×14다. 피해량 비교 화면은 엔진과 같은 tuning 함수를 사용한다. 오라 둔화는 기본 속도를 영구적으로 낮추지 않으며 범위 이탈 시 복구한다. 화면 오라 반경도 실제 판정값을 사용한다.

장착 표현은 임의의 아이템 하나를 옆에 띄우던 방식에서 카테고리별 몸체 소켓으로 변경했다. 통신/손목/백팩/보호/전술 부착 위치가 바라보는 방향을 따른다. 기존 승인 아틀라스를 사용하며 새 캐릭터 착용 원화를 제작한 것은 아니다. 완전한 캐릭터별 착용 아트와 관절별 의상 교체는 후속 아트 작업이다.

기존 장비의 실제 damage/cooldown/체력/회복/보호막/동행 억제 능력은 유지했다. 가까운 보급 회수에는 회수 연결선, 실제 억제 중인 물리 위험에는 통제 표식과 연결선을 표시한다. 보호막 흡수·소진·재충전은 기존 엔진 상태로 표현한다. 없는 공격/효과를 시각적으로 가장하지 않는다.

레벨 1~5를 기존 3개 묶음 대신 개별 tier로 구분했다. 탄환의 펄스 표식 수, 발광 크기, 꼬리와 접촉 효과의 차이를 주며 reduced-motion에서도 정적인 단계 표식은 유지한다. 진화는 별도 projectile kind와 기존 진화 장비 아트로 구분한다. 기존 원화는 모든 단계의 전용 원화가 아니라 아틀라스+모듈 방식이다.

장비실은 독립 컴포넌트로 분리했다. 상단 6개 슬롯과 장착 해제, 분류/보유/구매가능 필터, 가격·부족 크레딧, 동일 카테고리 교체 대상, 구매/장착/해제 완료 상태를 제공한다. 보유 장비 장착과 구매는 별개의 동작으로 유지하며 자동 구매/자동 장착은 하지 않는다. 기존 PSI 지갑과 저장 규칙을 사용한다. 실제 현금 결제는 이번 범위가 아니다.

## 검증

- 타입 검사 통과.
- 전체 Vitest: 221 파일 통과, 1 파일 skip / 1169 테스트 통과, 1 skip.
- npm run build 및 prebuild의 자산/기존 Episode 01 회귀 통과.
- 원거리 헌터 탐색 제한, 위성탄의 진입 지점 무피해, 오라 밖 테슬라 무피해, 기본 이동속도 보존 회귀 추가.
- 장비 필터, 보유 여부, 구매불가, 교체 안내, 기존 구매/장착/저장 실패/재실행 회귀 통과.
- 변경된 레벨 tier 계약에 맞춰 기존 VFX 테스트 수정. 무전 장비가 헌터 명중을 금색으로 바꿔야 한다는 오래된 테스트 기대도 현재 무기별 색상 계약에 맞췄다.
- 짧은 피드백 테스트는 사거리 안 표적을 명시해 화면 밖 즉시 공격에 의존하지 않게 했다.

jsdom의 Canvas/Audio/scrollTo 미구현 경고는 실기기 검증을 대신하지 못한다. 모든 진화 빌드와 20개 스테이지의 체감 난이도, 실제 Android 장착 가독성, 최종 착용 아트 품질은 별도 플레이/아트 리뷰가 필요하다. 최종 무기가 더 이상 쉽지 않다는 주관적 결론은 테스트만으로 확정하지 않는다.

브라우저 검수: 1440x900 장비실/전투와 390x844 장비실/전투 캡처를 저장했다. 모바일 장비실 clientWidth/scrollWidth 모두 356px로 가로 넘침이 없다. 전투 캔버스 픽셀 샘플에서 80,985개 유색 샘플을 확인했으며 실제 시간 진행/자동 공격을 화면으로 확인했다. 브라우저 오류 목록은 비어 있었다. 검수 브라우저의 지갑은 테스트용 보유 장비를 주입했으며 실제 결제 증거가 아니다. 상점 제품 이미지의 검은 배경이 전투에 남는 문제를 발견해, 전투 부착물/동행은 배경 제거된 기존 equipment/pickup 아틀라스로 변경했다. 전용 착용 원화의 완성으로 계산하지 않는다.

최종 renderer 변경 후 관련 17개 회귀, 타입 검사, Vite build를 다시 통과했다. 로컬 빌드 미리보기: http://127.0.0.1:5195 (별도 프로세스 PID 18836). GitHub push/배포는 수행하지 않았다.
