# 마스터 보드 반영 — 첫 타설 장면 안내와 기록

사용자 ZIP 28장 검토 후 기존 첫 타설 이벤트에 장면 맥락을 연결했다.
원본 전체 검토는 작업 폴더 masterboard-review-20260918/검토결과.md에 있다.

- REF01: 기존 제목 화면과 현장 합류 이벤트 유지.
- REF20: 차량 동선·첫 타설 장면 목표를 기존 계획/경사로/진입/타설 이벤트에 연결.
- REF04: 점검과 재점검, 재개 압박 이벤트에 작업 통제·재확인 목표 연결.
- REF05/18: 반응, 책임 조율, TBM, 작업중지 이후 소통, 지시 전달 이벤트의 맥락 안내.
- REF06/12: 실제 방문한 선택/결과를 장면별로 필터링하는 기록을 홈과 완료 화면에서 공유.

분류는 읽기 전용이며 진행률, 점수, 안전 판정, 해금 조건으로 쓰지 않는다.
방문하지 않은 분기나 미래 결과는 표시하지 않는다. 직접 연결된 결과 문장이 없는 선택은 이를 명시한다.
기존 저장 데이터 구조는 변경하지 않는다. 장면 목표는 기본 접힘이며 키보드 조작이 대화 진행과 충돌하지 않게 한다.

이번 범위에서 새 배경/캐릭터 이미지를 생성하거나 ZIP 이미지를 게임 자산으로 채택하지 않았다.
장면별 독립 배경, 회의 공간 연출, 캐릭터 동작과 24개 에피소드 확장은 후속 작업이다.
캐릭터 역할 및 공정 단계가 다른 참고 이미지를 그대로 넣어서는 안 된다.
