작성일 2026년 10월 19일. 사용자의 「기획서를 바탕으로 우선순위로 구현실시」 요청에 따라 기존 Episode 01과 공개 가드의 개선을 적용했다. 신규 캠페인이나 전투 수치 변경은 포함하지 않는다.

## 기록과 호환성

서사 기록은 `psi.story.evidence.v2`에 쓴다. 기존 `psi.story.evidence.v1` 원문은 변경하지 않고, 새 저장이 없을 때 읽어 일반 훈련 이력으로 투영한다. 구형 기록에 구역·날짜·실행을 만들어 넣지 않는다. 저장 거부 시 현재 수집 자료를 표시하고 저장 실패를 알리는 기존 동작을 유지한다.

워치 인계에는 새 저장 시의 관찰 시각과 가능한 경우 실행 식별자를 부여한다. UUID를 제공하지 않는 환경에서도 기존 인계 저장은 계속 허용한다. 기존 인계 읽기는 시각과 실행 ID를 새로 생성하지 않는다. 동일 구역의 인계 교체 정책은 유지한다.

가드 시나리오 기록에는 `lastResultWon`을 선택 필드로 추가했다. 기존 저장은 유효하다. 이 필드가 없으면 동일 실행 ID의 전술 보고만 보조 근거로 사용하고, 둘 다 없으면 완료 여부 미상으로 처리한다. `clears`는 누적 완료 이력으로만 사용한다.

이탈 시점의 조준은 엔진이 그 순간의 장비 목록에서 복사한다. 이후 조준 변경이나 장비 매각으로 과거 표본을 덮어쓰지 않는다. 구형 전술 보고의 최종 배치로 과거 조준을 추정하지 않는다. 표본 상한 24개와 저장 크기 상한을 유지한다. 조준 방식이 단독 패인이라고 단정하지 않는다.

재도전은 기존 시작 자원과 기존 저장 정산 경로를 사용한다. 최종 장비를 무료 복제하거나 보상을 중복 지급하지 않는다. 동일한 최종 빌드를 시작 시점에 재현하는 별도 샌드박스는 추가하지 않았다.

## 빌드 경로 보수

첫 빌드는 최종 배경 경로 4개가 없다는 기존 자산 계약 오류로 중단됐다. 현재 HEAD의 카탈로그는 `*-cinema.webp`를 요구했지만, 원본 PNG를 변환하는 `scripts/build-story-cinema-art.mjs`가 일반 npm 전처리에 연결되어 있지 않았다. 저장소에 이미 보존된 네 PNG를 기존 스크립트로 변환하고, `assets:story-cinema`를 predev·pretest·prebuild에 연결했다. 검사 규칙을 완화하거나 이전 그림을 새 최종 자산으로 이름만 바꾸지 않았다.

변환 후 제작 경로 계약은 8/8로 일치한다. 원본의 실제 해상도는 1672×941이며 런타임 1920×1080은 업스케일이다. 기존 아트 README의 이 한계를 유지한다. 이 작업은 자산 재현 경로 보수이며 최종 시각 승인 선언이 아니다.

## 검증

추가한 데이터·UI 검사는 과거 승리 뒤 최신 패배, 구역 구분, 구형 원문 보존, 시간·실행 추정 금지, 중복·역순 수집, 저장 거부, 실제 이탈 시점 조준, 저장·복원과 중복 정산, 모드 저장부터 서사 UI까지의 연결을 확인한다. 기존 26이벤트 접근성 검사에 건너뛰기와 다음 날 맥락 표시 확인을 추가했다.

실행 결과와 로그는 `artifacts/player-priority-implementation-20261019/`에 보관한다. 최종 검증 수치는 실행 종료 후 아래에 기록한다.

검증 상태: npm test 2,315개 통과 / 기존 1개 skip, npm run typecheck 통과, npm run build 통과. 최종 기록 계약을 적용한 뒤 관련 4파일 24검사도 재실행해 통과했다. 개발 서버 127.0.0.1:5189에서 메인 HTML, 변경 모듈 4개, 후속 배경 4개의 HTTP 200 응답을 확인했다. 실제 화면 클릭 성공이나 음향 검수와는 구별한다. 빌드의 기존 500KB 초과 청크 경고는 유지된다.

이 세션의 UI 도구에는 연결된 브라우저와 네이티브 앱이 없어 실제 화면의 스크린샷·클릭 검수는 수행하지 못했다. DOM 통합 검사, 실제 엔진 명령과 로컬 저장 데이터, 개발 서버 로딩을 구분해 기록한다. Android·음향·사람의 재미 평가는 자동 검사 결과에 포함하지 않는다.

후속 업데이트: 이후 브라우저 연결이 가능해져 실제 26이벤트 완료, 모바일 화면, GUARD 전투·패배 회고·새 준비를 검증했다. 추가 발견과 수정, 최종 2,316개 통과 결과는 [플레이 화면 후속 검증](PLAYER-VISIBLE-QA-20261019.md)에 기록했다. 위 도구 연결 제한은 최초 구현 시점의 상태다.
