# 캐릭터 착용형 장비 제작 및 실행 명세

상태: 제작 명세 / Director 검수 전. 생성 이미지는 최종 후보이며 검수 전 게임 자산을 교체하지 않는다.

첫 착용 후보: `art-candidates/safety-monitor-equipped-v1.png`. 기존 인물의 얼굴/포즈/도구를 유지하며 어깨 송신기, 흉부 보호 모듈, 허리 전원팩, 등판 도킹 장치를 추가했다. 육안 확인상 신체 연결 구조와 손/태블릿이 보존된다. 등판 장치의 드론 형상은 정면 이미지에서 충분히 식별되지 않으므로 후면 납품과 분리 드론 검수가 필요하다. 보호 모듈이 일부 반사띠를 가리므로 안전복 가독성 재검수도 필요하다. 전투 실크기, 프레임 일관성, 독립 장비 레이어 및 실제 투명도 검증은 아직 완료하지 않았다. 런타임에는 연결하지 않았다.

## 1. 첫 제작 범위

대표 캐릭터는 `safety_monitor`(안전감시단). 기존 `safety-monitor-v2.webp`의 얼굴, 흰 안전모, 반사 조끼, 작업복과 장갑을 유지한다. 장비는 기존 상품 `voice_lens`, `shock_mantle`, `inspection_wing` 3종. 신규 능력이나 유료 결제를 추가하지 않는다.

목표는 상품 그림을 옆에 띄우는 것이 아니라 몸에 연결된 구조, 실제 발동 상태, 소리의 원인이 일치하는 착용 경험이다. 영화급은 해상도만으로 판정하지 않는다. 작은 전투 화면에서도 인물과 위험을 식별할 수 있어야 한다.

## 2. 장비별 결합 구조

| 장비 | 착용 및 물리 연결 | 동작과 시각 피드백 | 기존 실제 효과 |
|---|---|---|---|
| voice_lens | 조끼 어깨 무전기 클립, 안전모 외부 이어피스, 고정 케이블 | 무전 송신 시 어깨 송신등과 해당 무전 발사체 동기화; 손과 얼굴을 가리지 않음 | damage +0.15, 현재 전체 피해 보너스 유지 |
| shock_mantle | 조끼 바깥 흉부/등판 보호 모듈과 허리 전원 연결 | 대기 시 보호복 형태 유지; 실제 흡수 때 맞은 방향만 섬광; 소진 시 꺼짐; 재충전 완료 때 짧은 점등 | hp +20, shield 45, shieldPeriod 18 |
| inspection_wing | 등 상단 도킹 레일과 소형 점검 드론 | 등판 도킹 이미지와 분리된 드론을 구별; 활동 중 근처 대상 스캔; 억제 없는 대상에 제압 표현 금지 | suppression 0.2, 엔진의 지정 위험과 거리 조건 유지 |

드론 도킹/출격은 향후 표현 상태이며 새 전투 규칙이 아니다. 무전기 애니메이션을 위해 전체 피해 보너스를 무전 전용으로 변경하지 않는다. 상품 설명/실제 효과 차이는 별도 승인 항목이다.

## 3. 아트 납품 규격

- 피팅용 전신 PNG: 1024x1536 이상, 투명 배경, 발끝과 안전모까지 포함. 기본형과 장비 3종 동시 착용형의 카메라/포즈/비율 동일.
- 실제 전투 자산: 기존 렌더러의 방향과 프레임 계약을 먼저 확인한 뒤 동일 규격으로 납품. 임의 8방향 요구로 기존 런타임을 바꾸지 않는다.
- 장비 오버레이: 인체 앞/뒤 레이어 분리, 공통 캔버스와 발바닥 피벗. 이미지 생성 결과에서 임의 자동 크롭으로 피벗을 잃지 않는다.
- 필수 소켓: shoulder_radio, chest_guard, back_guard, back_dock, belt_power. 좌표는 프레임 실측 후 정규화하여 등록. 임의 좌표를 final로 선언하지 않는다.
- 상품 이미지와 착용 이미지는 별도 파일. 상품 아틀라스를 전투 캐릭터에 잘라 붙이지 않는다.
- 전투 실크기 약 74px에서도 기본형/착용형 실루엣 구별, 투명 가장자리 검수, 얼굴/반사띠 보존.
- AI 생성 한 장은 애니메이션/리깅 완료가 아니다. 프레임 일관성, 케이블 연결, 앞뒤 가림 관계를 별도로 검수한다.

## 5. 테크트리의 시각 문법

Lv1 단일 기능 모듈 → Lv2 케이블/보조 클립 → Lv3 이중 모듈 → Lv4 냉각/전원 구조 → Lv5 완성형 하우징. 이는 기본 무기 레벨의 제작 문법 제안이다. 고정 희귀도의 상점 장비에 존재하지 않는 레벨을 추가하지 않는다.

색만 바꾸거나 화면 전체 광원을 키우는 방식은 불합격. 레벨별 구조와 짧은 발동 패턴으로 구분한다. 이펙트 크기는 실제 판정 반경을 넘어서 공격 가능한 범위를 오인시키지 않는다.

## 6. 사운드: 오케스트라와 장비의 역할 분리

오케스트라는 상황의 감정과 긴장을, 장비 SFX는 조작과 결과의 정보를 담당한다. 전투마다 관현악 강타를 겹치지 않는다.

- 무전: 클립 조작/짧은 송신 클릭/대역 제한된 전자 신호. 반복 발사 변주와 동시 발음 제한.
- 보호복: 장착 버클/전원 기동/방향성 흡수 충격/소진/재충전 완료를 각각 분리.
- 드론: 도킹 잠금/모터 기동/짧은 스캔/복귀 잠금. 모터는 음악과 경고를 가리지 않도록 억제.
- 음악 스템: 현장 저강도, 위험 증가, 긴급 대응, 회복. 공통 BPM/조성과 루프 길이, 전환 마커로 끊김 없이 전환.
- 실제 위험 경고와 대사는 음악보다 우선. 헤드폰/휴대폰 스피커, 음소거/백그라운드 복귀, 반복 피로도를 청취 검수.
- 목표 납품: 음악 무손실 마스터와 웹용 압축본, 분리 스템, 루프 지점, SFX 변주, 사용권 기록. 현재 새 오케스트라 음원은 제작하지 않았다.

## 8. 승인 게이트

1. 대표 캐릭터와 3종 구조 승인.
2. 착용 전신 후보 승인 및 전투 실크기 확인.
3. 프레임/소켓 납품과 실제 상태 연동 승인.
4. 피팅 UX 및 사운드 청취 승인.
5. 대표 캐릭터 완성 후 다른 공식 캐릭터로 확장.

현재 범위에서는 신규 3D 엔진이나 전 캐릭터 프레임 대량 제작을 시작하지 않는다. 완성도 미달 후보를 기존 production 자산 위에 덮어쓰지 않는다.

## 9. 기능 통합 진행 기록

2026-10-05: 구매와 분리된 상점 피팅을 구현했다. 선택한 캐릭터의 실제 map art와 전투용 장비 렌더러를 공유하고, 엔진의 초기 상태에서 현재 장착 대비 수치 차이를 계산한다. 미소유/구매 불가 장비도 시험할 수 있으나 지갑과 저장 상태는 변경하지 않는다. 카테고리 교체와 원상 복귀를 지원한다. 영구 강화 수치도 동일하게 반영한다.
