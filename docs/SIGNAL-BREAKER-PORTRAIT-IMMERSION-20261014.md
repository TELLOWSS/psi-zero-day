# 시그널 브레이커: 세로 전용 몰입 화면

2026-10-14 / `0.57.0-portrait-immersion` / 통합 기준 `0869c717`.

사용자 첨부 영상(약 9.8초, 1080×2340)의 EP02 집진 보스 전투에서 상단 메뉴·보스 프레임·성장/목표 패널·우측 홈/전체 경로 버튼이 전투 장면에 겹치는 것을 확인했다. 원격의 NEW-PSI 모바일 명세·좌표 유틸·반응형 변경 3개 커밋을 보존하고, standalone 브레이커 세로 화면만 별도로 구성했다.

## 구현

- 세로에서는 **몰입 화면이 기본값**. 상단 메뉴를 56px 상태줄(작전·구간·방호·정보·정지)로 줄였다. 보스 이름/진행은 그림 없는 30px 띠로 전투 영역 위에 배치한다.
- 성장·신호 목표·장비 상세·홈·전체 경로를 자동 노출하지 않는다. **정보 → 정지 화면**에서 작전 선택·교본·특성/무기 공학·훈련·장비 자동 전환·자동발사·전체화면·전체 경로·홈과 상세 정보를 제공한다. 원래 기능을 삭제하지 않았다.
- 위험 경고·EP02 남은 시간·짧은 알림·강화/연쇄 안내는 **하단 한 줄**로 모으고, 위험 경고/임박 시간을 우선한다. 전투 중앙의 연쇄/강화 텍스트는 세로 몰입 화면에서 이 줄로 이동했다. 발사·피격·파편 등 실제 효과는 유지한다.
- **104px 이동 패드**와 자유 터치/두 손가락 이동·조준을 유지한다. 조준 패드·발사·두 장비 전환·방호판·벨트·자력·발생원·강화는 전투 영역 밖의 작은 하단 독에서 조작한다. 강화는 기존 엔진의 40P/쿨다운 조건을 그대로 사용한다.
- 보스 카메라는 이미 별도로 확보한 HUD/조작 공간을 중복 차감하지 않도록 세로 몰입 화면에서만 내부 여백을 조정한다. 물리·조준 좌표·충돌·속도·난이도·보상은 바꾸지 않았다.
- 정보 화면에서 **세로 몰입 화면/세로 기본 화면**을 전환할 수 있고 `psi.signal-breaker.portrait-immersion.v1`에 저장한다. 진행 저장 형식을 변경하지 않는다.
- 세로/가로 회전 시 진행 중인 터치 입력을 중립으로 정리한다. 전체 경로를 열고 가로로 회전해도 복귀 버튼이 보이고 정지 → 재개로 돌아온다.
- 가로/PC의 전투 배치는 유지한다. 새 정보 패널·독 축소·카메라 여백은 세로 전용이다. 전체 경로 복귀 버튼은 회전 후에도 접근 가능하도록 보완했다.

## 화면 면적

브라우저 실제 요소 좌표 기준이다. 화면 크기나 보스 상태에 따라 증가율이 달라진다.

| 화면 | 기존 전투 영역 높이 | 몰입 전투 영역 높이 | 증가 |
|---|---:|---:|---:|
| 320×568, 일반 전투 | 234px | 336px | 43.6% |
| 390×844, 일반 전투 | 510px | 612px | 20.0% |
| 390×844, EP02 집진 보스 | 510px | 576px | 12.9% |

영상과 같은 EP02-08의 진단 화면 비교: [몰입 화면](qa/portrait-immersion-20261014/ep02-extraction-immersive.png), [기본 화면](qa/portrait-immersion-20261014/ep02-extraction-classic.png). 보스/목표/접근 기록을 격리된 진단 fixture로 구성한 화면이며 실제 완주·승률·사용자 숙련도의 증거로 쓰지 않는다.

## 검증

- standalone **273개 통과**. 카메라 테스트는 실제 보스 약점/배우 위치가 새 여백 안에 들어오는지, 기본/잘못된 옵션이 기존 카메라를 유지하는지 검사한다.
- 통합 root **2,059개 통과, 기존 1 skip**. 최종 타입 검사·빌드 통과. 기존 큰 chunk 경고는 남아 있다.

- 사용자 영상의 EP02-08 집진 보스·완료 목표 상태를 별도 진단: 패널 숨김·카메라·남은 시간 한 줄 경고, 누른 채 회전 시 입력 중립, 전체 경로를 세로→가로로 회전한 뒤 복귀/재개 검사.
- 기존 6개 사용성 요청과 장비/재도전 검사도 새 정보 경로로 갱신해 작은 세로·일반 세로·가로·PC에서 통과했다. 기존 준비/완료/실패/튜닝의 홈 복귀 경로를 유지한다.
- 세로·가로·PC에서 각각 10작전·엔딩·보상·강화·저장 재접속 완료. 일반 엔진 명령을 가속한 자동 여정이며 승리를 강제하거나 생명을 리필하지 않았다.
- 최종 빌드의 서비스워커에서 새 CSS 캐시를 확인하고, **오프라인 새로고침 → 몰입 화면 → 플레이**를 확인했다. 지원 Chrome의 전체화면 진입/종료도 검사했다.
- 릴리스·서비스워커 캐시 버전을 갱신하고 **101개 자산**의 byte hash를 관리한다.
- 첫 Vercel 빌드는 Windows 작성 파일 5개의 CRLF와 Git/Linux LF 차이 때문에 릴리스 무결성 검사에서 중단됐다. 해당 텍스트에 LF 속성을 고정하고 실제 파일을 정규화했다. 이미지·오디오는 바꾸지 않았다. `node scripts/check-signal-breaker-release.mjs --git`로 Git에 저장된 101개 파일까지 대조한다. 비교를 느슨하게 하거나 배포 검사를 우회하지 않았다.
