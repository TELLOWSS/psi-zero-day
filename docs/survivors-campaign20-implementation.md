# 20단계 현장 연속 작전

기존 1~10단계 이후 11~20단계를 연결한다. 생존 완료 기록으로 다음 구역을 해금하며 기존 10단계 완료 저장도 11단계를 복구한다. 기존 Episode01의 결말 상태를 변경하지 않는다.

| 단계 | 공정 | 몰입의 중심 |
|---|---|---|
| 11 | 형틀·동바리 | 지지 확인과 작업반경 분리 |
| 12 | 철근 | 반입과 작업자 동선 |
| 13 | 야간 타설 | 조명과 작업 압박 |
| 14 | 갱폼 | 인양·해체 통제 |
| 15 | 비계 | 작업발판과 낙하 |
| 16 | 옥탑 | 복합 공정 인계 |
| 17 | 방수 | 용제·환기·격리 |
| 18 | 마감 | 내부 양중 동선 |
| 19 | 설비 | 시험과 전원 격리 |
| 20 | 준공 인계 | 잔여 위험 기록 |

브리핑과 결과에는 실제 통제 목표 달성 여부를 반영한다. 다음 구역에서는 이전 구역의 완료 기록에 따라 성공 또는 잔여 위험 인계를 보여 준다. 타격 반응은 실제 충돌·치명타·대표 위험 통제 이벤트에만 발생한다. 일반 타격은 작은 국소 반응, 치명타는 짧은 강조, 대표 위험 통제는 기존 정지·감속과 별도 소리를 사용한다. 사람 조치는 녹색으로 표시한다. 효과는 최대 24개로 제한하고 감소된 모션 설정을 따른다.

## 다음 제작 순서

1. 11~20단계 자연 진행 플레이를 통해 난도와 통제 목표 조정.
2. 각 공정의 고유 지형·장비·장애물 아트 제작 및 가독성 검증. 현재 기존 승인 바닥 아트를 재사용한다.
3. 장비별 실제 음원 후보 청취와 믹싱. 현재 신규 타격음은 합성 효과이며 오케스트라 최종 음원이 아니다.
4. 이동·제동·조치 모션과 모바일 실기기 성능 검증.

20단계 해금·저장·대표 위험 검증과 기존 전체 회귀 검사를 수행한다. 브라우저 후반 구역 검증은 해금 저장 fixture를 사용하므로 자연 진행 전체 밸런스 검증과 구분한다.
