## SOL High 후속 작업 지시

이 worktree/브랜치의 변경을 먼저 읽고 이어서 작업한다. P2/P3 인물 제작을 다시 시작하지 않는다. `npm run production:next`와 이 문서를 현재 상태로 사용한다. 기존 엔진·세이브·분기 규칙과 인물 설정을 보존한다. 첨부 참고 이미지 속 다른 이름/성별 설정으로 기존 캐스트를 교체하지 않는다. 다음 구현 범위는 남은 현장 소품과 인물 표정 세트이며, 파일 생성만으로 완료 처리하지 말고 실제 manifest 등록·브라우저 표시·선택 흐름까지 검증한다. 확인하지 못한 과거 ChatGPT 문서가 모두 반영되었다고 주장하지 않는다.
