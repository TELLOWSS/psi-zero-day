# SIGNAL BREAKER 장비실·부품 움직임 개선

범위: 기존 EP02·PSI 장비실 후속 마감. 새 캠페인·상품·원화 추가 없이 현재 게임의 사용성과 2D 부품 움직임을 개선한다.

- 장비실: 제목·닫기·크레딧 잔액·분류·현재/다음 모듈을 고정하고 상품 목록만 스크롤한다. 휴대폰 가로 화면에서도 상품 구매 후 가격 맥락과 다른 분류를 바로 확인한다. 분류 변경·재진입은 상품 목록 맨 위에서 시작한다. 현재/다음 모듈 구분과 구매 롤백·영구 소유·오프라인 재개 계약은 유지한다.
- 보스: 반입·전력망 하우징의 개방/폐쇄는 시뮬레이션 시간에 따라 짧게 완만하게 전환한다. 경고 진동 세기도 갑작스럽게 바뀌지 않는다. 장력 제어 시 이동 중이던 부품은 실제 위치에 정지하며 중앙으로 튀지 않는다. 같은 시뮬레이션 시간에서는 정지한다. 줄인 모션 설정에서는 추가 움직임을 억제한다.
- 판정: 화면 표현만 변경한다. 충돌·HP·장갑·보상·해금 규칙과 기존 원화는 유지한다.
- 캐시: 0.46.1-workshop-motion. 전체 88개 런타임 파일 해시를 다시 생성한다.
- 검증: 실제 장비실 구매·분류 이동·스크롤 고정과 4개 화면 크기·오프라인 흐름; 하우징 전환의 연속성·정지·줄인 모션; 기존 보스 20개 화면 조합; 전체 엔진 및 본편 테스트·타입 검사·빌드.

Director 검토: 실제 Android 성능·체감 난이도와 새 HUD/기존 보스 부품·손상 표현의 최종 미술 승인은 별도다. 자동 검사 통과를 미술 승인으로 표시하지 않는다.
