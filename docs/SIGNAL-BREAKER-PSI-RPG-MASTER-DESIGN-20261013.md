# 시그널 브레이커 PSI 캐릭터 성장 게임 상세기획서

NEW PSI ZERO DAY | 2026년 10월 13일 | 설계 버전 1.1

시그널 브레이커를 PSI 세계관의 현장 대응 액션 RPG로 설계한다. 현장을 관찰하고 동료의 말을 확인한 뒤 위험 신호의 연쇄를 끊고 결과를 기록하는 과정에서 캐릭터와 장비가 성장한다. 시그널 워치는 같은 현장의 관측과 전파 억제를 담당하고, 브레이커는 확인된 원인과 전달 경로를 직접 해소한다. 두 모드의 성과는 하나의 현장 기록과 캐릭터 이력에 남는다.

중심 결정은 영구 캐릭터 성장, 영구 무기 연구, 작전 중 무기 진화를 분리하는 것이다. 현재 제작한 발사체 16종과 4단계 진화 구조를 포함하고 반복 플레이가 연구 기록과 새로운 대응 선택으로 이어지게 한다. 상업용 배포는 사용권 증빙이 확보된 자산으로 구성하는 것을 필수 조건으로 둔다.

현재 기준선은 GitHub main 3b26270a91b4e280f03783c555404f233ff3be17, 브레이커 릴리스 0.48.0이다. 신규 캐릭터 성장, 영구 연구, 모드 연계, 경제 수치는 설계 제안이며 운영 게임에 구현된 기능으로 취급하지 않는다. PSI 공식 인물과 이야기, 안전 하한선, 기존 저장 기록을 보존한다.

## 01 제품 정체성과 재미의 기준

플레이어의 핵심 판타지는 위험을 정확히 읽고 현장 사람들과 실행 가능한 대응을 만들며 자신이 만든 경로로 위험 전파를 끊는 숙련 안전관리자다. 조준과 발사의 즉각적인 쾌감은 판단을 실행하고 확인하는 수단이다. 성장할수록 더 다양한 정보를 읽고 장비를 조합하며 동료와 현장의 조건에 맞는 계획을 세운다.

| 설계 축 | 플레이 결과 | 성공 판단 |
|---|---|---|
| 현장 판단 | 발생원 관찰 후 조치와 확인 | 장비 선택 이유를 설명할 수 있음 |
| 경로 액션 | 이동, 조준, 반사, 관통, 연결 | 같은 장비도 위치와 사선에 따라 결과가 달라짐 |
| 캐릭터 성장 | 전문 능력과 준비 선택의 누적 | 재도전에서 새로운 접근을 선택 |
| 무기 성장 | 연구 특성과 작전 진화의 조합 | 확산과 집중의 상황별 교차 우위 |
| 사람과 기록 | 제보와 대응 결과가 다음 준비에 남음 | 현장과 인물의 변화를 기억 |

한 번에 기억할 전투 판단은 현재 위험 유형, 사선, 보조 장비의 세 가지로 제한한다. 성장 선택은 정비와 기지에 모으고 전투 중 큰 메뉴를 띄우지 않는다. 브레이커의 필수 캠페인은 시그널 워치를 먼저 하지 않아도 완주할 수 있다.

차별점은 실제 확인한 신호를 성장의 근거로 삼는 것이다. 총 발사 횟수나 무의미한 처치량만으로 연구를 해금하지 않는다. 신호를 읽고 원인과 경로를 끊고 안정화를 확인한 기록이 다음 선택을 넓힌다.

## 02 PSI 세계관과 액션의 표현

공식 브랜드는 NEW PSI, 상위 작품은 NEW PSI : ZERO DAY — 오늘도 무사히다. 가상 시공사 NEW-PSI와 현장 NEW-PSI ZERO SITE 01을 중심으로 한다. ZERO DAY는 예정되었던 사고가 신호를 읽은 사람들의 판단으로 일어나지 않은 날을 뜻한다. PSI는 사고 전 신호를 모아 다음 위험을 먼저 읽는 안전지능이며 사람을 대신하는 만능 해결자가 아니다.

위험체는 사고로 커지기 전의 위험 신호다. 금속, 분진, 전력, 하중의 신호가 재응집하고 다른 공정에 전파된다. 발사체는 제어 신호의 게임적 시각화이고 사선은 신호 전달 경로다. 사람에게 발사하거나 현실의 위험한 작업을 공격 행동으로 해결하는 연출은 넣지 않는다. 실제 현장 통제는 사람의 조치로 수행하고 신호 해소와 별도로 결과를 확인한다.

| 세계의 원칙 | 브레이커 적용 |
|---|---|
| 사람의 말이 없으면 PSI도 모름 | 제보와 관찰로 준비 정보의 일부를 얻음 |
| 데이터가 틀리면 예측도 틀림 | 추정과 확인을 다른 표시로 구분 |
| 관계는 정보 흐름을 바꿈 | 존중한 제보가 이후 메모와 대화에 남음 |
| 현장은 공정에 따라 성장 | 반입, 집진, 철근, 장력, 전력망의 맥락 유지 |
| 안전 하한선은 협상하지 않음 | 방호 우회와 사람 노출로 보상 획득 불가 |

메모, 위험유형 기록, 근로자 이해, 소통 패턴, 공종별 패턴, 예측 보조로 이어지는 공식 PSI 성장 방향을 따른다. 이 기획으로 전체 단계의 완료를 선언하지 않는다. 본편 Career, Dark Path, 관계 공식과 엔딩 조건을 RPG 수치로 덮어쓰지 않는다.

## 03 캐릭터와 동료의 성장

이야기의 중심은 현장 안전관리자인 PLAYER다. 현재 원화의 젊은 한국인 여성, 네이비 작업복, 파란 안전조끼, 태블릿 등 정체성을 유지한다. 런타임 외형 선택과 공식 주인공을 구분하고 외형마다 새로운 공식 설정을 만들지 않는다.

| 인물 | 기존 역할 | 브레이커 연결 제안 |
|---|---|---|
| PLAYER | 현장 안전관리자 | 관찰, 장비 선택, 조치 설명, 결과 확인의 책임 |
| 강태식 | 형틀반장 | 작업 순서와 장력·고정 조치의 실행 가능성 |
| 윤성호 | 철근반장 | 반입·운반 동선과 팀 리듬의 정보 |
| 이재훈 | 공사대리 | 설비 조치와 재개 순서의 확인 |
| 임준호 | 신입근로자 | 익숙해서 놓친 징후와 반복 신호의 제보 |

동료를 전투 수치 공급 NPC로 축소하지 않는다. 임준호의 제보를 확인한 결과는 공격력 보너스 대신 다음 준비의 정확한 메모와 이후 대화의 기억으로 남긴다. 원래 전문 분야를 넘어서는 전능한 기술이나 새로운 과거사를 만들지 않는다.

관계 변화는 우선 확인된 행동과 대화 기록으로 표현한다. 본편 수치형 관계 시스템은 기존 계약에 맞춘 별도 설계가 필요하며 브레이커 기록을 그 수치의 증감으로 자동 변환하지 않는다.

성장의 시각화는 장비 수리 상태, 연구 부품, 작업복의 작은 표식, 태블릿 기록, 동료의 자발적인 제보를 사용한다. 기존 원화의 2D 부품 애니메이션과 손상 표현은 최종 미술 검토 대상이다.

## 04 기본 플레이 순환과 세션 구성

한 작전은 제보 확인과 준비, 다섯 필드의 대응과 정비, 발생원·보스 해소, 회복과 기록 정산으로 구성한다. 입문 목표 시간은 4~7분, 숙련은 6~10분이며 사람 플레이로 검증할 설계 목표다.

| 구간 | 플레이어 행동 | 결과 |
|---|---|---|
| 준비 | 제보 1개, 위험 요약, 프레임·보조 장비 선택 | 대응 계획 |
| 필드 | 관찰, 이동, 조준, 장치 통제, 신호 해소 | 부품과 확인 기록 |
| 정비 | 진화 노드와 튜닝 선택 | 다음 필드의 방식 변화 |
| 최종 대응 | 방호, 단계, 발생원 처리 | 전파가 멈춘 근거 |
| 종료 | 회복 장면, 인물 반응, 성장 정산 | 경험치·연구·현장 기록 |
| 기지 | 능력 배치, 연구 특성, 다음 준비 | 영구 성장의 체감 |

전투 순환은 위험 읽기 → 사선 확보 → 보조 도구로 조건 만들기 → 신호 전달 → 안정화와 회수 확인이다. 자동 발사는 접근성 기능으로 유지하고 진화 선택이나 발생원 통제를 대신하지 않는다.

실패하면 현재 작전의 부품과 일시 진화는 종료되지만 정당하게 확정된 필드 경험과 기록은 남는다. 재도전 비용을 부과하지 않는다. 실패 이유는 사선, 상성, 미확인 발생원, 회수, 압박 시간 중 실제 원인으로 설명한다. 일시정지와 이어하기는 성장 조건을 바꾸지 않는다.

## 05 기존 10개 작전과 캠페인 구조

현재 1~5는 입문, 6~10은 같은 다섯 현장의 숙련 변형이다. 숙련을 새로운 현장 원화 5개나 별도 본편 이야기로 계산하지 않는다. 순차 해금과 5 완료 후 숙련 진입을 보존한다. 대규모 신규 캠페인은 현재 에피소드의 품질 확인 뒤 별도 제작한다.

| 작전 | 대응 축 | 성장의 역할 |
|---|---|---|
| 1 반입 | 반사와 최초 발생원 | 관찰 뒤 확인하는 기본 흐름 |
| 2 컨베이어 | 벨트 방향과 금속 신호 | 이동과 장치 통제 |
| 3 집진 | 분진과 안정 회수 | 미스트와 회수의 역할 |
| 4 장력 | 하중과 앵커 | 조준 이전에 조건 만들기 |
| 5 전력망 | 복합 위험과 스캔 | 기록과 장비의 종합 |
| 6 반사 공명 | 반사 신호 3회 | 상성과 첫 조합 진화 |
| 7 역류 컨베이어 | 과부하 순간 벨트 정지 | 관통·집결 연구의 시험 |
| 8 재확산 | 분진 해소 3회 | 확산과 안정 회수 |
| 9 하중 장력 | 장력선 고정 | 집중과 선행 통제 |
| 10 복합 전력망 | 경고 중 스캔 | 최종 진화와 장비 교체 |

작전마다 새 제보 또는 신호의 반복이라는 짧은 맥락, 현장 행동, 회복 결과를 둔다. 같은 사건을 두 모드에서 중복 정산하지 않는다. 최초·재클리어·기록 열람 엔딩을 구분하고 신규 성과 보상은 한 번만 지급한다.

## 06 캐릭터 영구 성장의 규칙

공통 운영자 숙련 프로필은 모드 사이의 성장을 연결하지만 공식 직무·자격이나 본편 Career 수치를 대신하지 않는다. 외형을 바꾸어 보상을 다시 받지 못한다.

| 성장 층 | 유지 범위 | 성장 내용 |
|---|---|---|
| 운영자 레벨 | 모드와 작전 사이 | 전문 능력과 준비 선택 |
| 무기 연구 | 조합별 영구 기록 | 연구 특성과 운용 템플릿 |
| 현장 기록 | 사건별 누적 | 확인한 사실과 다음 준비 |
| 작전 성장 | 작전과 이어하기 | 부품, 진화, 튜닝, 충전 |

첫 구현 제안은 레벨 1~20이다. 다음 레벨의 필요 경험치는 120에서 시작해 현재 레벨마다 20씩 증가한다. 짝수 레벨 2~20에서 능력 포인트를 1개씩 얻어 총 10개를 배치한다. 첫 10작전에서 레벨 7~10에 도달하는 것을 목표로 하며 캠페인을 반복 노동으로 막지 않는다.

경험치 제안은 완료 필드당 10, 사건 최초의 검증된 발생원·체인 기록당 20, 작전 최초 완료 60, 신규 연구 목표 완료 20이다. 확인 기록 보너스는 작전당 최대 3건이다. 같은 증거의 재제출에는 신규 증거 보너스가 없다. 낮은 난도 반복 작전의 필드 경험 합계는 30으로 제한하되 실패 자체를 추가 감점하지 않는다.

예시: 다섯 필드 50 + 신규 확인 2건 40 + 최초 완료 60 + 연구 목표 20 = 170 경험치다. 경험치와 능력 포인트는 현금이나 PSI 크레딧으로 구매하지 않는다. 능력 배치는 기지에서 무료로 변경한다.

## 07 캐릭터 전문 능력 트리

관측, 협업, 경로 제어의 세 계열에 세 노드씩 둔다. 계열 내부는 선행 순서로 연결하고 비용은 1, 2, 2포인트다. 전체 15포인트 중 10포인트를 배치하므로 두 계열의 완성 또는 세 계열의 부분 조합을 선택한다. 다음은 신규 구현 제안이다.

| 노드 | 능력과 제약 | 선행 조건 |
|---|---|---|
| OBS1 관측 정리 | 준비에 최근 확인 기록 1개 고정 | 레벨 2, 비용 1 |
| OBS2 반복 신호 | 과거 동일 위험의 확인 경로 1개 참조 | OBS1, 레벨 4, 비용 2 |
| OBS3 관측 계획 | 출발 전 중점 위험 유형 1개 표시 | OBS2, 레벨 8, 비용 2 |
| COOP1 준비 협의 | 전체 장비 프리셋 2개 비교 | 레벨 2, 비용 1 |
| COOP2 안정 인계 | 체인 방호 1.5초를 1.8초로 연장 | COOP1, 레벨 4, 비용 2 |
| COOP3 회수 지원 | 검증 목표 뒤 안전 위치에 부품 1개 | COOP2, 레벨 8, 비용 2 |
| PATH1 사선 기록 | 확인한 반사 경로 최대 2초 표시 | 레벨 2, 비용 1 |
| PATH2 조준 준비 | 정지 후 실제 예상 사선 표시 길이 확대 | PATH1, 레벨 4, 비용 2 |
| PATH3 경로 설계 | 출발 전 레일 각도 프리셋 1개 선택 | PATH2, 레벨 8, 비용 2 |

관측은 현재 상황을 자동 정답 처리하지 않는다. 과거 기록은 오늘의 발생원 확인과 구분한다. 협업 보너스는 실제 검증 목표 최초 성공에만 작동하며 부품 추가는 작전당 한 번이다. 방호는 피해 판정과 같은 엔진 시계로 계산한다.

경로 표시는 실제 충돌 계산을 사용하고 가짜 명중 선을 그리지 않는다. 프리셋은 현재 현장이 허용한 각도와 조작 범위만 사용한다. 능력으로 방호를 우회하거나 발생원 조치를 생략하지 못한다. 체력 무한 증가와 상시 피해 배율 누적은 첫 버전에 넣지 않는다.

## 08 무기 영구 연구와 연구 증거

폭풍 회로, 특이점 코일, 프리즘 관통, 플라즈마 회수의 현재 진입 조건을 보존한다. 연구는 기존 진화를 잠그는 기능이 아니라 숙련한 조합의 추가 특성과 준비 선택을 제공한다.

조합마다 연구 I, II, III를 둔다. 비용은 해당 조합의 연구 증거 1, 1, 2다. I은 해당 조합을 포함한 숙련 완료 1회, II는 서로 다른 숙련 현장 두 곳의 해당 조합 기록, III는 II와 전문화·최종을 사용한 실제 완료 기록을 요구한다. 다른 조합의 증거로 대체하지 않는다.

증거 중복 키는 사건 ID + 숙련 현장 ID + 조합 ID + 검증 목표 ID다. 사건 ID는 고정된 현장 이야기의 ID이며 재시도 run ID로 새 사건을 만들지 않는다. 조합이 유효할 때 실제 장갑 손상 접촉 10회 이상, 필드 검증 목표 성공, 작전 완료를 모두 확인한다. 총 발사 횟수나 종료 화면의 장비 이름으로 발급하지 않는다. 접촉 카운터와 검증 키는 추가 구현 항목이다.

| 연구 단계 | 영구 보상 | 작전에서 유지할 비용 |
|---|---|---|
| I 구조 이해 | 특성 슬롯 1개와 확산 렌즈 | 활성 특성 1개만 장착 |
| II 정밀 제어 | 집중 렌즈와 조합 기록 비교 | 확산·집중 렌즈 동시 장착 불가 |
| III 운용 숙련 | 조합 운용 템플릿과 숙련 표식 | 부품·필드 진화 조건 유지 |

확산 렌즈 제안은 전격 연결 거리 +20 또는 레이저 사선 길이 +40, 대신 유효 조합 장갑 손상 -1이다. 집중 렌즈는 유리한 상성 손상 +1, 대신 발사 간격 +8%다. 거리는 1100×620 엔진의 월드 좌표다. 불리한 상성과 보조 장비 비호환 때 추가 손상은 작동하지 않는다.

같은 숙련 현장과 조합의 검증 목표는 한 사건에 한 번만 증거를 준다. 다섯 숙련 현장에서 각 조합의 다양한 기록을 확보하도록 하며 동일 기록 반복으로 연구 증거를 무한 생성하지 않는다. 연구 초기화로 증거를 환급하는 기능은 두지 않는다. 획득한 특성은 기지에서 무료 교체하고 부품 5·9·14는 매 작전에서 획득한다. 새 작전에 최종 진화를 즉시 상속하지 않는다.

## 09 현재 제작한 작전 무기 테크트리

현재 구현은 프레임 → 조합 → 확산 또는 집중 → 최종 진화다. 프레임은 출발 전에 고르고 첫 조합에서 해당 프레임으로 확정한다. 기존 저장과 성능 기준선이며 영구 연구 추가 후에도 유지한다.

| 단계 | 현재 조건 | 실제 효과 |
|---|---|---|
| 전격 또는 레이저 | 출발 준비 | 전격은 분진·전력, 레이저는 금속·하중에 유리 |
| 조합 진화 | 부품 5, 촉매 4, 정비 | 보조 장비 장착, 유효 조합 장갑 손상 +4 |
| 확산 회로 | 부품 9, 2필드 완료, 조합 선행 | 목표 +1, 전격 거리 +35 또는 레이저 길이 +60 |
| 집중 코어 | 부품 9, 2필드 완료, 조합 선행 | 유리한 상성 장갑 손상 +3 |
| 확산 최종 | 부품 14, 3필드 완료, 확산 선행 | 목표 추가 +1, 최대 5개, 상성 손상 +1 |
| 집중 최종 | 부품 14, 3필드 완료, 집중 선행 | 유리한 상성 손상 추가 +3 |

전격 조합은 미스트를 사용하는 폭풍 회로와 자력을 사용하는 특이점 코일이다. 레이저는 스캔을 사용하는 프리즘 관통과 포획망을 사용하는 플라즈마 회수다. 집진 현장의 안정 회수 제약을 유지한다.

부품은 누적 확보 수이며 소모하지 않는다. 노드 중복과 반대 전문화의 동시 선택을 거부한다. 후반에 조건을 채웠다면 같은 정비에서 선행 순서대로 따라잡을 수 있다. 보조 장비를 바꾸면 조합 효과가 멈추며 호환 장비를 다시 장착하면 재개한다.

영구 연구와 작전 전문화는 별개다. 폭풍 연구의 집중 렌즈와 작전 확산을 조합하면 연결 수와 단위 손상의 균형이 달라진다. 성능 표시는 연구 특성, 활성 보조 장비, 현재 전문화를 함께 계산해야 한다.

## 10 장비별 역할과 권장 빌드

주무기는 위험 신호를 해소하고 보조 장비는 현장 조건을 만든다. 표시 공격력만 선택하지 않도록 유리한 상황과 한계를 함께 둔다.

| 장비 | 역할 | 남아야 하는 한계 |
|---|---|---|
| 속사 펄스 | 기본 전달과 빠른 대응 | 숙련 장갑의 단순 소모전은 불리 |
| 반사 장비 | 구조물·레일을 활용한 우회 | 사선과 반사 조건 필요 |
| 공명 장비 | 신호 분리와 파동 읽기 | 살아 있는 장갑을 무시하지 못함 |
| 포획망 | 해소한 신호의 안정 회수 | 장갑이 남은 목표 포획 불가 |
| 자력 | 금속 집결과 방향 제어 | 모든 위험에 같은 효과 없음 |
| 미스트 | 분진 안정화와 폭풍 조합 | 전력망 확인을 대신하지 못함 |
| 앵커 | 장력·레일 고정과 재설정 | 직접 손상보다 선행 통제 중심 |
| 스캔 | 전력 경고 차단과 약점 분석 | 확인 결과와 공격 사선 필요 |

폭풍 확산은 가까이 재응집한 분진을 미스트와 번개로 처리한다. 프리즘 집중은 금속·하중을 한 사선으로 처리하므로 이동에 실패하면 이점이 줄어든다. 특이점 확산은 자력으로 연결 경로를 만들고 플라즈마 집중은 장갑 해소와 회수의 순서를 관리한다.

장력·전력 보스에서 앵커·스캔으로 교체하면 잠시 조합 효과를 포기한다. 이 비용을 없애는 자동 장비 교체는 넣지 않는다. 복잡한 다중 슬롯 대신 주무기 1개와 보조 장비 1개, 연구 특성 1개를 중심으로 선택한다.

## 11 시그널 워치와 연결하는 현장 기록

두 모드는 현장, 인물, 위험 분류, 사건 ID를 공유한다. 워치는 순찰·전파 억제·관측으로 맥락을 만들고 브레이커는 연쇄와 발생원을 대응한다. 어느 모드에서 시작해도 필수 장비와 기본 준비를 확보할 수 있어야 한다.

현재 워치 계열에는 OperationHandoff와 본편 연결 함수가 존재한다. 캐릭터·현장·승패·통제 구역·카트 정지·잔해 정리·피격·별 등을 저장한다. 이 기록은 브레이커의 검증된 발생원 증거와 같지 않으며 정지 횟수를 오늘의 원인 확인으로 변환하지 않는다.

| 전달 방향 | 전달 정보 | 상대 모드의 사용 |
|---|---|---|
| 워치 → 브레이커 | 위치, 위험 분류, 시점, 확인 상태 | 준비 메모와 위험 요약 |
| 브레이커 → 워치 | 해소 발생원, 확인 시점, 잔류 위험 | 다음 순찰 상태와 후속 확인 |
| 두 모드 → 공통 기지 | 경험 정산과 연구 증거 ID | 공통 성장과 중복 지급 방지 |
| 기지 → 두 모드 | 능력과 준비 정보 | 새 작전의 적용 스냅샷 |

신규 공통 기록 SignalDossier에는 사건 ID, 현장 ID, 공정과 시점, 출처 모드, 제보 인물, 관측 사실, 가설, 조치, 검증, 잔류 위험, 증거 ID를 둔다. 사실·가설·검증 완료를 별도 필드와 화면 표시로 관리한다. 과거 날짜의 결과를 현재의 안전 확인으로 쓰지 않는다.

연계 예시: 워치의 같은 위치 카트 정지와 제보가 브레이커 준비의 원인 추정 메모가 된다. 반입문 발생원은 실제로 다시 관찰·통제·확인해야 한다. 확인한 조치를 워치에 인계하고 후속 공정의 징후를 여는 근거로 사용한다. 이 양방향 어댑터는 신규 개발 대상이다.

## 12 화면 흐름과 성장의 표현

공통 기지의 주요 행동은 이어하기, 다음 작전, 성장이다. 캐릭터 능력·장비 연구·기록을 성장 화면에서 열고 선택 상태를 비교한다. 메뉴 깊이는 기지 → 성장 탭 → 상세 노드의 세 단계로 제한한다.

| 화면 | 필수 정보 | 입력과 연출 |
|---|---|---|
| 준비 | 확인 메모, 상성, 장비 역할, 연구 특성 | 프리셋 비교 후 출발 |
| 전투 HUD | 체력, 필드, 현재 목표, 활성 장비 | 긴 안내는 한 번에 한 줄 |
| 정비 | 연결 경로, 조건, 적용 결과, 잠금 이유 | 선행 노드와 선택 경로 |
| 성장 | 영구 연구와 작전 진화의 차이 | 획득 근거와 다음 목표 |
| 종료 | 현장 회복, 인물 반응, 신규 성과 | 엔딩 뒤 정산과 다음 행동 |

산업용 HUD와 제작한 발사체 16종을 사용한다. 숫자와 설명은 이미지에 구워 넣지 않고 텍스트 ID로 표시한다. 노드는 효과, 선행 조건, 자원, 선택 비용을 설명한다. 보조 교체로 조합이 멈췄다면 HUD에 이유를 표시하는 기능을 추가한다.

16:9 가로를 기본으로 세로 모바일에서도 이동·발사·조준을 겹치지 않게 한다. 입력 영역은 44px 이상, 카드는 내용에 맞는 높이와 내부 스크롤을 사용한다. 색만으로 잠금이나 상성을 구분하지 않는다.

발사체의 일반 48, 조합 62, 최종 76 월드 픽셀 상한과 실제 충돌 반경의 분리를 유지한다. 저품질은 장식만 줄이고 목표·사선·약점은 유지한다. 움직임 감소는 시각 진동을 줄이며 판정이나 공격 주기를 바꾸지 않는다.

세계관 원화와 UI UX 전용 이미지 제작을 필수 납품 항목으로 추가한다. 기지·연구·캐릭터 성장·동료·전투·엔딩·상점이 같은 PSI 작품으로 읽히도록 통합 미술 기준을 적용한다. 화면별 제작 범위와 1차 원화, 구도·크롭·가독성·상용 권리·실제 연결 기준은 [세계관 원화와 UI UX 제작 계획](art/PSI-WORLD-UI-ART-PRODUCTION-20261013.md)을 따른다. 원화 생성과 운영 화면 적용을 구분하고 최종 적용에는 모바일과 오프라인 검증을 요구한다.

## 13 난이도와 성장 밸런스

입문은 도구를 익히고 숙련은 상성과 진화를 요구한다. 영구 성장 때문에 장치 판단이 사라지지 않게 한다. 자동 발사를 켰다는 이유로 피해를 낮추거나 강제 실패시키지 않고 장갑·시간·위치·도구·목표의 실제 조합으로 난도를 만든다.

현재 재현 입력은 비상성 1/15, 상성 9/15, 첫 진화 15/15 완료다. 확산·집중의 추가 30회는 모두 최종에 도달했고 29회 완료했다. 지정된 자동 입력 결과이며 사람 승률이나 재미를 뜻하지 않는다.

| 사람 플레이 검증 | 최초 목표 | 조정 대상 |
|---|---|---|
| 입문 이해 | 2분 내 이동·장치·회수 이해 | 안내와 초기 배치 |
| 숙련 첫 도전 완료 | 경험별 40~65% | 장갑·압박·조합 조건 |
| 실패 원인 설명 | 80% 이상 | 실제 원인과 기록 요약 |
| 두 빌드의 유효성 | 현장별 교차 우위 | 역할·범위·발사 간격 |
| 영구 연구의 영향 | 무연구도 필수 캠페인 진행 | 선택 확장과 제약 |

12~20명의 초보·중급·숙련 플레이로 가정 수치를 검증한다. 표본을 전체 승률로 확대하지 않는다. 같은 시드에서 장갑 해소시간, 피해, 필요한 이동, 장치 조작, 진화 시점, 실패 원인을 비교한다. 연계 없이도 두 모드를 시작할 수 있는지 확인한다.

최종 연결은 5목표로 제한하고 기존 투사체·위험체·단기 효과 상한을 유지한다. 대형 구조물과 지속 불투명 발광으로 시야를 가리지 않는다. 낮은 사양의 실제 기기에서 10분 혼잡 장면의 프레임·발열·입력을 확인한다.

## 14 PSI 크레딧과 상업 모델

사용권 확보와 현금 판매 방식은 별개다. 첫 출시안은 기본 게임 또는 에피소드 판매와 선택형 외형 콘텐츠다. 가격·플랫폼·결제 제공자는 별도 사업 결정이다. 현재 로컬 PSI 크레딧은 플레이 재화이며 현금 구매 기능으로 표현하지 않는다.

| 재화 또는 상품 | 사용 범위 | 판매 원칙 |
|---|---|---|
| 경험치·능력 포인트 | 영구 캐릭터 성장 | 현금 판매 없음 |
| 연구 증거 | 무기 연구 | 플레이 검증으로 획득 |
| 부품·충전 | 작전 진화·강화 | 새 작전에 초기화 |
| PSI 크레딧 | 외형과 기존 모듈 | 기존 잔액과 소유 보존 |
| 외형 팩 제안 | HUD, 표식, 잔광 | 상성 색과 가독성 유지 |
| 에피소드 상품 제안 | 이야기·현장 묶음 | 기존 진행을 불편하게 만들지 않음 |

현재 상품은 무료 4개, 고정 가격 9개, 총 13개다. HUD 180·240, 조준 80·120, 잔광 100·140, 모듈 180·220·300 크레딧의 기준선을 보존한다. 릴레이·촉매·관측 증폭기는 실제 성능이 있으므로 현금용 외형 상품으로 분류하지 않는다.

기존 모듈은 플레이 재화로 획득하고 구매 상태를 유지한다. 성능 판매나 성장 가속 판매로 연구 의미를 약화시키지 않는다. 확률형 무기 뽑기는 추가하지 않는다. 현금 판매를 도입한다면 당시 플랫폼·환불·구매복원·등급·지역 요건을 별도 확인한다. 로컬 잔액을 현금 자산의 구매 원장으로 사용하지 않는다.

## 15 상업 사용권과 창작물 권리

상업용 배포를 목표 요건으로 확정한다. 자산의 이용허락, 작품의 권리 확보, 타인의 권리 침해 여부는 각각 확인한다. 신규 창작이나 기술 검사만으로 모든 검토가 끝났다고 선언하지 않는다.

저작권은 아이디어·절차 자체보다 창작적 표현을 보호한다.[R1] 분기 성장과 반사 물리를 활용하더라도 타 게임의 구체적 트리 배치, 도상, 캐릭터, 이야기, 코드, 고유 효과를 복제하지 않는다. 명칭과 로고의 상표는 별도로 검토한다.[R2]

OpenAI 공개 약관은 법이 허용하는 범위에서 사용자와 제공자 사이의 산출물 권리를 정하지만 유일성을 보장하지 않으며 입력과 사용의 책임도 둔다.[R3][R4] 실제 사용 계정과 제품에 적용되는 약관·생성일을 보존하고 제3자 비침해나 배타적 권리의 자동 보증으로 취급하지 않는다.

한국 저작권법 제2조의 인간 창작물 정의를 기준으로 AI 이용허락과 인간이 기여한 창작적 표현의 보호 범위를 구분한다.[R5] 독자적인 이야기·선택 구조·도구 역할·장면 편집·시각 보정의 작업 이력을 남긴다. 생성 횟수나 프롬프트 길이만으로 독점 권리 성립을 주장하지 않는다.

| 검토 영역 | 확보 자료 | 상업 출시 처리 |
|---|---|---|
| 원화·UI·애니메이션 | 원본, 제작 이력, 적용 약관 | 불명확하면 확인 또는 교체 |
| 음성·음악·효과음 | 제공자 조건, 사용자 확인, 화자 범위 | 플랫폼·지역·홍보 이용 정리 |
| 글·캐릭터·세계관 | 작성 이력, 외주 계약, 참고 범위 | PSI의 독립 표현 유지 |
| 코드·라이브러리 | 기여 계약, 라이선스, 고지 의무 | 실제 출시 목록 대조 |
| 폰트·로고·상표 | 원문, 변형 조건, 명칭 조사 | 스토어·광고 소재도 확인 |

미확정 자산을 그대로 상업 출시 후보에 승격하지 않는다. 이 문서로 기존 운영 전체의 권리 완료를 소급 선언하지 않는다. 출시 자산과 증빙을 버전으로 고정하고 최종 법률 검토를 완료하는 것을 출시 게이트로 둔다.

## 16 기존 자산의 권리 기록과 제작 기준

2026년 10월 8일의 부분 감사는 전체 게임 사용권 완료가 아니다. 이후 사용자 확인을 취소하거나 반복해서 미확인으로 표시하지 않는다. 네 음성 버전과 타격 효과음의 공개 배포권은 사용자 확인 완료이며 제공자 약관 문서와 최종 청취 승인은 별도 기록이다.

| 자산 범위 | 확인된 상태 | 기획의 처리 |
|---|---|---|
| 발사체 16종 | 독립 imagegen 프롬프트와 WebP 경로 기록 | 적용 약관·유사성·미술 검토 |
| HUD·현장·보스 원화 | 생성과 연결 기록 존재 | 실제 사용 파일별 권리 대장 |
| 폰트 | OFL 동봉 기록 | 라이선스와 필요한 고지 유지 |
| 네 음성·타격 효과음 | 사용자 공개 배포권 확인 완료 | 확인 범위를 보존하고 근거 보강 |
| 음악·일부 SFX·본편 음원 | 전체 완료로 확정하지 않은 범위 | 제공자 조건 확인 또는 교체 |
| 로고·스토어 소재 | 디자인 승인과 상표는 별개 | 국가와 상품 범위 기준 조사 |

대장 항목은 자산 ID, 런타임 경로, 원본·납품 SHA-256, 제작자·도구·일자, 입력 권리, 적용 약관과 증빙, 상업·배포·수정·홍보 범위, AI 사용 여부, 권리 상태, 미술·청취 상태, 승인자·일자다. 권리·기술·미술의 세 상태를 따로 관리한다.

새 프롬프트에 타 게임명, 특정 캐릭터·아이콘, 브랜드 로고, 무단 사진·음원, 특정인의 무단 음성 복제를 넣지 않는다. 참고는 현장 소재·시인성·기능·색상 역할처럼 독립적으로 설명한다. 검색 이미지나 안내서 도판을 게임 원화로 재사용하지 않는다.

PSI는 금속·회로·관측 장비의 고유 언어와 안전모·작업복·태블릿의 일관성을 유지한다. 사운드는 신호 상태와 실제 사건에 연결하고 특정 작품의 선율·대사·음색을 재현하도록 주문하지 않는다. 저작권위원회 안내서는 검토 자료로 참조하며 본문과 그림을 상용 게임 자산에 통째로 넣지 않는다.[R6]

## 17 구현 구조와 저장 호환

브레이커는 독립 JS 엔진과 전용 저장, 워치는 별도 상태와 OperationHandoff를 사용한다. UI가 두 저장을 직접 합치는 대신 공통 프로필과 전달 어댑터를 설계한다. 첫 버전은 오프라인 우선이며 새 서버·클라우드 저장을 필수로 만들지 않는다.

| 구성 | 소유 책임 | 연결 |
|---|---|---|
| OperatorProfile | 레벨, 경험, 능력, 연구, 정산 ID | 공통 성장의 단일 기록 |
| SignalDossier | 사실·가설·조치·검증·잔류 위험 | 사건과 시점 |
| BreakerRun | 부품, 프레임, 조합, 전문화, 최종 | 작전과 체크포인트 |
| ModeRewardAdapter | 유효 완료·증거의 정산 명령 | 모드 원본 규칙 유지 |
| Presentation | 화면·원화·이펙트·텍스트 | 엔진 결과 표시 |

출발 때 능력과 연구 특성을 스냅샷으로 고정한다. 다른 탭이나 기지에서 배치를 바꾸어 현재 작전 효과를 변경하지 못한다. 핵심 규칙은 순수 엔진, UI는 입력과 저장을 소유한다.

기존 체크포인트의 현재 복원 규칙을 유지한다. 영구 성장 없는 계정은 새 프로필을 만들되 완료·크레딧·구매·이어하기를 보존한다. 과거 완료로 기존 해금은 유지하지만 기록하지 않았던 연구 증거를 꾸며 지급하지 않는다.

고유 정산 ID가 포함된 하나의 저장 스냅샷으로 정산한다. 저장 실패는 보상 적용을 되돌리고 재시도를 허용한다. 여러 탭은 revision을 확인해 충돌 쓰기를 거부하고 최신 상태를 다시 읽는다. 손상된 프로필이나 체크포인트가 정상 기록을 덮어쓰지 않게 격리한다.

출시 전 내보내기·가져오기와 업그레이드 백업을 제안한다. 오프라인 기록은 조작 가능하므로 현금 구매 원장이나 온라인 경쟁 순위의 권위 있는 증거로 확장하지 않는다.

## 18 개발 순서와 납품 산출물

원화와 진화 구현을 출발점으로 새 시스템을 하나씩 통합한다. 첫 작업은 상업 자산 대장과 공통 성장 계약이다. 기존 10작전에서 성장과 연계를 검증하고 세계관을 한 번에 새 캠페인으로 늘리지 않는다.

| 단계 | 범위 | 산출물과 게이트 |
|---|---|---|
| G0 권리 기준 | 자산 목록, 사용권, 교체 계획 | 파일별 증빙과 미확정 처리 |
| G0A 원화 기반 | 세계관·기지·연구·성장·UI 원화와 부품 | 화면 슬롯·크롭·권리·미술·가독성 검토 |
| G1 성장 계약 | 프로필, 정산 ID, 마이그레이션 | 기존 저장·중복·실패 복구 |
| G2 캐릭터 성장 | 경험, 9노드, 기지 배치 | 무료 재배치와 엔진 적용 |
| G3 무기 연구 | I~III, 증거 카운터, 렌즈 | 실제 효과와 선행 조건 |
| G4 모드 연계 | 사건 기록과 양방향 어댑터 | 날짜·확인 상태·중복 정산 |
| G5 이야기 통합 | 제보, 인물 반응, 회복 기록 | 공식 역할과 인과 검토 |
| G6 상업 출시 | 최종 자산·문서·기기·배포 | 권리·품질·복원 게이트 |

2D 부품 애니메이션은 미술 검토 뒤 손상 단계와 조치 후 정지 상태를 정리한다. 신규 원화는 권리와 실제 게임 시인성을 확인해 제작하고 임시 도형을 최종 자산으로 계산하지 않는다.

기획, 구현, 자동 검증, 사람 플레이, 미술·음향 판단을 구분한다. CI 성공으로 재미와 권리를 확정하지 않는다. 일정과 견적은 자산 교체량, 성우·음원 이용 범위, 플레이 결과 확인 뒤 산정한다.

재미는 클리어 외에 재도전 계획의 변화, 동료 제보의 기억, 빌드 선택 이유로 확인한다. 게임 테스트만으로 실제 안전 교육 효과나 사고 예방 효능을 홍보하지 않는다.
