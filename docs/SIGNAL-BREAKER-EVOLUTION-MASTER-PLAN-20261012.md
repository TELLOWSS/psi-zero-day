# SIGNAL BREAKER — 입문 이후 무기 진화·숙련 작전 상세 기획

Director 요청 1~6 / 2026-10-12. 기존 NEW PSI의 ‘사고 전 신호를 읽고 위험의 흐름을 끊는다’는 정체성을 유지한다. 사람은 공격 대상이 아니며 위험체는 가상의 신호 응집체다. 전격·레이저는 게임 속 위험 해소 연출이며 실제 안전 작업방법을 표현하지 않는다.

## 1. 먼저 닫을 결함

| 요청 | 확인한 원인 / 진단 | 수정·수용 기준 |
| --- | --- | --- |
| 메인 두 모드의 폰트 | 워치는 별도 제목 클래스, 브레이커는 일반 strong과 영문 줄을 사용 | 두 카드의 한글·영문 이름 구조와 font-family/size/weight/line-height/letter-spacing을 동일하게 |
| 1스테이지 엔딩 | 첫 웨이브 source가 다음 웨이브에서 null이 되어 최종 엔딩의 관찰·통제·확인 근거가 사라짐 | 확인된 근거를 별도 보존하고 이어하기에도 전달. 근거 없는 엔딩 기록은 생성하지 않음 |
| 2스테이지 엔딩 | 이미 본 endingMemory.seen이 다음 클리어 때 자동 재생을 막음 | 매번 실제 클리어 후 엔딩 재생. 보상은 최초 클리어만 지급. 재감상은 별도 유지 |
| 2·3의 시야 가림 | 중앙 이동 완충 장치·회전 방호판이 고밀도 소품 원화로 전면을 차지함 | 충돌 경계는 유지하고 이동 완충기의 내부 원화 비중·불투명도를 축소. 방호판은 얇은 장비로 표현. 위험체·약점은 위에 렌더 |
| 5의 엔딩 끊김 | 단일 img의 src를 회상 컷마다 교체, 해당 순간 이미지 디코딩·읽기가 발생 | 모든 회상 이미지를 미리 디코딩한 별도 레이어로 준비. 준비 중에는 시계·음성을 정지. 컷 전환 때 src를 교체하지 않음 |
| 보스 2D 검수 | 전 원화를 작은 원형/사각형 마스크로 움직이는 상태 | 멈춘 컨베이어의 구동축도 정지. 움직임 감소·장력 고정·일시정지에서 각도/진동 안정. 최종 미술 승인을 자동 PASS로 기록하지 않음 |

## 2. 플레이 구조

1~5는 현재의 입문 캠페인이다. 조종, 반사, 회수, 장치 개입, 보스 약점의 기본 원리를 배운다. 5 클리어 후 **숙련 작전 6~10**이 열린다. 기존 다섯 현장을 재검증하는 연속 작전이며 신규 현장 원화를 제작했다고 표기하지 않는다.

**현장 선택 → 무기 계열 선택 → 교전 → 아이템 획득 → 웨이브 사이 정비·진화 선택 → 위험체 상성 공략 → 보스 → 현장 회복 → 수동 다음 작전.**

숙련 구간에서는 다음 웨이브도 자동으로 넘어가지 않는다. 진화의 선택이 끼어들 시간을 제공한다. 종료 후 다음 스테이지도 직접 출발한다. 입문과 숙련 기록·최초 보상·이어하기를 분리하여 기존 저장을 보존한다.

## 3. 위험체 내구성과 상성

| 위험체 | 내구성의 의미 | 적합한 공격 | 선택하지 않았을 때 |
| --- | --- | --- | --- |
| 금속 응집체 | 다층 잔재 장갑 | 정밀 레이저, 반사 후 강화 관통 | 기본 펄스는 반복 타격 필요 |
| 분진 응집체 | 재확산성 피막 | 전격 계열 + 미스트 진화의 연쇄 억제 | 큰 범위에 오래 남아 경로를 압박 |
| 전력 응집체 | 다중 회로층 | 전격 코일, 스캔과 결합한 프리즘 | 비상성 공격 효율 감소 |
| 하중 응집체 | 관성 장갑 | 레이저 계열·앵커를 활용한 사선 유지 | 움직임 때문에 지속 명중이 어려움 |

숙련 6~10의 기본 장갑은 순차적으로 증가한다. 부모 코어와 분리된 자식 모두 표시된 실제 HP를 가진다. 장갑이 남았으면 포획망·게이트가 즉시 삭제하지 못하며, 상성 공격 또는 진화로 장갑을 해소한 뒤 기존 분리·안정화·회수 규칙을 따른다.

HP만 늘려 지루하게 만들지 않는다. 상성에 맞는 무기는 장갑을 빠르게 줄이고, 진화는 둘 이상의 목표 또는 하나의 사선을 동시에 활용한다. 장갑 게이지와 계열 색으로 현재 효과를 읽을 수 있게 한다.

## 4. 무기·진화

기본 공격 장비는 기존 pulse 슬롯을 사용하되 숙련 출발 전 **전격 코일 / 정밀 레이저** 중 하나를 선택한다. 실제 shot에 계열을 기록하므로 그래픽만 바뀐 이름 교체가 아니다.

| 진화 | 조합 | 전투 결과 | 시각 결과 |
| --- | --- | --- | --- |
| 폭풍 회로 | 전격 + 미스트 | 인접한 위험체까지 연쇄 장갑 손상 | 목표 사이 청백색 번개가 연결되고 짧게 소멸 |
| 특이점 코일 | 전격 + 자력 | 금속 집결 뒤 연쇄 손상 효율 증가 | 청록 회로 연결과 전격 코어 |
| 프리즘 관통 | 레이저 + 스캔 | 사선상 후속 위험체 장갑도 처리 | 선명한 백색 중심선·자홍 잔광 |
| 플라즈마 회수 | 레이저 + 포획망 | 장갑 해소 이후 후속 회수에 유리 | 레이저 중심선과 회수 파동을 구별 |

아이템을 모아 성장 조건을 충족하면 웨이브 정비 화면에서 진화를 **선택**한다. 조건 미충족은 잠금으로 표시한다. 선택하면 필요한 보조 장비가 실제 장착되고 해당 조합에만 진화 효과가 작동한다. 이후 보조 장비를 바꾸면 조합 효과가 비활성화된다. ‘장착 없이 프리미엄 효과만 표시’하지 않는다.

출발 무기 계열은 무료 선택이다. 성장 자원은 현재 작전에서 얻고 사망·새 출발 시 초기화한다. 재도전 비용·현금 결제·확률형 뽑기는 추가하지 않는다.

## 5. 난이도 곡선·자동발사

| 구간 | 역할 | 공략 요구 |
| --- | --- | --- |
| 1~2 | 반사·회수 입문 | 이동과 조준 개입으로 기본 클리어 가능 |
| 3~5 | 환경 장치·보스 이해 | 미스트·앵커·스캔과 약점 순서 |
| 6 | 내구성·계열 선택 도입 | 표시된 위험체에 맞는 무기 선택 |
| 7 | 분산 목표와 방향 | 반사 사선·금속 상성·보조 장비 |
| 8 | 재확산 압박 | 미스트 진화와 연쇄 효율 |
| 9 | 움직이는 하중 | 앵커와 레이저 사선 관리 |
| 10 | 복합 위험 | 진화 조합·스캔·안전 구역 이동의 종합 |

자동발사는 접근성 기능으로 유지한다. 자동조준이 진화나 장치 조작을 대신 선택하지 않는다. 숙련에는 웨이브별 제한시간을 표시하며 잘못된 계열·기본 펄스만으로 장갑을 깎는 소모전은 제한시간과 이동 압박에 의해 불리해진다. 단순히 자동발사 플래그를 보고 피해를 낮추거나 강제로 패배시키지 않는다.

밸런스 수치는 1차 플레이 검증값이다. ‘자동발사 무조건 실패’ 또는 숙련자 승률을 실제 입력 시뮬레이션 없이 확정하지 않는다. 비교 조건은 같은 seed·같은 이동·같은 조준에서 기본 펄스 / 상성 계열 / 진화의 장갑 해소시간과 피격량이다.

## 6. 타격·시각·음향

발사 시작에는 장비 계열 색, 이동에는 탄도/빔 중심선, 명중에는 실제 손상 위치, 소멸에는 짧은 잔광을 연결한다. 번개 연쇄는 실제로 손상시킨 목표 사이에만 그린다. 레이저는 실제 사선을 따라 표시한다. 풀스크린 섬광과 장시간 불투명 이펙트로 위험을 가리지 않는다.

low/balanced/high는 장식과 잔광 개수를 조절하고 손상·HP·약점 표시는 유지한다. 움직임 감소에서는 진동·번쩍임을 줄인다. 투사체 32·위험체 36·연쇄 3목표·단기 효과 22개 상한을 보존한다.

## 7. 제작 순서와 이번 구현 범위

G1 결함 1~4 수정과 보스 기계 정지 검수 → G2 숙련 캠페인·장갑·출발 계열 → G3 획득 조건과 선택 진화·실제 손상 → G4 전격·레이저 연출 → G5 저장·오프라인·화면·입력 회귀.

이번 개발은 이 순서로 진행한다. 신규 보스 3D 모델, 새 성우 녹음, Android 실기기 검증은 별도 작업이다. 새 현장 원화나 독립 파손 원화 제작을 완료했다고 기록하지 않는다.

## 8. 완료 기준

- 실제 첫 구간을 통과한 관찰·통제·확인 근거가 최종 엔딩까지 유지.
- 1·2 최초/재클리어에서 엔딩이 나오고 보상은 중복되지 않음.
- 5 회상 컷이 디코딩 완료한 이미지 사이에서 전환하고 로딩 중 시계/음성이 먼저 진행되지 않음.
- 2·3 중앙 이동 구조물의 실제 충돌은 읽히면서 위험체·약점·사선은 가리지 않음.
- 5 이전 숙련 잠금, 5 이후 6 해금, 숙련 다음 작전 수동 진행.
- 기본 펄스 < 상성 무기 < 조건을 충족해 선택한 진화의 장갑 해소 효율을 동일 입력으로 비교.
- 장갑이 남은 위험체의 포획/게이트 우회 금지, 실제 HP와 이펙트 일치.
- 진화 조건·상태가 정비 이어하기 후에도 보존되고 기존 입문 저장과 충돌하지 않음.
- 앱·브레이커 규칙·타입·빌드·PC/모바일/태블릿·오프라인 검사.

검증 결과와 실제 구현 제한은 별도의 QA 문서에 기록한다. Director의 플레이 느낌·미술 판단은 기술 검증과 구분한다.
