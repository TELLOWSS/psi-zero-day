# 작전 브리핑과 장비 시험장

## 기존 상태와 개선
- 기존 스테이지 글은 선택한 캐릭터의 개인 스토리가 아니라 담당자 무전이었다. stage_11~20은 콘텐츠에 지정된 speaker, stage_21~50은 담당자 순환 배정이었고 캐릭터 선택과 독립되어 있었다.
- 작전 준비에서 선택 캐릭터의 역할, 실제 스테이지 별 목표, 담당자 무전, 스토리 조사 단서, 디펜스 배치 근거를 구분한다. 임의의 과거사나 새로운 본편 분기를 만들지 않는다.
- 순찰의 승리·패배, 통제 구역, 카트 제동, 통로 정리, 피해, 별 결과를 캐릭터/스테이지별 version 1 인계 기록으로 저장한다. 최대 최근 50건. 공유 domain 형식이 향후 모드의 읽기 계약이다. 현재 스토리/디펜스 분기 자체는 변경하지 않으며 화면에서도 연결 예정임을 표시한다.

## 착용 개성 방향
- 캐릭터 고유 작업복·체형을 중심으로 손의 도구, 몸에 붙는 장치, 발동 신호를 구분한다. 기존 승인 캐릭터/장비 자산과 게임 렌더러를 재사용한다.
- 피팅은 고해상도 캔버스, 정사각 비율, 현장 바닥과 발 아래 접지 그림자로 표시한다. 기본 동작/좌우/확대/정지 조작은 유지한다.
- 장비 시험장은 일반 무기 7종 Lv.1~5, 모든 지원 장비, 진화 장비 7종을 비교한다. 실제 게임 엔진의 발사·투사체·충돌 규칙과 동일한 발사/접촉/투광 오라 렌더러를 쓴다. 진화는 해당 무기 Lv.5+지원 Lv.1 조건을 함께 표시한다.
- 실제 상태를 복사한 독립 엔진만 시험을 진행한다. 구매/착용/크레딧/캠페인 저장에는 영향을 주지 않는다. 반복되는 기존 카트 위험물을 대상으로 시험하며, 정지와 0.2초 단위 확인을 제공한다. reduced-motion에서는 정적인 효과 표본을 표시한다.
- 새 캐릭터 아트 또는 새로운 본편/디펜스 분기 완성으로 계산하지 않는다.

## 확인
- 테스트: 성장/진화의 실제 발사, 유한 투사체, 원본 상태 불변, 일반 엔진의 시험 동작 차단, 인계 기록 캐릭터 및 별 복사.
- 브라우저: PC/모바일 세로/모바일 가로, 캐릭터 변경 후 역할 변경, 무기·진화 전 종류, 정지 프레임과 저장소 불변.
- 추가 확인: 방어 반응 버튼은 복사된 시험 상태에서 실제 카트 접촉과 보호막 흡수 로직을 사용한다. 체력·보호막 잔량을 화면에 표시하고, 재생 중에는 실제 재충전 주기를 진행한다. 발사 시 몸동작은 실제 발사 이벤트에 맞춘다.

## 다음 연결: 순찰 인계함
- 메인의 스토리·디펜스 프리뷰와 기존 내부 스토리 시작/디펜스 지원 선택 화면이 같은 순찰 인계 기록을 읽는다. 공개 모드의 준비중 잠금은 유지한다.
- 인계함을 펼치면 캐릭터·현장별 최근 결과를 선택하고, 통제 구역·돌진 제동·통로 정리·피해·달성 목표를 확인한다. 두 모드의 안내는 이미 작성된 캐릭터별 관점을 재사용한다.
- 기록 저장을 app 계층으로 옮기고 domain에서 캐릭터·스테이지 번호의 일치와 유효 수치를 검증한다. 손상된 저장소나 접근 불가 상태에서도 빈 기록으로 화면을 표시한다. 읽기와 선택은 저장을 변경하지 않는다.
- 순찰 수치를 사진·증언 획득으로 해석하지 않는다. 본편 증거/분기/해금과 디펜스 자원·배치·지원 효과에는 아직 적용하지 않는다. 실제 적용 조건과 보상은 Director의 다음 명세가 필요하다.
- 검증: 같은 캐릭터/현장 갱신과 다른 기록 보존, 잘못된 기록 차단, 50건 제한, 저장 오류 회복. 브라우저에서는 PC·모바일 세로·가로·작은 가로 화면의 선택/스크롤과 저장 불변을 확인한다.
