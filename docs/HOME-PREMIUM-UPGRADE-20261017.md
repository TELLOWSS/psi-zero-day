# 메인 화면 — 캐릭터 중심 프리미엄 원화 적용

작성: 2026-10-17. 사용자의 메인 그래픽 개선 요청을 기본 홈 화면에 적용했다.

## 개선 방향과 결과

기존 화면은 넓은 공사장 전경과 작은 인물 중심이었다. 새 화면은 기존 성인 여성 주연의 얼굴, 표정, 몸의 흐름과 현장을 통제하는 동작을 주요 시각 요소로 삼는다. 인물의 매력과 게임 속 역할이 동시에 드러나도록 구성했다.

- 기존 플레이어의 얼굴 특징, 어두운 포니테일, 청색 띠가 있는 흰 안전모, 남색 작업복과 청색 조끼를 참고했다.
- 전체식 안전벨트의 가슴·허리·다리 스트랩과 장비를 유지했다. 손으로 현장 장비를 멈추고 다른 손으로 태블릿을 든 행동을 표현했다.
- 얼굴과 의상에 따뜻한 현장 조명, 배경에는 차가운 저녁빛과 젖은 바닥의 반사를 사용했다. 산업용 센서·이동 장비·동료·철골 구조가 같은 장면에 있다.
- PC용 가로 원화와 모바일용 세로 원화를 별도로 제작했다. 좁은 화면에 가로 그림을 그대로 잘라 얼굴이 사라지는 구성을 피했다.
- 얼굴 중심이 제목이나 조작 영역에 가려지지 않도록 메뉴를 배치했다. 첫 화면에 키보드로도 선택 가능한 시그널 가드 작전 준비 버튼을 추가했다.
- 기존 워치·브레이커·가드 모드 카드 및 준비 중인 스토리 안내는 실제 기능과 연결한다.

이미지 생성 방식은 **내장 image_gen**이다. 원화는 최종 후보로 게임에 통합했으며, 매출·선호도·플레이 의향이 검증됐다는 의미는 아니다.
