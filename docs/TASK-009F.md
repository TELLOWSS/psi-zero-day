# TASK-009F — 8인 최종 캐릭터 아트시트

## 목표

승인된 PSI : ZERO DAY 상용 비주얼 기준에서 8명의 캐릭터가 이름표 없이도 구분되도록 최종 제작 규칙을 고정한다.

## 기준

- 스타일: 밝고 고급스러운 2.5D 캐주얼 전략게임, chibi-realistic 3D.
- 귀엽고 접근성은 높지만 어린이용 캐릭터처럼 보이지 않는다.
- 실제 건설현장 PPE와 직무 소품을 유지한다.
- 안전모 색만으로 캐릭터를 구분하지 않는다.
- 동일 베이스 얼굴/몸체 재사용 금지.
- 이름표를 가렸을 때도 최소 3개 특징으로 식별 가능해야 한다.

## 8인 핵심 ID

1. PLAYER: 여성 안전관리자, 흰 안전모, 블루 안전복, 태블릿, 차분하고 결단력 있는 자세.
2. 강태식: 50대 형틀반장, 넓고 묵직한 체형, 콧수염/짧은 수염, 오렌지 안전모, 현장 지시 제스처.
3. 윤성호: 40대 후반 철근반장, 근육형, 각진 얼굴, 황색 안전모, 철근/철근 훅.
4. 이재훈: 30대 초반 공사대리, 키 크고 슬림, 깨끗한 얼굴, 흰 안전모, 도면/공정표.
5. 임준호: 20대 초반 신입근로자, 작고 슬림, 둥글고 어린 얼굴, 황색 안전모, 무전기/공구가방.
6. 최민석: 30대 후반 크레인 신호수, 역동적 체형, 오렌지 PPE, 양손 신호봉.
7. 서정민: 40대 중반 건축감리, 마른 체형, 사각 안경, 흰 안전모, 검측 클립보드.
8. 오승재: 40대 초반 현장 공사팀장, 중간 이상 체격, 흰 안전모+네이비 밴드, 전화/무전기, 조율 제스처.

## 제작 산출물

- 8인 lineup reference: 전신 또는 3/4신으로 한 화면에서 체형/직무 차이를 비교.
- portrait: 게임 카드/대화용, 투명 배경, 동일 인물 연속성 유지.
- map sprite: 2.5D 현장맵용, 직무가 읽히는 기본 자세.
- expression set: neutral / concern / determination / relief를 기본으로, 직무별 추가 표정 가능.

## 금지

- 이재훈과 PLAYER의 얼굴 구조 유사.
- 강태식과 윤성호의 체형/수염/색상 중복.
- 서정민과 오승재가 같은 흰 안전모 관리자 복제처럼 보이는 구성.
- 임준호를 단순히 작은 성인 NPC로 축소한 형태.
- 안전모의 의미 없는 글자, 실제 회사 로고, 실제 현장명.
