# 시그널 브레이커 — 잔광: 쉬어가는 무한모드 기획서

> 밀도 개정: 신호 부족에 대한 후속 요청으로 공급량·보충·대형을 개선했다. 아래 8/12개 제한보다 [밀도 개선 보고서](SIGNAL-BREAKER-AFTERGLOW-DENSITY-20261015.md)의 18/30개 제한을 우선한다.

> 후속 상태: 같은 날 사용자의 구현 요청으로 웹 모드를 제작했다. 아래는 구현 전 기획 원문이며, 실제 반영 범위·검증·남은 실기기 확인은 [구현·검증 보고서](SIGNAL-BREAKER-AFTERGLOW-IMPLEMENTATION-20261015.md)를 우선 참조한다.

**작성일:** 2026-10-15<br>
**상태:** Director 검토용 기획 제안 v1.0 · 구현 전<br>
**대상:** 시그널 브레이커의 선택형 서브 모드. EP01~03과 별도 진입·기록·규칙.<br>
**한 문장:** 피곤한 날, 익숙한 캐릭터와 장비로 신호를 시원하게 정리하고 원하는 순간 기분 좋게 나오는 작은 놀이터.

> 무한해야 하는 것은 난도와 보상의 의무가 아니라, 원할 때 계속 이어지는 놀이의 가능성이다.

## 1. 왜 이 모드를 만드는가

본편은 관찰·판단·회피·진화·설비 대응을 통해 성취감을 준다. 그러나 피곤한 사람에게는 그 장점이 입장 비용이 될 수 있다. 어떤 특성을 고를지, 부품을 잘 쓰고 있는지, 장비 조합이 끊겼는지, 다음 보스에 대응할 수 있는지를 계속 생각해야 하기 때문이다.

이 서브 모드의 목적은 플레이어가 더 오래 붙잡혀 있게 만드는 것이 아니다. **시작할 때보다 덜 부담스럽고, 내가 움직여서 보기 좋은 결과를 만들었다는 느낌으로 끝나는 것**을 목표로 한다. 3분만 즐기고 나가도 완전한 이용이다. 장시간 플레이는 선택 가능한 이용 방식이며 성공 지표가 아니다.

‘뇌 회복’, ‘스트레스 치료’, ‘심리 상태 개선’을 제품 효과로 보증하지 않는다. 아래는 편안한 플레이를 만들기 위한 설계 가설이다. 체감은 실제 플레이 조사로 확인한다.

### 근거와 해석의 경계

게임과 퇴근 후 회복을 다룬 Collins·Cox의 연구는 일에서의 심리적 분리, 이완, 숙련 경험, 통제감을 살펴본다. 이 네 관점을 설계 질문으로 참고한다. 설문 연구의 결과가 특정 게임이나 모든 사람에게 회복 효과를 보증하는 것은 아니다. [연구 원문·UCL 저장소](https://discovery.ucl.ac.uk/id/eprint/1418103/)

Vuorre 등의 2022년 연구에서는 플레이 시간과 웰빙 사이의 인과적 연결을 뒷받침하는 증거가 거의 없었다. 따라서 ‘무한히 오래 즐김’을 ‘더 많이 회복함’으로 해석하지 않는다. [연구 원문·Oxford 저장소](https://ora.ox.ac.uk/objects/uuid%3A681f8e3b-6ccc-4549-ad0e-64f4e561937a)

이 문서의 난도·리듬·보상 수치는 위 논문이 제시한 처방이 아니다. 현재 게임과 사용자 요청을 바탕으로 만든 **프로토타입 초기값**이다.

## 2. 현재 구현을 그대로 무한 반복하면 부족한 이유

확인 기준은 현행 `public/signal-breaker-dev/src/engine.js`, `burst-rules.js`, `session-flow.js`와 기존 연속 플레이 기획이다.

| 현재 확인한 구조 | 편안한 모드에서 생길 문제 | 새 설계 방향 |
|---|---|---|
| 기존 `continuous`는 `operation`과 별도 경로이며 5현장을 이어 순환 | 작전 모드에 무한 플래그만 켜서는 같은 흐름이 연결되지 않음 | 별도 모드 프로필과 순환 관리자를 설계 |
| 생명 5, 구역 완료 시 1 회복 | 휴식 목적에서도 생존 실패를 계속 의식 | 생명·사망·재도전 압박 제외 |
| 5구역을 마치면 성장·포인트 재구성 | 좋아진 무기를 다시 잃는 느낌 | 세션 내 선택한 외형·장비 유지, 다음 진입도 선호 구성 기억 |
| 연속 모드 아이템은 거리 밖에서 자동 회수되지 않으며 8초 수명 | 피곤해도 아이템을 쫓아야 함 | 이 모드 전용 전체 회수, 시간 내 습득 의무 제외 |
| 조합은 성장 단계·워치·보조 장비 조건에 영향 | 원하는 화려함을 보기까지 준비 필요 | 승인된 조합을 모드 안에서 처음부터 대여 |
| 실제 위험 신호·설비 개입·경보·실패가 존재 | 건설업 종사자에게 업무 상황을 다시 떠올리게 할 가능성 | 실제 작업 중이 아닌 가상 장비 시험 공간으로 구분 |
| 최신 진화 시스템은 부품·완료 구간·경로 선택을 사용 | 본편 규칙을 그대로 이식하면 정비 창과 선택 부담 증가 | 본편 진화는 보존하고 휴식 모드의 장비 체험은 별도 규칙 |

기존 연속 모드를 삭제하거나 같은 이름으로 덮어쓰지 않는다. 기존 저장의 누락 필드가 새 휴식 모드로 해석되지 않도록 한다.

## 3. 핵심 통찰: 편안함에도 손맛은 필요하다

### 3.1 위협을 낮춰도 인과관계는 남겨야 한다

아무것도 하지 않아도 화면이 자동으로 정리되기만 하면 처음에는 편하지만 곧 내 행동의 의미가 희미해질 수 있다. 플레이어가 한 발 옆으로 움직이거나 조준을 살짝 바꿨을 때, 연쇄 방향·반사 곡선·회수 장면이 달라져야 한다.

기본 자동 조준·발사는 켜져 있다. 수동 조준은 더 높은 보상을 얻기 위한 의무가 아니라 **장면을 내가 연주하는 선택**이다. 실수로 놓친 신호는 안전 회수 장치가 처리하고, 잘 맞춘 신호는 짧고 선명한 효과로 응답한다.

### 3.2 자극의 양보다 리듬의 대비가 중요하다

모든 순간이 최종 진화·최대 연사·폭발이면 무엇이 시원한 순간인지 구분하기 어렵다. 평소에는 장비와 신호의 움직임이 읽히게 하고, 짧게 화려해진 뒤 현장이 정돈되는 여백을 둔다. 큰 소리와 화면 흔들림으로 강함을 대신하지 않는다.

### 3.3 휴식과 성장은 충돌할 수 있다

매일 접속하거나 일정 시간 버텨야 얻는 성장 보상을 붙이면 휴식이 숙제가 될 수 있다. 본편 재화와 별도로 끝없는 수치를 올리는 구조도 추가 비용이다. 이 모드에서는 **즉시 사용할 수 있는 장비의 다양성, 익숙한 캐릭터, 내가 고른 분위기의 지속**을 애착의 중심으로 삼는다.

### 3.4 ‘안전하게 끝낼 수 있음’도 플레이 경험이다

5분 후 나가려고 했는데 마지막 보상까지 남아서 계속하는 구조는 목적에 맞지 않는다. 종료 시 잃는 점수·장비·보상은 없고, 끝내기 위해 적을 전부 처리할 필요도 없다. 나가기 쉬워야 다시 켜기도 쉽다는 가설을 검증한다.

### 3.5 건설 현장이라는 세계관은 편안함을 보장하지 않는다

익숙한 현장은 누군가에게 애착의 장소이고 다른 누군가에게는 스트레스의 장소일 수 있다. 사실적인 사고 경보·무전 독촉·붉은 위험 표식을 제거한 **퇴근 후 가상 장비 시연**을 기본 맥락으로 제안한다. 그래도 업무가 떠오른다는 반응이 크면 아트 방향을 수정한다. 현실 위험을 무시해도 된다는 메시지로 해결하지 않는다.

## 4. 모드의 정체성과 경계

**제안 이름:** `잔광`<br>
**로비 표기:** `쉬어가는 무한모드`<br>
**설명:** `자동으로 흐르는 신호를 가볍게 정리하세요. 언제든 멈춰도 괜찮습니다.`

공간은 실제 작업자와 사고 위험이 없는 가상 시험장이다. 기존 산업 시설과 장비의 형태는 유지하되 대상은 진단용 시험 신호다. 캐릭터는 승인된 6명 중 선택하고, 헬멧·작업복·인물 이미지는 기존 정본을 유지한다. 캐릭터별 말투나 새 대사는 별도 감수 전 확정하지 않는다.

| 구분 | 본편 EP01~03 | 기존 연속 플레이 | 잔광 |
|---|---|---|---|
| 목적 | 대응·판단·완주·성장 | 기존 현장을 끊김 없이 순환 | 부담 적은 조작·감각적 만족 |
| 실패 | 있음 | 있음 | 사망·게임오버 없음 |
| 진화 | 실제 재료·구간·경로 조건 | 기존 연속 성장 | 모드 전용 대여 체험 |
| 영구 성장 재화 | 기존 규칙 | 기존 규칙 | 지급하지 않음 |
| 진행 압박 | 작전별 목표 | 구역 순환 | 없음, 종료 자유 |
| 기록 | 완료·성장·엔딩 | 연속 기록 | 선호 설정·비경쟁 감상 기록 |

모드 전용 대여 장비는 본편 소유 장비로 표시하거나 저장하지 않는다. 본편의 장비 개조 가치와 실제 진화 규칙을 바꾸지 않는다. 그 때문에 `equipmentTier`나 `evolution`을 임의로 덮어쓰는 구현은 피한다.

## 5. 입장과 조작: 두 번의 선택으로 시작

1. 로비의 보조 카드 `쉬어가는 무한모드`를 누른다. 캠페인 진행과 무관하게 접근 가능하도록 제안한다.
2. `가볍게 시작`을 누른다. 이전 캐릭터·장비·입력·소리·움직임 설정이 적용된다. 최초에는 현재 선택 캐릭터, 폭풍 장비 체험, 차분한 리듬이 준비돼 있다.

장비·분위기 변경은 선택 사항이다. 필수 설명창·출석 확인·성장 투자·첫 실행 평가 설문은 넣지 않는다. 첫 장면에 1줄 도움말만 짧게 보여 주고 직접 움직이면 사라진다.

### 기본 조작

- 자동 발사·자동 조준 ON. 직접 조준하면 즉시 수동 개입하고, 손을 떼면 1.5초 뒤 자동 조준으로 돌아온다. 자동 복귀 시간은 기존 설정을 존중한다.
- 이동 패드는 기존 고정/자유 패드와 크기 설정을 유지한다. PC는 기존 A/D·화살표와 마우스를 사용한다. 자주 누르거나 연타할 필수 버튼은 없다.
- 주무기와 보조 장비는 하나의 체험 구성으로 연결한다. 휴식 모드에서 보조 장비를 눌러 조합을 실수로 해제하지 않게 한다. 본편의 독립 전환 규칙은 변경하지 않는다.
- `자동 조준/발사` 상태와 `설정·나가기`는 실제 누를 수 있는 조작부에 남긴다. 필요할 때 수동 발사로 바꿀 수 있다.
- 가만히 있는 플레이어에게 패널티를 주지 않는다. 기본은 90초 무입력 시 조용히 일시정지한다. 시간은 화면을 보고 쉬려는 사용자와 테스트해 조정하며, 사전 안내된 설정에서 변경할 수 있게 한다.

완전 자동 이동·장시간 감상 전용 모드는 MVP에서 제외한다. 최소한의 공간 조작이 즐거운지부터 검증한다.

## 6. 핵심 놀이: 쏘기 → 연결하기 → 정돈된 장면 보기

신호가 완만한 곡선과 대열로 들어온다. 자동 조준으로도 무리가 없고, 옆으로 움직이거나 조준 방향을 바꾸면 연결 경로가 달라진다. 장비가 신호를 분리·연결·회수하면 잔광이 짧게 남고 시설의 빛과 소리가 차분하게 정리된다.

필수 기믹, 제한 시간, 잠긴 약점, 피격으로 인한 사격 중단은 없다. 충돌한 시험 신호는 안전 회수 장치로 이동하며 생명이나 장비를 잃지 않는다. 카메라 흔들림·붉은 화면·경보음·깜박이는 무적 표현은 사용하지 않는다.

### 지루함을 줄이는 선택적 놀이

| 눈에 보이는 기회 | 플레이어가 해볼 행동 | 돌아오는 반응 | 하지 않아도 되는 일 |
|---|---|---|---|
| 3~4개의 작은 신호가 모임 | 반걸음 이동해 같은 사선에 놓기 | 긴 연쇄와 맑은 단음 | 실패 점수·콤보 단절 없음 |
| 완만하게 움직이는 반사 구조 | 사선을 바꿔 반사 경로 만들기 | 꺾인 궤적과 짧은 잔광 | 보너스 수집 의무 없음 |
| 넓게 펼쳐진 시험 신호 | 장비 체험 구성을 바꿔보기 | 전격·관통·회수의 다른 모습 | 정답 상성 시험 없음 |
| 정돈 구간에 남은 두 신호 | 직접 조준해 마무리 | 조용히 어두워지는 시설의 빛 | 남은 신호를 끝까지 쫓을 의무 없음 |

반사 구조는 플레이어를 압박하거나 가두지 않는다. 본편의 장력 파열·낙하·설비 방출을 장식처럼 그대로 옮기지 않는다.

## 7. 무한의 단위는 2분짜리 작은 호흡

아래 시간은 **능동 플레이 시간** 기준 초기값이다. 일시정지·백그라운드에서는 진행하지 않는다. 단계를 화면에 숫자로 계속 보여 주거나 다음 단계까지 카운트다운하지 않는다.

| 구간 | 기본 시간 | 밀도·감각 | 플레이어 경험 |
|---|---:|---|---|
| 진입 | 10초 | 2~3개, 낮은 속도 | 장비의 손맛에 적응 |
| 흐름 | 45초 | 4~6개, 익숙한 대열 | 부담 없이 이어 맞추기 |
| 개화 | 20초 | 6~8개, 잠깐 넓어진 연결 | 짧고 시원한 장면 |
| 정돈 | 35초 | 새 신호를 점차 줄임 | 남은 흐름을 정리 |
| 여백 | 10초 | 새 생성 중지, 잔광·환경음 | 빈 공간이 돌아옴 |

기본 120초 뒤 다음 호흡이 연결된다. 경계에 남은 신호는 최대 6초 추가 정돈 시간을 주고 안전 회수 장치로 이동시킨다. 따라서 실제 호흡 길이는 120~126초다. 강제로 격파된 것으로 계산하지 않고, 회수된 신호는 연쇄·시연 성취로 기록하지 않는다. 플레이어의 공격과 안전 회수를 시각·사건 타입으로 구분한다.

호흡마다 위치·대열·장비와 조화되는 연결 모양이 바뀌지만, 시간이 지났다고 밀도·체력·속도가 끝없이 오르지 않는다. 직전 호흡과 완전히 같은 대열은 피하고 같은 시드/호흡에서는 재현 가능하게 한다. 새로운 계절·공법 캠페인을 제작한 것으로 표현하지 않는다.

### 5분짜리 이용 예시

0:00 시작 → 첫 10초에 조준하지 않아도 한 무리가 정리됨 → 0:55 첫 개화 → 1:50 새 생성이 멈추며 화면이 비워짐 → 다음 호흡의 대열이 다른 방향으로 흐름 → 4:00 두 번째 작은 마무리 → 4:40 사용자가 나가기 → `오늘의 잔광` 짧은 정리 카드 → 로비.

5분 경과 알림이나 보상 만료는 없다. 기본 종료 알림도 없다. 사용자가 원할 때 설정하는 5/10/15분 쉬기 알림만 제안하며, 알림은 일시정지 메뉴의 조용한 문구로 처리한다. 더 하기 버튼을 강조하지 않는다.

## 8. 난도·자동화·장기 안정성

두 가지 리듬만 둔다. 최초 선택을 강요하지 않고 `차분하게`로 시작한다.

| 항목 | 차분하게 — 기본 | 시원하게 — 선택 |
|---|---:|---:|
| 목표 활성 신호 | 4~6 | 6~9 |
| 활성 신호 절대 상한 | 8 | 12 |
| 새 대열 생성 간격 | 3.5~5.0초 | 2.5~4.0초 |
| 초기 이동 속도 | 본편 기본값의 0.65배 | 본편 기본값의 0.80배 |
| 개화 동안 연결 상한 | 4목표 | 5목표 |
| 시간 제한·피해·사망 | 없음 | 없음 |

위 수치는 테스트 시작값이다. 장갑을 두껍게 하거나 다단 분할로 화면 밀도를 우회 증가시키지 않는다. 캐릭터의 정규 이동 속도를 몰래 바꾸지 않고 시험 신호의 속도와 구성으로 조절한다.

신호 상한에 도달하면 생성을 보류한다. 대기열은 최대 2대열로 제한하고, 오래된 미출현 대열은 건너뛴다. 뒤에 쌓인 대열이 한꺼번에 쏟아지지 않게 한다. 보류 중인 대열은 처치 대상으로 계산하지 않는다. 플레이어의 숙련도를 몰래 추측해 밀도를 올리는 자동 난도는 쓰지 않는다.

투사체 32개, 기존 품질별 효과 8/16/28개 상한을 넘지 않는다. 화면 밀도와 게임 규칙의 차이는 리듬 설정으로만 정하고, low 그래픽에서도 신호 수나 장비 성능을 줄이지 않는다. 30/60/120분 시뮬레이션으로 객체·이벤트·경로·저장 크기가 계속 늘지 않는지 확인한다.

## 9. 무기와 캐릭터에 애착을 만드는 방식

### 무기는 약한 상태를 견뎌야 주는 보상이 아니다

폭풍·특이점·프리즘·플라즈마의 승인된 표현을 모드 전용으로 대여한다. 기본은 폭풍, 나머지는 같은 수준의 선택지다. 정식 최종 진화 획득이나 캐릭터 특성 해금으로 오인할 UI를 사용하지 않는다. `이 모드에서 자유롭게 체험`을 준비 화면에 명시한다.

| 구성 | 편안한 손맛의 초점 | 연출의 핵심 |
|---|---|---|
| 폭풍 | 가까운 무리가 차례로 이어짐 | 실제 대상 사이의 짧은 청색 연결 |
| 특이점 | 흩어진 신호가 가지런해짐 | 완만한 녹색 궤도·회수, 화면 회전 없음 |
| 프리즘 | 같은 사선이 한 번에 정리됨 | 보라색 평행 빛, 얇고 읽히는 중심선 |
| 플라즈마 | 타격 뒤 부드럽게 회수됨 | 작은 주황빛 접점과 청록 회수 |

장비의 사선·연쇄·반사는 실제 모드 규칙의 결과에만 그린다. 보기 좋게 만들려고 맞지 않은 대상에 명중 효과를 만들지 않는다. 장비를 바꾸면 이미 날아간 탄은 발사 당시 구성을 유지한다. 현재 진화 검증에서 고친 원칙을 이어받는다.

개화 구간에는 추가 숙제 없이 연결 폭과 발사 표현이 잠시 넓어진다. 준비 화면에서 `주기적으로 장비가 활짝 전개됩니다`라고 알려 갑작스러운 규칙 변경으로 느껴지지 않게 한다. 스택·재료·특성 투자창을 새로 만들지 않는다.

### 캐릭터는 선호를 표현한다

승인된 6명을 처음부터 체험할 수 있도록 제안한다. 이 모드에서의 선택은 본편 캐릭터 해금·능력치·커리어 투자와 분리한다. 효과가 강한 인물을 고르도록 만들지 않고, 모습과 장비를 든 동작에 애착을 갖게 한다.

정지·걷기·조준·분사·발사는 현재 정본 동작을 사용한다. 기본 카메라에서 인물이 지나치게 작으면 손·장비가 읽히도록 모드 전용 구도를 조정한다. 새로운 표정·전신 원화·음성을 만들기 전에는 캐릭터별 고유 연기를 완료한 것으로 기록하지 않는다.

## 10. 그래픽·사운드: 선명하되 피로를 쌓지 않게

화려함은 짧은 순간의 선명한 결과에서 만든다. 기본 배경은 현재 승인된 현장 중 압박이 적은 후보를 선정하고, 퇴근 무렵의 빛과 가상 시험장 장치를 미술 검토한다. 실제 작업 공간의 조명을 단순히 꺼서 시험장이라고 부르지는 않는다.

| 항목 | 기본 방향 | 피할 표현 |
|---|---|---|
| 화면 구성 | 손·장비·다가오는 신호가 구분되는 명암 | 배경과 겹친 발사체, 빈 검정 무대 |
| 색 | 현장 중간색 + 장비별 한 가지 중심색 | 매 타격마다 전면 흰색 섬광 |
| 연결 | 실제 사선·짧은 잔광, 중심선 유지 | 화면을 덮는 불투명 구름·큰 텍스트 |
| 카메라 | 안정된 구도, 기본 진동 OFF | 강제 줌·잦은 흔들림·중앙 컷인 |
| 효과음 | 짧고 둥근 어택, 같은 소리 중첩 제한 | 높은 경보음, 연사 음량의 무제한 합산 |
| 음악 | 위협적 드롭 없는 완만한 루프와 구간별 레이어 | 개화마다 갑자기 커지는 음악 |
| 무전 | 기본 OFF, 필요한 경우 선택적 짧은 환경 대사 | 독촉·실패 통보·읽기 필수 정보 |

음악·환경음·장비음은 별도 볼륨을 기억한다. 동시 타격 시 같은 계열 소리를 합쳐 상한을 지키고, 개화 때 음량을 키우기보다 음색 레이어를 더한다. 휴대폰 스피커·이어폰에서 각각 확인한다. 저음/화이트노이즈가 누구에게나 편하다고 가정하지 않는다.

기존 무료 AI 제작 음원의 상업 사용 권리는 별도 검토가 진행 중이다. 이 모드가 그 권리를 새로 확보해 주지 않는다. 출시 자산은 출처·생성 서비스/요금제·약관 근거·권리 상태가 확인된 항목만 최종 후보로 올린다. 전용 곡은 원화·음원 제작 브리프 확정 후 별도 작업이다.

움직임 감소에서는 카메라 진동·장식 조각·광량 맥동을 끄고 중심선과 실제 신호를 남긴다. 소리를 꺼도 상황을 이해할 수 있어야 한다. 색과 모양을 함께 쓰고, 작은 한글과 아이콘만으로 필요한 설정을 숨기지 않는다.

## 11. 세로·가로·PC 화면 원칙

전투 영역을 가리는 상시 성장/보상 창은 없다. 캐릭터 선택·분위기·장비 체험 변경은 준비/일시정지 메뉴에서 한다.

- **세로:** 상단은 모드명·일시정지, 하단은 이동·조준·발사 상태. 기존 몰입 구도와 자유 패드 설정을 유지한다. 가변 주소창·안전 영역·작은 휴대폰에서 손과 장비를 확인한다.
- **가로:** 좌우 조작 영역과 중앙 플레이 영역을 분리한다. 작은 세로 높이에서 효과·장비 버튼이 인물을 덮지 않게 한다.
- **PC:** 기존 입력을 유지하고 메뉴 버튼 포커스 뒤에도 이동이 끊기지 않게 한다. 커서가 없어져도 일시정지/나가기 위치는 예측 가능해야 한다.
- **공통:** 회전·창 크기 변경 시 새 대열을 즉시 보류하고 입력을 해제한다. 배치가 안정된 뒤 플레이어가 재개할 수 있게 한다. 화면 회전 때문에 패배하거나 부상 입을 규칙은 없다.

검증 크기는 320×568, 390×844, 768×1024, 568×320, 844×390, 1440×900을 초기 행렬로 한다. 실제 화면 읽힘과 누르기 편함은 해상도 검사만으로 통과 처리하지 않는다.

## 12. 종료·저장·다시 켜기

`일시정지 → 오늘은 여기까지`로 즉시 종료할 수 있다. 정돈 연출은 최대 1.5초이며 바로 건너뛸 수 있다. 격파하지 않은 신호가 있어도 종료 가능하다. 확인창을 한 번 더 눌러야 나갈 수 있게 하지 않는다.

결과 카드는 `오늘의 잔광`이라는 작은 기록이다. 예: 선택 캐릭터와 장비, 정리한 시험 신호 수, 머문 시간. 최고점 대비 부족함·등급·실패·연속 출석을 표시하지 않는다. `로비로`가 기본 행동이고 `더 하기`는 보조 행동이다. 기록 수치도 숨길 수 있도록 제안한다.

저장 후보는 `psi.signal-breaker.rest.v1`로 분리한다. 저장 항목은 모드 버전·선호 캐릭터/구성·소리/입력 설정·시드·호흡 번호·호흡 시작 시점의 제한된 세션 요약이다. 모든 발사체·과거 경로를 누적 저장하지 않는다.

안전 저장은 호흡 시작, 설정 변경, 사용자가 나갈 때 수행한다. 호흡 중 앱이 종료되면 그 호흡의 시작으로 이어간다. 마지막 자동 저장 이후 변화는 정확 복원하지 않는다는 안내를 일시정지 메뉴에 둔다. 진입 시 재개/새로 시작을 고를 수 있고, 재개를 요구하지 않는다. 재접속 경과 시간만큼 적이나 재화를 생성하지 않는다.

가상 시험 신호 처리 통계는 호흡 확정 시 반영하고, 동일 시드·호흡의 체크포인트 재개로 중복 합산되지 않도록 한다. 저장 실패 시 플레이는 계속되며, 메뉴에 상태를 조용히 알린다. 손상된 저장은 다른 본편 저장에 영향을 주지 않고 기본 모드 설정으로 복구한다.

## 13. 보상과 사업 모델의 일관성

MVP에서는 본편 포인트·재료·커리어·클리어·업적 해금을 지급하지 않는다. 본편 규칙의 우회 파밍 장소를 만들지 않고, 휴식 모드에 오기 싫은 사용자에게 필수 콘텐츠로 만들지 않는다. 좋아하는 장비와 캐릭터를 자유롭게 체험할 수 있다는 것 자체를 제공 가치로 삼는다.

비경쟁 감상 기록은 선택 사항이며, 출석·기간 제한·확률형 장비·랭킹은 넣지 않는다. 장시간 유지·반복 종료/재개·안전 회수로 영구 재화를 만드는 경로도 없어야 한다.

유료 본편의 포함 콘텐츠 또는 무료 체험용 보조 콘텐츠 중 어느 쪽으로 판매할지는 미정이다. 이 문서는 가격을 확정하지 않는다. 광고를 채택하더라도 플레이·개화·일시정지 중 강제 광고나 이어하기 광고는 이 모드의 목적과 맞지 않는다. 광고가 없는 휴식 경험을 우선 제안한다. 실제 광고·결제 구현은 별도 결정 사항이다.

## 14. 구현 구조 제안과 범위

이 절은 개발 제안이며 이번 요청에서 코드를 구현하지 않는다.

| 계층 | 제안 책임 | 피할 접근 |
|---|---|---|
| 순수 규칙 프로필 | 피해/실패 없음, 리듬, 신호 수·속도·대여 구성 | UI에서 매 프레임 생명력이나 진화를 덮어쓰기 |
| 모드 순환 관리자 | 호흡 단계·시드·생성 보류·안전 회수 | `state='won'` 강제 주입으로 다음 현장 연결 |
| 입력·표현 | 기존 캐릭터·무기·궤적, 조작부와 소리 설정 | 표시 품질이 실제 성능·신호 수를 변경 |
| 저장 어댑터 | 제한된 모드 저장·오염 검증·중복 기록 방지 | 본편 재화·클리어 키를 함께 변경 |
| 세션 이벤트 | 실제 처리/안전 회수/대여 변경 구분 | 안전 회수를 격파·성장 달성으로 계산 |

`Game`에 복수의 충돌하는 boolean을 계속 더하기보다, 기존 생성 옵션을 분석한 뒤 `campaign / continuous / rest`의 명시적 모드 식별을 정한다. 기존 저장 이관과 `operation`·`veteran`·`continuous`의 조합 유효성을 먼저 설계한다. 대규모 엔진 교체·ECS·플러그인 프레임워크·백엔드·클라우드 세이브는 도입하지 않는다.

### MVP에 포함할 것

- 로비 보조 진입, 자유 종료, 한 종류 가상 시험 공간.
- 정본 6명 선택, 대여 4구성, 기본 추천 하나와 선호 기억.
- 차분/시원 두 리듬, 120초 기준 호흡과 유한한 생성/회수.
- 자동 조준·발사와 직접 개입, 기존 자유 이동 패드.
- 기본 진동/경보/실패/중앙 팝업 없는 표현, 별도 소리 설정.
- 오프라인·별도 저장·기존 캠페인 비침범·기록 중복 방지.

### 후순위로 남길 것

새 캠페인, 계절별 다수 맵, 캐릭터별 신규 특성 트리, 온라인 협동, 랭킹, 사진 모드, 완전 자동 이동, 감상 전용 재생, 새로운 화폐와 스킨 상점. 먼저 작은 모드가 피로와 지루함 중 어느 쪽으로 기우는지 확인한다.

### 제작 단계

1. **기술 확인:** 기존 연속 모드/작전/진화/보상/저장 진입점 조사, 모드 분리 계약과 회귀 기준 고정.
2. **플레이 검증판:** 승인된 기존 자산으로 한 공간·두 리듬·한 장비를 연결. 최종 아트 완료로 계산하지 않는다.
3. **감각 검수:** 5분 플레이에서 조작 의미·시원함·신호 읽힘·나가기 편함을 검증. 통과 후 4구성 확장.
4. **제작 확정:** 시험 공간 아트·음향 브리프와 권리 상태 검토, 필요한 최종 자산만 제작.
5. **릴리스 검증:** 장시간 순수 시뮬레이션, 브라우저·오프라인·실기기, 기존 15작전 회귀 후 배포 판단.

일정과 예산은 전용 아트·음원 필요량 및 1~2단계 기술 확인 후 산정한다. 기존 이미지 재사용을 이유로 최종 제작 비용을 0으로 가정하지 않는다.

## 15. 무엇을 확인해야 성공이라 할 수 있는가

### 기술 통과 기준

- 30/60/120분 동일 입력 시뮬레이션에서 게임오버·NaN·교착 없음, 신호/투사체/효과/대기열 상한 준수.
- 움직이지 않기·발사 끄기·조준 반대로 두기에서도 실패·오브젝트 무한 누적 없음. 안전 회수가 플레이어 격파로 기록되지 않음.
- 공격한 신호만 연결, 실제 연쇄 상한 일치, 이미 발사한 탄의 대여 구성 보존.
- 일시정지·백그라운드·화면 회전 중 시간·생성 정지, 누른 입력 해제, 복귀 직후 대열 폭주 없음.
- 오프라인 첫 진입 이후 재실행·재개·손상된 저장·저장 실패·중복 체크포인트 검증.
- 본편의 재화·해금·장비 소유·진화·캐릭터 커리어·15작전 경로에 영향 없음.
- 6개 화면 크기에서 조작부가 인물·신호·게임 영역을 가리지 않으며, 소리 OFF·줄인 동작·low에서도 필수 정보 유지.
- 실물 보급형 Android 30분 이상에서 입력 반응·온도·배터리·프레임 안정성 측정. 목표값과 기기는 검증 전 고정하고 브라우저 에뮬레이션으로 대체하지 않음.

### 사람 플레이 검증

초기 8~12명 정도의 소규모 사용성 검토를 제안한다. 무료 캐주얼 중심 사용자, 기존 브레이커 사용자, 건설 업무 경험자를 섞는다. 이 규모는 설계 문제 탐색용이며 의학적 효과나 전체 사용자 통계를 입증하지 않는다.

5분 기본 이용과 선택적 15분 이용을 관찰한다. 기존 연속 모드와 새 모드의 이용 순서를 바꿔 비교하고, 참가자가 원하면 언제든 끝낼 수 있게 한다. 과제 전후의 느낌과 그 이유를 묻되 게임 안에 매번 설문을 노출하지 않는다.

| 질문 | 관찰할 것 | 수정 방향 |
|---|---|---|
| 무엇을 할지 바로 알았는가? | 설명 요청·메뉴 왕복·첫 조작까지의 망설임 | 진입 선택과 도움말 축소 |
| 내가 움직인 결과가 보였는가? | 자발적 조준·이동, ‘자동 영상 같다’는 반응 | 반사/대열 인과관계 강화 |
| 더 피곤해진 부분이 있었는가? | 소리 중첩·시선 분산·손의 긴장·현장 연상 | 해당 자극/맥락 조정 |
| 언제 끝내고 싶었고 실제로 끝냈는가? | 보상 때문에 남는 행동·종료 위치 탐색 | 종료 접근성과 손실 없는 구조 확인 |
| 15분 후 지루해진 이유는 무엇인가? | 밀도 부족인지, 패턴 반복인지, 자동화 과다인지 구분 | 적 체력 대신 대열·장비 표현 변주 |

초기 통과 목표는 ‘대부분 설명 없이 시작하고, 임의 시점에 손해 없이 종료하며, 불필요하게 어렵거나 소란스럽다는 반복 의견이 해결됨’이다. 휴식감·즐거움이 낮으면 체류시간이 길어도 출시 근거로 삼지 않는다. 일과가 떠오른다는 반복 의견은 배경/맥락 재검토 사유다.

## 16. Director 검토가 필요한 결정과 권고안

| 결정 | 권고안 | 이유 |
|---|---|---|
| 모드명 | 잔광 — 쉬어가는 무한모드 | 여운과 자유로운 종료를 함께 전달 |
| 공간 | 실제 작업과 분리된 가상 장비 시험장 | 위험을 무시하는 규칙과 세계관의 충돌 방지 |
| 생존·보상 | 사망 없음, 본편 재화 지급 없음 | 부담·파밍 의무·본편 가치 훼손 감소 |
| 장비 | 4구성 모드 전용 대여, 폭풍 기본 추천 | 처음부터 손맛 제공, 선택 부담 제한 |
| 인물 | 정본 6명 자유 체험, 능력치 경쟁 없음 | 익숙한 캐릭터 애착 유지 |
| 기본 리듬 | 차분하게, 120초 기준 호흡 | 짧게 켜도 시작·개화·정리의 작은 완결 제공 |
| 감각 | 진동/경보/무전 기본 OFF, 장비음은 남김 | 조용함과 조작 피드백을 함께 유지 |
| 판매·광고 | 본편 포함 서브 콘텐츠 우선, 플레이 중 광고 없음 | 휴식 경험의 일관성 확보 |

사용자 요청은 기획서 작성이므로 위 항목은 권고안이며 승인·구현 완료로 간주하지 않는다. 이 문서만으로 본편의 난도·경제·판매 방식을 변경하지 않는다.
