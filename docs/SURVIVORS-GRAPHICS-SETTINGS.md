# 쉽게 고르는 그래픽 설정

메인화면 우측 상단 톱니바퀴 설정, 출동 준비 설정과 시그널워치 일시정지 설정에 같은 세 가지 모드를 제공한다. 메인에서도 즉시 저장하며 게임 진입 시 그대로 사용한다. 모바일의 설정 창은 화면 안에서 스크롤할 수 있다.

| 선택 | 선택할 상황 | 화면 배율 상한 | 장식 파편 비율 |
|---|---|---|---|
| 추천 | 처음 시작할 때 | 1.5 | 65% |
| 부드럽게 | 끊김 또는 발열이 느껴질 때 | 1 | 35% |
| 선명하게 | 현재도 원활하고 세밀한 화면을 원할 때 | 2 | 100% |

배율은 기기의 실제 배율 이내에서 적용한다. 렌더링 부담을 낮추며 프레임 향상 폭은 기기에 따라 다르다. 자동 성능 진단이나 FPS 보장을 의미하지 않는다. 몬스터·판정·위험 경고·보상은 변경하지 않는다. 흔들림과 섬광은 별도의 ‘눈이 편한 화면 · 세부 조절’에 유지한다.

설정은 즉시 반영하며 psi.survivors.graphics_v1에 저장한다. 두 화면은 같은 구독 상태를 사용한다. PC와 모바일, 배율 2 환경에서 모드 선택 시 실제 캔버스 너비가 1440→2880 및 390→780으로 변경되는 것과 화면 간 공유·재실행 복원을 확인했다. 브라우저 결과는 artifacts/graphics-settings/report.json에 기록한다.
