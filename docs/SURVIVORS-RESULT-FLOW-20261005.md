# Survivors result flow

- Victory and defeat display the engine's awarded PSI credits rather than a second score-based calculation. Difficulty bonuses and credits already accumulated during play remain visible.
- Retry returns to operation preparation without a delayed automatic start. Players can inspect durability, repair or change equipment before deployment; normal start readiness checks remain in control.
- Next-stage action explicitly opens preparation. Existing stage unlock and reward formulas are unchanged.
- Regression coverage checks the displayed reward, one-time wallet settlement and durability wear, and retry without an extra engine start.
- Follow-up: persistent result actions on compact landscape screens, result dialog keyboard focus, and recoverable reward persistence failures need separate verification. No art or audio production lock is claimed.
