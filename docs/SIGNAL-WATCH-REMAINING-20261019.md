# 시그널 워치 잔여 그래픽 적용 · 2026-10-19

사용자의 ‘이어서 나머지 사항 적용하여 완료실시’와 후속 ‘이어서 진행’ 요청에 따라, STAGE 02 이후의 49개 작업면 전경 제작·연결과 검증을 진행한다. 기존 원화와 전투·이동·저장 규칙은 유지한다. 전경은 각 작업면의 실제 원화를 대상으로 빌트인 `image_gen`의 `background-extraction` 모드로 제작하며, 프롬프트와 원본·파생 자산 해시를 함께 보존한다.

## 연결 원칙

각 원화의 하단 물리 구조물만 추출한다. 바닥 표시·배수로·중앙 보행면은 전경에 넣지 않는다. 생성된 RGB는 사용하지 않고 알파와 원화의 동일 좌표를 조합한다. 생성물의 원본 크기가 다르거나 중앙 바닥을 포함하면 등록하지 않고 다시 제작한다. 크롭 내부의 알파는 변형하지 않는다.

사용자의 잔여 작업 적용 요청은 런타임 반영 권한이다. 새 49개를 사용자가 개별 시각 검수했다고 기록하지 않으며, 전체 Final Visual Lock도 선언하지 않는다. STAGE 02의 기존 개별 확인 기록은 그대로 보존한다.

## 캐릭터 준비 메모리

선택한 요원의 모든 방향 원화 11~12장을 동시에 보유하던 로더를 방향별 필요한 원화만 읽도록 변경했다. 공유 회전·동작 원화는 마지막 사용 방향까지 유지하고, 이후 이미지 참조를 해제한다. 실제 6명·8방향·20프레임 레이아웃을 검사해 원화별 중복 로드 없이 모든 포즈에 필요한 원화를 유지하며 동시에 보유하는 원화 용량이 기존 절반 미만인 것을 확인했다. 캔버스 크기·원화·크롭·관절·장비 위치·타이밍은 바꾸지 않는다. 이 수치는 디코딩 원화의 계산상 동시 보유량이며 전체 앱 메모리 측정값은 아니다.

## 검증 기록

진행 중. 최종 전체 테스트·타입 검사·빌드·브라우저·배포 결과를 종료 시 기록한다. 로컬 네이티브 컴파일러가 Windows 메모리 부족으로 중단된 실행은 통과로 계산하지 않는다. 개발 서버와 이전 검수 탭을 닫고 `GOMAXPROCS=1`, `GOGC=50`로 재실행한 타입 검사는 통과했다. 제품 설정을 낮추거나 검사를 생략하지 않았다.

## Android

사용자가 ‘현재 연결된 기기 없음’이라고 확인했다. PC에서 ADB와 Android SDK도 확인되지 않았다. 모바일 크기 브라우저 검수는 진행하되 실제 기기 성능·발열·메모리 검증을 완료했다고 표시하지 않는다.
