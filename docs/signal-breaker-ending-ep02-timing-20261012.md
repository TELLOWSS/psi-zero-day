# EP02 엔딩 음성 권장 보정본

사용자의 「이어서 진행. 알아서 적용」 지시에 따라 후보 선택과 길이·음량 보정을 적용했다. 원본 후보 10개는 변경하지 않고, 슬롯마다 가장 짧은 제공 녹음을 권장 보정본으로 준비했다. 권장본은 최종 청취 승인이나 실제 게임 연결을 의미하지 않는다.

| 슬롯 | 선택 | 원본 | 보정본 | 속도 |
|---|---|---:|---:|---:|
| CH-06 | v01 | 4.240초 | 4.240초 | 1.000배 |
| CH-07 | v01 | 4.760초 | 4.445초 | 1.000배 |
| CH-08 | v01 | 4.400초 | 4.063초 | 1.000배 |
| CH-09 | v02 | 5.080초 | 4.431초 | 1.037배 |
| CH-10 | v01 | 5.720초 | 4.732초 | 1.000배 |

- 목표 길이: 5/5 통과. 전체 재생 음량은 -24 LUFS ±0.3, true peak는 -3 dBTP 이하, 샘플 클리핑 0.
- 기존에 길이가 맞는 CH-06은 무음을 편집하지 않았다. 나머지는 먼저 앞뒤 무음을 줄이되 100ms를 남겼다.
- 앞뒤 정리로도 초과하는 경우 -45 dBFS 이하로 검출된 450ms 이상 내부 무음의 가운데만 줄이고 최소 300ms를 남겼다.
- 여전히 초과하는 CH-09에만 ffmpeg atempo로 음정을 유지하며 약 3.7% 속도를 보정했다. 자동 생성의 상한은 8%이며 초과하면 재녹음 대상으로 실패한다.
- 길이를 맞추려고 끝 음절을 자르거나 대사·화자를 대체하지 않았다. 청취·발음·연기 검증은 별도 미완료 상태로 기록했다.

## 파일과 실행

- 재생·비교: `/signal-breaker-dev/qa/ep02-voice.html` — 각 슬롯의 권장 보정본을 먼저 표시하고 두 원본 후보도 유지한다.
- 권장본과 공개 manifest: `public/assets/survivors/voice-ending-ep02-prepared/`
- 수신·처리 기록: `content/signal-breaker-ending-voice-ep02-prepared.json`
- 재생성: `python scripts/prepare-ending-ep02-voices.py` (ffmpeg 필요)
- 검증: `npm run audio:ending-ep02-check` (기존 prebuild에 포함)

보정 manifest는 원본 해시, 무음 제거 구간의 샘플 위치, 속도·게인, 실제 길이·LUFS·true peak와 출력 해시를 보존한다. 빌드는 ffmpeg를 요구하지 않고 커밋된 WAV의 원본 대응·해시·PCM·길이·클리핑·처리 기록을 검증한다.

현재 작전·엔딩 계약은 여전히 CH-01~05다. CH-06~10의 신규 스토리·작전·화면·해금 규칙을 임의 생성하지 않았다. 보정본의 speakerId/lineId는 null이고 runtimeIntegrated/finalListeningApproved는 false다. 준비된 5개를 게임에 연결하려면 대응 엔딩 계약이 필요하다.
