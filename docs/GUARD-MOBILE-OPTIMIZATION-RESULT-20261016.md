# 시그널 가드 모바일 최적화 결과

[선행 기획](GUARD-MOBILE-OPTIMIZATION-PLAN-20261016.md)을 작성한 뒤 구현했습니다. 비교 기준은 운영 커밋 c32276c3의 [이전 검증 자료](qa/guard-usability-20261016/browser.json)입니다.

## 구현

- 상단을 보호막·자원·웨이브·일시정지·메뉴 한 줄로 줄였습니다. 메뉴에 배속·음소거·작전실·전술 정보·안내를 모았습니다.
- 준비 중 하단은 추천 배치·파 정보·시작, 전투 중에는 동료 지원·E-STOP, 정지 중에는 전투 계속을 우선합니다.
- 모바일 장비 패널은 맵을 줄이지 않고 겹쳐 열립니다. 닫기와 전투 재개를 구분하고, 재개는 하단에서 바로 조작할 수 있습니다.
- 구매 되돌리기를 패널 헤더에 모았습니다. 다음 강화 후보가 먼저 보이고, 전체 분기·실험·대상 설정·판매도 열어 볼 수 있습니다.
- 지점 목록은 가로 스크롤로 선택합니다. 낮은 가로 화면에서는 헤더의 선택 상자로 전환합니다.
- 전장 영역을 ResizeObserver로 관찰해 전체 경로를 더 크게 표현할 수 있는 가로/세로 방향을 선택합니다. 프레임별 크기 측정이나 새 게임 타이머는 추가하지 않았습니다.
- 통로 전환은 파 정보 패널에서 확인합니다. 지휘관의 장비 이동과 신호수의 방향 지원은 장비 선택 버튼으로 연결합니다.

## 측정 결과

준비 화면에서 실제로 표시된 전체 맵의 면적을 비교했습니다. 패널에 덮이는 부분까지 모두 볼 수 있다는 뜻은 아닙니다.

| 화면 | 이전 맵 크기 | 개선 맵 크기 | 면적 증가 |
|---|---:|---:|---:|
| 390×844 세로 | 315×525 | 382×637 | 47.1% |
| 320×568 세로 | 312×187 | 240×400 | 64.4% |
| 844×390 가로 | 463×278 | 550×330 | 40.9% |
| 568×320 가로 | 347×208 | 416×250 | 44.0% |

6개 모바일 크기 모두 장비 선택 전후 맵의 위치·크기가 유지됐습니다. 작은 화면에서도 다음 강화 후보 전체가 패널 첫 화면에 들어옵니다.

## 검증

- 전체 테스트 2,152개 통과, 기존 1개 제외. 신규 모바일 UI 테스트 4개 포함.
- 타입 검사와 프로덕션 빌드 통과.
- 브라우저 7개 크기: 320×568, 360×740, 390×844, 430×932, 568×320, 844×390, 1440×900.
- 실제 클릭으로 구매·전액 환불·강화 미리보기·확정·전체 분기·파 시작·정지·선택·재개·메뉴·배속·화면 회전을 검증했습니다.
- 핵심 터치 영역 최소 44×44px, 하단 선택 버튼의 화면 안 배치, 맵과 HTML 터치 지점의 좌표 정렬, 가로 넘침을 확인했습니다.
- 별도 세로·작은 가로 프로필에서 GD-06 통로 전환, 지휘관 재배치, 신호수 방향 지원, 저장 후 재진입을 확인했습니다.
- 완성된 프로덕션 번들에서도 세로·작은 가로 2개 화면의 맵 유지와 실제 강화를 확인했습니다. [번들 검사](qa/guard-mobile-layout-20261016/production-build.json).
