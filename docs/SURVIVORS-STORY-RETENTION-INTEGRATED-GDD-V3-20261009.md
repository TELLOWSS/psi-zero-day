본편과 슈팅은 동일한 '사고 전 신호' 철학을 공유하지만, 이번 개발은 **시그널 워치 슈팅**에 한정한다. 새로운 서사로 본편의 선택·증거·엔딩을 강제로 바꾸지 않는다.

## 1. 경험 목표

- **1초:** 발사→명중→재질 반응→해소가 소리·그림으로 정확히 일치.
- **1웨이브:** 내 장비/위치/제동으로 특정 위험 패턴을 해결.
- **1작전:** 내가 실제 처리한 구역·제동·정리 실적이 인계로 남음.
- **1챕터:** 기록의 충돌에서 '왜?'라는 궁금증이 생김.
- **장기:** 다른 캐릭터·다른 장비·놓친 인계를 다시 보고 싶어짐.

액션 80/서사 20. 안전지식은 '정답 퀴즈'가 아니라 게임 패턴의 인과관계로 경험하게 한다. 사람은 보호·대피·지원 대상으로 남기고, 산업 위험은 과장해도 작업자와 동물을 몬스터로 만들지 않는다. 몰입을 위해 수면을 방해하는 출석 벌칙·한정 보상 압박·무한 희귀 뽑기는 사용하지 않는다.

## 2. 50스테이지: 기존 아이디와 보스를 유지하는 미스터리

| 구간 | 제목·핵심 질문 | 대표 기억 지점 |
|---|---|---|
| 01–10 | **첫 신호:** 같은 작업면 기록이 왜 다를까? | ST01 후진 장비, ST06 숨은 활선, ST10 원격 기동 |
| 11–20 | **이어지지 않은 약속:** 어제 비운 길이 왜 오늘 다시 막혔나? | ST12 철근 반입, ST14 갱폼, ST20 인계 |
| 21–30 | **어제의 통로:** 기록을 믿을까, 현재 현장을 읽을까? | ST25 안내 경로 반전, ST30 탈출로 |
| 31–40 | **가장 높은 곳의 침묵:** 모두 맡은 일을 해도 왜 위기는 겹칠까? | ST35 비계, ST40 열린 가장자리 |
| 41–50 | **ZERO DAY:** 현장 전체가 한 번에 움직이면 무엇이 달라질까? | ST47 연쇄 시운전, ST50 단일 8초 최종 통제 |

누군가 기록을 악의적으로 조작했다는 음모로 도피하지 않는다. 실제 공정 압박·작업 시점·통로 변경·전달 실패를 모은 '연결되지 못한 인계'가 미스터리의 결론이다. 실재 사고/재해자/실제 회사명은 작품에 직접 차용하지 않는다.

**ST50의 절대 계약:** 기존 보스 패턴을 압축해 현장 전체의 위험을 상대한다. 최종 통제 피니시는 **한 번의 8초**. 별도 6초+8초로 늘리지 않는다. 임준호가 플레이어보다 먼저 위험을 보고하고, 다른 동료들도 자발적으로 대응하는 장면에서 감정을 완성한다.

## 3. 캐릭터 '친밀도 점수'보다 기억

| 요원 | 관찰의 초점 | 결과 문구의 근거 |
|---|---|---|
| 안전관리자 | 중지/재개 근거, 확인과 미확인 구분 | 내가 남긴 실제 인계 |
| 강태식 | 작업반 동선, 정리·차폐 | 작업반이 실제로 활용할 수 있는 공간 |
| 윤성호 | 철근 묶음·적치 상태 | 결속·자재 이동에 관한 짧은 기록 |
| 이재훈 | 도면/실제 작업의 차이 | 작업 조건의 다른 점 |
| 임준호 | 작은 예고·신고 | 위험을 먼저 알리는 대화 |
| 안전감시자 | 무전·사각·출입 | 다음 팀이 찾아볼 감시 지점 |

현재 6명은 기존 요원 ID에 맞추고 legacy 별칭을 호환한다. 임의의 과거 트라우마·관계수치·과금 결말을 추가하지 않는다. 직접 성공한 작업을 기억하는 **한 문장**과 요원별 **다른 관점**이 핵심이다.

## 4. 한 번의 순찰 작동 리듬

**짧은 작전 목표 → 강한 첫 손맛 → 선택한 보급/시너지 → 중반 위협 변주 → 보스 1개 핵심기믹 → 약점창 폭딜 → 실제 통제 결과와 동료 무전 → 다음 신호.**

전투 중 중앙 모달·긴 교육 텍스트를 추가하지 않는다. 보급·결과·자세한 기록은 게임이 정지된 UI에서 읽게 한다. 저화질에서도 예고선·약점·적 실루엣 보존. 게임 시간 목표는 자연 플레이로 확인한 뒤 조정하며 엔진의 목표 시간을 문서 숫자에 맞춰 독단적으로 바꾸지 않는다.

## 5. ST12 《퇴근 전에, 이 길만은》 단계적 구현

**기존 콘텐츠**: `stage_12`는 철근 반입·배근 작전이고 위험의 중심은 반입 차량·철근 작업 동선이다. 기록은 `OperationHandoff`의 `outcome, zones, cartStops, rubbleCleared, stars`를 재사용한다.

### Gate 1A — 이번 브랜치 구현

1. 준비 화면 `SurvivorsOperationBrief`: ST12에서만 요원 6명 각각의 짧은 작전 동기 표시.
2. 다른 캐릭터의 **실제 승리 기록**이 있을 때만 통제·제동·정리 수를 비교할 수 있는 한 줄 표시.
3. 클리어 화면 `PatrolSurvivorsGame`: 현재 엔진 결과에서 `operationHandoff(state)`를 받아 ST12의 상황별 인계 출력.
4. 잔재 정리 `0`이면 "정리 기록 없음"으로 출력. 승리만으로 통로가 확보됐다고 단정하지 않음.
5. ST13 야간 타설의 장비·조명 동선을 다음 신호로 예고. 새 결말/보상/난도/저장키는 추가하지 않음.
6. 단위 테스트에서 6인 대사 구별, 비ST12 영향 없음, 패배 시 승리 오표시 없음, 실적 허위 없음, 다른 요원 성공만 노출 확인.

**새 파일:** `src/domain/survivors-story-attachment.ts`, `content/localization/survivors-story-st12-ko.json`, `src/ui/SurvivorsStoryBeat.tsx`, `src/ui/survivors-story-beat.css`, `tests/survivors-story-attachment.test.ts`.

**수정 파일:** `src/ui/SurvivorsOperationBrief.tsx`, `src/ui/PatrolSurvivorsGame.tsx`.

**절대 오해 방지:** 준비/결과에 성과를 표시한다는 것과 실제 전투 지형을 동적으로 바꿨다는 것은 다르다. 통로의 충돌/이동 경로 변경 및 전후 영상은 **Gate 1B 미구현**이다.

### Gate 1B — '실제로 달라진 현장' (부분 구현 / 화면 검수 전)

1. **기존 엔진 검증:** 잔재물은 원래 실제 충돌/추적 장애물이며 `clearTerrain()`으로 HP가 0이 되면 `terrainMove/terrainHit/terrainWaypoint`가 더는 막지 않는다. 이번 작업은 새 물리·보상 규칙이 아니라 그 **기존 인과관계의 명확한 가시화**다.
2. **이번 코드 추가:** `src/engine/survivors-stage12-route.ts`가 해당 ST12 잔재의 양쪽에서 플레이어 반경(14)을 고려한 직접 통과 구간을 찾는다. 다른 활성 장애물이 경로를 가로막으면 '통과 가능'을 표시하지 않는다.
3. **전투 세계에 표시:** `src/ui/survivors-stage12-route-renderer.ts`를 기존 `drawTerrain` 직후 호출, 동일한 현장 카메라에서 **'잔재 장애 · 우회 필요' → '잔재 정리 · 직접 통과 가능'**으로 변화한다. 해당 소구간의 통과 판정만 나타내며 현장 전체 안전/재개 가능을 보증하지 않는다.
4. **회귀:** `tests/survivors-stage12-route.test.ts`가 기존 stage_12 지형에서 정리 전 통과 차단 → 후 즉시 직접 이동 허용, 타 장애물 시 허위 표시 방지, ST11 비간섭, 모션 감소 모드 텍스트 보존을 검사한다.
5. **잔여 잠금:** 실제 12스테이지 자연 플레이 영상으로 정리 전/후 같은 앵글 캡처, 캐릭터 행동/의미 일치, 저사양 Android 실기기 FPS, 세로/가로 6개 뷰포트 확인은 **미완료**. 이후 타 공정으로 확대하기 전에 위 관문을 닫는다.

### Gate 2 — ST14 갱폼
기존 진자 운동→잔재 낙하→하부 통제→약점 폭딜 그대로. 실제 패턴 성공/실패·캐릭터별 발화의 인과 추가.

### Gate 3 — ST25 반전
어제의 안전 표식이 틀린 상황. 플레이어에게 실제 사전 단서·복구 경로가 제공되는 **공정한 퍼즐**로 구현.

### Gate 4 — ST50 결말
기존 최종 연출의 단일 8초와 결말 감정을 통합. 미확정 자산은 텍스트/임시 이미지로 최종 완성 선언하지 않는다.

### Gate 5 — 재플레이 확장
완료한 현장의 다른 요원 관점, 반복 무전 억제, 결과 아카이브, 보스 연구실, 인계 릴레이. 아직 없는 모드는 플레이 가능하다고 표시하지 않는다.

## 6. 장비·프리미엄·경제

일반 장비 최고 레벨도 보스 기믹을 자동 무력화하지 못한다. 프리미엄 장비는 발사·명중·진화·제동·소리의 명확한 프레젠테이션과 효율로 체감 차이를 주되 **자동 정답/핵심 결말 독점 금지**. 조합은 실제 엔진/스토어 ID 검증 후에만 시너지라고 표기. 기존 크레딧/수리비/성장/해금/유료 구매 저장 및 정산은 이번 스토리 작업에서 변경하지 않는다.

## 8. QA Gate
