# 시그널 워치 타격음 검수 및 단순 쾌감 확장

## 첨부 검수와 반영

- 출처: signal-watch-impact-sfx.zip. Manus generate_sound_effect 네이티브 MP3 9개. 첨부 메타데이터는 제작 자료이며 별도 실행 지시로 취급하지 않았다.
- 사용권: 2026-10-07 사용자가 게임 공개 배포 사용권 확인 완료라고 답변. 제공자 약관 원문·모델 버전은 미제공이므로 독립적인 법적 인증으로 표현하지 않는다.
- 원본 파일 SHA-256을 기록했다. 원본은 변경하지 않는다. MP3 컨테이너 길이 약 0.522초, 실제 디코딩 PCM은 0.480초다.
- 원본·실행 파일의 디코딩 클리핑 0. 실행용은 모노 44,100 Hz / PCM 16-bit WAV, 측정 음량 보정과 짧은 가장자리 페이드만 적용했다. 업샘플링이나 손실 음원 복원으로 품질이 높아졌다고 주장하지 않는다.
- 금속/콘크리트는 기존 재질 접촉에 A/B/C 비반복 재생. 결정타는 크레인·폭주 카트·낙하물 중요 치명타에만 사용한다. 작업자 응답과 막힌 공격에는 적용하지 않는다. 새로운 피해·보상·게임 규칙은 없다.
- 접촉음은 장비별 중첩 대신 공통 재생 간격으로 제한하고 결정타에는 더 긴 간격을 둔다. 일시정지·음소거·종료와 기존 음성/경고 우선순위를 유지한다.
- 수치 검수는 사람의 청감 승인이 아니다. 최종 스피커·이어폰 청감과 음성/경고 동시 재생 평가는 Director 확인 대상으로 남긴다. 파일별 측정값은 content/survivors-impact-sfx-ingest.json 참조.

## 구현 상태

- 신규 적용: 실제 드롭 수집만 140ms 묶음으로 회수음 한 번·실제 개수 표시·짧은 이동 흔적. 수집 수치와 범위는 그대로다.
- 신규 적용: 실제 비작업자 통제 직후 살아 있는 위협이 0인 경우에만 현재 위협 해소 마침표. 전체 웨이브/맵 클리어로 오인하지 않도록 문구를 구분하고 8초 간격을 둔다.
- 신규 적용: 실제 통제 위치의 짧은 안전 표시, 투사체 ID로 확인된 동일 공격의 통제 건수. 임의 시간 콤보를 공격 합산으로 표현하지 않는다.
- 신규 적용: 위협 해소 순간 불필요한 플레이어 주변 입자를 줄이고, 큰 공격의 전체 화면 흔들림을 낮춰 현지 재질·접촉 연출을 강조한다.
- 신규 적용: 저장에 성공한 실제 수리만 장비 원화와 내구도 100 복구 영수증. 실패·재오픈 시 이전 수리 표시를 지운다. 저감 모션에서는 밝기 애니메이션을 끈다.
- 기존 유지·검증: 재질/장비별 실제 공격 효과음, 보스 사건 해소의 선택 성우 응답, 출동 START 음성. 조작을 차단하는 별도 컷신은 추가하지 않는다.
- 후속 적용: 장비 점검 8방향 전용 원화 최종 후보를 제작해 안전 대기·출동 직후·착용 미리보기에 연결했다. 이동/공격/피격/위험/경고가 우선이고 사람의 최종 외형 승인은 별도다. 제작 프롬프트와 이력은 docs/survivors-equipment-check-and-relief-production-20261007.md 참조.
- 음원 대기: 신규 일반 위기 후 숨소리는 실제 최종 음원 없이는 합성하지 않는다. 선택 성우 3종 A/B 제작 프롬프트를 위 문서에 준비했다.
- 일시정지에서 피드백 시간이 멈추고 새 순찰/재도전에서는 큐를 초기화한다. 시각/음향 큐는 게임 보상에 영향을 주지 않는다.
