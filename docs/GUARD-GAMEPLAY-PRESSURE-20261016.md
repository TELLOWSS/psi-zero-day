# 게임성 고도화: GD-06 지원 코어

기준은 Director의 세 모드 보스 종합본이다. 이번 제작은 GD-06에서 관찰 → 배치 → 대응 → 결과 확인이 실제 판정으로 이어지도록 하는 범위다. 50보스·신규 캠페인·미제작 원화 전체 완료를 뜻하지 않는다.

## 실제 데이터 정정

현재 GD-05는 upper/lower 두 진입로다. GD-06은 main 한 진입로가 W5에 다른 경로로 전환된다. 종합본과 이전 요약의 GD-06 '두 진입' 전제를 실제 구현 완료로 계산하지 않는다. 기존 경로·패드·완주를 유지하면서 지원 코어를 구현했다. 별도 두 진입 GD-06 지도 제작은 이번 변경에 포함하지 않는다.

## 플레이 규칙

- 새 GD-06 작전 W1~3에 장갑형 지원 코어가 1기씩 등장한다. 지정된 출현 그룹의 신호 1기를 대체한다. 개체 수·출현 시각을 늘리지 않고 기존 장갑형 정의와 Production 자산을 쓴다. 타워·보스 HP, 시작 자원 480, 레벨 비용을 일괄 상향하거나 하향하지 않는다.
- 지원 코어는 자신의 경로를 탐지할 수 있는 SENSOR 중 가장 가까운 한 기를 지정한다. 동률은 타워 ID로 결정한다. 대상이 없으면 탐색을 계속하며, 등장 즉시 임의의 장비를 고장내지 않는다.
- 대상과 연결선·`!`·패드명·4초 예고를 보여준 후, 살아남은 코어가 3초 동안 그 SENSOR의 새 탐지 펄스만 막는다. 공격은 계속되고 이미 확보한 탐지 시간은 지우지 않는다. 경고와 실제 방해는 다른 소리 및 문구·기호로 구분한다.
- 조기 처리로 발동을 막을 수 있다. 다른 SENSOR의 중첩 탐지와 OBSERVER의 전체 공개는 계속 작동한다. COMMANDER로 실제 대상 장비를 재배치하면 고정을 끊으며 지원 쿨다운을 소비한다. 장비 판매 역시 고정을 끊지만 기존 환급 손실이 적용된다.
- E-STOP/동결 지원은 코어의 남은 예고·방해 시간을 동결한다. 멀리서 정지시키면 공격 사거리 진입도 늦어지므로 항상 이득인 자동 해법은 아니다. 대상을 옮기거나 코어를 처리하면 즉시 방해가 끝난다. 같은 코어는 재지정·무한 재시전하지 않는다.
- 기존 FIRST/STRONG 목표 선택, 기본 타워, 지원과 재배치를 사용한다. 새 유료 필수 장비·자동 조작·무료 무한 대응은 추가하지 않는다.

## 정보와 기록

준비 화면과 배치 추천은 엔진과 같은 출현 예측 함수를 쓴다. '일반 28 + 지원 코어 1'처럼 수를 부풀리지 않고 '장갑형 지원 코어 1 + 일반 27'로 표시한다. 모바일에서는 기존 상단 한 줄을 현재 경고와 타이머로 사용하여 전장을 새 패널로 가리지 않는다. SVG 연결선은 실제 대상과 코어 위치를 따른다. 투사체나 피해 연출로 계산하지 않는다.

회고에는 실제 예고 수와 실제 발동 수를 별도로 남긴다. 조기 처리로 발동하지 않은 코어를 방해 성공으로 계산하지 않는다. 예전 회고에 이 수치를 채워 넣지 않는다.

## 저장과 회귀

새 작전 생성 시 `sensorPressureEnabled`를 저장한다. 이 필드가 없는 기존 진행 중 작전은 이전 출현·전투 규칙을 유지한다. 새 상태는 코어 단계·남은 틱·고정한 타워와 패드를 저장하며 재접속으로 4초 경고를 다시 얻거나 즉시 발동시키지 않는다. 추후 규칙을 바꾸면 기존 활성 작전과의 세대 구분도 유지해야 한다.

`SEEK → WARNING → ACTIVE → SPENT`는 순수 엔진이 소유한다. UI는 이를 표시하고 사용자의 기존 명령을 전달한다. 저장 검증은 잘못된 단계·음수 시간·방해 코어와 활성화 플래그가 모순된 데이터를 거부한다. 1×/2×, 일시정지, 동결, 저장/복원에서 같은 시뮬레이션 시간을 보장한다.

## 검증과 제작 게이트

`tests/guard-sensor-pressure.test.ts`에서 시간·단일 대상·탐지 분산·공격 유지·재배치 해제·저장·구버전·합법 구매를 검증한다. 3개 배치 성향 × 6명, 18개 조합은 실제 구매/진화/지원/E-STOP/수동 전환 명령으로 시뮬레이션한다. 승리나 재화·HP를 주입하지 않는다. 기존 자동 추천이 새 기믹에서도 항상 승리한다고 가정하지 않고, 실제 경고와 보스 위치를 보고 E-STOP을 사용하는 정상 대응을 검증에 포함한다.

브라우저 검증은 정상 자원으로 구매한 준비 상태를 격리된 프로필에 넣고 실제 시작 → 예고 → 방해 → 일시정지 → 타워 선택 → 수동 재배치 → 해제까지 확인한다. 실기 Android·사람의 재미 평가·최종 원화/음향 Production Lock은 별도 게이트다.

이번 검증: 전체 2,169 통과·기존 1건 skip, typecheck·정식 build 통과. 18개 조합 모두 시작 자원 480에서 방어력 18~20으로 승리했다. 6개 화면에서 경고 문구가 실제로 보이는지 확인하고, 네트워크 차단 후 수동 재배치로 방해를 해제했다. 브라우저 재로딩 없이 진행한 오프라인 대응 검증이며 Android 실기나 사람의 재미 승인을 뜻하지 않는다. 증거는 [verification.json](qa/guard-pressure-20261016/verification.json), [18조합](qa/guard-pressure-20261016/simulation.json), [화면별 실제 조작](qa/guard-pressure-20261016/browser.json)에 기록했다.
