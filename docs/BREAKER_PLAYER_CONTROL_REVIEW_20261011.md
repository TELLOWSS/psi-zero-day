# 시그널 브레이커 — 플레이 피드백 반영 (2026-10-11)

이번 결정이 이전 자동 스테이지 전환 방침을 대체한다. 웨이브 사이에는 자동 강화를 유지하지만 스테이지 완료 뒤에는 결과 화면을 유지하고 플레이어가 다음 작전을 선택한다.

| 피드백 | 구현 | 조작 |
|---|---|---|
| 무기 다양성 부족 | 펄스 속사·3방향 확산·고속 정밀 패턴, 기존 6종 장비 중 해금된 보조 장비 교체 | 선택된 펄스 버튼을 다시 누르면 패턴 변경. 선택된 보조 버튼을 다시 누르면 현장 조건을 만족하는 해금 장비 순환 |
| 스테이지 자동 전환 불만 | 완료 결과에서 대기, 다음 작전 버튼으로 진행 | 다음 진행 또는 작전 선택 |
| 현장별 보스 부족 | 각 5번째 웨이브에 현장 장비 보스 | 펄스로 방호 노드 해제 후 본체 해소 |
| 조작 중 자동발사 중단·뒤로 발사 | 새 작전은 이동·직접 조준·트윈 조작 중에도 자동발사 유지. 몸과 도구는 발사 방향을 향하며, 이펙트는 발사 시점 방향 보존 | AUTO 버튼은 명시적인 켜기·끄기. 장비 수동 선택은 자동 장비 선택을 해제 |

## 현장 보스

| 현장 | 보스 | 내구도 | 약점 노출 시간 |
|---|---|---:|---:|
| CH-01 | 반입 혼선 제어기 | 3 | 6초 |
| CH-02 | 컨베이어 과부하 | 4 | 7초 |
| CH-03 | 집진 압력 코어 | 5 | 8초 |
| CH-04 | 장력 불균형 릴레이 | 6 | 9초 |
| CH-05 | 복합 전력 제어기 | 7 | 10초 |

노드 3개를 해제해야 본체를 공격할 수 있다. 마지막 두 현장은 노드 순서를 지켜야 한다. 노출 시간이 지나면 방호를 다시 해제해야 한다. 위험 신호·발생원·보스가 모두 해소되어야 작전이 완료된다. 기존 장비 아트를 재사용하며 새 보스 전용 외형을 제작한 것으로 계산하지 않는다. 사람을 공격 대상으로 삼지 않는다. PSI의 정의와 발생원 관찰·차단 흐름은 유지한다.

## 확인 범위

규칙·회귀 95개 통과. 보스 해소 전 완료 차단, 각 현장 보스, 실제 사격 패턴·투사체 한도, 경계 저장 복원, 잘못된 패턴 거부, 발사 방향 이벤트 보존을 확인했다.

일반 입력 시뮬레이션은 5현장 × 3시드 × 3사격 방식 총 45회 모두 보스를 해소하고 완료했다. 최대 투사체 32개. 강제 웨이브 완료·보스 해소·생명 채우기는 사용하지 않았다. 실행 방법과 결과는 public/signal-breaker-dev/scripts/simulate-operations.cjs 및 docs/operation-simulation-20261011.json에 있다. 자동 조준으로 모두 성공했다는 사실은 인간 난이도·재미·중독성의 입증이 아니다.

실제 Chromium 검증은 네 화면에서 장비 버튼, 이동 중 자동발사, 직접 조준 연사, 반대 방향 이동 중 몸과 총구 방향, 보스 표시, 완료 뒤 직접 선택, 기존 발생원·체크포인트 흐름을 검사한다. 결과 화면 검증의 전투 완료는 명시적인 상태 시나리오이고 위 45회 일반 입력 시뮬레이션과 구별한다. GitHub PR #167의 최종 검증 커밋과 CI 결과를 배포 기준으로 사용한다.

다음 사람 플레이에서는 무기 교체 발견성, 패턴별 손맛, 보스 난이도와 반복감을 판단한다. 개별 보스의 신규 아트·공격 애니메이션은 이번 제작 범위에 포함하지 않았다.
