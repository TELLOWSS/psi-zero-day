## 1. 품질 목표 — ACTION FIRST / WORLD FIRST / PSI IDENTITY
브레이커는 위험이 산업 장치에서 발생하는 현장 물리 아케이드다. 사람을 공격하는 무기로 바꾸지 않는다. `PSI = Proactive Safety Intelligence — 사고 전 신호를 모아 다음 위험을 먼저 읽는 안전지능`을 조작·발생원 관찰·예방 연계로 체감하게 만든다.

**핵심 플레이 사이클**: 작전 미리보기 → 장비 선택 → 연속 웨이브·아이템 회수 → 현장 전용 보스 → 최종 격파의 여운 → 결과와 해금/획득 확인 → 직접 다음 작전/재도전/다른 현장 선택. 결과 화면 대기는 무기한이며 버튼 입력 없이 다른 지역으로 넘어가지 않는다.

## 2. 무기 다양화 — 이슈 #168 (P1)
### 체계
현재 **6종 기능 장비**: 펄스(`pulse`), 포획망(`net`), 자력(`magnet`), 미스트(`mist`), 앵커(`anchor`), 스캔(`scan`). 펄스 rapid/spread/precision은 무기 3개의 고유 최종 아트와 동의어가 아니다.

최종 목표는 **8개 구별되는 주 화력 계열 + 기존 6종 지원 역할**로 하되 1차 배포는 신규 주력 2종부터. 검토 후보:
| 신규 계열 후보 | 차이 | 반대급부 | PSI/현장 연결 |
| --- | --- | --- | --- |
| 반사 집중탄 | 방호판을 거칠 때 경로 유지/콤보 상승 | 직격 근접 성능 낮음 | 방호판 각도 학습 |
| 공압 산탄 | 짧은 거리 넓은 각도 다중 분리 | 원거리 부정확 | 혼잡 반입구 해소 |
| 관통 파동 | 일렬 신호 관통·연결 | 발사 전 짧은 예열 | 통로 선형 위험 |
| 포물 안정탄 | 높은 장애물 위로 아크 발사 | 사거리/낙하지점 판단 필요 | 집진 게이트 우회 |
| 공명 충격파 | 근거리 밀집 위험의 확산 해소 | 긴 쿨다운·범위 한계 | 연쇄 전파 예측 |

각 계열에는 **시각 실루엣 + 사격 리듬 + 이동·명중·소멸 연출 + 명확한 약점 + 해금 동기**를 요구한다. 단순 DPS 스킨·색상 변경 금지. 기존 P/C/W 드롭과 시그널워치 연계, 고정 투사체 최대 32개, 세이브 호환을 보존한다. 신규 모든 계열은 특정 전투만의 필수 유료 키가 되어서는 안 된다. 프리미엄 가치에는 시각·청각 연출과 수집을 고려하되 밸런스 파괴는 금지한다.

### UI 요구
작전 앞 로드아웃: `주력 슬롯 / 보조 슬롯 / 장점 / 약점 / 획득 조건 / 짧은 실제 샷 미리보기`. HUD에서 현재 장비 아이콘/발사 모드/쿨다운, 스마트 무기 선택 여부를 식별할 수 있어야 한다. 무기 버튼을 눌러 수동 선택해도 AUTO 사격 ON 상태를 유지한다.

## 3. 명시적 스테이지 진행 — 이슈 #169 (P0)
**단계 전이**: `PLAYING → BOSS_FINISH → CELEBRATE → RESULTS → OPERATION_SELECT → LOADOUT → READY → PLAYING`; 실패는 `LOST → RETRY / OPERATION_SELECT`.

- CH-01~05의 작전 맵·고유 이미지·잠금 및 도전 가능 여부·보스 실루엣·작전 목표를 제공.
- 스테이지 안은 끊김 없는 웨이브와 아이템 획득. 자동 중간 팝업 억제. **스테이지 완수만은 반드시 멈춘다.**
- 결과 화면: 마지막 타격 FX를 보존하는 짧은 종결 시간(실험 시작값 0.5~0.8초), 기록/보상/신규 장비 해금, 바로 재도전·다음 해금 작전·원하는 이전 작전·메인 복귀.
- 클리어 보상 중복 지급/언락 우회 금지. 저장이 오래돼도 복구되어야 함. LAB, 훈련, legacy continuous 흐름은 따로 회귀.
- 권장 **스테이지별 목표 3~5분**은 기존 `docs/SIGNAL-BREAKER-PACING-DEEP-AUDIT-20261011.md`의 비교 실험 시작치이지 실제 최적 게임 길이를 보증하지 않는다. 강제 타이머로 시간을 늘리지 않는다.

## 4. 보스 독립 제작 — 이슈 #170 (P0)
현재 `operationBoss()`는 다섯 보스가 공통 노드 3개/본체 HP 3~7/노출 6~10초의 공통 틀이고, `drawBoss()`는 공용 장비 아트를 사용한다. **5개 독립 보스 프로필·아트·동작·공략**이 목표다.

| 현장 | 보스 | 공격/기믹 특징 | 공략 차이 |
| --- | --- | --- | --- |
| CH-01 첫 반사 | 반입 혼선 제어기 | 방호판으로 반사되는 경로 노출 | 입문용 노드→본체 |
| CH-02 이동 반입 | 컨베이어 과부하 | 이동식 차폐/벨트 방향 교란 | 위치·타이밍 |
| CH-03 집진 통로 | 집진 압력 코어 | 분진 시야, 게이트 개방 | 미스트 안정화와 통로 읽기 |
| CH-04 장력 릴레이 | 장력 불균형 릴레이 | 장력 회전, 경고 후 노드 순서 | 앵커·순서 타격 |
| CH-05 전력 제어 | 복합 전력 제어기 | 전력 실드/스캔·다중 약점 연계 | 종합 퍼즐·최종 결산 |

전부 **전용 실루엣, 수리/경보 등 현장 장치의 인과관계, 텔레그래프, 약점 오픈, 강화 패턴, 파괴 FX, 독립 SFX** 필요. 모든 보스는 준비된 기본 무료 장비로 클리어 가능해야 하며 투사체·노드·발생원·위험 신호의 완료 조건을 우회하면 안 된다. 최종 영상·고유 보스 아트가 준비되기 전에는 PRODUCTION LOCK으로 보고하지 않는다.

## 5. 사격/방향 최종 고정 — 이슈 #171 (P0)
### 상태의 주인 분리
`autoFireEnabled`는 사용자가 명시적 AUTO ON/OFF를 할 때만 바뀐다. `movementAxis`, `aimDirection`, `manualAimActive`, `smartWeaponEnabled`, `selectedWeapon`과 독립이다. 모바일 화면에 **AUTO ON**이 선명해야 한다.

- 왼손 이동 + 오른손 조준과 `AUTO ON`: 무기 쿨다운마다 계속 발사.
- 무기 교체: 자동 무기 선택 기능은 변해도 자동사격은 유지.
- 이동 반전 중: 캐릭터 몸통/총구는 실제 사격 방향을 유지하고 다리만 스트레이프; 등에서 투사체가 생성되면 실패.
- `launchGeometry()`로 각 발의 `muzzle`과 `direction` 결정. 발사 스파크·탄도·반동·사운드·탄피는 같은 world-space 기준. 이미 발사된 탄은 몸 회전 때문에 방향을 바꾸지 않음.
- 직접 조준 중 assist는 입력을 덮어쓰지 않으며 직접 조준 종료 후 즉시 좌우 플립 떨림이 일어나지 않도록 안정화/히스테리시스 비교 실험.
- 터치 취소/다중 포인터/화면 회전/blur/일시정지/체크포인트 복원 테스트. 의도하지 않은 발사나 AUTO OFF 없음.

### 합격 기준
- AUTO ON 상태에서 이동·직접 조준·무기 교체·이동 반전 입력 시 발사 이벤트가 사라지지 않음(쿨다운 및 32발 예산 제외).
- 발사 방향 vs 속도 정규벡터 내적 **≥0.99**, 총구 스파크 vs 실제 발사점 오차 **≤10 world px**(규칙 검증 기준으로 제안; 구현에서 근거 있는 좌표 변환을 명시), 뒤로 출발하는 탄 0건.
- 상태가 일시정지·결과·로비라면 발사하지 않음. 앱 복귀 시 AUTO 설정은 복구, 터치 포인터는 새로 시작.

### 검증 매트릭스
1. 자동 시뮬레이션 5 CH × 3 seed × 3 pattern = 45 (변경 전 완료/투사체 상한과 비교; 강제 성공 fixture를 일반 입력 시뮬레이션으로 사칭하지 않음).

4. 실제 Android 폰/태블릿 최소 2 성능급 테스트: AUTO 유지, 2손 입력, 초당 fps/프레임 분포, 10분 이상 혼잡 장면, 발열, 옵션 high/balanced/low.
5. 사용자 플레이: 첫 30초 무기 이해 여부, CH별 보스 인지, 보스 성공/실패 원인, 결과에서 자기 선택권 체감, 15/30분 반복/피로를 자료로 남김. 봇 승률이나 CI 성공은 '재미가 검증됐다'는 근거가 아님.

## 7. 동결/비목표
- PSI 위험 인지·관찰·차단·보고 세계관, 근로자를 대상으로 공격하지 않는 규칙 유지.
- 타 게임의 캐릭터, UI, 소리, 스프라이트/로고를 그대로 복제하지 않음; 영감의 **기계적 원리**만 재해석. 상업적 사용 시 아트·음악·상표 권리별 별도 확인.
- Vercel 무료 빌드 반복 소모 금지. GitHub 테스트 → 변경 확정 시 한 차례 프리뷰 → 실기기 검증.
- 이 문서는 **구현 지시/요청**이며 오늘 이 문서를 생성했다는 사실로 게임이 개선 완료됐다고 표시하지 않는다.
