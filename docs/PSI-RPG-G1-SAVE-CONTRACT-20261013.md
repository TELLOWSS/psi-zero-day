# PSI RPG G1 성장 저장 계약

G1에서 순수 TypeScript 프로필과 정산 reducer를 추가한다. 브라우저·UI·저장소·시계에 의존하지 않는다. 구 저장의 크레딧, 장비, 엔딩, 설정, 체크포인트, 알 수 없는 필드를 보존하며 과거 기록에 경험치나 연구 증거를 소급 생성하지 않는다.

프로필은 스키마 버전, revision, 누적 경험, 정산 완료 run ID, 에피소드별 최초 완료, 확인 증거와 연구 목표 ID를 가진다. 중복 정산은 0 XP, 오래된 revision은 충돌로 반환한다. 손상된 프로필이나 미지원 스키마를 빈 프로필로 덮어쓰지 않는다. 출발 시 복사한 스냅샷은 이후 정산의 영향을 받지 않는다.

기획서의 초보 반복 필드 경험 상한 30은 반복 작전 1회의 필드 경험으로 적용한다. 확인·최초 완료·연구 보상과 별도로 계산한다. 레벨 1~20, 다음 레벨 120+20×(현재 레벨−1), 짝수 레벨의 총 10포인트를 계산한다.

이 단계는 저장 계약이다. 게임 정산 연결, localStorage 단일 블롭의 원자적 갱신·실패 롤백, 탭 간 실제 저장 충돌 처리, 전문 능력 9노드의 UI와 엔진 효과는 G2에서 구현한다. reducer의 revision 검사는 저장소 잠금을 대신하지 않는다. 영구 무기 연구와 Signal Watch 기록 어댑터도 아직 연결하지 않는다. receipt는 실제 엔진 확인 기록을 검증한 어댑터에서만 발행해야 한다.
