# 시그널 워치 전경 분리와 가림 고도화 · 2026-10-19

후속 상태: 사용자가 신규 전경의 실제 게임 적용을 승인했다. STAGE 02 승인 목록 등록과 적용 결과는 [게임 연결 보고서](SIGNAL-WATCH-FOREGROUND-ACTIVATION-20261019.md)에 기록한다. 아래 승인 대기 설명은 제작·검수 시점의 기록이다.

## 작업 범위

사용자가 STAGE 02 원화와 실제 투광등 조명 개선을 확인한 뒤 후속 고도화를 요청했다. 같은 작업 폴더 `psi-watch-graphics-20261019`, 브랜치 `work/watch-graphics-resume-20261019`에서 이어 작업했다. 스토리·GUARD 기능은 추가하지 않았다.

STAGE 02 원화의 하단 흙막이 구조물에 대해 투명 전경 후보 1개를 제작했다. 신규 마스크를 승인된 최종 자산으로 기록하지 않았다. 기존 원화 확인과 새 추출물의 정합 검토를 구별하며, 전경 자산 계약에 따른 후보 확인을 요청했다. 현재 후보는 개발용 검수 화면에 연결되어 있다.

## 구현

- `survivors-matte-texture.ts`: 추출물의 RGB는 버리고 알파만 사용한다. 실제 스테이지 원화의 같은 월드 좌표를 가져와 전경을 구성한다. 게임 화면과 동일한 색보정·깊이·현장 조명도 전경에 적용한다. 품질, 조명 상태, 실제 등과 확보 구역이 바뀔 때만 다시 굽고 프레임마다 픽셀을 읽지 않는다.
- `PatrolSurvivorsGame.tsx`: 승인된 전경에 대해 원화와 알파를 함께 비동기 로드하고, 품질·조명 상태별 텍스처를 재사용한다. 스테이지를 바꾸면 이전 참조를 해제한다. 승인 없는 후보를 몰래 등록하거나 정상 게임의 해금·저장을 바꾸지 않는다.
- `survivors-stage-mattes.ts`: 발의 한 점 대신 74월드 단위 인물의 몸 범위를 살피고, 측면 접근 16월드 단위 안에서 불투명도를 부드럽게 줄인다. 완전히 겹치면 55%, 위험 경고가 겹치면 25%까지 낮춘다. 인물 뒤에 정렬되는 전경은 불필요하게 옅어지지 않는다.
- `tests/visual/watch-foreground-review.html`: 같은 원화와 자세에서 평면 배경/전경 가림을 비교한다. 위치·깊이, 걷기, 접점 확대, 인물 보호, 검수용 경고, 품질을 조작할 수 있다. 인물과 경고 배치는 검수 fixture이며 실제 전투 결과를 뜻하지 않는다.

엔진의 충돌, 이동, 대미지, 위험 발생, 보상과 성장 계산은 변경하지 않았다.

## 제작·정합

빌트인 `image_gen`으로 배경 추출을 1회 수행했다. 원본 RGBA는 `docs/art-source/watch-foreground-20261019/stage-02-shoring-source.png`에 보존한다. 드문 1~3/255 알파 점 때문에 전체 이미지가 전경 경계로 잡히는 것을 피하도록, 알파 4/255 이상이 있는 영역의 경계로 크롭했다. 유지 영역의 알파는 변경하지 않았다.

배포용 알파 PNG는 `public/assets/survivors/foreground/stage-02-shoring-alpha-v1.png`, 크기는 1536×159다. 원본의 y=865부터 하단을 사용하며 월드 경계는 x=0, y=760.25390625, width=1400, height=139.74609375, feetY=900이다. 전체 프롬프트·후보 좌표·SHA-256은 같은 제작 기록 폴더에 보관했다.

원화 재사용을 확인하기 위해 브라우저에서 불투명도 240/255 이상인 12,205개 표본을 비교했다. 원본 RGB와 재구성 전경의 채널 최대 차이는 1/255로, 캔버스 알파 반올림 범위였다. 이 검사는 색 일치를 확인하며 알파 윤곽에 대한 사람의 최종 아트 검수를 대신하지 않는다.
