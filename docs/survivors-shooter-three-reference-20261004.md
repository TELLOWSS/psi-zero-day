# 최신 슈팅 흥행작 세 방향을 현장 플레이로 재해석

2026-10-04 확인. 선정 기준은 현재 Steam 플레이 규모, 최근 주목도와 PSI에 이식할 수 있는 서로 다른 재미다. 플랫폼을 합친 절대 판매/동접 순위 1~3위 목록은 아니다. 이번 확인 SteamDB 스냅샷에서 CS2는 전체 동접 1위(517,751), Helldivers 2는 29위(47,310), ARC Raiders는 43위(32,330)였다. ARC 공식 홈페이지는 10월 8일 업데이트와 10월 2일 체험 안내를 게시하고 있었다. 실시간 숫자는 변동한다.

| 참고작 | 공식 확인한 구조 | 우리의 재해석 | 구현 범위 |
|---|---|---|---|
| Counter-Strike 2 | 목표 중심 전투와 전술 유틸리티(동적 연막) | 현장 통제선의 위치·타이밍을 고르는 전술 | E/화면 버튼으로 현재 위치에 10초·반경 110 통제선, 작전당 2회·8초 재사용 대기. 운반차·가스 접근 속도만 0.65배로 늦춤. 중첩 배율 없음. 경고 시간을 변경하지 않음 |
| ARC Raiders | 수집/진행을 이어갈지 귀환할지 판단하는 extraction 긴장 | 핵심 조건 달성 후 직접 인계할지 별 목표를 이어갈지 선택 | 기존 90/105/120초 조건 달성 시 X/버튼 인계 요청. 요청 위치에서 반경 72 이내 4초 확인. 이동·피해로 취소 가능. 자동 조기 승리 제거, 180초 정규 완료 유지 |
| Helldivers 2 | 언제 어디서 지원을 호출할지 판단, 협력 임무 | 지연 도착 보급과 현장 지점 선택 | Q/버튼 호출 시 1.2초 후 호출 지점에 회복/무전 보급 도착. 작전당 2회·30초 대기. 직접 픽업하여 기존 효과 적용 |

위 대응은 게임의 실제 메커니즘에 대한 개발자의 설계적 추론/재해석이다. 원작의 이미지·음악·캐릭터·IP를 복사하지 않는다. CS2 연막 시뮬레이션, ARC의 전리품 전액 유실/PvP, Helldivers의 온라인 4인/아군 피해를 구현한 것은 아니다. 오프라인 단일 플레이 현장 통제·지연 보급·인계 판단으로 구현한다. 지원에 실물 NPC가 이동하거나 멀티플레이어가 참여하는 기능은 없다.

근로자는 적이나 통제선 감속 대상이 아니다. 크레인 보스·낙하물은 통제선으로 감속하지 않는다. 운반차가 보스인 경우에도 해당 종류의 접근/돌진 이동 속도는 감속할 수 있다. 통제선은 무적 지대 또는 물리적 충돌 장벽이 아니며 접촉 피해를 없애지 않는다. 기존 실제 원인의 HP 감소가 인계를 취소하며, 보급·통제선은 대응 횟수/경험치/인계 구역을 즉시 공짜로 늘리지 않는다. 기존 장비·스토리·저장·해금·규칙과 동일 엔진 경로를 유지한다.

## 검증 범위

엔진 준비 fixture로 유한 횟수·재사용 대기·잠긴 호출 좌표·늦은 도착·모션 정지·감속 대상/중첩 제한·목표 달성 후 자동 승리 방지·인계 이동/피해 취소·승리 보상 1회 지급을 검증한다. 브라우저에서는 실제 게임 시작 후 Q/E와 모바일 버튼으로 사용 횟수·통제선 및 호출 표시·HUD·정지/재개·콘솔 오류를 확인한다. 준비 fixture는 사람의 실제 몰입·승률 검증이 아니다. 원작의 흥행 수준이 PSI에 그대로 재현됨을 보장하지 않는다.

최종 검증: 209개 파일 / 1,123개 테스트, typecheck/build 통과. 390×844·844×390·1440×900에서 키보드/버튼 6건 모두 통과. 지원/통제선 실제 사용 후 재사용 대기, 모바일 영역, 초반 인계 버튼 비노출, 정지/재개 및 안내 확인. 브라우저 production 엔진 준비 fixture에서 목표 후 선택 대기→요청→4초 확인→승리 통과. 렌더 오류 0건. 터치 중첩 문제를 검증에서 발견하고 궁극기 래퍼 크기/포인터 영역을 수정했다.
