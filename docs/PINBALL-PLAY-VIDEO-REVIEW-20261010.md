# 실제 모바일 핀볼 영상 검토와 개선

## 검토한 자료

사용자가 제공한 `KakaoTalk_20261010_062119249.mp4`(55.05초, 1080×2340, 30fps)를 3초 간격 전체 프레임과 16–40초 구간의 0.5초 간격 확대 프레임으로 확인했다. 녹화는 이미 두 번째 공이 진행 중인 상태로 시작한다. 첫 공 전체, 실제 손가락 접촉, 이어폰의 주관적 청취 품질은 이 영상만으로 확인할 수 없다.

## 발견과 원인

- 두 번째 공 후반과 세 번째 공에서 하단 왕복이 길고, 세 번째 공은 약 18초 이후 점수/확보 보상이 오랫동안 늘지 않는다. 구슬이 계속 움직이는 것과 의미 있는 타격이 발생하는 것은 다르다.
- 하단 레일의 기존 `(90,640)→(246,826)` 및 대칭 선분은 패들 축 근처를 지난다. 축과 레일 사이가 좁아 구슬이 하단에서 반복 반동을 만들기 쉽다.
- 기존 보조는 `y>580 && vy>0`이면 미리 패들을 올린다. 실제 접촉 순간에는 이미 회전이 끝난 경우가 있어, 정적인 받침처럼 작동한다. 영상의 보조 작동이 많아도 상단으로 복귀하지 못하는 현상과 부합한다.
- 음악 설정을 펼칠 때 테이블 상단과 제목/점수가 스크롤 밖으로 이동한다. 중앙 상태 팝업은 테이블을 가린다.
- 배경에 고정 패들이 있다는 초기 추정은 원화와 전용 패들 이미지를 대조한 뒤 철회했다. 배경에는 패들이 없으며 신규 배경 제작으로 해결할 문제가 아니다.

## 실제 수정

하단 레일을 패들 축 아래의 두 선분으로 바꾸어 회수 깔때기를 유지하면서 축 주변의 간섭을 없앴다. 보조는 구슬의 하강 속도와 예상 도착 위치를 보고 접촉 직전 짧게 눌렀다가 복귀한다. 수동 조작은 동일한 회전 접촉 물리를 사용하며 보조 전용 순간이동/공 발사/점수 가산은 넣지 않았다. 삼세번, 기본 100 PSI와 최대 400 PSI 보상은 유지한다.

모바일 창은 viewport에 고정하고, 제목/점수와 테이블/패들, 조작 콘솔의 높이를 나눴다. 설정은 콘솔 내부를 교체해 테이블 좌표와 크기를 유지한다. 설정을 열면 게임과 오디오를 정지하며, 닫은 뒤 플레이어가 명시적으로 재개한다. 설정 중 P/방향키로 배경 조작이 일어나지 않는다. 설정의 select도 포커스 순환에 포함하고 열기/닫기 시 포커스를 이동한다. 조작 안내를 펼칠 때도 일시정지한다.

상태 안내는 중앙 팝업에서 테이블 위쪽의 작은 strip으로 바꿨다. 구슬에는 짧은 속도 잔상과 가는 밝은 외곽을 넣어 작은 화면에서 추적하기 쉽게 했다. 움직임 줄이기/부드러운 그래픽 모드는 잔상을 생략하며 물리는 같다. 기존 원화와 전용 음원은 유지한다.

## 검증과 한계

동일한 자연 시뮬레이션 조건(직접 공 배치 없음, 수동 조작 없음, 보조만 사용)에서 배포 당시 엔진과 수정 엔진을 비교했다. 30/60/120fps 모두 같은 타격 수와 점수를 얻었다.

| 지표 | 기존 | 수정 |
| --- | ---: | ---: |
| 하단 y>640 연속 체류 최대 | 약 23.3초 | 약 0.9초 |
| 세 공 합계 타격 | 8 | 29 |
| 세 공 합계 점수 | 1,025 | 7,725 |
| 확보 PSI | 150 | 400 |
| 실제 공 진행 시간 합계 | 약 90초 | 약 25.4초 |

수정은 공을 무조건 살려 주는 기능이 아니다. 공이 회수구로 빠지면 기회를 쓰므로 한 판 길이가 짧아질 수 있다. 위 숫자는 정해진 시작 조건의 엔진 검증 결과이며 모든 플레이어의 점수나 체류 시간 보장이 아니다. 실제 모바일 손맛은 추가 실기기 플레이로 판단한다.

회귀 테스트는 접촉 전 보조 타이밍, 하단 긴 반복 방지, 프레임 속도 일관성을 포함한다. 브라우저 검증은 1440×900, 390×844, 844×390, 360×640, 412×740에서 PC/두 손가락 입력, 테이블 종횡비, 설정 전후 위치 일치, 설정 자동 정지/단축키 차단, 음소거, 화면 경계와 조작부 겹침, 세 공과 보상 저장을 확인한다. 보상 상한 검사는 별도 QA 공 배치와 시간 단축을 사용하며 자연 플레이와 구분한다.

검토 영상 프레임과 수치, 화면별 스크린샷은 로컬 `artifacts/pinball-video-review/` 및 `artifacts/pinball/`에 저장한다. 사용자 원본 영상은 저장소에 올리지 않는다.
