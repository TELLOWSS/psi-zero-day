# NEW PSI — 위험 해방·연쇄 사격 개선 기획 및 검증

## 1. 목표와 판단

좋다고 평가한 발사와 폭발의 손맛을 유지하면서, 버블이 사라지는 순간 내부 위험도 함께 없어지는 단절을 해소한다. 새 흐름은 **외피 분할 → 외피 파괴 → 위험별 짧은 예고 → 현장 위험의 움직임 → 자동 사격으로 해소 → 아이템 회수 → 화력·장비 조합 성장 → 포인트로 순간 강화**다. 모든 위험은 작전 안에서 유한하게 계획된다. 화력이 성장해도 위험의 원인 통제와 장비 노드 판단은 생략되지 않는다.

PSI의 저장소 공식 정의는 **Proactive Safety Intelligence — 사고 전 신호를 모아 다음 위험을 먼저 읽는 안전지능**이다. NEW는 상위 브랜드이며 별도의 영문 약어 뜻을 만들지 않는다. 사람을 몬스터로 표현하지 않고 철재·분진·전류·하중의 산업 물체를 위험의 대상으로 쓴다. CH-01의 관찰·현장 인력 통제·잔류 위험 검증, CH-05의 노드와 장비 순서는 유지한다. 승인된 기존 Signal Breaker 5개 챕터의 개선이며 본편 신규 캠페인 확장이 아니다.

## 2. 벤치마킹 확인과 독자 설계

공식 개발사 상품 설명을 확인했다. 1945 계열의 주 사격 성장과 보조 공격의 순간 화력이라는 추상적인 리듬을 참고한다. 특정 버전의 기체·무기 모양·명칭·화면 배치·음악·수치·과금 구조는 가져오지 않는다. 사용자가 말한 1945의 버전이 특정되지 않았으므로 본 게임의 40P 소비 시스템을 그 게임의 동일한 포인트 시스템으로 설명하지 않는다. 이는 NEW PSI의 독자적인 작전 자원 설계다.

- Strikers 1945 공식 개발사 상품 페이지: https://store.steampowered.com/app/4123570/Strikers_1945/
- Strikers 1945 II 공식 개발사 상품 페이지: https://store.steampowered.com/app/4123580/Strikers_1945_II/
- 확인일: 2026-10-11. 공식 설명의 파워업과 보조 공격 원리를 검토했다.

시그널워치의 조합 아이디어는 이 모드의 장비 페어로 변환한다. 다른 게임의 저장 데이터나 장비를 읽어 오는 연동은 구현하지 않았다. NEW PSI의 현장 위험·통제·회수라는 표현을 중심으로 독자적인 조합을 만든다.

모션 감소 설정에서는 추가 회전·팽창을 줄인다. 규칙상의 이동은 그대로 유지해 위험 판단을 가능하게 한다. 분진/전류의 숫자는 아케이드 이동 파라미터이며 물리적 안전 기준이 아니다.

| LV.2 이후 장비 페어 | 실제 보조 효과 |
|---|---|
| 펄스 + 회수망 | 펄스 4회 발사마다 지원 회수망 1발 |
| 펄스 + 분진억제 | 펄스 6회 발사마다 조준 지점 분진억제 필드 |
| 펄스 + 자력유도 | 펄스 6회 발사마다 조준 지점 자력유도 필드 |

새 챕터 작전에서만 새 규칙을 적용한다. 짧은 모드·실험실은 기존 규칙을 유지한다. 기존 체크포인트에 새 규칙 플래그가 없으면 기존 규칙으로 복원한다. 신규 체크포인트는 작전포인트·아이템·해방/해소량·발사 누적을 보존한다. 신규 최고점·최근 기록은 bestCascade/lastCascade에 따로 기록하여 기존 bestPremium 기록을 덮어쓰지 않는다. 공통 챕터 해금과 보상은 유지한다.

## 4. 고품질 그래픽 자산

`public/signal-breaker-dev/art/released-hazards-v1.webp`를 위험 해방 상태의 실제 게임 렌더링에 연결했다. 버블 없는 4종 산업 위험을 투명 배경 2×2 아틀라스로 제작했다. 원본 생성 PNG는 보존하고 WebP로 형식 변환했다. 기존 전경·배경·인물·장비 아틀라스를 유지해 현장의 시각적 맥락을 잇는다. 화력 단계가 발사 이벤트에도 반영되어 성장 시 기존 총구·반동 연출을 사용한다. 아이템은 기능을 읽을 수 있는 코드 기반 육각형 장비 칩이며 별도의 최종 캐릭터 자산으로 계산하지 않는다.

출처: 이 작업에서 이미지 생성 도구로 신규 제작. 외부 원작 그림을 참조 이미지로 넣지 않았다. 원본: `generated_images/exec-5d02010d-7d5b-4014-bbe9-1ea9f62478ea.png`, RGBA 1254×1254. 제작 지시의 핵심은 독자적인 고품질 2×2 산업 위험 스프라이트, 철재·분진·전류 코일·콘크리트 하중, 투명 배경, 동일 조명·원근, 원·버블·얼굴·문자 없음이었다. 생성 자산이 있다는 사실만으로 Phase D의 시각 품질 최종 승인을 선언하지 않는다.

상용 출시 전에 명칭·상표와 모든 기존 자산·음원·폰트의 사용권을 별도로 확인해야 한다. 이번 변경은 원작 고유 표현의 복제를 피하도록 설계했으며 법적 비침해나 상표 등록 가능성을 확정한 검토는 아니다. 이전 기획서의 권리 검토 항목을 유지한다.

## 5. 시뮬레이션 발견과 개선

동일 엔진, 5챕터 × 정지/이동 두 입력 정책 × 시드 1~8 = 80회. 각 180초 한도, 규칙 120Hz, 자동 조준 0.12초 간격, 첫 강화 선택, 통상 관찰·통제 명령. 포인트가 충분하고 위험 2개 이상이면 통상 순간 강화 명령을 사용했다. 강제 해소·생명 회복·완료 상태 주입은 사용하지 않았다.

|---|---:|---:|
| 전체 완료 / 시간 초과 | 66 / 14 | 74 / 6 |
| 이동 정책 완료 | 40 / 40 | 40 / 40 |
| CH-03 정지 정책 완료 | 0 / 8 | 8 / 8 |

| CH-05 이동 평균 완료 시간 | 45.89초 | 45.89초 |

첫 구현의 CH-03은 분진억제+회수망만 기본 장비여서 주 사격 성장의 효과를 못 받았다. 신규 규칙의 기본 장비를 펄스+분진억제로 바꾸었다. 기존 저장은 기존 장비와 규칙을 그대로 복원한다. 보정 후 최대 활성 위험은 12개, 투사체는 32발이다. CH-05 정지 정책의 6회 시간 초과는 장비 차단 경로를 이동으로 풀지 않는 조건이며, 이동 정책은 모두 완료했다. CH-03 정지 조건의 최장 해소 진행 간격 24.97초와 CH-04의 44.55초는 남아 있다. 이동·조준 없이 모든 조건이 자동으로 끝나는 것으로 설명하지 않는다.

자동 입력 결과는 실제 사람의 재미·몰입·중독성이나 기기 FPS 측정이 아니다. 이동 정책에서 생명 소모가 적은 점은 사람 플레이에서 난도·판단 부담을 추가로 검토할 항목이다. 단순히 적을 무한 생성하거나 피로를 늘려 몰입이 검증됐다고 주장하지 않는다.

재현 자료: `public/signal-breaker-dev/docs/burst-simulation-initial-20261011.json`, `burst-simulation-after-20261011.json`. 기존 80회 시뮬레이션은 종전 확정 JSON과 정확히 같았다. 새 규칙과 회귀 테스트 79개가 로컬에서 통과했다.

## 7. 실제 화면에서 발견한 표시 문제의 수정

첫 CI는 4개 화면의 기능 검증을 통과했다. 내려받은 캡처를 직접 확인했을 때 휴대폰의 강화 알림과 버튼이 같은 높이에 겹쳤다. 강화 버튼의 시작 높이를 112px에서 162px로 변경하고, 실제 알림·버튼 영역의 비겹침 검사를 추가했다. 위험 아틀라스 fixture는 스테이지 변경 전 카메라를 사용하던 문제를 고쳐 새 카메라가 갱신된 뒤 배치한다. 4종의 전체 그림 영역이 실제 화면 안에 존재하는지 검사하고, 초기 폭발 연출이 지나간 뒤 캡처하도록 바꾸었다. 이 발견은 기능 통과만으로 화면 품질을 승인할 수 없다는 사례이며, 수정 커밋의 전체 CI와 캡처를 다시 확인한다.
