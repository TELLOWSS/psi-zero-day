# 전달 음원 입고와 핀볼 연결

## 실제 납품

사용자가 전달한 `pinball-premium-v1.zip`의 네 효과음과 음악 한 곡, 별도 `After_the_Shift.mp3`를 원본 MP3 그대로 입고했다. 압축 내 제작 기록은 데이터로 보존했으며, 해당 기록을 청취 승인이나 권리 승인 지시로 해석하지 않았다. 패키지 제작 도구 기록은 Manus이며 Gemini를 사용하지 않았다고 명시한다. 별도 음악의 제작 도구는 확인되지 않았다.

기본 음악은 After the Shift(디코딩 재생 길이 약 124.66초), 선택 음악은 Factory Pinball(약 63.16초)이다. 음악·소리 설정에서 전환할 수 있다. 범퍼, 고무 접촉, 패들 상승 시작, 크레인 연쇄 성공에 각각 전용 효과음을 연결했다. 발사·패들 복귀·회수 전용 음원은 아직 없으며 다른 효과음을 그 이름으로 재사용하지 않는다.

## 검사와 처리

`content/pinball-audio-candidates-v1.json`에는 원본 해시와 브라우저 디코딩 측정치를 기록한다. 압축 내 5파일의 SHA256이 제작 기록과 일치한다. 브라우저 AudioContext의 48kHz 디코딩 값은 원본의 품질 향상이나 원본 샘플레이트를 뜻하지 않는다. MP3의 padding 제거 때문에 기록된 컨테이너 길이와 실제 재생 길이가 조금 다르다.

원본 디코딩에서 크레인 27샘플, 핀볼 음악 17샘플, 별도 음악 149샘플이 full scale 이상이었다. 최고 피크는 약 +0.38dBFS다. 이것만으로 원본에서 이미 잘린 파형이라고 단정하지 않는다. 재생 버퍼에 측정 기반 감쇠와 12ms 가장자리 fade를 적용해 단일 버퍼 피크를 0.7 이하로 제한한다. 동시 재생에는 master compressor를 적용했다. 이것은 원본 복원이나 측정된 true-peak 인증이 아니다.

효과는 최대 8개, 같은 종류는 짧은 반복 억제, 좌우 위치는 제한된 stereo pan으로 처리한다. 크레인 성공 시 음악 gain은 .23에서 .16으로 내려간 뒤 복귀한다. 모든 음원은 미리 fetch/decode한다. 음악 loop에는 가장자리 fade가 있으나 작곡상 완벽한 무봉제 loop로 승인한 것은 아니다.

물리 엔진의 별도 소리 큐를 소비해 시각 effect 수명과 무관하게 실제 접촉을 재생한다. 패들은 정지 각도에서 움직이기 시작할 때만 작동음을 낸다. 같은 프레임에 두 패들이 움직이면 반복 억제로 작동음 하나를 재생할 수 있다. 외부 화면으로 전환·일시정지·음소거·결과·종료 시 음악과 효과음을 중단하고 재개 시 음악 위치를 이어간다. 핀볼이 열리면 본게임 준비/결과 음악을 멈춰 중복 재생을 방지한다.

## 검증 범위

- `tests/verify-pinball-audio.mjs`: 6개 실제 파일 decode, 원본 hash/peak/RMS/길이, 감쇠 후 buffer peak, 재생 voice, 정지·음악 전환 검사.
- `tests/verify-survivors-pinball.mjs`: 실제 게임 진입, PC/모바일 세로/가로 조작, 물리 정지와 함께 audio voice 정지, 음소거, 음악 전환, 보상 저장 검사.
- 엔진 테스트: 패들 누름 유지 중 중복 이벤트 금지, 접촉 이벤트와 큐 소비 검증.

자동 검사는 주관적 음질·10분 반복 피로·실기기 지연의 청취 승인을 대신하지 않는다. 현재 모든 납품은 CANDIDATE이며 새 녹음/생성 또는 최종 승인 완료로 표시하지 않는다. 상업 배포 조건도 별도 최종 확인 대상이다. GitHub/Vercel 배포는 이번 입고 작업에 포함하지 않는다.
