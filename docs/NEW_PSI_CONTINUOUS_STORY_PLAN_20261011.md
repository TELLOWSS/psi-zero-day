# NEW PSI — 한 호흡 연속 플레이·구역별 이야기 개선

2026-10-11 · 사용자 피드백: 강화와 완료창으로 게임이 자주 끊긴다. 이야기를 살려 장시간 몰입과 스트레스 해소를 지향한다.

## 변경 방향

새 챕터 작전은 웨이브와 구역 사이에 강제 확인창을 띄우지 않는다. 웨이브의 강화를 유효한 후보 중 첫 항목으로 자동 적용하고 다음 웨이브를 같은 엔진 흐름에서 시작한다. 완료한 구역의 보상·기록을 저장한 뒤 다음 구역으로 자동 연결한다. 사격 설정과 누르고 있는 이동 입력을 유지한다. 사용자가 누르는 일시정지와 실패 후 재도전은 유지한다.

중간에 생각할 여유는 정지창 대신 위험 해소 뒤 다음 등장 간격과 짧은 무전으로 만든다. 이야기는 입력을 잠그거나 클릭을 요구하지 않는다. 현재 다섯 구역의 현장 기믹과 사운드·배경을 사용하며 새 대규모 캠페인으로 범위를 넓히지 않는다.

## 구역별 이야기

| 구역 | 사건과 궁금증 | 실제 플레이와 연결 |
|---|---|---|
| 첫 반사 | 같은 자리에서 반복되는 작은 제보 | 원인 관찰·현장 인력 통제·남은 위험 검증 |
| 이동 반입 | 바뀐 반입 길과 예전대로 걷는 사람 | 움직이는 완충 장치·벨트·금속 유도 |
| 집진 통로 | 기록과 다른 바람, 옆 구역에서 오는 분진 | 안정화·게이트 개방 타이밍 |
| 장력 릴레이 | 변경 전달 지연과 다른 구역의 동시 신호 | 앵커·장력 움직임·릴레이 순서 |
| 반입동선 혼선 | 서로 다른 신호가 한 장비에 모인다 | 사선 이동·노드 순서·약점 노출 |

세 개의 이야기 흐름은 **작은 제보 → 누락된 기록을 비교 → 팀이 먼저 확인하는 변화**로 이어진다. 5구역 × 5웨이브 × 3흐름 = 서로 다른 무전 75개를 제작했다. 원전의 강태식·임준호·윤성호를 사용하며 실제 근로자 발언의 인용이 아닌 창작이다. 장비의 노드가 열리기 전 열렸다고 말하는 식의 선행 완료 표현은 피했다.

무전은 최대 5.5초 노출되며 일시정지하면 시간을 함께 멈춘다. 세 이야기 순회를 마친 뒤에는 성숙한 팀의 흐름을 유지하고 첫·마지막 웨이브에만 무전을 보여 반복 피로를 줄인다. 1시간 분량의 새로운 고유 스토리 전체를 제작한 것은 아니다. 장시간 접속에서도 끊김 없이 이어지는 구조를 먼저 만들고 사람 플레이로 재미와 반복 피로를 확인한다.

PSI는 **Proactive Safety Intelligence — 사고 전 신호를 모아 다음 위험을 먼저 읽는 안전지능**이다. 사람을 적으로 만들지 않고 현장의 물체·분진·전류·하중과 정보 흐름을 읽는다. 무조건 위험을 없애는 영웅보다 서로 먼저 제보하고 확인하는 팀의 변화를 이야기의 결과로 삼는다.

## 연결·성장·저장 규칙

- 웨이브 경계에서 기존 강화 후보 중 하나를 자동 적용한다. 잘못된 장비 조합·중복 강화는 기존 후보 필터로 제외한다.
- 같은 순회의 다음 구역으로 이동할 때 아이템 성장 단계·작전포인트·플레이어 위치를 유지한다. 구역별 기본 장비는 해당 기믹에 맞게 바뀐다.
- 구역 완료 시 생명 1만 회복하고 최대 5를 유지한다. 무적·전체 위험 삭제는 추가하지 않는다.
- 5구역 순회를 마치면 새 시드로 다음 순회를 시작하고 장비 성장·포인트를 재구성한다. 끝없이 화력이 커지지 않으며 화면의 위험·투사체 한계를 유지한다. 별도 완료창은 없다.
- 연속 모드 최고점은 bestContinuous/lastContinuous로 분리한다. 기존 챕터 해금·첫 완료 보상과 기존 최고점을 보존한다.
- 자동 강화 직전의 웨이브 경계를 체크포인트로 보관한다. 재접속해서 이어하기를 누르면 같은 후보를 적용하고 다음 웨이브로 바로 복귀한다. 현재 웨이브 중간의 정확한 위치를 저장한 것은 아니다.
- 기존 저장에 continuous 플래그가 없으면 기존 강화 선택 방식으로 복원한다. 짧은 모드와 실험실은 기존 흐름을 유지한다.

## 시뮬레이션과 검증

로컬 규칙·회귀 테스트 83개 통과. 자동 강화·경계 저장과 복원·일시정지·잘못된 저장 거부·구역 간 성장/위치 유지·75개 무전 ID를 확인했다.

일반 입력으로 3개 시드 각각 3,600초를 시뮬레이션했다. 120Hz 규칙, 이동과 자동 조준·발사·관찰·통제·40P 강화 명령을 사용했다. 강제 위험 해소·상태 완료 주입·임의 생명 회복은 사용하지 않았다. 구역 완료 생명 1 회복은 구현된 정상 규칙이다.

| 초기 시드 | 시뮬레이션 시간 | 완료 구역 | 강제 중단 상태 | 위험 최대 | 투사체 최대 |
|---|---:|---:|---:|---:|---:|
| 1 | 3,600초 | 84 | 0 | 11 | 32 |
| 3 | 3,600초 | 88 | 0 | 12 | 32 |
| 8 | 3,600초 | 85 | 0 | 13 | 32 |

세 조건 모두 마지막 시점에도 플레이 중이었다. 이 결과는 한 시간의 엔진 연속성과 유한한 화면 밀도 검증이다. 사람이 한 시간 지루하지 않다거나 스트레스 해소 효과가 입증됐다는 뜻은 아니다. 기존 이동 봇의 생존이 쉬운 점도 사람 플레이에서 난도와 선택 부담을 확인해야 한다.

GitHub CI에 기존 각 80회 시뮬레이션과 신규 3시간 시뮬레이션의 결과 재현을 추가했다. 4개 화면에서는 기존 관찰·통제·장비 회귀에 더해 강화창 없는 웨이브 연결, 무전의 화면 내부 배치, 이어하기 후 즉시 복귀, 완료창 없는 다음 구역 연결, 누른 이동 입력 유지까지 확인한다. 화면 경계 검사는 명시적인 fixture이며 일반 입력 시뮬레이션과 구분한다.
