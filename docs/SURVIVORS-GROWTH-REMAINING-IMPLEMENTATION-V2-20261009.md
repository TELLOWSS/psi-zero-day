# 인물 성장 후속 구현 V2

2026-10-09. 사용자의 남은 기획 재작성 및 연속 구현 요청에 따른 실행 기준. 앞선 문서의 인물별 관점과 기존50구역은 유지한다. 아래는 현재 상태와 남은 납품을 구분하며 전체 구현 완료 보고가 아니다. 동기화는 사용자 요청 시에만 한다.

## 닫힌 로컬 구현

6명×5장 완수 기록, 실제 인계 수치 회고, 안전관리자 STAGE12 완료/통로 정리 CG, 승인 A/B 대화, 선택 보류/재시도/다시보기, 결과→다음 구역 준비, 세 관심사 별도 변경 저장이 구현됐다. 실제 UI봇 완주 및 reload 별/지갑/장비 내구/STAGE13 준비를 검증했다. 선행해금/보유장비는 fixture이며 자연 구매·실기기 증거가 아니다.

주인공 인계1장과 관심사3장 총4장의 디자인·정확 파일이 사용자 승인됐다. 관심사 원화는 저장된 선택에만 대응하고 초안/실패는 이전 선택을 유지한다. 실기기/사용권/직업 획득을 이미지 승인으로 대신하지 않는다. 새 음성은 없다.

## 인물별 후속 브리프

안전관리자: 실제 확인과 미확정 내용을 구분하고, 중지/재개 경계를 전달하는 자세의 변화. 이미 승인된 관심사를 직업 판정으로 바꾸지 않는다.

강태식: 작업반 이동을 챙기는 현재 역할에서 다음 팀 통로와 작업 순서를 설명하는 관계로 확장. 제동 횟수를 후배 신뢰 점수로 치환하지 않는다.

윤성호: 자재·결속 차이 관찰에서 기술 근거를 다음 작업자에게 전달하는 관계로 확장. 적 처치를 실제 기술 자격으로 계산하지 않는다.

이재훈: 계획/설치의 차이와 기존/신설 설비를 구분해 전달. 전투 수치만으로 도면 검토나 계획 변경이 완료됐다고 말하지 않는다.

임준호: 작은 이상을 보고하고 다음 팀의 답을 듣는 관점. 기존 숙련 인물까지 신입으로 초기화하거나 실패로 외모·진로를 낙인찍지 않는다.

안전감시자: 출입/무전/사각/신호 제한을 전달하는 관점. 인물 ID와 본편 신호수/다른 조연을 임의로 통합하지 않는다.

이 브리프는 기존 기획을 정리한 것이며 아직 없는 사건·동료 응답·해금 수치를 확정 대사나 실제 기록으로 만들지 않는다. 후속 인물은 한 명의 한 사건부터 납품한다.

## 저장·자산 불변 조건

wallet/inventory/stage_stars/growth_v1/본편 flags 불변. 새 그림을 얻었다고 focused/skilled 또는 Career/PSI/Dark Path 수치를 자동 갱신하지 않는다. 관심사 저장은 기존 direction 키만 사용한다. CG replay는 읽기이고 보상은 기존 실제 종료 처리만 소유한다. 최초 선택 대화는 기존 write-once 정책이며 미래 관심사만 변경 가능하다.

미승인 최종 파일은 문서 검수 영역에만 둔다. 승인 파일은 SHA를 보존하고 사용권/청취/실기기를 독립 기록한다. 기존 단계별 별도 manifest 이미지0을 placeholder로 메우지 않는다.

## 다음 판단이 필요한 내용

focused/skilled의 정확 장면·표시 조건, 다음 인물/사건/대사, 본편 게이트와 모드 공유 계약, 새 음성 및 최종 사용권·실기기 검수는 미확정이다. 전체 구현 지속 요청은 실행 권한이지만 미확정 공식이나 최종 파일을 대신 승인하는 근거로 사용하지 않는다. 배포 대기와 독립적인 로컬 제작·검증을 진행하며 같은 완료 fixture만 반복하지 않는다.
