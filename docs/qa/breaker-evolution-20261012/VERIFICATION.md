# 시그널 브레이커 수정·숙련 진화 검증

최신 CH04 하중 재시험·UI 이미지 교체(main PR #198)를 보존해 통합했다. 입문 1~5의 기존 입력 시뮬레이션 45회는 최신 main의 기록과 정확히 일치한다.

- 엔진 회귀: 215개 통과(최신 main 207개 + 이번 8개). 진화 장비 조건, 장갑 우회 방지, 중단 저장 복원, 출발 프레임 잠금, 압력 제한시간, 출처 관측 기록 유지, 컨베이어 정지 확인.
- 본편 테스트: 2039개 통과, 1개 건너뜀. TypeScript 검사와 빌드 통과. 통합 후 배포 검증은 PR CI 기록을 기준으로 한다.
- 네 화면(1920×1080, 844×390, 390×844, 768×1024): 메인 두 제목의 글꼴·크기·두께·행간·자간 일치. CH01/02 첫 클리어와 반복 클리어 엔딩, 보상 중복 방지 확인.
- 숙련 작전: 준비 화면에서 레이저 선택, 부품 5개 정비에서 프리즘 선택, 실제 pulse/scan 장착, 튜닝 선택 후 재개 확인.
- 오프라인: v0.45 캐시에 진화 모듈 포함, 오프라인 새로고침 후 프리즘·pulse/scan 복원과 수동 재개 통과.
- 느린 CH05 이미지 로딩: 준비 중 elapsed=0; 서로 다른 이미지 5개 사전 디코드; 회상 전환 중 src 변경 0회.
- 45회 숙련 입력: 비상성 1/15, 상성 9/15, 진화 15/15 완료. CH04 재시험과 경고 구역 회피·보조 장비 교체를 포함한다. 같은 이동·발사 정책을 적용하며 승리·체력·보스 상태를 강제로 변경하지 않는다. 사람의 승률 측정은 아니다.

기존 원화 기반 2D 부품 애니메이션과 실제 엔진 손상 단계가 연결되어 있다. 전격·레이저 효과는 실제 손상 대상에 한정한다. 신규 효과음은 합성음이다. Android 실기기, 사람 대상 난이도·재미, 자연스러운 동작과 손상 표현의 최종 미술 검토는 별도 확인이 필요하다.
