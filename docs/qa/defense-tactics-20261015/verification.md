## 검사 범위

- [다섯 화면의 정상 조작/저장 복귀](browser.json): 허브 진입, 두 지원 중 선택, 추천 패드 확인, 비용80 구매 및 비용60 L2 개조, 장비 네 노드, 회전 강요 없음, 가로 넘침 없음, 검토·닫기 후 정지 유지, 방호/자원 보존한 이어하기.
- SVG의 실제 화면 좌표와 HTML 터치 버튼 중심을 비교한다. 최대 오차2px 이내를 합격 기준으로 두고 JSON의 `alignmentError`를 기록한다.
- PC는 두 번째 탭 차단과 이미 로드한 상태의 네트워크 단절 후 진행을 추가 확인한다. 최초/재접속 웹 오프라인 보장은 아니다.
- [실제 UI 정상 완주](natural-play.json): 각 파의 추천 확인·확정·지원·시작 버튼을 클릭한다. 브라우저 시간만 가속하며 승리/방호/자원/적/세이브를 주입하지 않는다. `purchases`와 `waves`, 결과, 정상 저장된 기록을 보관한다.

실제 캡처는 `*-preparation.png`, `*-board.png`, `*-tree.png`, `*-actual-combat.png`, `*-actual-result.png`다. 완성 빌드(`vite preview` :4176)에서 최종 증거를 생성한다.

## 경계와 미검증

본편은 아직 준비중이며 잠긴 경사로 이벤트의 선행 조건을 우회하지 않았다. 사람의 재미·선호, 실제 휴대폰의 터치/발열, 모든 모드의 새 왕복, 음원 저작권은 이 자동 검사의 범위가 아니다. 기존 아트 재사용이며 최종 그림 승인으로 보고하지 않는다. root 테스트의 jsdom 미구현 media/scroll/canvas 메시지는 실제 기기 사운드 확인을 대신하지 않는다.

개발 서버 도중 발견한 StrictMode 잠금과 오래된 모바일 CSS 충돌은 수정 후 완성 빌드에서 다시 확인했다. 개발 중 HMR로 중단된 완주 결과는 최종 완주 성공에 포함하지 않는다.
