# 시그널 브레이커 — 장착·발사·동작 정밀 검토

사용자 요청(2026-10-15)에 따른 무기 메커니즘/그래픽/장착 애착감과 캐릭터 동작 개선. 별도 유료 화폐·성장 공식·신규 캐릭터 이미지를 도입하지 않았다. 기존 승인된 6명 인물, 6종 장비, 16종 발사체 원화를 사용하고 실제 조작/발사 정보를 표현에 연결했다.

## 발견한 문제와 수정

1. 발사 이벤트가 `this.id`(마지막 생성물)를 가리켰다. 연사 날개탄과 자동 보조망/필드 생성 뒤에는 주탄이 아닌 다른 ID가 될 수 있었다. 이제 실제 주탄 ID를 기록하고 존재·무기 종류·총구 위치를 검증한다.
2. 주탄 업그레이드가 같은 발사에서 생성된 보조탄에도 적용됐다. 특히 T4 펄스가 자동 포획망에 관통/방사 효과를 붙일 수 있었다. 각 탄은 자기 무기의 개조 등급을 사용하며 보조망은 펄스 관통/방사 효과를 상속하지 않는다.
3. 궤적은 프레임 시작점만 기록해 반사 모서리를 직선으로 생략했다. 실제 충돌 지점을 짧은 꼬리와 기록 경로에 추가했다. 미리보기는 전투 상태를 바꾸지 않는다.
4. 접촉/반사에 무기·등급·발사 ID가 부족했다. 실제 접촉점에 해당 정보를 넣었다. 반사 효과는 실제 나가는 방향을 사용하고 스캐너/자력/미스트는 파괴용 섬광과 구분한다.
5. 포획망 시각 범위가 기본 82로 그려졌다. 이제 해당 발사의 실제 회수 반경을 이벤트에 넣고 그림에 사용한다. 포획 성공·장갑 무시·추가 피해를 시각 효과가 만들어내지 않는다.
6. 손목→총구 거리에 맞춰 장비 크기를 매번 바꿨다. 조준/동작에 따라 늘거나 줄어들 수 있었다. 승인된 장비 원화의 손잡이→끝 길이를 30~34 월드 단위로 고정하고 최대 1.8 단위의 짧은 시각 반동만 적용한다. 실제 탄은 권위 있는 엔진 총구에서 나온다. 장비 손잡이와 손목은 짧은 장착 연결로 표현하고 손/몸의 앞뒤 가림을 유지한다.
7. 이동 자세에 조준 방향을 즉시 덮어쓰면서 이동 트래커의 회전 상태가 남았다. Breaker 전용 시각 계층에서 몸의 회전을 시간 기반으로 완충한다. 이동 중에는 정지 회전용 발 디딤으로 잘못 처리하지 않는다. 기본 보행 위상/거리/반응은 실제 이동 트래커를 그대로 쓴다.
8. 고정 시뮬레이션 시간과 렌더 프레임 간격 차이로 순간 속도에 흔들림이 있었다. 시각적 보행/달리기 선택만 0.065초 완충한다. 실제 이동속도·입력·회피·충돌은 바꾸지 않는다.
9. 펄스와 미스트/망/스캐너가 같은 발사 동작을 사용했다. 후자는 기존 승인된 전개/분사 동작을 사용한다. 피격/걷기/달리기/정지/재도전의 기존 동작과 얼굴·PPE를 유지한다.
10. 진화 펄스의 장착 색이 일반 펄스 주황으로 돌아갈 수 있었다. 실제 전격/레이저 계열 색을 유지하고 일시정지에서도 마지막 발사 자세를 정확하게 고정한다.
11. 발사체 원화가 충돌 중심보다 앞서 닿아 보였다. 원화 앞끝을 실제 충돌 반경에 맞추고 발사 직후 꼬리가 총구 뒤로 삐져나오지 않도록 비행 거리로 자른다. 반사 후에는 실제 반사 방향으로 회전한다.
12. 방호판 같은 버튼을 누른 뒤 키보드 이동이 멈췄다. 플레이 중 버튼에 포커스가 있어도 좌우 이동키를 받는다. 텍스트 입력과 메뉴의 Enter/Space 동작은 유지한다.

## 무기별 유지한 역할과 강화한 읽기

| 무기 | 실제 역할 | 표현 |
|---|---|---|
| 에어 펄스 | 빠른 직선 타격·분리, 개조 후 방사/관통 | 짧은 반동, 단계 표식, 단계별 크기/발광 |
| 반사 집중탄 | 반사 이후 인접 신호 추가 처리 | 실제 충돌 모서리와 반사 방향, 청색 식별 |
| 공명 충격파 | 근거리 군집 최대 3개 처리 | 넓은 공명 발사체와 분홍 식별 |
| 전개형 포획망 | 안정화·범위 회수 | 전개 손동작, 실제 회수 범위/격자 |
| 자력 유도기 | 금속 유도·극성/등급에 따른 필드 | 자력 고리, 파괴 섬광과 구분 |
| 안정화 미스트 | 체류 후 분진/전력 안정화 | 부드러운 분사 동작·구름형 접촉 |
| 장력 앵커 | 대상/장력선 고정·해제 | 짧은 고정 장비, 실제 연결 규칙 유지 |
| 회로 스캐너 | 분석·약점/회로 정보, 직접 피해 없음 | 스캔형 동작·분석 고리/십자 표시 |

지원 장비의 탄도·쿨다운·장갑·설비 제약은 기존 규칙을 유지한다. 위 T4 보조망 상속 오류만 실제 메커니즘을 바로잡았다. ‘분사 동작’은 캐릭터 손동작이며 탄을 임의의 연속 광선으로 바꾼 것이 아니다.

## 장착 애착감

준비 화면의 ‘나의 현장 장비’는 현재 캐릭터 이름·실제 장비·개조 T1~4·조합 진화·제약을 보여 준다. 다이아 표식은 보유 개조 단계이며 임시 튜닝/아이템 레벨과 구분한다. 개조 단계가 손에 든 장비의 표식과 발사체 크기/고리에 반영된다. 장비 원화 자체를 4종으로 새로 그린 것은 아니다.

정해진 무기 규격은 재조준 때마다 크기가 바뀌지 않으므로 같은 장비를 들고 있다는 인상을 유지한다. 강화 효과는 실제 `TalentTechManager` 능력치로부터 읽는다. 닉네임·유료 스킨·새 저장 화폐를 추가하지 않는다.

## 접근성과 검증 범위

기본 효과 상한(low 8 / balanced 16 / high 28)과 수명 제한을 유지한다. 줄인 동작에서는 시각 반동과 장식 광량을 줄이고 무적 표시를 빠른 점멸 대신 일정한 투명도로 보여 준다. 일시정지/재시작에 오래된 발사나 다른 인물의 자세가 남지 않는지 확인한다. WATCH 공통 이동 규칙은 수정하지 않고 Breaker 전용 계층을 추가했다.

순수 검증: 실제 발사 ID와 개조/쿨다운, 보조망 상속 금지, 반사 모서리, 분석 장비 무피해, 포획 범위 일치, 전격 장착 색, 읽기 전용 장비 설명. TypeScript 검증은 거리 위상 보존·회전 완충·시간 정지·같은 시간의 새 발사·인물 교체·장비 규격/반동을 확인한다.

브라우저: 6명 실제 선택→키보드 좌우 이동→장착 규격→일시정지. 8무기 그림 행렬은 개발용 자유 접근과 합법적 일시정지 장비 선택, 평범한 조준/발사/시간 진행을 사용한다. 강제 승리나 체력 수정은 하지 않는다. 별도의 15작전 경로 검증은 개발용 해금 없이 실제 신규 계정에서 진행한다. 실기기 프레임률·주관적 애착감은 자동 검증으로 보증하지 않는다.

릴리스 `0.61.0-equipped-motion`, 캐시 자산 179개. 새 래스터/음원 없이 작은 UI JS/CSS를 추가했다. 결과는 `docs/qa/equipped-motion-20261015/`에 보존한다.
