# NEW-PSI 인물 일관성 · 스토리 통합 구현 보고

2026-10-17 / 기준: [스토리 시네마틱 통합 기획](STORY-CINEMATIC-INTEGRATION-20261017.md)

## 적용 내용

- 동료 8명의 초상·맵·표정 24개 슬롯을 교체했다. 안전모는 방패 왼쪽 / NEW-PSI 오른쪽 한 줄, 인물별 색·띠와 곡면·기울기를 기준으로 정리했다. 강태식의 콧수염과 턱수염 차이를 수정하고, 일부 표정 슬롯의 다른 바지·작업화도 기준 복장에 맞췄다. 전신형 안전벨트를 유지했다.
- 8명 각각의 8방향 머리 원화를 제작했다. 실제 전투 동료 5명의 800개 원본 동작 프레임에 같은 인물의 방향별 머리를 합성한다. 몸·발 접점·도구 소켓·엔진 이동은 유지한다. 두 얼굴을 알파 혼합하던 전환은 단일 원화 선택으로 바꿨다. 몸 동작은 기존 제작 프레임이다.
- 메인에서 본편 시작·이어하기를 연결했다. 제목은 「돌아갈 자리」다. 첫 7개 사건과 주요 후반 회수 문장을 기존 localization ID 위에 개작했다. 26개 사건, 선택 ID, 효과 묶음, 완료·저장 계약은 유지한다.
- 프롤로그는 수동 진행이다. 큰 글씨에서도 본문을 한 열로 끝까지 스크롤할 수 있다. 읽기·음량·지난 대사·음성 건너뛰기를 제공한다. 음성 자막이 본문을 지우지 않는다. 장면과 충돌하던 보조 기록은 독립 펼침 메뉴로 옮겼다.
- 기존 OGG·음성 마스터를 유지하며 장소별 조용한 환경음을 연결했다. 설정·지난 대사·탭 숨김에서 재생을 중지하고 장면 변경 시 지난 단발음을 취소한다. 음악/환경음/효과/음성 음량은 개별 조절한다. 새 OST나 전체 대사 더빙을 제작한 것은 아니다.

## 데이터 경계

별도 버전의 제한된 로컬 receipt 장부는 모드 기록의 출처·사건·상태를 읽어 문장 반응만 투영한다. 훈련 완료로 본편 점검 사실이나 보상을 만들지 않는다. Guard 캠페인 기록을 읽을 때 자동 migration이나 원본 쓰기를 실행하지 않는다. 저장이 막히거나 기록이 없어도 본편을 진행할 수 있다.

대표 원화·동작·브라우저 증거는 `docs/qa/crew-story-release-20261017/`에 보관한다. 브라우저 테스트의 합성 기록은 `tests/browser/story-recovery.cjs`의 격리된 fixture이며 제품 콘텐츠·사용자 저장과 구분한다.

## 최종 제작 검토

자동 검사와 브라우저 에뮬레이션은 미술·감상 승인과 다르다. Director의 마킹·인물 유사성·첫 10분 원고 검토, 실제 독자 3–5명의 첫 플레이, 스피커·이어폰 청취, Android 기기의 입력·메모리·성능 검수가 남는다. 신규 OST·추가 성우 제작은 별도 범위다. 이번 오프라인 검증 대상은 독립 Breaker의 6명 선택·실제 전투와 추가 머리 자산 캐시다. 본편 전체 웹 오프라인 캐시를 새로 만들지는 않았다.
