# SIGNAL BREAKER — 발사체 원화와 무기 테크트리 기획

작성: 2026-10-13 / 범위: Breaker EP02 6~10 및 전체 발사체 표현. 본편 이야기·EP01 난도·유료 결제 구조를 확대하지 않는다.

## 경험 목표
기본 프레임 → 조합 진화 → 전문화 → 최종 진화가 한 작전의 다섯 필드를 따라 누적된다. 정비 화면에서 연결선, 선행 조건, 필요 누적 부품, 적용 효과, 선택한 경로를 확인한다. 두 계열과 각 계열 두 조합으로 시작하되 각 조합은 확산/집중 두 전문화 중 하나만 택한다. 획득 부품을 기준으로 해금하며 CP를 소비하지 않는다. 자동 발사는 조준을 돕고, 사선·상성·현장 장치·보조 도구의 판단은 계속 필요하다.

## 성장 규칙과 선택 비용
| 단계 | 조건 | 효과 | 비용·제약 |
|---|---|---|---|
| 프레임 | 출발 준비 | 전격은 분진/전력, 레이저는 금속/하중에 유리 | 출발 후 프레임 버튼 잠금; 첫 조합 진화 시 해당 조합의 프레임으로 최종 확정 |
| 조합 진화 | 누적 부품 5, 촉매 4 / 정비 | 기존 폭풍·특이점·프리즘·플라즈마 규칙 유지 | 현장 안정 회수 조건 유지; 조합 선택 후 경로 고정 |
| 전문화: 확산 | 부품 9 / 2필드 완료 이후 | 추가 목표 1개, 전격 연결 거리 +35 / 레이저 사선 길이 +60 | 집중 전문화와 동시 선택 불가 |
| 전문화: 집중 | 부품 9 / 2필드 완료 이후 | 상성 장갑 손상 +3 | 목표 수와 사선 범위는 기존값 유지 |
| 최종: 확산 완성 | 부품 14 / 3필드 완료 이후, 확산 선행 | 추가 목표 1개 및 상성 손상 +1 | 최대 5목표, 현장 장치와 보스 방호를 우회하지 않음 |
| 최종: 집중 완성 | 부품 14 / 3필드 완료 이후, 집중 선행 | 상성 손상 추가 +3 | 단일 사선 중심의 기존 목표 수 유지 |

부품은 소모품이 아닌 해당 작전에서 확보한 성장 증거다. 노드 구매는 정비에서만 가능하며 전문화와 최종은 선행 순서대로 선택한다. 후반에 부품을 모았다면 같은 정비에서도 순서대로 따라잡을 수 있다. 취소·중복·상호 배타 경로 구매로 성장 수치를 중첩할 수 없다. 조합만 선택한 기존 기록은 그대로 첫 진화 단계로 복원한다. 새 전문화/최종 필드는 선택값을 저장하고 잘못된 경로·부품·필드 조건은 복원에서 거부한다. 새 작전은 기본 프레임부터 시작한다.

## 발사체 아트 디렉션
별도 제작한 투명 4×4 원화 아틀라스를 사용한다. 1행은 속사·반사·공명·포획망, 2행은 자력·미스트·앵커·스캔, 3행은 전격·레이저·폭풍·특이점, 4행은 프리즘·플라즈마·최종 전격·최종 레이저다. 기존 산업 현장의 금속·코일·세라믹·전력 신호 소재와 정교한 발광을 결합한다. 진행 방향은 우측이며 코드에서 속도 방향으로 회전한다. 프레임/조합/최종에 따라 실제 원화가 바뀌고 확산과 집중은 외곽 궤적/핵 밀도 표현으로 구별한다.

최대 폭은 일반 48, 진화 62, 최종 76 월드 픽셀로 제한한다. 실제 충돌 반경과 속도는 기존 엔진 값 그대로다. 투명 여백을 유지하고 화면 전체 플래시를 사용하지 않는다. 저품질 모드에도 원화는 유지하고 추가 글로우와 흔들림만 줄인다. reduced motion은 발광 진동을 정지한다. 아틀라스는 로딩과 서비스 워커 캐시에 포함한다.

## 저작권과 제작 이력
다른 게임의 분기 성장 원리는 참고하되 이미지·코드·아이콘·명칭·배치·캐릭터·시그니처 이펙트는 가져오지 않는다. 생성 프롬프트에 타 게임명·작가명·브랜드명·참조 이미지를 넣지 않는다. PSI 현장 제어 장비에서 독립 제작하며 원본 프롬프트·도구·실제 자산 경로·크롭 메타데이터를 기록한다. WIPO는 아이디어와 표현을 구분하지만 개별 결과물의 비침해를 자동 보증하지는 않는다. 상업 출시 전 최종 산출물의 유사성 및 권리 검토를 별도로 남긴다.

## 검증과 출시 기준
순수 엔진 테스트: 선행 노드·필드·부품 조건, 중복·다른 경로 거부, 기본/확산/집중의 실제 장갑 및 연쇄 접촉 결과, 기존 체크포인트 및 신규 경로 복원, 보조 장비 제거 시 진화 효과 비활성화. 기존 숙련 시뮬레이션 45회 결과와 비교하여 첫 진화 기준선을 보존한다. 신규 경로는 동일 목표 배치에서 장갑 해소와 최대 목표 수를 별도 비교한다.
브라우저: 실제 정비 버튼 입력, 작은 모바일 스크롤·연결선·버튼 상태, 모든 발사체 원화 준비 및 실 렌더 기록, 오프라인 재진입, 콘솔 오류 없음. npm test/typecheck/build 및 Breaker 회귀 후 GitHub CI 통과, Vercel 배포 SHA/런타임 일치 확인. 미술의 자연스러움·가독성은 Director 최종 검토, Android 실기기는 별도 확인한다.

## 구현 검증 결과
Breaker 231개 테스트, 본편 2039개 테스트(1 skip), typecheck와 build 통과. 기존 숙련 45회는 상성 불일치 1/15, 일치 9/15, 첫 진화 15/15로 기존 기준선과 동일하다. 확산·집중 경로를 각각 15회 실행한 총 30회에서 모두 최종 진화에 도달했고 29회 클리어했다. 강화된 손상이 위험 분리 시점을 바꾸므로 선택 자체가 승리를 보장하지 않는다. 이 수치는 실제 이용자 승률이 아니다. 상세 결과는 `docs/qa/breaker-weapon-tree-20261013/`에 보존한다.
데스크톱·가로폰·세로폰 실제 버튼 입력에서 조합/전문화/최종을 연결했고 원화 16셀의 게임 렌더링과 오프라인 재진입을 확인했다. 모바일 카드의 기존 고정 44px 높이를 제거해 이미지·명칭·설명이 카드 내부에 머물도록 수정했다.
