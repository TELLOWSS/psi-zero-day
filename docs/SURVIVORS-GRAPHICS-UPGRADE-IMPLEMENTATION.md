## 실제 적용 내용

후속 요청에서 전체 제작 진행을 승인받았다. 운영 기준선 `6c2812df`와 구분되는 로컬 구현이다. 이번 변경을 GitHub/Vercel에 배포했다고 보고하지 않는다.

캐릭터별 160개, 총 **960개 논리 자세 슬롯**을 적용했다. 실제 고유 소스 영역은 **836개**다. 방향·자세를 재사용한 영역과 명시적인 좌우 반전은 메타데이터로 구분한다. 배우 원화 PNG 74개와 환경 원화 2개를 제작·보존했으며, 소스 기록 76개 중 69개를 현재 슬롯에 연결했다. 준비하는 시트는 선택 캐릭터의 11~12개다. 모든 캐릭터를 처음부터 함께 로드하지 않는다.

격자가 합쳐진 주인공 정면 v1, 잘못된 후방 방향 후보, 이재훈에게 안경이 생긴 회전 v1은 보존하되 해당 슬롯에서 제외했다. 이재훈 회전 v2는 안경 없는 기존 얼굴에 맞춰 다시 제작했다. 장비 점검에는 지시/도구 자세를 공유한다. 독립적인 점검 원화나 별도의 옆걸음 전용 시트를 제작했다고 계산하지 않는다. 후진 검증은 현재 방향 원화의 역위상 재생과 도달 범위 제한을 검수한 것이다.

정지·걷기·회전 모두 동일한 몸과 장비 렌더러를 쓴다. 손목은 캐릭터와 행동 프레임별 실제 위치에 맞춰 보정하고, 일부 자세만 손목 기준점이 있는 경우에도 기존 위치와 부드럽게 연결한다. 뒤에서 뻗은 손목은 보이며 몸통 뒤의 장비는 가림 규칙을 따른다. 발바닥 추출은 공중에 든 부츠를 실제 바닥 접점으로 잘못 잡지 않도록 고쳤다. 접지 추적 결과는 다리 비율 제한 후 다시 기준점으로 반영한다.

STAGE 42의 바닥·주변 설비 원화는 동일한 카메라·배치·빈 전투 구역을 유지하면서 콘크리트, 금속, 고무의 반사와 마모를 정리했다. 지형 좌표·충돌·보상·진행 규칙은 엔진 변경 없이 유지했다. 방향 캐릭터의 중복 타원 그림자는 제거하고 바닥 반그림자와 발 접촉 그림자를 함께 쓴다.

공통 산업 위험 아틀라스를 교체하고, 기존 공정별 몬스터와 재질 종의 고유 아틀라스는 그대로 활용한다. 금속 카트의 타격은 차체 늘이기 대신 하중 이동·국소 회전으로 표현한다. 기존 금속/분진/증기/전기 접점과 해소 상태를 유지하며 전기 몬스터 능력 같은 새 전투 규칙은 추가하지 않았다.

혼잡 검수에서 발견한 `brightness(3.2) contrast(1.6)` 전체 물체 필터를 제거했다. 재질별 국소 타격이 물체 표면을 읽을 수 있게 한다. 동시에 겹치는 돌진 경고는 주황 경계와 진행 방향을 유지하고 내부 채움만 감쇠한다. 전경 위험에 가려진 주인공은 약 1 CSS px의 몸 윤곽을 표시하며 깊이 순서와 충돌을 변경하지 않는다.

장식 비행·주변 광량·수치 피드백의 예산을 기존 그래픽 세 설정과 자동 품질에 연결했다. 실제 투사체와 위험 경계는 생략하지 않는다. 화면 밖 장식은 계산을 줄인다. 자동 변경 안내는 화면 가장자리에 표시하고 조이스틱을 사용하는 동안 숨긴다. 안내에서 설정을 열면 전투를 정지한 뒤 설정으로 이동하며 수동 설정 복구가 가능하다.

메인과 시그널 워치의 설정 저장·복구는 같은 설정을 공유한다. 스토리·디펜스는 현재 준비중 진입 계약과 기존 최종 후보 아트를 유지하고 공통 산업 재질/PPE/안전·위험 색의 제작 기준으로 검수했다. 슈팅의 전투 리그를 본편 인물 연기나 디펜스 게임 규칙으로 강제 이식한 것은 아니다. 이번 작업에 새 캠페인이나 전체 3D 렌더러 전환은 포함되지 않는다.

## 성능과 접지의 실제 한계

최종 10분 검사는 **데스크톱 Chrome / 390×844 모바일 화면 / DPR 2 / 현재 캐릭터 / 65개 위험 유지 / 장비 6종 Lv5**의 QA 전투다. 첫 웨이브를 유지해 보급으로 정지하지 않게 했으며 실제 시뮬레이션 시계가 600초 진행했는지 검증했다. 브라우저 예외와 렌더러가 잡아낸 console error도 확인했고 오류는 없었다.

전체 물체 타격 필터 제거 후 최종 검사에서 모든 분의 p95 프레임 시간은 약 **16.8ms**, 가장 긴 프레임은 **69.2ms**였다. 모든 분에서 자동 품질 high를 유지했다. 이전 필터 포함 검사의 p95는 약 33.3~33.5ms였다. 같은 데스크톱의 유사 QA 장면 비교이며 통제된 실기기 벤치마크나 모든 모바일의 60fps 보장이 아니다. JS 힙은 약 **63.4~87.9MB** 사이에서 회수되고 마지막은 약 68.0MB였다. GPU 자원·전체 프로세스 메모리·휴대폰 온도는 측정하지 않았다.

선택 캐릭터 원화 준비는 localhost 검사에서 약 **422~715ms**였다. 전체 배우 PNG 소스는 약 108.7MiB이며 이것은 동시에 로드하는 양이 아니다. PNG 전송 크기, 시트 디코딩 메모리, 캔버스 복제와 JS 힙은 다른 값이다. 실제 네트워크에서의 첫 준비 시간은 별도 확인 대상이다.

몸 높이 74인 연속 걷기/달리기 검사에서 제한 후 접점 이동의 최대값은 캐릭터별 약 **5.64~8.07 CSS 단위**였다. 역위상·30Hz의 값은 원본 보고서에 별도로 기록한다. 이는 완전한 무미끄럼 발 접지 달성을 뜻하지 않는다. 기존 `<1e-6` 접점 수치는 좌표 역투영 오차이며 발 미끄러짐 측정과 구분한다. 비율 보호가 먼저이며 원화 및 제작 리그의 추가 품질 개선을 런타임 늘이기로 숨기지 않는다.

## 최종 승인과 외부 검수

구현과 자동 회귀 검증은 완료했지만 **VISUAL PRODUCTION LOCK은 승인하지 않았다**. 실제 휴대폰의 온도·전력·GPU 메모리와 네트워크 준비 시간, 현장 경험자의 주인공/위험/탈출 방향 식별 관찰, 감독의 최종 움직임·착용·화면 승인이 남는다. 현장 관찰 결과나 실기기 성능을 자동화된 브라우저 검사로 대신했다고 보고하지 않는다.

소스·프롬프트·고유 영역·반전·불량 후보 상태는 `content/design/survivors-graphics-animation-v1.json`, 슬롯은 `content/art/survivors-authored-actor-layouts-v1.json`, 손목 기준점은 `content/art/survivors-authored-joints-v1.json`에서 확인할 수 있다.
