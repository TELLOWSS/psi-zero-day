# PSI EP01 가이드·완성형 연습·전투 영역 설계 — 2026-10-13

## 1. 이번 변경의 목적
상단 HUD, 보스 상태, 성장 안내와 하단 조작이 전투 캔버스 위에 다시 겹친 문제를 해소한다. EP01은 대응 문법을 배우는 과정, EP02는 이해한 문법을 조합하고 진화하는 과정으로 연결한다. 첫 진입부터 보상 없는 완성형 체험을 선택할 수 있다.

## 2. 화면 계약
상단 정보, 상태 안내, 하단 입력을 실제 독립 영역으로 배치한다. 세로는 상단 48px + 상태 84px + 하단 184px, 가로는 44px + 68px + 84px를 예약하며 기기 safe area를 더한다. 전투 캔버스는 나머지 영역만 사용한다. 보스·발생원·캐릭터 좌표와 충돌 크기는 바꾸지 않는다. 보스와 모든 노드, 조작원 발끝을 새 캔버스 경계 안에 맞추는 순수 카메라 계산을 사용한다. 넓은 화면의 여백은 기존 현장 원화로 채운다.
안내는 현재 행동 한 줄과 상세 가이드로 나눈다. 여러 팝업이 시야 중앙에 쌓이지 않는다. 좁은 가로 장비 줄은 좌우 스크롤을 허용한다. 주요 이동·발사·조준 버튼은 유지한다. 가이드 열기는 실제 전투를 일시정지하며 닫기·ESC는 원래 진행하던 게임만 재개한다.

## 3. EP01 학습 순서
| 현장 | 배우는 대응 | 실제 확인 |
|---|---|---|
| CH01 | 이동, 발생원 관찰·요청·확인, 발사, 반사, 회수 | 엔진의 위치·확인·타격·회수 사실 |
| CH02 | 이동·벨트 흐름·반사·회수 | 벨트 방향과 반사·회수 |
| CH03 | 분진 안정화와 집진 대응 | 미스트 사용과 회수 |
| CH04 | 장력 고정과 사선 | 앵커 사용과 반사 |
| CH05 | 전력 격리와 복합 대응 | 스캔 사용과 회수 |
가이드는 학습 보조이며 읽기 여부로 캠페인을 막지 않는다. 장비를 눌렀다는 사실과 위험을 최종 확인했다는 사실을 구분한다. 상세 설명에서 조작·위험 예고·대응 순서를 제공한다.

## 4. 완성형 연습
90초, 무보상, 무해금, 무연구 증거. 공식 인물의 기존 승인된 얼굴·모습을 유지하고 실제 최종 발사체 및 장비 조합으로 체험한다. 캐릭터마다 4종 조합과 확산·집중의 다른 완성 상태를 부여한다. 이는 대응 장비 시뮬레이션이며 인물의 본편 전투 서사를 새로 확정하지 않는다.
| 캐릭터 | 완성형 |
|---|---|
| 플레이어 | 프리즘·집중 |
| 강태식 | 스톰·확산 |
| 윤성호 | 특이점·확산 |
| 이재훈 | 플라즈마·집중 |
| 임준호 | 스톰·집중 |
| 안전 모니터 | 프리즘·확산 |
금속·분진·하중·전력 4종을 초기 28개로 시작하고 3초 또는 잔여 8개 미만일 때 보충한다. 기존 동시 코어 36개, 발사체 32개, 입자 100개 상한을 유지한다. 완성형의 실제 장갑 손상, 다중 전기 연결과 레이저 관통이 해소 결과를 만든다. 자동발사를 사용할 수 있고 이동·직접 조준·직접 발사가 가능하다. 연습 시작 전 캐릭터를 선택하며 진행 중 교체로 상태를 뒤섞지 않는다. 기존 실제 작전 체크포인트·보상·엔딩을 변경하지 않는다.

## 5. EP02와 영구 성장
부품 5 → 조합, 2필드/9 → 확산·집중, 3필드/14 → 최종형을 명시한다. 현장 정산을 G1 프로필 reducer에 연결하고 로비에 조작원 레벨과 경험 진행을 표시한다. 실제 완료 필드와 엔진이 확인한 발생원·EP02 목표만 정산한다. ID에 캐릭터를 넣지 않아 외형 교체로 경험을 재지급하지 않는다. 옛 클리어에 경험·연구 증거를 소급 생성하지 않는다. 저장 실패 시 새 성장 상태를 되돌리고 기존 저장의 알려지지 않은 필드도 보존한다. revision 확인으로 오래된 상태의 덮어쓰기를 거절한다. 이 검사는 저장소 잠금이 아니며 탭 간 동시 쓰기의 엄밀한 직렬화는 후속 과제다.
전문 능력 9노드의 실제 배치·효과와 영구 무기 연구, Signal Watch 사건 어댑터는 후속 단계다. 현재 단계에 없는 능력을 작동하는 것으로 표시하지 않는다.

## 6. 검증 게이트
기존 회귀 수치를 바꾸지 않고 재현한다. 모든 6개 연습 빌드의 실제 충돌·보충·정지·종료와 자산 적용을 확인한다. 세로·가로·태블릿·PC 및 실행 중 회전에서 HUD·조작 영역과 전투 캔버스의 교차 면적이 0인지 확인한다. 가이드 정지·닫기·ESC, 연습 보상 격리와 실제 작전 성장 저장·재로딩을 검증한다. 사람의 재미·캐릭터 미술·저사양 기기 체감은 자동 테스트와 별도로 남긴다.

보완: 완성형 체험에 사용한 6종 장비 원화는 EP02에서도 해당 조합의 최종 진화와 실제 활성 보조 장비를 충족하면 손목·발사점에 연결해 표시한다. 연습의 외형은 실제 도달 가능한 상태다. 같은 시드의 재도전은 새 시도 번호로 정산하되, 이어하기와 동일 완료 재제출은 번호를 유지한다. 검증 증거 ID는 시도 번호와 무관하게 유지한다. 실패 후 같은 시드로 성공해도 최초 완료와 실제 완료 필드 경험을 받을 수 있도록 구분한다.
