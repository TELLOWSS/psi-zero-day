# 현장도감 잔여 원화 교체 — 2026-10-17

## 확인한 문제와 적용 범위

현장도감 118개 중 57개는 개별 래스터 원화가 연결되어 있었지만, 전환층부터 상부·마감 공정에 걸친 61개는 `FieldGuideArt`의 코드 기반 도해로 노출됐다. 이전 화면 스타일 개선만으로는 이 자산 격차가 해소되지 않았다.

이번 범위는 남은 61개에 대한 개별 원화 제작과 실제 도감 연결이다. 기존 57개 자산, 118개 정본 제목·관찰 설명, 법적 근거와 해금 규칙은 유지한다. 게임 장면용 `art.path`의 제작 상태를 도감 교체만으로 변경하지 않는다.

## 제작·표현 기준

- Built-in image_gen으로 항목마다 별도 제작. 공통 이미지를 여러 품목에 돌려 쓰지 않는다.
- 실물 재질, 일관된 중립광, 네이비·안전색 포인트, 투명 배경을 사용한다.
- 핀·웨지·샤클·볼트는 결합부 중심, 구조물·통로·개구부는 작은 현장 단면으로 구성한다.
- 추락·비래·사각지대 등은 현장 조건과 물체로 표현한다. 사람의 부상이나 장식용 경고 아이콘으로 대체하지 않는다.
- 표지판의 설명 문자는 정본 UI가 제공한다. 생성 이미지의 임의 문자에 정보를 의존하지 않는다.
- 원화는 WebP로 알파를 보존한다. 목록은 최대 240px 썸네일을 지연 로딩하고 상세·확대는 원본 해상도를 사용한다.
