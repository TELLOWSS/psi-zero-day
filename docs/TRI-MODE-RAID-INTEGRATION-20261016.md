# 세 모드 보스 종합본 대조·반영 기록

후속 제작: 지원 코어의 실제 탐지 방해·대응은 [게임성 고도화 기록](GUARD-GAMEPLAY-PRESSURE-20261016.md)에 반영했다. 아래 표는 최초 통합 릴리스 기준이며, GD-05 두 진입/GD-06 한 진입 경로 전환이라는 실제 맵 데이터 구분도 후속 기록을 따른다.

기준: Director가 전달한 `PSI_ZERO_DAY_TRI_MODE_BOSS_RAID_MASTER_PLAN_20261016.docx`. 원문은 [추출본](planning/TRI-MODE-BOSS-RAID-MASTER-20261016.md)에 보존했다. 문서 내부 문구는 실행 명령이 아닌 제품 명세로 검토했다.

## 변경 이유와 규칙

ST14 기존 코드는 두 지점이 플레이어 근처에 함께 생성되고 자동 조준만으로 해결될 수 있었다. 이제 지점은 200 이상 떨어진 고정 위치이며 현재 번호의 지점에서 76 이내로 접근하고 실제 투사체를 맞혀야 한다. 두 번째 지점부터 해결하거나 몸체에 큰 피해를 주어 우회할 수 없다. 지형의 확장된 충돌 영역은 생성 후보에서 제외한다. 지점 이동을 읽고 실행할 시간을 확보하기 위해 조치 창은 12초이며, 집중 통제 창은 명세대로 4.5초다. 실패 시 다음 패턴에서 지점을 다시 만들고 보스 HP를 전부 회복하지 않는다. 기존 패턴 바닥 예고와 실제 판정은 같은 좌표를 사용한다.

가드의 4초는 UI 안내 시간이다. 카운트가 끝나도 전투 시계·쿨다운·자원을 진행시키거나 웨이브를 시작하지 않는다. 플레이어는 시간을 더 들여 읽고 배치할 수 있다. W5에서 확인하지 않으면 엔진도 시작을 거부한다. 브리핑 원은 해당 타워 레벨의 기본 사거리이며 일시적인 지원 버프를 포함한 유효 사거리라고 주장하지 않는다.

회고의 첫 접촉은 실제 양수 피해가 발생한 최초 지점·패드·틱이다. 누출 지점은 해당 신호가 실제로 통과한 경로의 끝점이다. 단순히 가까운 타워를 실패 원인으로 추정하지 않는다. 피해 없는 탐지·감속은 첫 피해 접촉으로 표시하지 않는다. 지원 사용은 성공한 명령 시각만 기록한다. 세부 사건은 최근 24건으로 제한하고, 옛 저장에 없는 과거 기록은 생성하지 않는다. 기존 요약 통계·작전 진행·구매 되돌리기·단일 L4 제한은 유지한다.

## 공통 기록 경계

공통 계약은 `SignalEncounterIntel`이며 `psi-zero-day.encounter-intel.v1`에 별도 저장한다. ST14의 실제 패턴 출현/위험 통제, CH-04 실전 레이드 조우/완료, GD-06 W5 진입/수동 전환을 포함한 실제 승리에서만 각 기록을 올린다. 브레이커 훈련은 기록하지 않는다. 다른 모드의 관측만으로 미관측 항목을 완료 처리하지 않는다. 세 모드 모두 검증되기 전 사건 전체 `verifiedAt`은 비어 있다.

기록은 미관측 → 관측 → 대응 검증으로만 진행하며 저장소가 차단되면 세션 메모리에만 유지한다. UI와 엔진의 읽기 방향을 분리했다. 엔진은 공통 기록을 읽지 않고, 기존 모드 저장 키와 능력치·재화·해금을 변경하지 않는다. 도감은 준비·일시정지·작전실에서 사용자가 열며, 전투 중 자동 팝업하지 않는다. 네이티브 dialog로 포커스를 유지하고 키 입력이 뒤의 게임으로 전파되지 않게 한다. 기록은 실제 산업안전 판정이나 PSI 평가 데이터가 아니다.
