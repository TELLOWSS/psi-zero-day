# 핀볼 음원 2-A 적용 결과 — 2026-10-10

사용자 제공 industrial_pinball_audio_phase2.zip은 실제 오디오 50개(보완 46개, 짧은 지급음 3개, 비교 데모 1개)다. 모두 새로운 SHA-256이며 1차와 동일 바이너리는 없다. 음악·테이블 폴더는 비어 있다. README의 미제작 표기와 실제 구성은 일치한다.

브라우저 44.1kHz 디코드로 샘플 피크/RMS, DC, 종료부, 모노 합산, 직접 PCM 상관을 검사했다. 36개 공통 효과음의 실제 디코드 길이는 여전히 약 0.48초이며 끝 파형·레벨 문제도 모두 해결된 것은 아니다. 4개 파일에 full-scale 이상 샘플이 있어 원본 확인 대상으로 보류한다. 파형 검사로 가청 품질 또는 true-peak/LUFS를 승인하지 않는다.

8개 반영:
- paddle_left_v02_03, paddle_right_v02_03: 좌우 패들 원본 교체.
- hit_rubber_heavy_v02_02: 두 번째 고무 변형 교체.
- harbor_crane_motor_stop_v02: 항만 성공 구동의 정지.
- harbor_success_finish_v02: 항만 성공의 음악적 마무리.
- harbor_cargo_impact_v02, harbor_cargo_debris_v02: 타워 공의 실제 낙하 충돌과 잔해.
- pneumatic_payout_short_01: 보상 저장 성공 후 한 번만 재생.

원본 MP3를 보존하고 런타임에서 DC 제거·짧은 어택/릴리스 페이드·개별 게인만 적용한다. 1차 파일 3개를 우선 교체하되 이전 원본은 보존한다. 현재 공략과 관계없는 유리·콘크리트 음원이나 데모는 임의로 추가하지 않는다. 음악 stem과 9개 테이블 파일이 없으므로 제작 완료로 계산하지 않는다.

보상음은 연습·저장 실패·음소거에 나오지 않는다. 저장 재시도 성공 시 정확히 한 번 재생한다. 결과 화면은 보상음 재생 시간 동안만 오디오를 허용하며 음악은 정지한다. 설정 열기·앱 숨김·음소거·일시정지·재시작·종료 시 미래 예약도 취소한다. 이 시간은 presentation 전용이며 점수/보상/물리에 영향을 주지 않는다.
