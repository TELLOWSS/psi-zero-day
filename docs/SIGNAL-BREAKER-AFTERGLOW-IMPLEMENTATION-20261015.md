# 잔광 — 쉬어가는 무한모드 구현·검증

2026-10-15 · 사용자 기획 승인 및 구현 요청에 따른 웹 구현. 릴리스 `0.63.0-afterglow`, 오프라인 캐시 186자산.

## 실제 이용 흐름

브레이커 로비의 **잔광 — 쉬어가는 무한모드** → **가볍게 시작** → 자동 조준/발사와 자유 이동 → **설정·쉬기** → **오늘은 여기까지** → **오늘의 잔광** → 로비. 출석·필수 성장 투자·패배·재시도 광고·강제 정산 대기는 없다.

첫 진입은 로비의 선택 캐릭터를 검증된 URL 매개변수로 전달한다. 이후에는 잔광에서 선택한 캐릭터·장비·입력·소리 설정을 기억한다. 본편 저장을 직접 읽거나 수정하지 않는다. 정본 6명과 폭풍·특이점·프리즘·플라즈마 4구성을 처음부터 체험한다. 이 체험은 본편의 장비 소유·개조 등급·특성·진화 해금이 아니다.

## 구현한 규칙

- `RestGame`은 명시적인 `mode='rest'`를 가진 순수 규칙 클래스다. 기존 엔진의 고정 120Hz 이동과 swept collision을 공유한다. 캠페인 작전·장갑·성장·보상 처리와 UI 관리자는 실행하지 않는다. 본편 엔진 파일을 수정하지 않았다.
- 기본 120초는 진입 10 → 흐름 45 → 개화 20 → 정돈 35 → 여백 10초. 남은 신호는 최대 6초 동안 안전 회수하고 다음 호흡으로 이어진다. 새 생성은 정돈 후반부터 멈춘다. 대상이 없는 동안 자동 사격도 멈춰 여백에 장비음이 계속 울리지 않는다. 수동 발사는 선택 가능하다.
- 차분한 리듬의 신호 상한 8, 시원한 리듬은 12. 공간이 차면 생성을 보류하고 대기열을 누적하지 않는다. 시간 경과에 따른 난도 상승이 없다. 위험체 다단 분할·장갑·필수 설비 해제는 사용하지 않는다.
- 실제 발사체가 실제 신호에 닿았을 때만 연결·회수가 발생한다. 전격은 근거리, 레이저는 진행 방향의 사선으로 후보를 고른다. 특이점은 가까운 잔여 신호의 속도를 완만하게 모으고, 플라즈마는 접점의 회수 고리를 보여 준다. 개화는 실제 연결 상한을 차분 4 / 시원 5목표로 넓힌다.
- 반사 구조물은 시야를 독점하지 않는 우측에 놓았다. 시작 조준을 계속 가로막지 않으며, 실제 충돌 위치와 원화의 위치가 같다. 벽·반사 구조물의 궤적은 공유 충돌 계산을 사용한다.
- 놓친 신호, 오래 남은 신호, 호흡 경계의 신호는 `safereturn`으로 분리한다. 안전 회수는 플레이어 처리 수로 합산하지 않는다. 생명 감소·사망·게임오버·본편 보상·재화는 없다.
- 이동 A/D·←/→, 직접 화면/패드 조준, 수동 Space/발사 버튼, 자동 발사·조준 독립 전환. 자유/고정 이동 패드와 세 크기. 직접 조준 후 1.5초 동안 방향을 유지하고 자동 조준으로 복귀한다.
- 일시정지·회전·창 크기 변경·blur/visibility 이벤트에서 누른 입력을 해제한다. 90초 무입력 자동 쉬기(해제 가능), 선택적 5/10/15분 쉬기 안내. 안내는 하단의 작은 문구이며 플레이를 강제로 종료하지 않는다.

## 그래픽·음향

승인된 해질녘 반입 현장 `art/map-delivery-v3.webp`, 기존 위험 신호 원화, 16셀 발사체 원화, 정본 캐릭터와 장비를 재사용했다. 실제 작업이 아니라 **가상 장비 시험장**이라는 문구를 화면에 명시한다. 새로운 배경·인물·장비 래스터를 생성한 것으로 계산하지 않는다.

캐릭터·조준·장착은 기존 공용 actor의 방향·손·장비 규격을 사용한다. 세로와 폭이 좁은 화면은 인물 중심 구도로 읽힘을 높이고 전체 보기로 공간을 확인할 수 있다. 조작부는 플레이 영역 밖이다. 작은 가로 화면에서 캔버스가 첫 행에 눌리는 결함을 화면 검사로 발견해 수정했고, 검증에 영역 높이·상단 위치 조건을 추가했다.

화면 흔들림·경보·실패 컷인·전체 화면 섬광을 호출하지 않는다. 효과는 기존 low 8 / balanced 16 / high 28개 상한, 짧은 수명이다. 줄인 동작에서는 환경 장식과 시각 반동을 줄인다. 위험 신호/발사체 수와 규칙은 품질 설정에 영향받지 않는다.

음향은 별도 `rest-audio.js`의 실시간 Web Audio 합성이다. 단순한 화음·낮은 환경음·장비음이며 샘플 음원이나 기존 무료 AI 음원을 가져오지 않았다. 음성·실제 현장 경보·타 작품의 음원은 포함하지 않는다. 음악/환경음/장비음 볼륨을 각각 기억하고, 타격음 중첩 간격과 12개 음성 노드 상한을 둔다. 일시정지 시 재생 중인 합성음을 중단한다. 이것은 새 녹음 음원이나 치료용 음향의 제작·검증을 의미하지 않는다.

## 저장과 본편 보호

저장 키는 `psi.signal-breaker.rest.v1` 하나다. 별도 어댑터가 버전·캐릭터·조합·리듬·설정 범위·시드·호흡·통계를 검증한다. 캠페인 매니저·특성·워크숍·보상 스크립트를 잔광 페이지에 로드하지 않는다. 본편 연결 코드는 로비의 선택 캐릭터를 링크에 전달하는 한 줄과 진입 카드뿐이다.

호흡 시작의 시드·호흡 번호·확정 통계만 체크포인트에 보존한다. 종료하지 않고 앱이 닫히면 현재 호흡 처음부터 재생하고, 그 호흡의 미확정 통계를 다시 더하지 않는다. 오프라인 경과 시간만큼 성장·재화를 만들지 않는다. 사용자가 직접 마치면 현재 세션의 작은 기록을 저장하고 체크포인트를 비운다. 따라서 완료한 세션을 이어하기로 다시 정산하지 않는다.

이전 기록은 마지막 세션 요약 하나이며 끝없이 늘어나는 이력이 아니다. 잘못된 저장은 본편과 분리해 기본 설정으로 복구한다. 저장 공간 부족에서도 게임과 종료는 동작하고, 저장 실패를 메뉴에 표시한다. 종료 기록을 숨기는 선택도 제공한다.

## 검증 결과

### 경계별 확인

| 경계 | 결과와 근거 |
|---|---|
| 로비 → 잔광 | 실제 링크 클릭으로 별도 HTML 진입, 기본 준비 후 시작 |
| 입력 → 규칙 | 실제 키보드·드래그·모바일 동시 두 손 터치, 해제 후 이동 0 |
| 규칙 → 표현 | 4체험 구성 실제 발사·회수, 정본 6명 로드, 영역/효과 상한 |
| 규칙 → 저장 | 실제 고정 스텝 진행으로 호흡 경계 도달 후 저장 |
| 저장 → 복구 | 새로고침 후 같은 호흡 번호로 재개, 종료 후 체크포인트 비움 |
| 본편 격리 | 잔광 이용 전후 **잔광 키를 제외한 localStorage 전체 값의 정확한 비교** 통과 |
| 네트워크 → 오프라인 | 서비스워커 설치 후 네트워크 차단, 재접속·전투·설정 변경·6명 선택 |
| 저장 실패 → 종료 | 실제 UI에서 QuotaExceededError 주입 후 플레이·마무리 통과 |

서버 API·환경 변수·외부 DB는 없는 정적 오프라인 모드다. 따라서 서버 간 데이터 경계를 새로 만들지 않았다.

### 자동 검사

- Breaker 전체 테스트 **319개 통과**. 신규 10개는 규칙 격리, 네 구성의 실제 접촉, 안전 회수/상한, 일시정지, 재개 중복 방지, 저장 오염/실패, 여백의 사격 중단, 합성 음성 수명/상한, 오프라인 매개변수 주소를 포함한다.
- 본편 전체 **2,072개 통과 / 기존 1개 스킵**. TypeScript 검사·프로덕션 빌드 통과. 빌드 자산 186개를 릴리스 SHA-256과 대조한다.
- 신호·탄·이벤트·좌표·저장 크기 검증을 포함한 일반 입력 시뮬레이션: 폭풍 차분 30분, 특이점 시원 60분, 프리즘 차분 120분, **사격 없는** 플라즈마 시원 120분. 사망·교착·NaN·상한 초과 없음. 공격하지 않은 조건은 플레이어 처리 수 0이며 안전 회수로만 순환한다. 통과 기록은 `simulation.json`.
- 320×568 / 390×844 / 768×1024 / 568×320 / 844×390 / 1440×900의 6화면: 시작·4구성·키보드·패드·복구·회전 정지·종료 통과. PC에서는 정본 6명을 각각 실제 선택·준비했다. 390×844에서는 Chrome 터치 프로토콜로 **이동과 조준의 동시 터치**를 검증했다. `browser.json`과 화면 30장.
- 오프라인 재접속·실제 전투·low/줄인 동작·6명 캐릭터 의존 자산 로드·저장 용량 실패 통과. 처음 보는 캐릭터 매개변수 주소도 캐시된 잔광 HTML을 찾아야 한다. 이 경로가 로비 HTML로 되돌아갈 수 있던 문제를 고쳐 실제 오프라인 탐색으로 재검증했다. HTML 탐색에서만 검색 매개변수를 무시하며 JS 자산의 버전 매칭은 완화하지 않는다. `offline.json`, `offline-low.png`.
- 가상 벽시계 91초 진행으로 무입력 정지, 실제 고정 스텝 301초 진행으로 선택적 쉬기 안내, 첫 캐릭터 전달·자유 종료를 검증한다. blur 처리는 명시적인 브라우저 이벤트 fixture로 확인한다. 헤드리스 Chrome은 실제 OS 탭 포커스 변경을 재현하지 못했으므로 **네이티브 백그라운드 전환을 검증한 것으로 기록하지 않는다**. `lifecycle.json`.
- 기존 캠페인도 신규 계정으로 세 화면에서 15작전씩 **총 45작전 완주**했다. 실제 이동/조준/발사·진화·튜닝·보상·엔딩·저장을 사용하며 승리/생명/부품을 강제 주입하지 않았다. `campaign/full-journey.json`.

### 남는 실제 이용 검토

실물 보급형 Android의 30분 발열·배터리·프레임률·OS 백그라운드 복귀·이어폰 음량과, 기획의 8~12명 사용성 관찰은 이 자동 검증으로 대체하지 않는다. 휴식감·즐거움·업무 연상은 사람마다 다르며 체류시간으로 효과를 입증하지 않는다. 웹 모드는 구현했지만 Android 앱 스토어 출시나 그 품질 판정을 완료했다고 표현하지 않는다.
