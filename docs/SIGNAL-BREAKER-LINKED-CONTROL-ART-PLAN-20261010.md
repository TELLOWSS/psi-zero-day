# 시그널 브레이커 — 방향·각도 연동 조작과 현장 아트 개선

2026-10-10 · 구현·검증 기준서

## 목표와 원전 적용
마스터 바이블의 WORLD FIRST, MOBILE FIRST, ONE PRODUCTION GENERATION, 기존 엔진·좌표 보존 원칙을 적용한다. 사용자의 최신 지시대로 각도를 직접 맞춰 반사·명중시키는 게임성을 유지한다. 이동 방향을 바꿀 때 발사 방향을 다시 터치해야 하는 불편을 없애며, 자동 표적 추적이나 무입력 발사를 넣지 않는다. 기존 시그널 브레이커 엔진을 보완하고 시그널 워치와 본편의 상태·저장소는 변경하지 않는다.

## 1. 조작 명세 — 구현 완료
기본은 **이동·각도 연동**, 선택 사항은 **개별 정밀 조준**이다.

| 입력 | 이동·각도 연동의 동작 | 보존되는 게임성 |
|---|---|---|
| 이동 패드 좌우 | 좌우 이동 + 해당 방향으로 조준 벡터 반전 | 플레이어가 정한 상향 각도를 그대로 유지 |
| 이동 패드 위아래 | 상향 각도를 연속 조절 | 표적을 고르는 것은 플레이어이며 추적 없음 |
| 패드에서 손 떼기/취소 | 이동과 각도 변경 중단, 현재 각도 유지 | 발사하지 않음 |
| FIRE 버튼 누르기 | 현재 방향·각도로 발사, 누른 동안 장비 쿨다운에 맞춰 반복 | 명시적 발사 입력이 있어야 함 |
| FIRE에서 손 떼기/취소 | 반복 발사 중단 | 무입력 자동 발사 없음 |
| 전장 직접 터치/드래그 | 직접 조준. 기존 누른 채 발사/터치 해제 발사 설정 적용 | 자동 표적 추적 없음 |
| 미니맵 터치 | 직접 지정한 현장 좌표로 조준·발사 | 화면 밖 위험도 직접 판단 |
| A/D 또는 좌우 키 | 이동·각도 연동에서는 방향 반전 | 정확한 조준 각도 유지 |
| 정밀 조작 선택 | 이동과 직접 조준을 분리 | 이동하면서 뒤쪽 목표를 조준하는 자유 유지 |

조준 벡터는 플레이어 이동량에 맞춰 함께 이동한다. 왼쪽 전환은 수평 성분의 부호만 바꾸고 수직 성분을 보존한다. 입력 패드의 위아래는 초당 최대 1.6rad로 각도를 바꾸며 5°~90° 범위를 사용한다. 패드 손잡이는 손가락 이동에 반응하고 상향 각도를 숫자와 방향 화살표로 표시한다. 정지 중에는 이동·각도·물리 시간 모두 진행하지 않는다.

장비 자동/수동 전환은 기존 선택 설정이며 조준 기능과 별개다. 스캐너의 약점·순서 확인 기능과 반사 예측의 실제 엔진 판정도 유지한다.

## 2. 실제 SVG 감사와 이미지 교체
브레이커 전용 폴더에서 실행 화면에 사용되는 SVG는 앱 아이콘 1개였다. 캐릭터·장비·위험 코어는 이미 래스터 자산이며, 경로·조준선·에너지·상태 효과는 Canvas 렌더링이다. 이를 전부 SVG라고 분류하지 않는다.

- 아이콘: 유니크한 이미지 제작 후 PNG 192/512 크기로 패키징. HTML favicon 및 PWA manifest 교체. 활성 SVG 요청 0개 검증.
- 원래 `icon.svg`는 마스터 바이블의 롤백 보존 원칙에 따라 파일만 보관한다. 실행 이미지로 사용하지 않는다.
- 산업 장치: 새 투명 아틀라스에 방호판, 완충 장치, 전자석, 회수 게이트, 릴레이, 보스 전력 허브 6종 제작·교체.
- 맵: 서로 다른 건축 구조·재료·조명·현장 맥락을 가진 5장 제작·연결.
- 기존 캐릭터 얼굴·장비 6종·위험 코어 재료 이미지 및 애니메이션 체계 유지. 좌표를 생성 이미지에 맡기지 않는다.

## 3. 스테이지별 현장과 플레이 변화
| 작전 | 새 맵 | 핵심 장치·동작 | 플레이어의 판단 |
|---|---|---|---|
| CH-01 첫 반사 | 주간 반입 야드 | 방호판·완충 장치·자력장 | 기본 각도와 반사 후 회수 |
| CH-02 이동 반입 | 컨베이어 반입 홀 | 벨트 방향 + **7초 주기로 좌우 65px 이동하는 완충 장치** | 움직이는 충돌 위치와 회수 동선을 읽기 |
| CH-03 집진 통로 | 지하 집진·환기 공간 | 미스트 안정화 + **5초 개방/3초 대기 집진 게이트** | 안정화 후 개방을 기다리거나 포획망 직접 회수 |
| CH-04 장력 릴레이 | 고층 양중 플랫폼 | 장력선·앵커 고정·순차 릴레이 | 각도 변화와 고정 시점을 직접 만들기 |
| CH-05 반입동선 혼선 | 야간 전력 중계실 | 순차 보스 노드·스캔·8초 약점 노출 | 회로 순서를 읽고 노출 시간 안에 직접 명중 |

시험판 SB-01~04도 대응하는 새 맵을 사용한다. 새 완충 장치의 시각 위치와 실제 충돌 위치는 동일한 엔진 메서드가 제공한다. 이동 속도를 충돌 상대 속도에 반영한다. 게이트 상태·남은 시간도 엔진이 제공하며, 닫힌 상태에서는 코어를 소비하지 않는다. 일반 스테이지의 기존 게이트는 상시 개방 상태를 유지한다.

## 4. 지루함을 줄이는 진행 기획
이번 구현은 배경색 변화만으로 반복을 숨기는 대신 **각도 → 이동하는 충돌 위치 → 회수 시간 창 → 장력 고정 → 순차 약점**으로 판단 과제를 바꾼다. 새 장치를 한꺼번에 던지지 않고 기존 5개 작전에서 순서대로 소개한다. 전장 상황은 버튼 설명보다 실제 움직임·상태 색·게이트 카운트다운·충돌 반응으로 전달한다.

재도전의 초점은 같은 위험을 더 빨리 없애기보다 새로운 반사 경로와 장비 조합을 시도하는 것이다. 수동 조준, 기존 실제 발사 경로 재생, 연쇄 기록, 장비 성장·LAB을 유지한다. 이동·발사를 자동으로 해결하여 명중의 성취를 없애지 않는다.

후속 기획 항목(이번 구현에 포함하지 않음): 스테이지별 반사 경로 숙련 목표, 선택 가능한 장치 조합 변형, 현장 사건과 연결되는 짧은 결과 연출. 보상 공식·챕터 수·새 캠페인은 추가하지 않았다.

## 5. 이미지 제작·성능·좌표 계약
내장 imagegen으로 7개 이미지 자산(맵 5, 장치 아틀라스 1, 아이콘 1)을 각각 제작했다. 원본을 새 버전 WebP로 인코딩해 기존 롤백 자산과 구분한다. 실제 맵 해상도는 **1672×941**, 장치 아틀라스는 **1536×1024**다. 생성기가 반환한 실제 크기이며 업스케일을 4K 원본으로 표시하지 않는다. 기존 4분할 환경 아틀라스의 타일보다 개별 맵의 유효 해상도가 높다.

현장 그림의 바닥 경계를 수동으로 확인하고, 렌더러에서 고정 GROUND=536에 맞춘다. 하단 보행 영역과 플랫폼 지지 구조를 분리 렌더링하여 세로 화면 하단을 늘린 한 줄 텍스처로 채우지 않는다. 새 장치도 측정한 아틀라스 영역만 사용해 이웃 이미지가 섞이지 않게 한다. 이미지에 HUD·조작·충돌 좌표·텍스트를 넣지 않는다.

모바일은 기존 balanced 프리셋을 유지한다. 배경 캐시는 스테이지/품질/이미지 로딩 완료 상태가 바뀔 때만 갱신한다. 반사 예측 계산은 high 15Hz / balanced 10Hz / low 6Hz로 제한하며 실제 물리는 기존 고정 스텝을 유지한다. 저사양 효과 수 상한과 reduced-motion 설정을 유지한다. 캐릭터·이미지의 디코딩은 기존 공유 이미지 캐시를 사용한다.

## 6. 검증 기준과 증거
- 독립 회귀: 방향 반전 시 각도 보존, 경계까지 이동할 때 각도 보존, 상하 각도 조절, 무입력 발사 없음, 정지 중 변경 없음.
- 장치 회귀: 이동하는 충돌 형태와 렌더링 위치의 일치, 실제 충돌 반사, 게이트 주기와 닫힌 상태의 코어 보존, 정지 시 장치 시간 동결.
- 브라우저: 5개 맵 × 세로/가로 2방향, PNG 아이콘, 장치 아틀라스, 패드 좌우/상하 조작, 직접 발사와 손 떼기, 무입력 발사 없음, JS/HTTP 오류와 활성 SVG 요청 없음.
- 기존 몰입형 회귀: 6개 viewport, 두 손가락 이동/조준, 누름/해제/취소, 자동/수동 장비 선택, pause/resume, 시야 전환, 회전, 결과 경로 접힘/펼침과 버튼 터치 영역.

## 7. 남은 실기기 판정
실제 Android/iPad에서 두 엄지 도달 범위와 이동 패드의 상하 각도 민감도, 3분 이상 혼잡 장면 FPS·발열을 확인해야 한다. 이번 생성물은 실제 런타임에 연결한 새 Production 후보 자산이며, 영화급 최종 미술 Lock이나 시그널 워치와의 완성도 동등성을 선언하지 않는다. 운영 URL에 최신 소스가 배포됐는지 확인한 것과 GitHub 반영은 구분한다.
