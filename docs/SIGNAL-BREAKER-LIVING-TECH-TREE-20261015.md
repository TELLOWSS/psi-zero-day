# 시그널 브레이커 — 이미지 기반 기술망

2026-10-15 사용자 요청에 따라 전용 이미지를 제작하고 테크트리 화면을 교체했다. 생성에는 기본 내장 `image_gen` 도구를 사용했다. CLI/API 키나 다른 이미지 서비스를 사용하지 않았다. 아래 PNG는 생성 결과 원본이고, 게임에는 같은 구도의 WebP를 사용한다.

## 제작 이미지와 최종 경로

| 용도 | 게임 파일 | 원본 | 크기 |
|---|---|---|---|
| 3계열 기술 연구실 | `public/signal-breaker-dev/art/tech-reactor-world-v1.webp` | `docs/art/signal-breaker-tech-tree-20261015/tech-reactor-world-v1.png` | 1672×941 |
| 15개 기술 장치 | `public/signal-breaker-dev/art/tech-nodes-atlas-v2.webp` | `docs/art/signal-breaker-tech-tree-20261015/tech-nodes-atlas-v2.png` | 971×1620, 3열×5행 |

두 게임 이미지의 합계는 870,908바이트(약 0.83MiB). 원본을 임의로 다시 그리거나 확대하지 않고 WebP 품질 92로 저장했다. 첫 atlas의 공학 3단계 그림이 스캐너와 맞지 않아 내장 도구로 해당 칸만 수정한 v2를 최종 선택했다. v1 PNG는 수정 입력 이력이며 최종 게임 이미지가 아니다.

전체 생성 프롬프트와 수정 프롬프트, 원본 경로·배치 순서는 `public/signal-breaker-dev/art/tech-tree-art-v1.json`에 보존했다. 기획은 실제 게임 기술에 맞춘 건설현장 연구실/가공 금속/구리 코일/유리/에너지 배관이다. 방호는 녹색, 키네틱은 주황, 공학은 보라색으로 구분했다. 상용 게임 이미지나 캐릭터를 참조하지 않았다. 생성 이력 보존은 별도의 권리 증빙을 대체하지 않는다.

## 실제 화면과 상호작용

- 배경 그림, 15개 장치 그림을 실제 테크트리 UI에 적용했다. 한글 이름·등급·잠금 이유·비용은 그림에 박아 넣지 않고 DOM으로 제공한다.
- 기존 카드 열을 기술망으로 교체했다. 완료된 선행 기술에서만 연결선에 에너지가 흐른다. 부분 투자와 완료, 추천 노드, 선행 조건 미충족을 색상·문구·등급으로 함께 구분한다.
- 기술 이미지 선택은 설명 확인이다. 잠긴 기술과 미래 단계도 읽을 수 있으며 포인트를 쓰지 않는다. 설명 패널의 ‘이 기술에 투자 · 1P’만 실제 투자다. 기존 초보자 추천 1회 적용도 유지한다.
- 투자 직후 장치의 점등과 고리 효과를 보여 준다. 연구실에는 느린 발광 호흡, 연결선에는 짧은 에너지 이동을 적용했다. 무작위 깜박임·화면 진동·무한 JS 파티클 루프를 넣지 않았다.
- 세로/작은 가로 화면은 세 계열 버튼으로 한 경로씩 탐색한다. PC는 세 경로를 나란히 비교한다. 긴 기술망에서는 선택한 설명으로 이동하고 ‘선택한 기술 위치로’ 돌아올 수 있다.
- 성장 규칙은 펼칠 수 있는 설명으로 정리했다. 투자 이후 스크롤 위치를 유지하고, 탭을 바꾸면 새 탭의 시작으로 이동한다.
- 장비 탭에는 기존 승인된 6종 장비 그림을 활용한 24개 단계 미리보기를 추가했다. 미리보기는 부품/젬을 소비하지 않으며 실제 개조·소켓 거래는 기존 버튼과 관리자가 처리한다. 24개 별도 새 무기 원화를 제작한 것으로 계산하지 않는다.

## 안전한 적용 범위

특성 효과·가격·선행 조건·31P 한도·보상·캐릭터별 저장·전투 판정은 기존 `TalentTechManager`와 엔진을 사용한다. 새 모듈이 기억하는 것은 선택한 경로/노드와 연출 상태뿐이다. 저장 실패 시 투자 취소와 저장 재시도 안내를 유지한다. 캐릭터 얼굴과 이미지를 교체하지 않았다.

연출 정지 버튼을 제공하며 줄인 동작 설정과 low 화질에서는 정적으로 표시한다. 시스템의 `prefers-reduced-motion`도 CSS에서 따르고, 닫힌 창의 애니메이션은 정지한다. 포인트 선택·해금 표시와 위험/전투 판정은 애니메이션 여부와 관계없이 같다.

이미지·JS·CSS·제작 이력 JSON을 서비스워커 캐시에 추가했다. 릴리스는 `0.60.0-living-tech-tree`, 자산은 177개다. PNG 원본은 제작 문서용이며 모바일 게임 캐시에 넣지 않는다.

## 검증

새 그래프 테스트는 15개 실제 ID/서로 다른 그림 칸, 잠긴 기술 확인의 무과금, 실제 1P 투자와 선행 노드 연결, 저장 실패 시 투자 취소, 계열 선택의 상태 불변, 연출 정지/줄인 동작/low 화질을 확인한다. 기존 캐릭터 성장과 장비 거래의 검증도 유지한다.

브라우저는 320×568, 390×844, 568×320, 844×390, 768×1024, 1440×900와 줄인 동작 모드에서 이미지 로딩·가로 넘침·선택·5회 실제 투자·연결선·장비 24단계 미리보기·비용 불변·정지 동작을 확인한다. 오프라인에서는 캐시 설치 후 네트워크를 끊고 새로고침해 이미지와 투자 상태를 다시 확인한다. 수치 변경이나 강제 승리로 화면을 검증하지 않는다.

자동 브라우저 검증은 실제 Android 기기의 프레임률과 주관적인 미적 만족도의 증거가 아니다. 최종 시각 판단은 직접 기술망을 열어 해금 전후를 비교하는 방식으로 할 수 있다.

확인 결과: Breaker 296개 테스트(새 그래프 5개 포함), 본편 2,068개 통과/기존 1개 스킵. TypeScript 검사와 배포 빌드 통과. 7개 브라우저 조건에서 잠금·이미지·실제 5P 투자·계열 선택·정지·미리보기·화면 넘침 검증 통과. 기존 캐릭터 3개 화면 회귀(독립 투자·교대·실제 능력치·훈련 저장 격리)와 오프라인 이미지/실제 투자/재접속 보존도 통과했다. 결과 JSON과 스크린샷은 `docs/qa/living-tech-tree-20261015/`, 기존 캐릭터 회귀 로그는 `artifacts/living-tree-careers-final.log`에 보존했다.
