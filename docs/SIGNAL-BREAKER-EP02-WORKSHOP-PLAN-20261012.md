## 2. 손쉬운 관심과 반복 동기

처음에는 잠긴 EP02 현장 이미지와 한 줄 훅으로 다음 작전을 예고한다. 진입 전 전격·레이저 선택은 그대로 유지한다. 교전 중에는 ‘반사 1/3’처럼 현재 목표만 읽는다. 달성 순간 짧은 PSI 신호 응답과 충전 보상을 보여준다. 종료는 기존 회복 엔딩 → 다음 작전 직접 선택이다. 6~10은 장갑 상성·부품 진화·기존 현장 장치가 핵심이며 단순 HP 증가만 새 콘텐츠라고 주장하지 않는다.

## 3. 이미지 기반 HUD

PSI는 사고 전 신호를 읽고 흐름을 끊는 안전지능이다. UI는 산업용 수신기·보호 케이블·회로 광원·신호 칩을 표현한다. 실제 생성한 투명 이미지 부품을 HUD 프레임, 보스 계기판, 발사 베젤, 이동/조준 링, 방호 셀에 사용한다. 배경이 보이는 투명 창을 유지하고 숫자·한국어·버튼 접근성은 DOM 텍스트로 표시한다. 이미지에 숫자와 설명을 구워 넣지 않는다. 모바일 44px 이상 입력 영역, 기존 버튼 위치와 충돌 판독성을 보존한다.

기본 FIELD 수신기는 무료 적용한다. 황동 관제·전력망 수신기는 서로 다른 프레임 원화를 사용한다. 저사양에서는 지속적인 점멸·확대 애니메이션을 억제한다. 외형 때문에 판정·장갑·경고 구역을 가리지 않는다.

## 4. PSI 크레딧 장비실

브레이커가 이미 지급하는 PSI 크레딧을 사용한다. 현금 결제, 충전 결제, 확률형 상품, 외부 결제 서버는 구현하지 않는다. 가격을 먼저 표시하고 구매 즉시 영구 보유한다. 보유품의 재장착은 무료다. HUD·조준기·잔광·작전 모듈 각 한 개를 선택한다. 모든 구매는 저장 성공 후 확정하며 저장 실패 시 차감과 지급을 함께 되돌린다.

| 종류 | 상품 | 가격(CP) | 적용 |
|---|---|---:|---|
| HUD | FIELD / 황동 / 전력망 | 무료 / 180 / 240 | 다른 실제 프레임 이미지 |
| 조준기 | 신호 링 / 비콘 / 프리즘 | 무료 / 80 / 120 | 실제 이미지 조준 표시 |
| 잔광 | 기본 / 앰버 / 이온 | 무료 / 100 / 140 | 발사 잔광 색, 피해량 유지 |
| 모듈 | 기본 / 릴레이 / 촉매 / 관측 | 무료 / 180 / 300 / 220 | EP02 한 슬롯, 아래 규칙 |

- 릴레이: 작전 시작 20P. 강화에 40P가 필요하므로 실제 위험 해소와 추가 충전이 필요하다.
- 촉매: 해당 작전의 진화 요구 부품 5→4. 장갑 피해를 직접 늘리지 않고 진화 선택을 앞당긴다.
- 관측: 신호 체인 달성 시 추가 30P. 작전당 한 번이며 관찰·개입을 수행해야 한다.
- 모듈은 EP02 해금 후 구매할 수 있고 다음 새 작전부터 적용한다. 진행 중 모듈 교체로 충전·진화 조건을 재계산하거나 보상을 반복 받지 않는다. 현재 적용 모듈과 다음 장착 모듈을 구분한다.

첫 클리어 보상과 반복 클리어 중복 방지는 기존 규칙을 유지한다. 일반 공격과 무료 진화로도 완료 가능한 기준을 보존한다. 모든 상품은 능력 설명·가격·보유·선택 상태를 확인할 수 있게 한다. 사람의 재미·승률과 Android 실기기 성능은 별도 플레이 검토 항목이다.
