# 시그널 브레이커 발사·명중 연출 강화

2026-10-14 / `0.54.0-combat-vfx` / 이전 배포 `681f956a`

최신 종합 기획서 v4.5의 산업 안전 개입 장비와 기존 원화·재질·색을 기준으로 발사·명중 효과를 강화했다. 기존 발사체 atlas가 정상 로딩되는 경로에서도 전격·레이저 등 장비별 꼬리 연출이 적용되도록 연결했다. 원화를 재제작하거나 새 원화를 최종 승인한 작업은 아니다.

## 강화한 연출

| 범위 | 적용 |
|---|---|
| 에어 펄스·반사 집중탄 | 방향을 따르는 짧은 섬광, 따뜻한 펄스/청록 반사탄 잔광, 충돌 지점의 금속 파편 |
| 공명 충격파 | 겹치는 압력 고리와 짧은 파면 |
| 포획망 | 전개 고리, 회수 지점의 수축 고리와 6방향 잠금 표시 |
| 자력 유도기·회로 스캐너 | 기존 장비색의 단계적 전개 고리, 짧은 잔광 |
| 미스트·장력 앵커 | 넓은 분사 섬광/짧은 장력 발사선, 분진의 퍼지는 고리/편하중의 굵은 충격선 |
| EP02 전격 | 발사 시 짧은 아크, 실제 궤적의 짧은 꼬리, 실제 연쇄 이벤트의 분기 선 |
| EP02 레이저 | 분홍 외곽과 밝은 중심선, 실제 관통 이벤트의 일직선 잔광 |
| 장갑·보스 명중 | 일반 신호와 구분되는 장갑색·보스 충격 반경 |
| 겹침·밝기 | 기존 명중 원화가 새 파편과 겹쳐 중심부가 과하게 하얗게 번지던 합성 완화. 원화 크기·투명도 조정, 추가 발광은 반경 17–22 월드 단위로 국소화 |
| 움직임 감소 | 새 연출의 밝기 감소, 분기 흔들림·국소 발광 감소. 기존 코드에서 남아 있던 화면 흔들림과 전체 화면 섬광도 억제 |

기존 캐릭터 발사 자세·음향·반동과 연결한다. 새 효과는 `CombatVfx`가 소유하며 게임 상태·랜덤·명중 판정·재장전·보상·저장에는 쓰지 않는다. 꼬리는 기존 실제 탄도 점을 따라 그려 반사 궤적을 바꾸지 않는다. 가짜 명중이나 화면 전체 레이저를 추가하지 않았다.

## 성능·검증

- 추가 이벤트 효과 동시 상한: 저화질 8, 균형 16, 고화질 28. 발사 효과 0.16초, 명중 0.25초, 포획 0.38초 후 제거. 기존 파편 상한은 유지한다.
- 추가 JS는 서비스워커에 포함. 릴리스·캐시와 99개 자산 해시 갱신. 신규 대용량 이미지 다운로드는 없다.
- standalone 테스트 265개 통과: 실제 전투 이벤트 표시 전후 게임 상태 불변, 이벤트 폭주 상한·수명, 모든 장비/화질/움직임 감소의 유한 좌표와 canvas save/restore 균형 검사 포함.
- root 테스트 2,059개 통과·1개 기존 skip, 타입 검사·빌드 통과. 총 통과 2,324개.
- 브라우저 360×640, 844×390, 1440×900의 실제 발사·원화 로딩·효과 상한·일시정지 설정을 통한 움직임 감소 확인. 콘솔 예외 없음.
- 별도 연출 fixture에서 8장비·2프레임과 재질별 명중을 비교해 원화와 합성 확인. 1,000개 이벤트 폭주 fixture도 각 화질의 상한 유지. 이 갤러리는 전투 승리 시뮬레이션이 아니다.
- 새 효과 draw CPU 시간의 데스크톱 브라우저 p95는 저화질 약 0.1ms, 균형 약 0.2ms, 고화질 약 0.3ms. 계측 해상도가 낮은 짧은 실행이고 GPU·전체 게임 프레임·모바일 성능을 측정한 값이 아니다.
- 실제 입력으로 3개 방향의 10개 작전·엔딩·보상·강화·소켓·재접속 흐름도 회귀 검사. 최종 결과는 `docs/qa/signal-breaker-combat-vfx-20261014.json`에 기록.

## 남은 확인

실제 모바일 기기의 발열·GPU 프레임 시간, 사람의 장비별 타격감·경고 가독성·장시간 피로 평가는 남는다. 밝기와 파편 강도를 더 높이는 판단은 이 평가 결과를 기준으로 한다. 기존 원화의 최종 visual lock과 유료 구매 가치는 이번 자동 검사만으로 승인하지 않는다.
