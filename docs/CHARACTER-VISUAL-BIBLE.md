# PSI : ZERO DAY — Character Visual Bible

상태: TASK-009E approved direction.

## 최종 방향

캐릭터는 **상용 캐주얼 전략게임 수준의 2.5D 건설현장 디오라마 스타일**로 제작한다. 귀엽고 접근성이 높지만 유아틱하지 않으며, 실제 건설현장 직군과 역할이 한눈에 구분되어야 한다.

핵심 규칙:

1. 이름표를 읽지 않아도 실루엣만으로 1차 구분 가능해야 한다.
2. 각 캐릭터는 `체형 + 얼굴 + 복장 + 소품 + 자세` 중 최소 3개가 다른 캐릭터와 명확히 달라야 한다.
3. 안전모 색깔만 바꾼 복제 캐릭터는 금지한다.
4. 얼굴형·눈·코·입·연령감도 반복하지 않는다.
5. 안전모에는 실제 회사명·가짜 문자·의미불명 로고를 넣지 않는다. 단순 추상 표식만 사용한다.
6. 지도용 캐릭터는 작은 크기에서도 소품과 실루엣이 남아야 한다.
7. 초상화와 맵 스프라이트는 동일 인물로 즉시 인식되어야 한다.
8. 사고 장면도 슬랩스틱으로 표현하지 않는다.

## Player 캐릭터

현재 승인된 비주얼 기준에서는 Player를 **젊은 여성 안전관리자**로 고정한다. 대사·규칙에서 성별을 과도하게 강조하지 않으며, 게임의 대표 얼굴 역할을 맡는다.

- 흰 안전모 + 단순 청색 PSI 계열 스트라이프.
- 검측 태블릿.
- 청색 안전조끼.
- 친근하지만 현장에서는 판단을 주도하는 자세.
- 작은 맵 스프라이트에서도 머리 실루엣과 태블릿이 보여야 한다.

## 역할별 대비

### 강태식 vs 윤성호

둘 다 베테랑 반장이므로 특히 겹치기 쉽다.

- 강태식: 둥글고 넓은 체형, 콧수염, 주황색, 지시 동작.
- 윤성호: 근육형 V 실루엣, 각진 얼굴, 황색, 철근 소품.

### 이재훈 vs 임준호

둘 다 젊은 인물이므로 얼굴 나이와 비율을 분명히 한다.

- 이재훈: 30대 초반, 키 크고 슬림, 정돈된 복장, 도면.
- 임준호: 20대 초반, 작은 체형, 둥근 얼굴, 녹색 현장복, 무전기.

### 서정민 vs 오승재

둘 다 흰 안전모 관리직이므로 안경·체형·소품으로 분리한다.

- 서정민: 마르고 차분함, 안경, 클립보드.
- 오승재: 넓은 체형, 피곤한 관리직 인상, 휴대전화.

## 제작 규격

- Portrait: WebP, 투명 배경, 상반신 중심, 최소 1024×1024 원본.
- Map sprite: WebP, 투명 배경, 3/4 view, 최소 768×1024 원본.
- 게임 내 축소 시 헬멧·소품·체형이 유지되어야 한다.
- 동일 seed/동일 얼굴을 재활용하지 않는다.
- 표정 기본 세트: neutral / concern / resolve / relief / conflict.
- 캐릭터마다 표정 세트는 인물 고유 얼굴형을 유지한다.
