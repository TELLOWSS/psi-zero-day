# 윤성호 대화 표정 통합

윤성호의 협력 반응 대사 `ep01.reactions.yoon.high`에 전용 표정 원화를 연결했다. 실제 화자와 대사 ID가 모두 맞을 때만 `yoon-sungho-appreciative.webp`를 사용한다. 낮은 신뢰 반응과 등록되지 않은 대사는 기존 초상화를 유지한다.

원화는 기존 윤성호 초상화를 참조해 built-in image_gen으로 편집했고, 1254×1254 투명 WebP로 저장했다. 생성 프롬프트는 `docs/DIALOGUE-ART-PROMPTS-2026-09-18.json`에 추가했다.

`VisualImage`에는 전용 원화 로딩 실패 시 기본 초상화로 복귀하는 경로를 넣었다. 동일한 파일을 기본값으로 중복 지정해도 오류 재시도를 반복하지 않는다. 이 변경은 게임 규칙, 분기, 저장 상태를 바꾸지 않는다.

남은 일은 윤성호의 다른 감정 변형, 전 인물의 동작 애니메이션, 외부 플레이테스트다. 표정 파일의 기술적 로딩 성공은 현장 안전 판단의 인증을 의미하지 않는다.
