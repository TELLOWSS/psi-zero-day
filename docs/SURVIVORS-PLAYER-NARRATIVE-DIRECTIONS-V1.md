# 안전관리자 세 서사 방향 V1

2026-10-09 사용자 직접 답변: **서사 방향 구체화 승인**, 이어서 **문장·표시·변경 가능 저장 승인**. 질문에 제시한 아래 세 문장과 표시/변경 가능한 작은 저장 정책만 승인됐다. 로컬 기록 UI에 연결했으며 새 파일/음성/진로 공식 승인이 아니다. 운영 미반영.

## 공통 의미

직업 판정 대신 앞으로 더 맡아보고 싶은 역할이다. 세 방향 모두 가치가 있고 언제나 현재 안전관리자의 직무·정체성을 유지한다. 공격력/보상/수리비/실제 자격·승진에 차이가 없다. A/B 인계 문장 하나로 진로를 자동 지정하지 않는다. 실패, 유료 장비, 접속 일수도 방향 잠금 근거가 아니다.

| 방향 | 관심 | 확인 가능한 회고 | 확인하지 않는 것 |
|---|---|---|---|
| 현장 통제 전문 | 중지와 재개 경계를 명확히 전달 | 통제 구역·제동·정리의 실제 횟수 | 완전 안전 보증·법적 권한 |
| 작업 조율·멘토링 | 다음 팀이 질문하고 이해할 여지를 남김 | 실제 인계 기록과 사용자가 선택한 문장 | 동료의 신뢰 상승·후배 양성 완료 |
| 위험 조사·개선 | 관측한 것과 더 확인할 것을 구분 | 실제 기록의 존재/부재를 함께 읽기 | 전투 횟수로 조사 능력 측정 |

## 최종 문장 검토안

제목: **다음에 더 맡아보고 싶은 역할**

- 현장 통제 전문: “중지와 재개 경계를 더 명확히 전달하는 역할을 맡아보고 싶어요.”
- 작업 조율·멘토링: “다음 팀이 질문하고 이해할 수 있도록 함께 확인하는 역할을 맡아보고 싶어요.”
- 위험 조사·개선: “확인한 것과 아직 모르는 것을 나누어, 위험의 원인을 더 살피는 역할을 맡아보고 싶어요.”

문장은 미래 관심사이지 이미 획득한 성격·성과·직업이 아니다. 새로운 동료 응답이나 확정 후일담은 포함하지 않는다. 기존 음성을 이 문장처럼 재생하지 않는다.

## 승인된 표시·선택 정책

첫 시범의 실제 player/STAGE12 완료·통로 기록과 승인 대화 선택이 확인된 뒤, 전투 밖 기록에서 선택형으로 표시한다. 결과 화면에 필수 선택을 추가하지 않는다. “나중에”로 기존 다음 작전 준비를 유지한다. 저장 전에는 선택 완료로 표시하지 않으며 실패 시 동일 선택을 재시도한다.

변경 가능한 관심사 한 개를 기록하고 다시보기는 쓰기 없이 읽는다. 승인된 별도 저장 `psi.survivors.narrative-direction.v1`에는 `{version:1, characterId:'player', direction:'control'|'coordination'|'investigation'}`만 저장한다. 동일 관심사 저장은 추가 쓰기를 하지 않는다. 추정 점수·시간순 성장 로그·새 Career 상태는 만들지 않는다. 기존 종료 수치와 인계 대화 선택을 덮어쓰지 않는다. 다른 캐릭터에 공유하지 않는다.

## 이미지 후속 브리프 (미제작)

### 현장 통제 전문 V1 승인·로컬 연결

2026-10-09 기존 player 초상 및 승인 인계 CG를 reference로 built-in image_gen 원화1장을 제작했다. 사용자는 표시된 정확 파일에 `디자인·파일 승인, 검증 후 연결`이라고 답변했다. `PLAYER-CONTROL-INTEREST-APPROVAL.json`에 SHA/출처/의미/경계를 기록했다. 유효한 인계·승인 대화 및 저장된 control 관심사일 때만 전투 밖에 표시한다. 초안 선택만 바꾸거나 저장에 실패하면 기존 저장 관심사의 그림을 유지하고 coordination/investigation 저장시 숨긴다. 승진/자격/직업 획득이나 새 능력치·음성은 없다.

집중9건, 타입/prebuild/build 통과. 실제 빌드3viewport decode/contain/다른관심사숨김/저장실패/재시도/actor분리/44px/오류넘침 검증 통과. 낮은 가로에서는 화면 높이에 맞춘 contain 표시로 고정 상하단 사이 전체 그림을 볼 수 있게 했고 가로 PNG를 직접 확인했다. 최신 CSS 보완 뒤 Vite 빌드 및3화면 재검증 통과. 전체1894pass1skip은 원화 연결 직전 회귀이며 최종 변경 전체 회귀로 확대하지 않는다. 운영/사용권/실기기는 별도다. 조율·조사 원화는 미제작이며 현재 파일 승인을 확장하지 않는다.

첫 성장 인계 CG의 얼굴/PPE/체형을 기준으로 동일 인물을 유지한다. 통제는 출입 경계와 재개 확인, 조율은 서로 바라보며 인계 항목 확인, 조사는 실제 상태를 관찰하는 장면을 고려한다. 직함·훈장·자격증 문자를 그림에 넣지 않는다. 새 그림 없이도 텍스트 시범이 검증될 때만 한 장씩 납품하며 파일 승인 전 public/runtime에 넣지 않는다.

## 구현 게이트

최종 세 문장, 표시 조건, 변경 가능한 선택 정책과 작은 저장 계약 승인 후 domain 값 검증 → app 실패/복구 → 기존 기록 UI 연결을 구현했다. 집중 저장 계약4건 및 PC·폰세로·폰가로3경로에서 대화 전 숨김/즉시 연결/건너뛰기/3방향 변경/실패 이전값 유지/재시도/중복/새로고침/44px/초점 복구/다른 캐릭터 분리를 통과했다. 증거 `artifacts/narrative-direction/report.json`과3PNG. 저장 handoff fixture이며 자연 성장/실기기 증거는 아니다. 최종 추가 CG·새 음성·실기기 승인은 별도다.
