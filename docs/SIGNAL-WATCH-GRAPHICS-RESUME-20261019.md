# 시그널 워치 그래픽 고도화 재개 · 2026-10-19

## 확인한 중단 지점

최근 로컬 작업은 스토리와 GUARD의 기획·기록·접근성 보완으로 옮겨가 있었다. 작업 중이던 로컬 브랜치는 `7eb90e61`이었고, 원격 main의 최신 워치 작업은 `fb7daca5`였다. 기존 변경을 덮지 않기 위해 `../psi-watch-graphics-20261019`, `work/watch-graphics-resume-20261019`에서 최신 main을 기준으로 재개했다.

기존 구현을 다시 확인한 결과, 50스테이지 공통 색보정·조명·깊이, 인물의 현재 원화 윤곽 그림자, 장비 3종의 Y 가림 처리, 승인된 전경 마스크의 연결 기반은 이미 있었다. 전경 마스크 자산 목록은 실제로 비어 있었다. 이번 작업을 50종 마스크 완성이나 새로운 인물 애니메이션 제작으로 계산하지 않는다.

## 이번에 구현한 것

1. STAGE 02 굴착 현장의 기존 원화를 편집해 `excavation-ground-v4.webp`로 연결했다. 수평 녹색 통로와 둘레 흙막이 배치를 유지하며 토양의 넓은 재질 변화, 강재의 두께·부식, 목재·배수재의 재질 구분을 보강했다. 첫 후보의 과도한 잔무늬는 두 번째 편집에서 완화했다. 원본 v3는 보존한다.
2. 실제 `active` 투광등의 좌표·범위에 따라 인물 원화의 조명 색, 밝기와 윤곽 그림자 방향을 조절한다. 서로 마주보는 등은 부드럽게 혼합하며, 경고·파괴 상태와 비광원 설비는 제외한다. 50스테이지 공통 렌더러에 적용하되 광원이 없는 곳의 기존 표현은 유지한다. 저사양의 접지 그림자와 조명 끄기 설정도 유지한다.
3. 같은 원화 배치·인물 자세에서 전후를 비교하는 개발용 검수 화면을 `tests/visual/watch-graphics-review.html`에 추가했다. 50현장, 세 품질, 정지/동작, 광원 켜기/끄기와 인물 위치를 비교할 수 있다. 제품 메뉴와 저장·해금 흐름에는 추가하지 않았다.

`survivors-local-light.ts`는 presentation 전용이다. 엔진, 보상, 성장, 충돌, 스폰, 해금과 저장 스키마는 변경하지 않았다. 원화 후보는 최종 시각 승인과 구별한다.

## 원화와 재현

빌트인 `image_gen`의 기존 이미지 편집을 두 번 사용했다. 선택한 PNG 원본은 `docs/art-source/watch-graphics-20261019/excavation-ground-v4-source.png`, 실제 게임 자산은 `public/assets/survivors/excavation-ground-v4.webp`다. 1536×1024를 리샘플링 없이 WebP quality 90으로 인코딩했다. 전체 프롬프트는 같은 폴더의 `prompts.json`, 입력·원본·배포 파일의 SHA-256은 `provenance.json`에 있다.

검수 URL: `http://127.0.0.1:5191/tests/visual/watch-graphics-review.html`. 실행 중 개발 서버는 이 작업 폴더의 `npm run dev -- --host 127.0.0.1 --port 5191 --strictPort`다.

## 검증과 한계

실제 게임 STAGE 01에서 정상 시작, 대응 8회, 레벨업 선택과 일시정지를 조작했고 새 광원 영향 값과 기존 원화 그림자가 함께 표시됨을 확인했다. 테스트 편의를 위한 게임 해금·자원·엔진 상태 주입은 하지 않았다. STAGE 02는 비교용 렌더 검수 화면으로 확인했으며, 정상 플레이 클리어로 보고하지 않는다.

검수 화면에서 50개 현장의 실제 바닥 자산을 차례로 디코딩하고 공통 인물·조명 렌더를 확인했다. 1440×900, 390×844, 844×390에서 high/low 6경우와 광원 끄기를 확인했고 가로 넘침이 없었다. 이는 50현장의 전체 HUD·전투·승리 검사가 아니다. 동작 체크 해제는 검수 화면의 애니메이션 정지이며 운영 게임의 모든 reduced-motion 효과 검사를 뜻하지 않는다.

첫 전체 검사 2,352 통과·1 실패는 기존 브랜드 SVG의 CRLF 체크아웃으로 승인 해시가 달라진 데서 발생했다. 공식 빌드도 공유 presentation-cache JS의 같은 문제로 처음 중단됐다. 두 파일을 기록된 SHA-256과 일치하는 Git 원본 바이트로 복원하고 `.gitattributes`에 두 경로의 LF 규칙을 추가했다. 해시를 새 값으로 바꾸거나 검사를 완화하지 않았다. 그 외 모드의 기능은 수정하지 않았다.

실행 로그와 화면은 `artifacts/watch-graphics-20261019/`에 보관한다. 최종 자동 검사 수치는 종료 후 아래에 기록한다.

최종 결과: `npm test -- --maxWorkers=4` 2,353 통과·0 실패·기존 1 skip. `npm run typecheck` 및 공식 `npm run build` 통과. 기존 큰 청크 경고는 유지한다. 자동 전처리가 재생성한 스토리 카탈로그 변경은 이번 워치 변경에서 제외했다.
