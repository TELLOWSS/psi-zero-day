# 시그널 가드 — 캐릭터 확장 보강안

2026-10-15 · 독립 캠페인 기획 보강 · **신규 능력/해금/트리는 기획이며 미구현**

## 1. 권장 수정: 첫 제작 4명, 정규 캠페인 6명

앞선 기획의 2명은 현재 작동하는 지원 능력을 기준으로 잡은 최소 검증 범위였다. 독립 게임의 정식 캐릭터 구성으로는 부족하다. **첫 3작전에서 4명, 정규 캠페인에는 기존 세계관 인물 6명**을 권장한다. 처음부터 임의의 새 얼굴을 늘리기보다 워치/브레이커에서 만난 인물을 새로운 전술로 다시 좋아하게 만든다.

6명은 **안전관리자(플레이어), 강태식, 윤성호, 이재훈, 임준호, 최민석**이다. 이름과 실제 역할은 `content/episode01/{characters,ko}.json`, 얼굴/전신은 WATCH 순찰 요원의 승인된 자산을 따른다. `player`의 표시 이름은 기존 플레이어 설정을 사용하고 새 고정 이름을 붙이지 않는다.

현재 실제 지원 효과가 있는 것은 강태식/임준호 두 명이다. COMMANDER/REBAR_LEAD/ENGINEER의 이름 매핑이 있다는 사실을 완성된 능력으로 보지 않는다. 최민석은 현재 디펜스 지원 ID도 없으므로 콘텐츠·명령·저장·UI 계약을 함께 추가해야 한다.

## 2. 같은 장비를 다르게 쓰게 만드는 6가지 전술

| 인물 / 기존 역할 | 전술 정체성 | 대표 능력 제안 | 플레이에서 달라지는 선택 | 균형의 제한 |
|---|---|---|---|---|
| 강태식 / 형틀반장 | 흐름 제어형 | **작업 흐름 정리**: 현재 이동 정지 3초, 재사용45초를 초기 기준으로 유지 | 신호를 집중 구간에 모은 뒤 분산기로 연쇄 해소 | 이동 제어이며 피해·장갑을 직접 없애지 않음 |
| 임준호 / 신입근로자 | 발견·정보형 | **전 구역 확인**: 현재 확인8초·사거리+30, 재사용40초를 초기 기준으로 유지 | 은폐가 겹칠 때 확인을 먼저 쓰거나 넓은 관측 배치로 대응 | 사람의 경험 부족을 초능력 설정으로 바꾸지 않음. 신호를 다른 시각에서 읽는 재구성 지원 |
| 윤성호 / 철근반장 | 장갑 핵심 해체형 | **집중 대응 표식**: 선택한 장갑 핵심 하나에 짧은 대응 창을 열어 물리 대응 효율을 높임 | PURE 분기에 올인할지, 물리 연사+표식으로 핵심을 줄일지 선택 | 단일 대상·짧은 창·장갑 감소 상한. 장갑 수치를 음수로 만들지 않고 PURE에 이중 보너스를 주지 않음 |
| 이재훈 / 공사대리 | 장비 가동 타이밍형 | **교대 가동**: 선택한 한 장비의 다음 공격 준비를 즉시 완료. 반복 사용은 긴 대기시간으로 제한 | 느린 고위력 분산기와 묶음이 만나는 순간을 맞춤 | 자원·업그레이드 무료 지급 없음. 공격/탐지 쿨다운 구분, 한 프레임 이중 발사 방지 |
| 최민석 / 크레인 신호수 | 공간·유도형 | **유도 표지**: 한 설치 지점을 지정해 짧은 시간 특정 경로 방향의 대응 범위를 확장 | 같은 장비를 먼 합류점까지 닿게 할지, 후방 보완에 쓸지 선택 | 전역 범위 증가 대신 한 지점·방향을 선택. 실제 원뿔/구간 판정과 표시 일치. 없는 길을 새로 만들지 않음 |
| 안전관리자 / 플레이어 | 재설계·복구형 | **방어선 재정렬**: 사용 가능한 빈 패드로 장비 하나를 이동하는 제한적 재배치 | 전반 집중 배치를 후반 은폐·진입 방향 변화에 맞춰 재해석 | 이동 시 레벨·투자·공격/탐지 대기시간 보존. 되팔기 차익·쿨다운 초기화·차단물 통과 금지 |

윤성호/이재훈/최민석/플레이어의 능력은 이번 신규 제안이다. 구체적인 지속시간·장갑 감소율·확장각·재사용 시간은 미확정이며 시뮬레이션과 사람의 플레이로 정한다. 실제 공사에서 장갑을 없애거나 안전한계를 넘겨 장비를 과가동하는 기능으로 설명하지 않는다. 전술 재구성 안의 규칙이다.

윤성호는 ‘핵심 한 개’, 이재훈은 ‘지금 한 발’, 최민석은 ‘공간 한 곳’, 플레이어는 ‘배치 한 번’을 바꾼다. 전부 공격력 몇 % 증가나 동일한 정지 효과의 색상 변형으로 만들지 않는다. 기존 4장비와 조합하는 것이 우선이며 캐릭터마다 전용 포탑 4종을 다시 만드는 방식은 피한다.

타워는 [진화·그래픽·효과 통합 기획](DEFENSE-TOWER-EVOLUTION-AV-MASTER-PLAN-20261015.md)의 4계열24상태를 사용한다. 각 인물이 최소 두 계열과 유효하게 조합되게 하며, 특정 인물을 골라야만 L4가 열리는 전용 진화 잠금을 두지 않는다. 윤성호의 장갑 표식/PURE 중복, 이재훈의 점사/착탄 중복 발동, 플레이어 이동 후 대기 공격의 정체성, 최민석 범위와 관측 범위의 분리를 교차 검증한다.

## 3. 선택 구조와 초보 추천

기본 출전은 **주역 1명 + 공통 4장비**다. 6명을 전투 중 동시에 조작하거나 6개 지원 버튼을 늘리지 않는다. 부관/2인 조합은 첫 캠페인 범위에서 제외한다. 장비와 배치의 선택을 캐릭터 능력이 모두 대신하지 않게 한다.

선택 화면에는 전신, 정식 이름/역할, ‘흐름 제어’ 같은 한글 전술 이름, 실제 작동하는 짧은 능력 미리보기, 장점과 제한 한 줄을 배치한다. 추천은 현재 작전의 편성/경로에 따라 1명을 표시하고 이유를 알려준다. 특정 인물이 없으면 클리어할 수 없는 추천을 만들지 않는다. 추천 이외의 인물을 고를 자유를 보존한다.

미리보기는 전투 엔진의 동일 판정과 샌드박스 콘텐츠를 사용한다. 강태식은 묶이는 흐름, 윤성호는 핵심의 표식/장갑 변화, 이재훈은 장비가 준비되는 한 발, 최민석은 확장 구간, 플레이어는 이동 전후 방어선으로 구별한다. 초상을 움직이거나 빛나는 테두리만 붙인 것을 능력 시연으로 세지 않는다.

## 4. 독립 모드 안에서 만나는 순서

| 시점 | 구성 | 설계 이유 |
|---|---|---|
| 최초 진입 | 강태식·임준호 | 제어와 관측을 비교. 둘 중 누구로 시작해도 GD-01 완료 가능 |
| GD-01 클리어 | 윤성호 합류 | GD-02의 약한 장갑과 단일 핵심 우선순위를 경험 |
| GD-02 클리어 | 이재훈 합류 | GD-03의 묶음과 지원 타이밍을 비교 |
| GD-03 클리어 | 플레이어 재설계형 합류 | 구역 변화와 배치 재해석을 능동적으로 경험 |
| GD-04 클리어 | 최민석 합류 | GD-05의 합류점/여러 경로를 공간 전술로 비교 |

모든 합류는 1회 클리어만 요구한다. 3별·본편·워치·브레이커·뽑기·반복 재료·결제/광고를 조건으로 붙이지 않는다. 12작전은 초기 두 명으로도 완주 가능한 해법을 유지한다. 뒤에 합류한 인물도 이전 작전 재도전에 사용할 수 있어야 하며, 단일 경로에서도 유도 범위/재배치 기능이 정상 작동해야 한다.

## 5. 캐릭터별 전술 갈래와 애착

영구 피해량을 반복해서 쌓는 방식 대신 **한 번에 한 갈래를 고르는 수평 특화**를 제안한다. 기본 능력 → A/B 전술 선택 → 그 갈래의 작전 서명 순서로 보여준다. A/B 동시 장착은 금지하고 작전 준비에서 무료로 바꾼다. 재화로 리셋 비용을 요구하지 않는다. 첫 3작전에서는 기본 능력 4명에 집중하고 전체 트리 제작은 뒤로 나눈다.

| 인물 | A 갈래 | B 갈래 | 애착을 남기는 장면 |
|---|---|---|---|
| 강태식 | 좁은 구간을 오래 묶는 **버티는 선** | 넓은 구간을 짧게 정리하는 **흐름 나누기** | 지원 지점에서 실제 다수 해소가 난 구간에 짧은 회고 |
| 임준호 | 확인 상태를 오래 유지하는 **끝까지 보기** | 넓은 범위를 짧게 읽는 **놓치지 않기** | 은폐 신호를 놓치지 않은 작전 도면에 관측 기록 |
| 윤성호 | 장갑 핵심 하나에 깊게 대응하는 **핵심 분리** | 표식 창은 약하지만 주변 소수로 넓히는 **하중 나누기** | 큰 핵심과 군집 중 실제 선택한 우선순위에 반응 |
| 이재훈 | 한 장비의 강한 한 발을 맞추는 **정시 가동** | 작은 효과를 두 장비에 나누는 **교대 연결** | 몰려온 신호와 실제 가동 타이밍이 맞물린 장면 |
| 최민석 | 좁고 멀리 보는 **긴 유도선** | 짧고 넓게 다루는 **넓은 인계선** | 이전에는 닿지 않던 합류 구간을 다룬 실제 기록 |
| 플레이어 | 이동 횟수는 적지만 고위 장비도 다루는 **결정적 재배치** | 낮은 단계 장비를 자주 옮기는 **유연한 설계** | 내가 변경한 배치의 전후 축소도와 마지막 서명 |

갈래 이름/효과는 신규 기획이다. 한 갈래가 다른 갈래의 모든 면에서 우수하면 폐기한다. 작전 회고·동료 서명·선택 대사·외장으로 애착을 보강하고, 발생하지 않은 활약을 칭찬하지 않는다. 숙련 장식은 기본 장갑/은폐 정보를 가리지 않는다.

## 6. 그래픽·연출 납품과 검증

기존 6인 원본의 얼굴을 다시 생성하지 않는다. 승인된 순찰 요원 자산을 중심으로 선택/준비/전투 HUD/결과/도감에서 같은 ID를 사용한다. 전신·초상·포즈/손 소품·실제 역할·안전모와 PPE를 대조한다. 플레이어는 현재 선택/저장된 플레이어 외형을 사용하며 다른 NPC 얼굴로 대체하지 않는다.

각 캐릭터는 기본 전신/초상 연결 외에도 능력의 준비·사용·종료 상태와 작은 화면용 효과를 갖춘다. 기존 장비 광원·금속 재질·접촉점과 맞추고 초상마다 서로 다른 그림체를 허용하지 않는다. 소리는 6개의 큰 대사가 아니라 짧은 사용 표식으로 구별하며 핵심 경보보다 앞서지 않는다. 한글 이름/능력 설명과 모션 줄이기를 유지한다.

검증은 인물별 정상 구매·지원만으로 대표 작전 완주, 핵심 장비와의 조합 비교, 특정 인물 필수화 여부, 장갑 감소 하한/PURE 중복, 쿨다운 초기화 악용, 지점 이동 저장/재개, 범위 확장 실제 판정/표시, 1·2배속 재현, 음소거/정지 정리까지 포함한다. 새 능력은 순수 엔진과 명시적 저장 필드/버전으로 구현한다. 추천이나 SVG 효과로 판정을 몰래 추가하지 않는다.

## 7. 제작 범위 수정

독립 캠페인의 첫 3작전 패키지는 **기존 능력 2명 + 윤성호/이재훈 신규 능력 = 4명**으로 보강한다. 다음 패키지에 플레이어/최민석을 추가해 정규 6명을 완성한다. 모든 기본 능력이 재미·가독성·저장 검증을 통과한 뒤 전술 갈래를 확장한다.

8명 이상으로 늘리는 것은 아직 권장하지 않는다. 기존 6명의 조작 차이와 애착이 먼저다. 이후에도 새 얼굴을 넣을 때는 기존 6명으로 표현할 수 없는 현장 역할과 전술 질문이 있어야 한다. 이번 문서에서 인물/능력이 게임에 추가됐다고 보고하지 않는다.
