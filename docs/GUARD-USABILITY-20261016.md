# 시그널 가드 · 오늘도 무사히 UI/UX 개선

대상: psi-zero-day-main, 2026-10-16. 로컬 구현과 브라우저 검증 결과입니다.

| 요청 | 확인 결과와 변경 |
|---|---|
| 시그널 가드 UI/UX | 준비 중 비활성 전투 버튼과 불필요한 상시 설명을 줄였습니다. 조작 설명은 펼쳐 읽을 수 있고, 설정의 안내 다시 보기도 해당 설명을 엽니다. |
| 스테이지별 차별화 | 6개 실제 경로와 배경이 모두 다릅니다. 선택 카드에 실제 엔진 좌표의 경로·배치 지점, 위험 조합과 대응 초점을 표시했습니다. GD-05의 두 진입선과 GD-06의 전환 경로는 청록색으로 구분합니다. 캐릭터 선택 배경도 선택한 현장을 사용합니다. |
| 메인화면 통일감 | 게임 카드의 높이, 제목, 브랜드 표기, 상태 배지, 좌측 정렬, 테두리를 통일했습니다. PC는 2열, 모바일 세로는 1열로 배치합니다. |
| 캐릭터가 3명만 보임 | 해금되지 않은 동료를 필터링해 숨기는 것이 원인이었습니다. 전체 6명과 선택 가능 인원, 잠긴 동료의 합류 조건을 표시합니다. 기존 진행 해금 규칙은 유지합니다. |
| 타워 구매 되돌리기 | 마지막 기본 타워 구매를 전액 환불합니다. 파 시작 또는 시뮬레이션 진행, 강화·판매 이후에는 취소할 수 없습니다. 자원과 타워만 변경하며 전투 결과를 되감지 않습니다. 구매와 취소 모두 즉시 저장하고 재진입 후에도 유효한 구매를 취소할 수 있습니다. |
| 모바일 진행 화면 | 일반 세로 화면의 맵을 확대하고 준비·전투·장비 선택 패널을 구분했습니다. 낮은 세로 화면은 전체 맵을 가로로 표시하고 배속은 설정에서 조절합니다. 가로 화면은 맵 옆에 전투 버튼을 배치합니다. |

## 검증

- 전체 테스트: 370개 파일 통과, 2,148개 테스트 통과, 기존 1개 테스트 제외.
- 후속 검증: 가드 캠페인·지원·저장·구매 취소·UI 관련 41개 테스트 통과, 마지막 UI 수정 후 관련 18개 테스트 통과.
- TypeScript 및 프로덕션 빌드 통과.
- 브라우저 프로필: 1440×900, 390×844, 320×568, 844×390, 568×320.
- 브라우저에서 확인한 흐름: 허브 → 작전 선택 → 동료 선택 → 타워 구매 → 전액 환불 → 재구매·저장 → 새로고침·이어하기 → 구매 취소 → 실제 전투 진행.
- 새 프로필은 6명 중 2명, 3개 작전 완료 프로필은 6명 중 5명, 전체 완료 프로필은 6명 모두 선택 가능.
- 잠긴 동료의 출전 방지, 배속 설정, 조작 안내 다시 보기, 맵과 터치 지점 정렬, 가로 넘침과 런타임 오류를 확인합니다.
- 반복 실행: scripts/verify-guard-usability.cjs. 개발 서버와 Playwright가 필요합니다.
