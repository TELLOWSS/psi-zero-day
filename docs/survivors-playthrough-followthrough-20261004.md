# 정상 성장 작전 통합 검증 — 2026-10-04

20개 맵 × 시드 42/137/509의 60회 자동 플레이로 보급, 통제선, 실제 장비 성장, 대표 위험 통제, 인계 연결을 검증했다. 윤의 기본 상태에서 시작하며 HP, 시간, 장비, 보스 완료 상태를 주입하지 않는다. 실제 제시된 성장 선택지만 고르고, 정상 엔진 입력과 공개 액션으로 진행한다.

## 발견 및 수정

수정 전 57회는 조기 인계했으나 15번 맵의 세 실행은 대표 낙하 위험이 자연 소멸하여 180초 종료에 의존했다. 대표 낙하 위험은 실제 통제까지 유지하고, 낙하 후 3초 휴식 뒤 플레이어의 당시 위치를 관측하여 1.25초 경고를 반복하도록 수정했다. 경고 시작 후 위치는 고정되어 회피할 수 있다. HP 2600은 그대로다. 일반 낙하 위험의 자연 소멸 규칙은 유지한다. 대표 위험의 HP가 0이 되는 프레임에서도 실제 통제 판정 전에 제거되지 않는다.

수정 후 60회 모두 보스 통제와 조건 충족 후 4초 인계로 종료했다. 15번 맵은 세 실행 모두 124초 종료했다. 자동 정책이 환경 통제와 회피에 능숙하므로 이 결과를 사람의 승률 또는 재미 평가로 사용하지 않는다. 별도 UI 스토리 선택과 Android 기기 성능은 이 실행에 포함하지 않는다.
