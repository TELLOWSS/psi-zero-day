# 08. 구역 클리어 큐

사용: Gemini의 음악 만들기. 보컬 없음. BGM은 화면에서 긴 트랙 옵션을 선택하고, 큐는 가장 짧은 옵션을 선택한다. 요청한 큐 길이를 정확히 생성한다는 보장은 없으며 필요한 부분은 이후 편집한다.

```text
Create instrumental music for this game scene. 실제 음악 생성 기능으로 오디오를 생성하라.
이 게임을 처음 접한다고 가정하고 아래 설명만으로 제작하라. PSI: ZERO DAY는 한국 건설현장의 야간 안전 순찰을 소재로 한 PC/모바일 탑다운 자동공격 생존 슈팅 게임이다. 플레이어는 안전관리자로 이동하며 무전기·소화기·안전 드론으로 가스 누출, 화재와 현장 위험을 통제하고 작업자를 보호한다. 전쟁·좀비·군인 총격 게임이 아니다. 한 판은 최대 약 3분이며 장비 성장, 보스 위험, 작업중지 궁극기가 있다. 목표는 공포나 살상이 아니라 긴장 속 책임감과 통제의 성취다.
이번 요청은 '구역 클리어 큐' 한 개만 제작한다. 다른 이벤트나 여러 파일을 한 번에 만들지 않는다.
장면과 역할: 작업자를 지키고 구역의 위험을 통제한 성공. 다음 구역으로 이어지는 안도감.
음악 설계: 2–4초의 짧은 현악·호른 해결, D minor에서 따뜻한 F major 방향. 폭발적인 심벌 대신 부드럽고 명확한 한 번의 성취. 승전가나 웅장한 엔딩곡 금지. 한 개의 짧은 제스처 후 잔향만 남긴다.
노래가 아닌 순수 기악. 보컬·가사·말소리·합창 없이. 가수나 기존 영화 음악을 모방하지 않는다. 오케스트라 악기의 생생한 어택과 자연스러운 공간감을 살리고 휴대폰 스피커에서도 주요 동기가 들리게 한다. 길이는 현재 도구에서 선택한 출력 길이에 맞춘다. 파일 형식은 도구가 실제 제공하는 형식을 사용하며 WAV/분리 스템/정확한 루프를 제공한다고 허위로 말하지 않는다.
설명이나 코드 대신 재생 가능한 생성 오디오를 결과로 제공한다. 생성 기능이 없으면 없다고 밝히고 오디오를 생성했다고 주장하지 않는다.
```

결과 관리 이름: PSI_CUE_SUCCESS_v01 (다운로드된 원본 확장자 유지). 무보컬·장면 적합성·효과음/음성 공간·끝의 편집 가능성을 청취한다. 기존 승인 자산을 덮어쓰지 않는다.
