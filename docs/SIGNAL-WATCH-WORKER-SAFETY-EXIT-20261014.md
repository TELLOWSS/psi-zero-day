# 시그널워치 — 계도 후 안전통로 퇴장

사용자가 요청한 안전모 착용 근로자의 퇴장을 기존 맵의 중앙 안전통로와 연결했다. 이전 구현은 중앙으로 움직이면서 동시에 상·하 방향으로 이동하고, 출구 도착 여부와 관계없이 3초 뒤 사라졌다.

## 적용한 흐름

1. 계도로 위험이 해소되면 기존 안전모 착용 근로자 표현을 유지하고 퇴장 동선을 생성한다.
2. 현재 높이의 중앙 안전통로로 합류하되, 해당 지점이 막혀 있으면 가까운 빈 합류 지점으로 연결한다. 기둥·자재·잔해와 투광기·전기설비·보관물의 바닥 면적은 경유점을 통해 우회한다. 장비 효과 반경 전체를 고체 장애물로 취급하지 않는다.
3. 통로에 도착한 뒤 가까운 위쪽/아래쪽 출구로 이동한다. 중앙에 받침이 있으면 통로 폭 안에서 옆으로 비켜 걸으며, 출구 방향은 시작 때 고정하여 중간에 뒤집히지 않는다.
4. 낙하 경고·작동 구간에 들어가기 전 기다린다. 현재 위치에 새 경고가 생기면 걸어서 범위 밖으로 물러나고, 해소 후 동선을 이어간다.
5. 실제 선택한 출구의 맵 밖 지점에 도착한 뒤 퇴장 객체를 제거한다. 통로 도착 전 임의의 3초 제한으로 사라지지 않는다.

통로 폭과 위치는 순수 도메인 함수 하나를 엔진과 렌더러가 함께 사용한다. 기존 폭 180, 중앙 X=700인 통로를 유지하고 위·아래 출구 표지를 추가했다. 근로자의 안내는 합류/통로 이동/위험 해소 대기로 나눠 한국어로 표시한다. 전투 중앙 팝업은 추가하지 않았다.

## 유지한 규칙과 범위

- 계도 성공 보상·위험 해소 횟수는 기존 성공 시점에 한 번 계산한다. 출구 도착으로 추가 보상을 지급하지 않는다.
- 일시정지·성장 메뉴에서 엔진 시간이 정지하면 근로자도 정지한다.
- 기존 근로자 외형·안전모 표현·음성·캐릭터 저장 데이터는 유지했다. 기존 객체의 `remaining`은 하위 호환하고 화면 밖 퇴장 구간의 표시 투명도에 사용한다.
- 기존 활성 표시 수 제한 128은 유지했다. 퇴장 연출은 구조 지형과 낙하 경고에 대응한다. 모든 건설장비·사진 속 장애물의 실제 보행 안전을 시뮬레이션하는 기능으로 해석하지 않는다.
- 검증용 테스트의 근로자는 격리된 이미 계도 완료 상태로 생성한다. 운영 콘텐츠에 새 NPC·새 에피소드나 무적 옵션을 추가하지 않았다.

## 검증

전체 테스트 2,068개 통과, 기존 1개 건너뜀. 경로·관련 계도·음성 테스트 17개 통과. 50개 맵의 양쪽 위치 100개에서 지형 충돌 없이 합류·퇴장할 수 있는지 확인했다. 통로 합류 전 수직 퇴장 금지, 3초 이후 표시 유지, 장애물 우회, 낙하 경고 대기/해제 후 재개, 새 경고에서 걸어서 이탈, 일시정지, 보상 중복 방지를 확인했다.

세로 390×844, 가로 844×390, PC 1440×900의 실제 UI에서 엔진 진단 fixture를 통해 합류→통로 이동→출구 제거를 확인했다. 강제 승리나 체력 보충을 통한 클리어율 측정은 아니다. 타입 검사·production 빌드도 통과했다. 공개 사이트는 상태를 조작하지 않은 정상 시작으로 출구 표지 렌더링을 추가 확인한다. 증거는 `docs/qa/signal-watch-worker-egress-20261014.json`과 같은 이름의 이미지 폴더에 보관한다.
