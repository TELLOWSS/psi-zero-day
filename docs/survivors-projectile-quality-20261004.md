# 장비별 발사체·현장 반응 품질 개선

기존 발사체는 단색 원·원형 테두리와 실시간 shadowBlur를 반복했다. 장비 본체와 달리 분말·신호·전기·지시광의 형태가 구분되지 않았다.

| 장비 | 적용된 표현 |
|---|---|
| 무전 | 진행 방향으로 열린 금색 신호 전면, 짧은 잔광, 강화 단계별 신호 층 |
| 소화기 | 입자가 섞인 반투명 분말, 흐르는 분사 꼬리 |
| 드론 / 진화 드론 | 방향성 지시광, 밝은 중심과 부드러운 꼬리 |
| 위성 | 청색 신호 전면과 다층 파동 |
| 극저온 | 분말과 다른 결정 무늬·냉각 안개 |
| 테슬라 | 분기 전기 아크, 얇은 접지 반응 |
| 전자기 차단 | 속이 비치는 격자와 차단 테두리 |
| 작업중지 | 바닥을 덮지 않는 얇은 다중 압력파 |
| 라바콘 | 기존 승인 장비 스프라이트 유지 |

기존 게임의 Canvas2D presentation을 개선한다. 새 엔진 전환, 충돌/데미지/수명/저장 규칙 변경은 없다. 실제 속도로 방향을 정하며 실제 반경을 사용한다. 분말과 광원 소재는 최초 사용 시 한 번 생성하여 재사용한다. 실시간 shadowBlur 대신 캐시된 소재를 drawImage한다. 발사체 90개 초과 시 장식 요소를 줄이고, 움직임 감소 설정에서는 흔들림·잔광을 줄인다.

## 검증과 제작 순서

전체 회귀 검사 및 4개 화면 크기의 기존 브라우저 게임 검사를 유지한다. 20단계 실제 시뮬레이션에서 새 소재가 그려지는지 확인한다. 별도 표현 검수 장면은 실제 렌더러를 사용하되 자연 진행 플레이 증거와 구분한다. 캐시 재사용 반복 검사는 실기기 FPS 인증으로 부르지 않는다.

다음은 실제 Android 장시간 혼잡 장면 검수, 발사 시작과 충돌 반응의 장비별 연계, 공정별 고유 지형 아트 순서다. 이번 변화는 손으로 작성한 실시간 효과이며 실사 이미지나 최종 영화급 VFX로 선언하지 않는다.

근거: https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Optimizing_canvas (반복 소재 사전 렌더링). 현재 Canvas2D 구조에는 Phaser 전체 교체보다 캐시된 방향성 효과를 적용하는 편이 범위와 회귀 위험을 줄인다.
