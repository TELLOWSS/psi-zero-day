## 최종 작업, 승인 및 게임 적용
1. 8방향 모두 **독립 작화**; NW·W·SW 반전 금지. 조명·소켓·장비 위치 검수.
2. 8×20 실제 키프레임 160개를 새로 그리되, 발 접지 Y=454±2, 384×512 RGBA, 포니테일/무기/관절별 자연스러운 움직임을 보장.
3. 각 프레임에 장비 뒤 마스크 160장, 앞 마스크 160장을 따로 생성. 파일별 알파 무결성/해시 및 독립 방향 검수.
4. 기존 `src/ui/omega-protocol-art-slot.ts`, `omega-protocol-art-motion.ts`, `OmegaGroundedGait`에 실제 승인 원화를 연결. **현재는 APPROVED_ART=null / BINARY_AUDIT_PASSED=false** 유지.
5. `npm run omega:art-verify`, 전체 Vitest, 브라우저 4해상도, 실제 Android 테스트와 15개 노드·웨이브9/15 보스전을 통과한 후에만 사용자 승인 받아 main/Production 진행.
