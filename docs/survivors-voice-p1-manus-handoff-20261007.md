# 마누스 전달용 P1 음성 제작 요청

상태: 제작 제안. 아래 14개는 아직 생성·청취 승인·게임 연결되지 않았다. 기존 P0 원본과 소장 음성은 교체하지 않는다.

아래 요청 전체를 마누스에 전달한다. 첫 작업은 기존 P0와 같은 화자를 유지할 수 있는지 확인하는 것이다. 화자 유지가 불가능하면 임의로 새 목소리를 확정하지 않고 샘플을 먼저 전달한다.

## 제작 요청

시그널 워치 게임의 주인공 현장 안전관리자 한국어 음성 14개를 제작해 주세요.

기존에 제작한 `PSI_V_PLAYER_START_A_v01.wav`를 화자 기준으로 사용합니다. 같은 생성 모델과 화자 ID를 유지하고, 가능한 경우 같은 화자 설정/시드를 사용합니다. 실제 인물이나 유명 성우를 모사하지 않습니다. 기준 파일을 사용할 수 없다면 먼저 알려주세요.

안정적인 성인 여성 중음역, 또렷한 한국어 발음, 자연스럽고 침착한 현장 말투입니다. 위험 경고만 짧고 긴박하게 말하고, 나머지는 과장 없이 전달합니다. 대사 본문만 정확히 한 번 읽습니다. 파일명, 지시문, A/B 표시는 읽지 않습니다. 음악, 효과음, 무전 잡음, 반향, 추가 대사, 다른 화자, 웃음은 넣지 않습니다.

각 행은 별개의 파일입니다. A/B를 하나의 파일로 합치지 않습니다. 문장 시작과 말끝을 자르지 않고 앞 약 0.10초, 뒤 약 0.20초의 짧은 무음을 둡니다. 길이는 목표일 뿐입니다. 발음이 뭉개지거나 인위적으로 빨라질 만큼 속도를 높이지 않습니다. 이전 P0 경고가 2초 이상이었으므로 새 경고는 가능하면 짧은 호흡으로 전달하되 원문을 생략하지 않습니다.

가능하면 mono PCM WAV 원본으로 전달합니다. 도구가 실제 지원하면 48kHz/24-bit를 사용하되, 24kHz/16-bit 원본을 업샘플링해서 고품질이라고 표시하지 않습니다. 원본을 보존합니다. 출력 레벨을 끝까지 밀어 붙이거나 강한 리미터로 눌러 0dBFS에 붙이지 않습니다. 측정 기능이 있는 경우 피크 여유를 확보하고 측정값을 첨부합니다. 측정하지 않았다면 수치를 추측하지 않습니다.

## 전달 후 연결 기준

- 원본 해시·형식·길이·음량 검수 후 기존 P0와 함께 화자와 발음을 청취 확인한다. 제작 요청 자체가 최종 청취 승인을 의미하지 않는다.
- 가스는 실제 가까운 경고, 핵심부는 실제 개방 전환, 작업자 안내는 실제 성공 확인에만 연결한다. 사실 이벤트가 없는 곳에 대사를 붙이지 않는다.
- 장비 진화는 실제 획득, 지원은 요청 성공, 재준비는 실패 후 사용자의 재시도 선택에 연결한다. 메뉴 탐색이나 취소로 재생하지 않는다.
- 최종 클리어 두 개는 stage_50의 실제 victory에만 사용한다. 기존 CLEAR A/B는 일반 맵용으로 유지한다.
- 기존 단일 음성 소유자·긴급 우선순위·쿨다운·늦은 경고 폐기·음소거/일시정지 취소 규칙을 확장한다. 새로운 게임 수치나 위험 경고 시간을 변경하지 않는다.
- 파일이 없는 동안 runtime URI, 임시 합성 음성, PRODUCTION_APPROVED 상태를 추가하지 않는다. 자산 전달 후 구현·회귀 검증·GitHub/Vercel 동기화를 진행한다.
