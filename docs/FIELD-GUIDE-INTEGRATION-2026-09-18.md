# 현장 도감 통합

## 구현
- 소품 10종을 모두 투명 WebP로 등록하고 현장 도감의 선택 목록과 큰 미리보기에 연결했다.
- 새 원화: 일반 중량물, 갱폼, 금속 작업발판, 통제선, 젖은 바닥. 기존 콘크리트 단부 원화는 개구부·단부 슬롯으로 이동했다.
- 모든 설명은 한국어 로컬라이제이션에 저장했다. 관찰 질문을 통해 이미지에 보이는 것과 추가 확인이 필요한 정보를 구분한다.
- 플레이 화면의 개발용 아트 제작률 표시는 제거했다.
- 도감 탐색은 게임 진행과 저장 상태를 변경하지 않는다.

## 연결 범위
10종은 도감에서 실제 열람 가능하다. Episode 01 사건 맵의 자재 배치 두 곳은 유지했다. 제작 완료를 이유로 비계나 갱폼을 무관한 기초공사 사건에 삽입하지 않았다.

## 남은 검토
기술 게이트는 파일 크기, 투명도, 자산 등록을 확인한다. 공학적 정확성이나 상업 출시 적합성을 증명하지 않는다. 안전대의 Y 분기 연결과 양중 훅 상단 여백, 슬링 체결 형상은 후속 시각 검토 대상이다. 이미지의 와이어 직경은 실측 가능한 증거가 아니다.
다음 작업은 표정·동작 변형과 사건별 연결, 외부 플레이테스트다. 현재 결과는 로컬 개발본이며 공개 배포는 하지 않았다.

## 제작 자료
원화 출처는 scene-element-catalog.json의 art.source에 기록했다. 최종 WebP는 public/assets/episode01/scene-elements에 버전 관리된다. 게임 실행과 빌드에는 로컬 원본 PNG가 필요하지 않다.
생성 프롬프트는 PROP-ART-PROMPTS-2026-09-18.json에 보존했다.

## 검증 결과
- Vitest: 59개 파일, 397개 테스트 통과. 도감 선택 후 게임 상태 보존과 10종 이미지 연결 포함.
- 소품 production check: 10/10 투명 WebP 통과.
- TypeScript 검사, Vite 빌드, 한국어 문구 검사 통과.
- 브라우저: 854×393 및 1280×720에서 항목 선택 확인, 이미지 11개(목록 10 + 미리보기 1) 로드 성공, 가로 넘침 없음, 콘솔 경고·오류 없음.
- 빌드의 기존 500KB 초과 청크 경고는 남아 있음(주 JS 610.76KB, gzip 163.38KB). 후속 성능 작업 대상.
