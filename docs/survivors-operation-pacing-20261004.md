# 스테이지 반복 피로 개선 — 목표 기반 조기 인계

원인: 모든 작전이 고정 180초 생존으로 끝나 목표를 먼저 수행한 플레이에도 시간이 남았다. 다음 맵 진입, 기본 생존, 비슷한 성공 화면이 반복됐다. 기존 20개 맵을 유지하며 완료 방식과 목표 노출을 개선한다.

| 작전 | 적용 맵 | 조기 인계 최소 시간 | 구역 조치 | 일반 대응 |
|---|---|---:|---:|---:|
| 신속 통제 | 1,4,7,10,13,16,19 | 90초 | 1곳 | 8+맵 번호의 절반 내림 |
| 구역 확보 | 2,5,8,11,14,17,20 | 105초 | 2곳 | 8+맵 번호의 절반 내림 |
| 집중 대응 | 3,6,9,12,15,18 | 120초 | 1곳 | 18+맵 번호 |

구역 조치 목표는 실제 맵의 조치 가능한 구역 수를 넘지 않는다. 모든 작전에서 실제 지정 보스 통제도 필수다. 인화물 격리 완료, 전원 차단, 플레이어의 양중 중지로 확인된 구역만 고유 ID로 기록한다. 자연 발생 양중 낙하의 active 상태는 조치로 세지 않는다. 임시 표시가 끝나도 완료 조치는 기억하며 동일 구역 반복은 횟수를 늘리지 않는다.

180초 정규 생존 경로와 기존 기본 보상·저장·해금·장비 성장·계도 스토리는 유지한다. 조기 인계 승리도 같은 승리 처리 경로를 사용하며 보상은 한 번만 지급한다. 화면에 작전 유형과 다음 남은 조건을 표시하고 일시정지 화면에 전체 인계 조건을 보여준다. 선택 카드에 90/105/120–180초의 작전 리듬을 안내한다. 승리 설명을 조기 인계/정규 순찰로 구분하고 고정 S급 대신 실제 달성 별 수에 따른 결과를 표시한다.

이 변경은 전투 목표/종료 리듬 개선이며 새 랜덤 사건, 보스 패턴, 신규 서사·맵 추가는 아니다. 인계 조건 달성 가능성·클리어 시간·몰입도는 실제 플레이 검수를 통해 조정해야 한다. 테스트의 준비된 완료 fixture를 사람의 승률로 해석하지 않는다. 정규 승리 시 미달 목표가 자동 완수되거나 새로운 저장 페널티로 변환되지 않는다.

검증: 208개 파일 / 1,118개 테스트, typecheck/build 통과. 세 작전 유형을 포함한 1·2·3·20 맵 × 3개 화면 크기 = 실제 초반 UI 12건 통과(목표 표시·HUD·정지/재개·렌더 오류 0). 엔진 테스트는 준비된 fixture로 조기 승리/조건 미달/180초 승리/보상 1회 지급을 검증했다. 실제 사람이 달성한 조기 클리어 UI·몰입도·승률 검증은 아니다.

후속 수정: 목표 달성 즉시 자동 완료는 선택형 인계로 대체했다. X/버튼 요청 후 현재 지점에서 4초 확인해야 조기 완료하며, 이동/피해 시 취소된다. 자세한 현재 동작은 `survivors-shooter-three-reference-20261004.md` 참조.
