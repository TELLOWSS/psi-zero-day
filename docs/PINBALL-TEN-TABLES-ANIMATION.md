# 5구역 해금 핀볼 — 구현 및 환경 애니메이션

## 해금과 플레이
기본 야간 공장에 추가되는 10개 현장 테이블. 1~5, 6~10처럼 해당 5구역 묶음을 모두 완수하면 대응 테이블을 연다. 다른 구역의 반복 클리어·중복 기록으로 대체할 수 없다. 다음 테이블과 남은 구역 수는 작전 구역 및 핀볼 선택 화면에 표시한다. 첫 완수로 테이블이 열리면 결과에 안내한다.

| 완수 구역 | 테이블 | 구조 / 공략 | 특수 액션 |
|---|---|---|---|
| 1~5 | 컨베이어 | 엇갈린 범퍼와 좌우 운반 레인, 강판 | 교대 레인 충전, 관통탄 |
| 6~10 | 항만 | 오른쪽 크레인 램프, 컨테이너 표적 | 추가 공 2개 투하 |
| 11~15 | 주조 | 상단 가열·좌측 냉각 레인, 주괴 | 가열 산탄·인접 용융 폭발 |
| 16~20 | 터널 | 갈림 레일, 세로 암반 열 | 실제 관통 굴진탄 |
| 21~25 | 타워크레인 | 상단 포획 컵, 하단 적재물 | 0.45초 포획 후 고속 낙하, 충돌 시 주변 타격 |
| 26~30 | 전력 | 순서가 표시된 릴레이 | 순서 공략, 인접 노드 방전 |
| 31~35 | 수처리 | 전환되는 수문 레일, 양측 수류 | 밸브 파괴 전환·고압 상승류 |
| 36~40 | 철도 | 중앙 분기기, 연결기 | 레일 전환·급행 가속 |
| 41~45 | 해체 | 지지대와 콘크리트 구조 | 활성 중 다음 지지대 붕괴 |
| 46~50 | 제로데이 | 코어·복합 레인 | 파괴마다 굴진→전력→수류 전환, 최대 다섯 공 |

수동 패들의 실제 퍼펙트 접촉만 충격탄을 발사한다. 누르고 있기·자동 보조로 사격을 반복하지 않는다. 탄이 표적에 도달해야 체력과 점수가 변경된다. 표적 파괴는 원화 조각의 물리적 파편과 실제 손상 링크로 표현한다. 모든 표적을 파괴하면 1.2초 뒤 다음 표적을 재정비해 특수 액션 중 사격할 대상이 사라지지 않게 한다. 세 번의 기회와 기존 보상 상한을 유지한다. 연습은 무제한 재시작 가능하며 PSI 지급은 항상 0. 테이블·규칙·보상/연습 모드별 개인 기록은 분리한다. 기존 공장 기록과 저장 키는 유지한다.

## 정지 원화를 움직이는 방식
배경 원화에는 물체 분리 정보가 없으므로 배경 전체를 흔들지 않는다. 바닥·외곽 건축은 정지 원화, 설비와 물체는 별도 알파 원화, 수면과 빛은 표면 연출, 충돌과 파편은 실제 엔진 상태로 분리한다.

- 공통: 시차를 둔 경광등 밝기, 독립 팬 날개 회전. 정지 하우징 안의 원형 영역만 회전.
- 항만: 예인선 이동과 약한 상하 흔들림, 뒤쪽 항적, 수면 반사, 크레인 이송·케이블·매달린 적재물.
- 컨베이어/철도: 벨트 진행 표시, 프레스 작동, 분기 전환에 대응하는 신호등.
- 주조/터널/해체: 상승·확산·소멸하는 증기와 먼지, 용광로 열기. 큰 표적 파괴는 원화 조각으로 표현.
- 수처리: 수면 반사, 밸브 회전, 펌프 증기, 실제 수문 전환.
- 전력/제로데이: 코어 회전과 발광, 실제 릴레이 손상 링크의 방전.
- 크레인: 공 포획과 투하를 엔진 시간으로 제어. 공이 적재물에 실제 충돌한 다음 파괴 효과가 나온다.

상시 환경 움직임보다 성공 연출의 강도를 높인다. 일반 광원은 천천히 변화하고, 특수 액션 활성 중 이송·설비·발광을 강화한다. 퍼펙트는 접점의 충격 링과 탄 궤적, 금속 접촉은 짧은 방향성 스파크, 파괴는 최대 48개 원화 파편. 실제 공과 패들은 마지막에 그려 읽기 쉽게 유지한다. 안내는 테이블 바깥에 두며 중앙 성공 팝업을 만들지 않는다.

## 가독성과 성능 기준
240Hz 물리 하위 단계, 최대 공 속도 1,300, 추가 공 4개, 충격탄 16개, 효과 24개 제한. 이미지와 소리는 병렬 로딩하며 테이블 교체 후 로딩 완료 전에 발사하지 않는다. 설정·앱 포커스 상실·전체화면 이탈 시 물리와 소리를 일시정지한다. 시스템 움직임 줄이기 및 부드러운 그래픽 모드는 설비 애니메이션·잔상·파편·증기를 정지/생략하면서 공·패들·실제 사격과 레일 상태를 보여준다.

## 다음 연출의 판단 기준
새 장식은 현장 정체성 또는 공략 신호에 도움이 될 때 추가한다. 장면별 성공 연출의 확장 우선순위는 크레인 투하→릴레이 연쇄→용융 파괴→제로데이 단계 전환이다. 큰 기계가 화면 안으로 들어오는 컷신보다 테이블 안의 실제 경로 변화와 타격에 반응하는 설비로 표현한다. 장시간 플레이 재미는 해금 목표·다른 공략·개인 기록으로 만들고, 번쩍임·강제 연속 플레이·보상 손실 압박으로 만들지 않는다. 주관적 손맛과 추가 사운드 원본 제작 여부는 실제 플레이 피드백으로 결정한다.

## 검증
순수 테스트는 정확한 해금 묶음, 레거시 선택 이동, 수동 접촉/보조 사격 차단, 탄 도달 손상, 릴레이 순서, 크레인 포획/낙하/추가 공 승계, 수문/레일 전환, 도미노 붕괴, 컨베이어 교대, 주조 산탄, 터널 관통, 제로데이 전환, 30/60/120 FPS 자연 진행, 무보상 연습, 기록 분리를 검사한다. 브라우저 검증은 기본+10개 테이블 × PC/모바일 세로/모바일 가로에서 원화 로딩, 움직이는 픽셀과 움직임 줄이기의 정지 픽셀, 선택/설정/플레이/연습 정산을 확인한다. 강제 접촉 검사는 fixture이며 자연 플레이 승리로 보고하지 않는다.
