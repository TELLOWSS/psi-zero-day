# 안전한 웨이브 보급과 공통 설정

웨이브 1·2 완료 시 보급 보상을 지급하고 엔진의 기존 일시정지를 사용해 정비 보급소를 연다. 보급 확인·구매 중에는 게임 시간, 몬스터 이동과 피해 처리가 멈춘다. 이동 입력을 비우고, 보급 중 P/Escape 및 상단 재개 버튼은 잠근다. 정비 완료 버튼을 누르면 같은 세션을 재개하며 다음 웨이브를 진행한다. 시간을 제한하거나 자동 재개하지 않는다.

출동 준비의 설정 탭과 시그널워치 일시정지의 ‘설정 · 커스터마이징’에서 동일한 화면 흔들림·타격 섬광 설정을 조작한다. 공통 컴포넌트와 상위 상태를 사용하고 기존 저장 키를 유지한다. 음량 믹서도 양쪽에서 제공한다.

브라우저 검증은 실제 게임에 웨이브 경계 시간을 주입한다. PC 1440×900과 모바일 390×844에서 두 보급의 시간·체력·몬스터 상태 정지, 단축키 잠금, 명시적 재개 및 설정 공유·저장을 확인한다. 결과와 화면은 artifacts/safe-supply에 기록한다. 회귀 테스트에서는 보급 완료 동작을 추가해 크레딧 저장 실패 복구와 장비 구매·보상 중복 방지 흐름을 계속 검증한다.
