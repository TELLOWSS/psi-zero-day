# 전투 이벤트 가시성 개선

전투 중 안내를 HUD 아래 가장자리의 작은 알림으로 통일했다. ZERO DAY 축하와 감독관 컷인은 색상, 캐릭터, 짧은 등장 효과를 유지하면서 중앙 전투 영역을 비운다. 중복된 중앙 이벤트 문구와 감독관의 전체 화면 흰색 효과를 제거했다. 위험 대응 안내와 입력이 필요한 일시정지 선택 화면은 유지한다.

모바일에서는 보스 정보와 조작부를 피하고, 낮은 가로 화면에서는 보조 설명을 줄인다. 알림은 포인터 입력을 가로채지 않으며 동작 줄이기 설정을 따른다.

검증: 전체 테스트 1,778개 통과(1개 건너뜀), 타입 검사 및 빌드 통과. 최종 변경 후 관련 테스트 23개와 빌드를 재확인했다. 실제 게임 엔진에 이벤트 상태를 주입한 브라우저 배치 검증에서 4개 화면 크기, 총 24개 경우의 중앙 영역, 입력 통과, 가로 넘침, 오류 및 동작 줄이기 설정을 확인했다. 결과는 artifacts/event-visibility/report.json과 화면 이미지에 기록했다. 배치 검증은 전체 스테이지 자연 진행의 플레이 체감 검증을 대체하지 않는다.
