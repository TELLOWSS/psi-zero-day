## 적용한 음악

첨부 fuiqzJgdWiMFbTcB.zip은 모든 엔트리의 CRC 검사와 안전한 압축 해제를 통과했습니다. 루트 음악 5개와 테이블 전용 효과음 후보를 실제 Chrome Web Audio로 디코딩·계측했습니다. 음악은 이전 손상된 72초 v02와 다른 64초 원본입니다.

## 몬스터 연출 방향과 반영

1. 물체의 재질과 표시된 원화를 기준으로 움직입니다. 단단한 낙하물의 피격 squash/stretch를 없애고 회전만 적용합니다. 높이와 함께 그림자 농도가 줄어 착지점이 읽힙니다.
2. 카트 전조의 빛 방향은 실제 이동 방향을 따릅니다. 수직 이동 때 방향 계산을 수정했습니다. 속도/이동거리와 기존 공격 단계에 연결된 서스펜션과 준비·제동을 유지합니다.
3. 실제 기계와 기체를 구분합니다. 실린더·기계 본체는 호흡하듯 늘리지 않습니다. 지역별 가스 원화는 같은 색과 질감을 가진 원화 조각이 서로 다른 위상으로 흘러갑니다. 소용돌이는 최대 3개, 혼잡 시 1개로 제한합니다.
4. 처치 이벤트에 ID·variant·behavior·signatureEventId를 보존합니다. 생존·처치가 같은 원화 선택 함수를 사용하고, 직전 실제 렌더의 source/cell/크기/방향을 보관해 반대 방향으로 뒤집히는 것을 방지합니다. 이 캐시는 256개로 제한하며 처치·초기화 때 정리합니다. 다른 몬스터 원화로 바뀌는 현상을 제거합니다. 보스·시그니처 원화 우선순위도 유지합니다.
5. 50개 지역별 원화의 실제 소재를 연출에 반영합니다. 판·브래킷·모터는 강체 회전·착지, 벽돌·콘크리트는 파편, 느슨한 금속 묶음은 분리, 가스는 상승·소산합니다. 게임 규칙의 species/피해량/보상/충돌은 변경하지 않습니다.
6. 파편은 원본 paint를 잘라 서로 다른 초기 속도·지연·무게로 띄우고 떨어뜨립니다. 사각 격자 모양을 피한 비대칭 조각을 사용합니다. 최대 16개 처치·24개 접촉, 1.15초/0.32초 수명을 유지합니다. 프레임마다 픽셀 스캔·새 이미지·랜덤 생성은 하지 않습니다.
7. reduced motion은 장식 흐름·회전·파편 이동을 정지시킵니다. 기존 위험 경고와 조작 판단은 보존합니다. 화면 전체 섬광·팝업은 추가하지 않습니다.

## 검증

신규 테스트는 원화의 생존/처치 연속성, 50개 소재 매핑, 단계 기반 가스 흐름, 파편 범위와 정착을 확인합니다. 브라우저 검증은 원본 래스터를 사용해 reduced motion 픽셀 정지, 가스 움직임, regional atlas/cell 유지, 단단한 판과 벽돌의 다른 처치 연출을 확인합니다. 픽셀 비교용 Canvas는 CPU readback을 사용해 GPU의 반복 샘플링 오차를 배제했습니다.
