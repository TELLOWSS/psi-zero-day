# 시그널 브레이커 — 전체 경험 벤치마크와 개선 구현 v4

2026-10-10 · 사용자 추가 지시: 제기한 화면 문제에 한정하지 않고 장르 전체의 좋은 설계를 추가 기획·반영한다.

## 1. 제품 목표와 보존 계약

각도를 직접 맞춰 쏜 뒤, 반사와 산업 장치를 이용해 위험 신호를 해소하는 수동 물리 아케이드다. 플레이어가 경로를 만들고 결과를 읽는 성취가 핵심이다. 자동 표적 추적·무입력 발사는 없다. 기존 물리 엔진·좌표·장비·5작전·시험판·보상·오프라인 저장을 보존한다. 본편 DefenseGame과 시그널 워치의 규칙을 변경하지 않는다.

v3의 화면·아트 진단을 유지하면서, 이번 문서는 조작 숙련, 진행 리듬, 재도전, 결과 피드백, 접근성, 기술 성능까지 다룬다. ‘최고의 게임’ 단일 순위 대신 이 장르에 맞는 대표작을 설계 축별로 선정했다. 공식 자료로 확인한 사실과 우리 게임의 응용 명세를 구분하며 경쟁작 실기기 플레이/성능 측정을 수행했다고 주장하지 않는다.

상위 기준: 첨부 마스터 바이블의 WORLD FIRST, MOBILE FIRST, IMPACT FIRST, AUDIO=GAMEPLAY, ONE PRODUCTION GENERATION; `MASTER-DESIGN-PRINCIPLES.md`와 `GAMEPLAY_DOCTRINE.md`. 실제 현장 안전 하한선을 낮추는 선택에 보상을 부여하지 않는다.

## 3. 이번 실제 구현 — 핵심 경험 9개

### A. 한 번에 이해되는 현장

배경용 확대 변환과 게임 객체 변환을 따로 사용하는 이중 현장 렌더링을 없앴다. 장치·위험 코어·캐릭터·현장은 같은 월드 카메라로 그린다. 맵을 수평 띠로 잘라 각각 늘리는 렌더링도 제거했다. 캐시의 이미지 로딩 완료 상태와 자산 경로가 바뀌면 배경을 재생성한다.

세로 현장은 `world-*-v4.webp` 5장, CH-01 가로 대표 현장은 `map-delivery-v3.webp`를 새로 제작했다. 세로는 위와 아래가 실제로 이어지는 하나의 긴 환경이다. 가로는 기존 고해상도 폭의 대응 맵을 사용한다. 두 방향은 동일 산업 현장의 별도 제작 후보이며, 세부 건축 배치가 회전 전후 픽셀 단위로 같다는 주장은 하지 않는다. 회전 시 게임 좌표·진행·장비는 유지된다.

맵 메타데이터는 원본의 플랫폼 위치를 확인한 뒤 월드의 실제 캐릭터 발 위치594에 맞춘다. 위험 코어의 충돌 기준 `GROUND=536`은 유지한다. 캐릭터 발 위치와 위험 코어 충돌 높이를 같은 값으로 잘못 해석하지 않는다. AI 이미지에 충돌 좌표를 맡기지 않는다.

세로 카메라는 직접 지정한 조준점 또는 현재 보스 노드와 플레이어 간 거리를 읽어 600~800월드px 시야를 선택한다. 필요한 여백을 넣어 좌우 위치를 제한하고 세로 이미지 경계 안에서 이동한다. 카메라의 노드 표시 판단은 화면 구성만 바꾸며 조준/명중/발사에 개입하지 않는다. 일부 멀리 있는 목표는 방향·개수 표식으로 알리고 전체 경로에서 확인한다.

### B. 수동 조준의 정밀도

좌우 이동 시 방향만 반전하고 직접 정한 상향 각도를 유지한다. 상하 각도 입력은 기존 데드존을 유지하고 `dt × |input|^0.7` 응답으로 세밀한 조절을 제공한다. 최대 입력 속도와 엔진 각도 범위는 그대로다. 손을 떼거나 입력 취소하면 이동·각도 변경·발사도 중단한다.

전장 드래그 조준은 포인터가 시작할 때의 카메라 변환을 저장한다. 이동 중 카메라가 바뀌어 손가락이 지정한 좌표가 다른 세계 좌표로 튀는 문제를 줄인다. 잡은 포인터를 다른 손가락이 빼앗지 못한다. 입력 종료/취소 시 변환도 해제한다.

### C. 전체 경로를 직접 판단

‘전체 경로’를 누르면 명시적인 전술 지도가 열린다. 진행 중 물리가 정지하고 전장 조작 패드는 숨긴다. 지도 터치는 각도만 지정하며 발사하지 않는다. ‘현장 복귀’로 돌아오면 원래 진행 상태로 복귀하며 이전 발사 입력을 이어 받지 않는다. 이미 정지된 상태에서 열었다면 임의로 재개하지 않는다.

이 지도는 상시 붙은 작은 게임 화면이 아니다. 사용자가 필요할 때 호출하는 경로 확인 화면이다. 지도는 실제 월드0~1100/0~620 구간만 보여 주며 세로 배경 확장부를 월드로 오인하지 않는다.

### D. 장치 읽기와 조합

5작전의 이동 완충 장치·벨트 방향·집진 개방 창·장력 고정·순차 보스 문법은 유지한다. 전체 화면에 한꺼번에 설명을 붙이는 방식 대신 첫 반사 작전에서 상황에 따라 ‘각도 조절 → 반사 → 포획’ 한 개 안내만3초 표시한다. 같은 세션에서 이미 읽은 단계는 재도전 시 반복하지 않는다.

장치 상태의 게이트 타이머·개폐 색·릴레이 순서·노출 시간은 기존 실제 엔진 상태에서 표시한다. 각 장치의 기능·실패 이유를 숨기는 방향으로 HUD를 최소화하지 않는다.

### E. 가리지 않는 HUD

상시 설정·메인 이동·전체화면·조작모드·장비 자동 버튼 무리를 플레이 전장에서 제거했다. 설정은 준비/일시정지의 세부 설정으로 접근한다. 전체화면과 바로 재도전은 정지 메뉴에서 제공한다. 캐릭터 선택도 준비의 세부 설정으로 옮겼다.

좌측 이동/각도, 우측 장비2슬롯+직접 발사, 필요한 장치 조작을 남긴다. 현재 장치가 없는 벨트 버튼은 숨긴다. 상시 미니맵과 큰 중앙 장비 설명을 없앴다. 연쇄 바는 실제 연쇄 창2.5초 동안만 작은 표시로 나온다. 점수는 결과 화면에서 크게 읽고 플레이 중에는 회수/실드를 우선한다.

### F. 즉시 재도전

결과의 재도전과 정지 메뉴의 ‘바로 재도전’은 준비 패널을 다시 통과하지 않는다. 선택한 장비2슬롯·레벨·업그레이드 가지를 유지해 같은 작전을 바로 시작한다. 재도전 시 시간·위험·투사체·입력은 초기화하고 기존 보상/중복 보상 방지 규칙을 유지한다.

### G. 숙련의 되먹임

결과에 실제 발사 수, 실제 반사 수, 작전 시간과 이전 최고 점수를 표시한다. 처음 기록과 이전 기록 비교를 구분하고 기존 최고를 넘어선 경우만 ‘최고 기록 경신’을 표시한다. 클리어 시간 최솟값을 오프라인 기록에 추가했다. 이전 저장에 시간 필드가 없어도 호환된다.

3개의 숙련 목표는 ‘연쇄3 / 반사3 / 장비2종 연계’다. 엔진의 실제 `bestChain`, `bounces`, `usedWeapons`를 사용하며 자동 완료·새 크레딧·강제 진행 잠금은 없다. 장비 사용 수는 명중률이 아니므로 정확도 수치로 오인하게 표현하지 않는다. LAB은 계속 무보상이다.

### H. 준비·결과 흐름

큰 블러 중앙 패널을 현장이 보이는 하단 임무 준비 바와 접힌 설정으로 바꿨다. 고급 설정·대원·LAB·시험판은 기존 기능을 유지한다. 결과는 실제 기록과 재도전/다음 행동을 우선하고 실제 발사 경로 재생은 기존 접힘 상태를 유지한다.

### I. 성능·오프라인

기존 물리 고정 스텝과 예측 계산 상한을 유지한다. 세로 배경 캐시는 긴 현장 전체를 한 번 생성하고 게임 중 재사용한다. 가로/세로 방향과 이미지 완성 상태만 캐시 키에 반영한다. 서비스워커 캐시를 v0.9로 올리고 새6자산을 포함했다. 범위 요청과 다른 모드 캐시를 건드리지 않는다. 실제 FPS/발열은 실기기 측정 전이다.

| 접근성 | 손·눈·기기 조건에도 수동 재미 보존 | 안내 다시 보기, 사용자 감도 세부 설정, 왼손 UI, 대비 검수 | 실제 이용자/기기 기록 |

새 게임 모드나 신규 보스·새 캠페인을 먼저 양산하지 않는다. 대표 작전의 조합·가독성·명중 연출을 통과시킨 뒤 같은 기준을 적용한다. 교육 설명을 더 길게 넣는 것으로 실패를 해결하지 않는다. 전 세계 순위/과금 성장/온라인 서버는 이번 범위에 없다.

## 5. 제작 자산과 실제 해상도

내장 이미지 생성 도구로 가로1장·세로5장을 각각 제작했다. 반환 원본은 가로1672×941, 세로1024×1536이다. 단순 업스케일을4K 원본으로 표시하지 않는다. WebP94 인코딩만 수행했으며 내용 보정은 하지 않았다. 실제 바닥 비율은 생성 지시와 다르므로 출력 확인 후 메타데이터로 맞췄다.

자산 경로·native 크기·바이트·해시는 `public/signal-breaker-dev/art/production-v4.json`에 기록한다. 프롬프트는 별도 [제작 프롬프트](SIGNAL-BREAKER-BENCHMARK-ART-PROMPTS-20261010.md)에 보존한다. 가로 기존4맵도 uniform scale로 그리며 원본을 삭제하지 않는다. 고밀도 태블릿/PC 최대 확대에서 native 해상도 한계는 남아 있고 Final Art Lock은 선언하지 않는다.

## 6. 검증과 시각 판정

검증 대상 흐름: 준비 → 연동 수동 이동/각도 → 직접 발사/취소 → 전체 경로 정지/수동 지정 → 복귀 → 정지/장비 설정 → 즉시 재도전 → 결과 → 오프라인 기록 저장.

검증 로그와 실제 캡처는 `docs/qa/signal-breaker-benchmark-20261010/`에 저장한다. 6viewport와5작전×2방향을 확인한다. 브라우저 검증은 실기기 손 감도/FPS/발열을 대신하지 않는다. 화면이 작동하는지와 최종 미술이 충분한지의 판정은 구분한다.

남은 실기기 기준: Android/iPad3분 혼잡 플레이,2포인터 조작/회전, 손가락 도달 범위, 고밀도 화면 native 선명도, 음향 믹스. 남은 디자인 기준: 첫 사용자 안내 이해와 반사 성공률, 실제 대안 해법 검증, 장치와 배경의 접촉/원근 일치. GitHub 반영과 운영 URL 배포 여부도 구분한다.
