# 시그널 브레이커 UI·UX 확인검증 및 개선

2026-10-13 / `0.51.0-uiux` / 이전 기준 커밋 `76e8b57e`

사용자 요청에 따라 현재 시그널 브레이커의 실제 화면과 조작을 점검했다. 승인된 게임 규칙·원화·캠페인은 유지하고, 표시·안내·설정 접근·키보드 동작을 개선했다. 기존 구매 가치 점검의 후속 UI·UX 보고서이다.

| 발견한 문제 | 구현한 개선 |
|---|---|
| 세로 화면의 아이템 성장 정보가 왼쪽으로 잘림 | 좌측 배치에 남아 있던 중앙 정렬 transform 제거, 화면 폭 안에서 줄바꿈 |
| PC 상단 메뉴 글자가 여러 줄로 갈라짐 | PC에서는 내용에 맞는 너비와 한 줄 표시, 모바일은 기존 축약 버튼 유지 |
| 시작 안내가 AUTO 상태와 달리 직접 발사를 요구 | 실제 AUTO/수동 상태에 맞는 시작 안내 |
| 교훈·모바일 안내가 FIRE로 자동발사를 끈다고 설명 | 별도 AUTO 버튼을 사용한다는 설명으로 정정 |
| 집중 모드에서는 설정 버튼이 숨겨지고 일시정지 설정은 접힌 메뉴 안에 있음 | 일시정지에 조작·소리·화질 설정 바로가기 추가, 설정 요청 시 실제 항목을 펼침 |
| 버튼에 포커스가 있어도 Space/Enter가 전역 게임 단축키로 처리됨 | 버튼·링크·summary의 기본 키보드 동작을 우선. 방호판에서 Space를 눌러도 발사되지 않음 |
| 준비/결과 오버레이의 의미와 키보드 이동 범위가 불명확 | dialog 역할과 제목 연결, 주요 버튼 초기 포커스, Tab/Shift+Tab 순환, 명확한 포커스 표시 |
| EP02 선택창에서 이름이 undefined이고 번호가 EP02-01~05로 표시됨 | 실제 에피소드 콘텐츠의 이름·소개, EP02-06~10 번호 사용 |
| 선택창의 ‘즉시 개입’ 버튼이 실제로는 준비 화면을 엶 | ‘출발 준비’로 표시 일치. 현재 작전도 ‘다시 준비’로 설명 |
| 전력/하중의 대응 도구 설명이 실제 조작과 맞지 않음 | 미스트·스캔 / 앵커로 대응 표시 수정 |
| 성장 + 버튼이 이름 없이 반복되고 잠금 이유를 알기 어려움 | 특성 이름·현재 랭크·투자 비용을 접근성 이름에 포함, 선행 조건/포인트 부족/최대 랭크 사유 표시 |
| 좁은 화면에서 잠금 이유가 특성 설명을 밀어냄 | 특성 내용·투자 버튼은 2열, 잠금 설명은 아래 전체 폭. 설명 12px/이름 13px 확보 |
| 투자 후 메뉴를 다시 그리면 키보드 포커스가 사라짐 | 동일 특성 버튼으로 포커스 유지, 최대 랭크가 되면 해당 특성 그룹으로 이동 |
| 스테이지 탭의 선택 상태가 화면/보조기술에 불명확 | aria-pressed와 선택 배경·밑줄, 특성 메뉴 탭 상태도 동기화 |
| PC 선택창에 불필요한 큰 빈 영역 | 콘텐츠에 맞는 높이와 내부 최대 스크롤 영역 |
| 짧은 가로 화면에서 조준 각도와 조작 패널이 겹침 | 조준 각도 표시 위치 조정 |
| 일시정지 설정 패널 상단이 HUD에 가려짐 | 세로·짧은 가로에서 HUD를 피하는 패널 배치 |

## 검증

- 전용 브라우저 검사 `public/signal-breaker-dev/scripts/verify-uiux.cjs`: **360×640, 390×844, 667×375, 844×390, 768×1024, 1440×900, 1920×1080, 3840×2160**.
- 오버레이 초기 포커스와 Tab 순환, 자동발사 상태 안내, 성장 정보 화면 경계, 버튼의 Space 동작, 일시정지→실제 설정 항목 접근, EP02 코드·이름·선택 상태, 특성 잠금 사유·내용 폭·투자 후 포커스, 메뉴 가로 넘침을 검사한다.
- 기존 8개 기기 회귀: 터치 도달성, 모달 정지, 화면 회전, 캔버스 예산, 교본 보상, EP02 준비, 훈련장 분리 통과.
- 전체 여정 회귀: 모바일 세로·가로·PC에서 각각 10작전 전투 완료 및 엔딩·전리품·개조·저장 복원·다시 보기 통과. 전투는 일반 엔진 명령 가속 입력이며 승리 상태를 주입하지 않는다.
- 본편 **2,059 테스트 통과 / 1 skip**, 브레이커 **254 테스트 통과**, 타입 검사·빌드 통과. 기존 대형 번들 경고는 남아 있다.
- 실제 스크린샷을 확인하고 모바일 특성 설명이 세로로 갈라지는 문제를 추가 수정했다. 신규 이미지/placeholder를 추가하지 않았다.
- 릴리스 98개 자산 해시와 서비스워커 캐시 버전을 갱신한다. 배포 후 공개 주소의 동일 해시와 UI·UX 브라우저 검사를 확인한다.

증거: `artifacts/uiux-20261013/`의 `uiux.json`, 화면 PNG, `device/device-verification.json`, `journey/full-journey.json`, 테스트/빌드 로그. 요약: `docs/qa/uiux-audit-20261013.json`.

## 남은 확인

실제 Android/iOS에서 엄지 동선·장시간 피로·발열·햅틱, 화면읽기 프로그램의 전체 발화, 신규 이용자의 메뉴 이해도를 별도로 확인해야 한다. 이번 키보드/ARIA 검사만으로 전체 접근성 인증이나 실기 사용성 검증을 완료했다고 계산하지 않는다. 최종 아트·사운드 승인과 가격/결제 결정은 이전 보고서의 남은 항목을 따른다.
