# 직접 치는 공장 핀볼: 손맛·러시·반복 연습

## 방향

자동 패들 기본값은 끈다. 플레이어가 공을 읽고 직접 친 순간, 더 높은 점수와 선명한 반응을 얻어야 한다. 계속 버튼을 누르고 있는 것과 정확한 순간에 누른 것을 구분한다. 자동 보조는 설정에서 명시적으로 선택하는 접근성 옵션으로 남긴다.

## 이번 구현 범위

| 요소 | 행동과 보상 | 쾌감의 이유 |
| --- | --- | --- |
| 퍼펙트 타격 | 수동 누름 직후 회전 중인 패들의 유효 구간에 실제 접촉하면 +250점 | 정확하게 친 손맛과 즉시 확인 |
| 발사 세기 | 발사 전 15~100% 조절로 진입 궤도 선택 | 첫 타격부터 직접 선택 |
| 스킬샷 | 공마다 지정된 범퍼를 발사 후 2.5초 안에 처음 맞히면 +500점 | 발사부터 작은 목표가 생김 |
| 좌우 반동 패널 | 원화의 좌우 금속 패널에 강하게 접촉하면 반동과 +50점 | 넓은 궤도와 연속 타격을 만듦 |
| 크레인 러시 | 세 범퍼 점등 완료 시 +1,000점, 10초 동안 세 공과 타격 점수 ×2 | 성취 후 짧은 절정과 직접 처리할 공 증가 |
| 러시 잭팟 | 러시 중 다시 세 범퍼를 모두 켜면 +2,000점 | 절정 안에 다음 목표가 이어짐 |
| 수동 흔들기 | Space 또는 버튼, 한 공당 3회, 반동 속도를 조금 바꿈. 연타하면 1.5초 틸트 | 위기를 내 손으로 구하지만 남용에는 제약 |
| 반복 연습 | 동일한 물리·목표, 세 공 후 얼마든지 다시 연습. PSI 지급 함수 자체를 호출하지 않음 | 실패 부담 없이 타이밍 학습 |
| 전체화면 | 화면을 채우는 핀볼 무대, 지원 브라우저에서는 발사 클릭으로 native fullscreen 요청 | 게임 외 패널을 걷어내고 테이블과 공에 집중 |

러시의 추가 공은 새 기회로 계산하지 않는다. 공이 모두 회수되면 다음 기회로 넘어간다. 러시가 끝나면 추가 공을 정리해 한 공 플레이로 복귀한다. 기존 삼세번과 보너스 한 판 기본 100~최대 400 PSI를 유지한다. 연습 기록은 보너스 기록과 분리한다.

## 연출과 조작

범퍼 점등·수동 정확 타격·러시·잭팟을 HUD에서 구분하고 중앙을 가리지 않는다. 세 공은 실제 충돌과 궤도로 표현한다. 기존 전용 원화와 음원을 유지하면서 접촉 광원, 짧은 잔상, 크레인 동작을 활용한다. 모바일은 테이블을 직접 터치하거나 아래 좌우 버튼을 두 손가락으로 조작할 수 있다. 흔들기에는 별도 버튼을 둔다.

음악 설정과 안내 중에는 정지한다. native fullscreen 미지원/거부 시에도 화면을 채운 무대를 유지하고 수동 전체화면 버튼을 제공한다. 전체화면에서 나가면 일시정지한다. 움직임 줄이기에서는 잔상과 흔들림을 줄이고 물리·보상을 동일하게 유지한다.

## 검증 기준

수동 기본값, 가만히 있을 때 패들 정지, 수동 퍼펙트와 보조 구분, 실제 세 공, 잭팟 조건과 시간 종료, 연습의 지급 차단·무제한 재시작·기록 분리, 흔들기 한도와 틸트, 화면 5종 및 native fullscreen 진입/종료·정지·설정 안전, 기존 보상 단일 지급을 검사한다. 숫자 검사와 별개로 실제 플레이에서 쾌감과 난이도는 Director의 체감 평가 대상으로 남긴다.

## 구현 검증 결과

- 전체 테스트 1,960 통과 / 1 제외. typecheck와 production build 통과.
- 실제 앱 진입으로 1440×900, 390×844, 844×390, 360×640, 412×740의 수동·멀티터치·전체화면·설정 정지·반복 연습 지갑 안전을 확인.
- native fullscreen 미지원 390×844에서도 화면 전체 무대와 조작·정지 복귀 확인.
- 러시·잭팟 QA는 명시적인 공 위치 배치로 조건을 검사하며 자연 플레이 달성으로 해석하지 않는다. 자동 보조 자연 3회 진행과 프레임률별 물리 회귀는 별도 엔진 테스트로 확인.
- 기존 final 후보 테이블 원화와 음원을 재사용. 손맛과 사운드의 최종 품질 판정은 실제 사용자 체감 검토 대상.
