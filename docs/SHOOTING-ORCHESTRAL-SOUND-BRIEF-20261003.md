# SURVIVORS 오케스트라급 사운드 제작 기획

## 목표

사운드는 음악 장식이 아니라 행동의 확인, 보이지 않는 위험의 예고, 타격의 무게, 성장의 보상, 세션의 감정 곡선을 담당한다. 음악을 크게 만드는 것으로 완성도를 판정하지 않는다. 중요한 경보·무전·피격은 휴대폰 스피커에서도 식별되어야 한다.

기존 G8-A의 오케스트라/현장 사실성 제작 원칙과 자산 승인은 존중한다. 현재 슈팅의 synth는 최종 오케스트라 자산이 아니다. 디펜스 곡을 단순 반복하는 대신 동일 PSI 모티프를 액션 템포와 사건 흐름에 맞게 편곡할지 먼저 평가한다. 실제 오케스트라 녹음, 샘플 기반 작곡, 생성 음악은 제작 수단이며 각각의 출처·라이선스를 기록한다.

## 음악 방향

- 정서: 현장에 대한 집중 → 압박 → 위험 인지 → 책임 있는 개입 → 안도와 다음 날.
- 편성: legato/tremolo/spiccato 현악, 저현 pulse, 절제된 호른·저금관, 목관의 인간적 호흡, timpani/콘서트 큰북/금속 현장 타악, 짧은 piano anchor.
- 핵심: 독창적인 3-5음 PSI 모티프. 위협은 불협/리듬, 개입은 명료한 모티프, 결과는 절제된 해소로 구분.
- 금지: 유명 영화음악 복제, 지속적인 trailer braam, 항상 최대 편성, 의미 없는 sub-bass, 과도한 승리 fanfare.
- 작곡 초안: 96 BPM, 4/4, 8마디 루프 약 20초. 현재 G8-A 84 BPM 스템과 직접 합치지 않는다. 공통 키·템포·길이 편곡 또는 독립 score를 택한다. 수치는 승인 전 초안이다.

| 큐/스템 | 역할 | 길이 초안 | 재생 |
|---|---|---|---|
| patrol.foundation | 현장 집중, 저현·piano·air | 8/16마디 | 공통 clock 루프 |
| patrol.pressure | 밀도 증가, spiccato와 작은 타악 | foundation과 동일 | 세로 레이어 |
| patrol.heavy_risk | 대표 위험의 무게, 저금관 | 동일 | 위협 상태 레이어 |
| patrol.intervention | 궁극기/통제 개입의 PSI 모티프 | 2-4초 | 즉시 one-shot |
| patrol.evolution | 성장 전환의 확신 | 1-2초 | one-shot, 겹침 제한 |
| patrol.success | 안전하게 닫힌 하루 | 6-10초 | 결과 1회 |
| patrol.failure | 손실 인지와 재정비 | 4-8초 | 결과 1회 |

READY → PATROL → PRESSURE → HEAVY_RISK → INTERVENTION → RESOLUTION. 저체력은 별도 강조 레이어/duck 조건이며 음악 전체를 계속 바꾸지 않는다. 상태 흔들림을 막는 최소 유지시간과 진입/이탈 hysteresis를 둔다. 위험 등장 경보는 즉시, 지속 음악은 마디 경계에서 전환. levelup은 완화, pause는 정지/완화 중 정해진 정책 적용, 숨김은 정지한다.

## 효과음과 공간

| 사건 | 음색/정보 | 반복 정책 |
|---|---|---|
| 무전 대응 발사 | 짧은 RF click와 지시 전달의 질감 | 실제 발사 이벤트, 3-5개 변형 |
| 소화기 분사 | 압력/밸브/분말의 질감 | 시작·지속·종료 분리 |
| 드론/통제선/투광등 | 기계·릴레이·전원·설치 질감 | 도구별 구분 |
| 명중/위험 통제 | 접촉과 기능 정지 확인 | 명중과 완료음 구분 |
| 수집 | 짧고 부드러운 확인음 | 몰아서 수집 시 집계 |
| 피격/저체력 | 정보 우선, 공포 과장 금지 | cooldown, 경보 독점 금지 |
| 중장비 등장 | 엔진 질량과 식별 가능한 경보 | 음악 duck, 위치 감쇠 |
| 궁극기 | 실제 무전 지시와 현장 통제 반응 | Voice가 음악보다 우선 |

카메라 기준으로 약한 좌우 pan과 거리 attenuation을 적용한다. 중요 경보는 화면 밖이어도 최소 가청성을 유지한다. 긴 reverb는 현장 구역에 따라 제한한다. 단순히 샘플 pitch를 랜덤 변경해서 다양성을 대신하지 않는다.

## 런타임 기술 요구

세션당 AudioContext 하나, decode 버퍼 캐시, 공통 시작 시각을 쓰는 스템, GainNode 기반 Music/SFX/Voice/Ambience/Master 버스. 반복은 equal-power crossfade 후보를 비교한다. 모든 one-shot과 loop를 추적해 mute/exit/hidden 때 즉시 정리하고 pause 정책을 통일한다. 중복 이벤트 ID를 제거하고 중요도에 따라 voice를 제한한다. 초안 총 24 voices, 실제 모바일 trace에 따라 조정한다.

목표 시작값: Voice/필수 경보 > 피격·개입 > 발사·명중 > ambience > music. 경보/무전 중 음악 4-8dB duck, attack 30-80ms / release 250-600ms를 후보로 청취 비교한다. 이 값은 합격 기준 자체가 아니다. 저주파를 줄여도 필수 사건이 중역에서 남아야 한다.

원본은 실제 생성/녹음 포맷으로 보존. runtime은 기존 OGG/Opus 파이프라인과 호환한다. 단순 upsample을 고음질이라고 부르지 않는다. 전체 대표 믹스 목표 -18~-14 LUFS, true peak -1dBTP 이하, 동적 범위 보존. 짧은 one-shot에 integrated LUFS/LRA를 일괄 강제하지 말고 체감 크기와 peak를 맞춘다. dBFS peak와 dBTP 측정값을 구분한다.

manifest: id, 사건, URI, native 포맷, runtime 포맷, 길이, loop 포인트, 제작자/도구, 권리, SHA256, 상태, 기술/청취/실기기 증거. 후보와 승인 파일을 구분한다. 자동 재생 성공은 청취 합격을 의미하지 않는다.

## 작곡/생성 프롬프트

> NEW PSI의 건설현장 서바이벌 액션용 독창적인 hybrid orchestral score를 제작한다. 인간의 집중과 책임 있는 개입이 중심이다. 96 BPM, 4/4 초안, 공통 조성·구조·시작점으로 서로 겹쳐 재생 가능한 foundation / pressure / heavy-risk 세 스템을 분리 납품한다. 낮은 현악과 절제된 piano, spiccato와 실제 금속 타악 질감, 위험 구간의 호른·저금관을 사용한다. 3-5음 원창작 모티프를 짧은 intervention과 결과 coda에도 연결한다. 경보·무전의 중역 공간을 비워둔다. 지속적인 epic wall, 유명 작품 모사, 긴 braam, 과도한 sub-bass, 영웅 승리 fanfare를 배제한다. 원본 master와 스템, 정확한 loop 시작/끝, key/BPM/bar 수, 라이선스와 제작 출처를 납품한다. 생성 도구가 독립 스템을 보장하지 못하면 통합 믹스를 스템으로 가장하지 말고 작곡/편곡으로 해결한다.

## 효과음 제작 프롬프트

> Stage 01의 도구별 발사·명중·위험 통제 완료, 피격, 수집, 성장, 중장비 경보, 무전, 승패 효과음을 사건별로 분리 제작한다. 현장 장비의 작동 원리를 떠올릴 수 있는 Foley를 중심으로 하되 짧은 플레이 확인음으로 정리한다. 무전/RF click, 소화기 압력과 밸브, 드론 전동기, 통제선 설치, 장비 정지의 질감을 구분한다. 사람을 공격하는 소리나 대형 폭발의 쾌감으로 통제를 표현하지 않는다. 반복 사건마다 3-5개 변형, 불필요한 선행 무음 제거, click 없는 tail, mono 호환, 모바일 중역 식별성을 확보한다. 각 파일의 native master/권리/용도/길이/peak를 기록한다.

## 청취 승인

헤드폰 stereo, laptop/작은 스피커, 실제 Android speaker와 유선/Bluetooth 조건을 각각 기록한다. 10분 반복에서 자원 누적·음량 피로·loop click·stem drift를 확인한다. 화면 없이 경보/피격/개입/승패를 구분하는 blind test를 수행한다. 새 사용자 5명 중 4명 이상 식별은 초안 목표다. 중요한 정보는 화면에서도 전달해 무음 플레이를 보장한다. 이 세션의 청취/실기기 평가는 NOT_RUN이다.
