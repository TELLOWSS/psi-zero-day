## 간단한 설명 초안

사고 전 신호를 읽고 현장 판단을 선택하는 건설안전 전략 시뮬레이션

## 전체 설명 초안

PSI : ZERO DAY는 건설현장에서 사고가 발생하기 전 나타나는 작은 신호를 읽고, 사람·공정·책임 사이에서 실제 현장 판단을 선택하는 전략 시뮬레이션 게임입니다.

플레이어는 현장 안전관리자의 시점에서 작업자, 반장, 공사 담당자, 감리 등 여러 관계자와 협력하거나 충돌하며 상황을 해결합니다. 정답을 알고 있어도 그대로 실행하기 어려운 현실적인 현장 압박 속에서 무엇을 우선하고 누구와 소통할지 직접 결정해야 합니다.

주요 특징

- 건설현장 2.5D 전략맵에서 위험신호와 작업구역을 직접 확인
- 사람, 위험요인, 현장구역을 선택한 뒤 담당자와 조치를 결정
- 선택에 따라 관계, 보고문화, 작업흐름과 후속 상황이 달라지는 Episode 01
- 장비 획득과 장착에 따라 추가 현장 행동이 열리는 성장 구조
- 작업중지, TBM, 감리 지적, 책임전가, 보고 압박 등 실제 건설현장에서 일어날 수 있는 갈등을 게임플레이로 구성
- 오프라인 우선 진행 및 기기 로컬 저장

PSI는 Proactive Safety Intelligence의 약자입니다.

“사고 전 신호를 모아 다음 위험을 먼저 읽는 안전지능.”

PSI : ZERO DAY는 단순히 안전수칙을 외우는 게임이 아니라, 현장에서 왜 안전한 판단이 어려운지 경험하고 그 안에서 더 나은 선택을 찾아가는 것을 목표로 합니다.

## 현재 릴리스에서 포함되는 기능

- Episode 01 vertical slice
- 분기형 11~16 이벤트 플레이
- 8인 주요 캐릭터
- 전략맵 기반 대상/행동/결과 루프
- 캐릭터 성장, 인벤토리, 장비 장착
- 장비 기반 행동 해금
- 관계 변화 피드백
- 자동 저장 및 재개
- Android 가로모드 대응

## 현재 릴리스에서 주장하지 않는 기능

스토어 설명과 스크린샷에서 아래 기능을 현재 구현된 것처럼 표현하지 않습니다.

- 온라인 멀티플레이
- 계정 로그인/클라우드 세이브
- 실시간 현장 데이터 연동
- 실제 PSI 점수 산출 공식
- 광고/보상형 광고
- 미구현 Episode 02 이후 콘텐츠
- 실제 건설현장 회사명/현장명/실명

## 스크린샷 문구 후보

1. 사고 전 신호를 먼저 읽어라
2. 누구에게, 무엇을, 어떻게 조치할 것인가
3. 정답을 알아도 실행하기 어려운 현장
4. 장비와 경험이 새로운 행동을 연다
5. 오늘의 선택이 내일의 현장을 바꾼다

## 개인정보처리방침

배포된 정적 정책 페이지 `/privacy.html`을 Play Console 개인정보처리방침 URL로 사용합니다. 최종 Production 도메인이 확정되면 절대 URL을 기록합니다.

## 출시 전 카피 검토

- 게임 화면에 실제로 존재하지 않는 기능을 홍보하지 않는다.
- 실제 회사, 현장, 개인을 연상시키는 고유명사를 사용하지 않는다.
- 교육효과를 과장하거나 사고 예방을 보장한다고 표현하지 않는다.
- 건설안전 전문성과 게임성을 함께 보여주되 업무용 안전관리시스템으로 오인시키지 않는다.
