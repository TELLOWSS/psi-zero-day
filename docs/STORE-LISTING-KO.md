# PSI : ZERO DAY — Google Play 스토어 등록정보 초안

Status: RELEASE COPY FOUNDATION

## 앱 이름

NEW PSI : ZERO DAY

## 한 줄 포지셔닝

공기 압박, 묵인된 관행, 한 번의 타협이 부르는 대참사. 무너져가는 현장 속에서 당신의 선택은 누구를 지켜낼 것인가?

## 간단한 설명 초안

공정과 안전, 책임의 최전선에서 사고 전 신호를 읽어내는 현장 생존 전략 시뮬레이션

## 전체 설명 초안

**“정답을 아는 것과, 현장에서 그 정답을 작동시키는 것은 전혀 다른 문제다.”**

**NEW PSI : ZERO DAY**는 실시간으로 공정과 비용, 사람과 책임이 충돌하는 거친 건설현장을 배경으로 한 **현장 생존·위기관리 전략 시뮬레이션 게임**입니다.

타워크레인이 돌고 레미콘이 쏟아지는 현장. 밀려오는 공기 단축 압박과 "늘 이렇게 해왔다"는 베테랑 반장의 고집, 사소해 보이지만 치명적인 균열의 징후들이 당신의 눈앞에 펼쳐집니다. 

당신은 현장 안전관리자의 시점에서 누구와 대화하고, 어떤 타협을 거부하며, 어디에 통제력을 집중할지 결정해야 합니다. 서류상의 정답은 쉽지만, 현실의 선택에는 반드시 대가가 따릅니다.

### 🎮 게임플레이 특징

- **2.5D 전술 디오라마 맵**: 작업 구역과 이동 동선, 장비와 작업자를 한눈에 조망하며 현장의 이상징후(PSI 신호)를 탐색합니다.
- **사람과 관계의 시스템화**: 작업자의 신뢰, 반장의 권위, 시공사의 공기 압박은 단순한 대화가 아닌 게임 속 자원이자 변수로 작동합니다. 당신의 태도가 현장의 침묵을 깨뜨릴 수도, 더 깊은 은폐를 부를 수도 있습니다.
- **지연된 나비효과**: 현장에서의 작은 타협은 당장 드러나지 않습니다. 다음 날의 재개, 후속 공정의 부실, 그리고 예상치 못한 순간의 참사로 되돌아옵니다.
- **전술적 긴급 개입 (ZERO BREACH)**: 위험이 임계치를 넘어설 때, 장비와 방호시설, 유도 인력을 직접 배치하여 현장의 붕괴를 막아내는 긴박한 디펜스 모드를 지원합니다.
- **장비 획득과 현장 행동 해금**: 무전기, 점검 키트, 가설 통로 등의 장비와 시설을 갖추며 점차 위기 대응 능력을 키워나가는 전략적 성장 시스템.
- **100% 오프라인 플레이 지원**: 번거로운 계정 가입이나 강제 광고 없이, 순수한 전략적 판단에 집중할 수 있는 완성형 에피소드.

## 현재 릴리스에서 주장하지 않는 기능

스토어 설명과 스크린샷에서 아래 기능을 현재 구현된 것처럼 표현하지 않습니다.

- 온라인 멀티플레이
- 계정 로그인/클라우드 세이브
- 실시간 현장 데이터 연동
- 실제 PSI 점수 산출 공식
- 광고/보상형 광고
- 미구현 Episode 02 이후 콘텐츠
- 실제 건설현장 회사명/현장명/실명

## 스크린샷 문구 후보

1. **사고 전 신호를 포착하라** — 보이지 않던 위험이 수치와 동선으로 드러난다
2. **공정인가, 안전인가** — 타협 없는 선택에도 반드시 비용과 대가가 따른다
3. **침묵하는 현장을 움직여라** — 신뢰와 체면, 관계가 실제 정보의 흐름을 바꾼다
4. **전술적 긴급 개입 (ZERO BREACH)** — 위험 임계치를 돌파한 현장을 방호 수단으로 지켜내라
5. **오늘의 선택이 내일의 현장을 바꾼다** — 정답표 대신 다음 날의 현실로 되돌아오는 나비효과
