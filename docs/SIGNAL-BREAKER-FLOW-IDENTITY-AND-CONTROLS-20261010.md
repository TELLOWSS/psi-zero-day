# SIGNAL BREAKER — 흐름의 해소 / 경험 개선 v5

2026-10-10 · 캡처의 보고서형 결과창, 가로 홈 잘림·스크롤 불가, 짧고 단조로운 작전, 진입 준비창 및 후속 조작 불편 피드백을 반영한다.

## 정체성

**각도를 바꿔, 흐름을 끊어라.**

PSI는 사고 전 신호를 읽는 세계다. 시그널 워치는 다가오는 위협을 견디며 현장을 지키고, 브레이커는 사람이 직접 만든 발사 경로로 위험의 연쇄를 해소한다. 산업 장치가 퍼즐이 되고, 정확한 반사와 연쇄 회수가 성취가 되는 현장 물리 아케이드다. 실제 안전조치를 생략하는 행동에 보상을 주지 않는다.

- 이름: SIGNAL / BREAKER · 시그널 브레이커. 상위 NEW PSI : ZERO DAY 유지.
- 표어: 각도를 바꿔, 흐름을 끊어라.
- 형태: 꺾인 경로와 금색 끝점. 도착점보다 플레이어가 만든 경로를 기억하게 한다.
- 색: 현장 사진의 재료와 빛, 조준/회수의 청록, 성취의 따뜻한 금색. 모든 장치를 동일한 네온색으로 덮지 않는다.
- 문체: 짧은 행동과 결과. ‘작전 완료 보고’ 대신 현장의 흐름이 돌아왔다는 표현.
- 브랜드 적용: 홈 카드 영문 서명·경로 심벌·표어, 결과 서명/점수. 기존 회사·세계관 워드마크는 유지.

첨부 마스터 바이블의 WORLD FIRST / MOBILE FIRST / IMPACT FIRST / AUDIO=GAMEPLAY / ONE PRODUCTION GENERATION을 따르며 기존 엔진 좌표·안전 하한·장비/보상 계약은 보존한다.

## 실제 반영

### 1. 홈과 진입

홈을 스크롤 가능한 실제 콘텐츠 흐름으로 바꿨다. 고정 화면 높이와 숨겨진 overflow로 가로 하단이 접근 불가였던 부분을 수정했다. 세로는 두 플레이 카드가 순서대로, 가로는 두 카드가 함께 보이며 나머지 기능은 아래에서 접근한다. 실시간 사용 가능한 워치/브레이커를 강조하고 준비 중 모드와 기능 영역은 낮은 우선순위로 배치한다. 반복 현장 상태 카드와 캐릭터 명패는 홈에서 숨기며 동료/도감 기능은 보존한다.

브레이커 카드 → CH-01 직접 시작. 입력 전에는 발사하지 않는다. 기존 준비 화면은 `?entry=prepare` 진단 경로와 설정/모드 선택에 남아 있다. 실제 기본 진입과 결과의 다음 작전은 준비 확인을 다시 요구하지 않는다. 소리는 브라우저의 실제 사용자 입력에서 활성화된다.

### 2. 기본 양손 조작 — 후속 피드백 우선 반영

| 입력 | 결과 |
|---|---|
| 왼손 패드 수평 | 이동 속도와 바라보는 좌우 방향. 선택한 상향 각도 유지 |
| 왼손 패드 상하 흔들림 | 각도에 영향 없음 |
| 왼손 중심 16% | 입력 무시. 작은 흔들림으로 방향이 바뀌지 않음 |
| 오른손 발사 버튼 위/아래 드래그 | 누른 순간 각도를 기준으로 직접 조준. 1px=0.006rad, 상향5~90도 |
| 오른손 떼기 | 설정한 각도로 한 발 발사. 장비 쿨다운은 그대로 적용 |
| 터치 취소·포인터 소실·정지 | 발사 없음, 입력 해제 |
| 양손 동시 | 이동·좌우 반전 중에도 오른손의 상향 각도 유지 |

이전의 한 패드 수평 이동+상하 각도 속도 입력을 기본 조작에서 제거했다. 왼손은 방향, 오른손은 수동 각도와 샷을 맡는다. 방향 변경 버튼을 추가로 누르지 않는다. 무입력 발사·표적 추적은 없다. 발사 버튼 드래그는 엔진에 각도 자체를 지정하여 맵 가장자리의 조준점 clamp로 각도가 바뀌지 않게 한다. 기존 정밀 모드/캔버스 직접 조준과 PC 키보드는 선택 기능으로 보존한다.

오른손을 떼는 순간 발사하는 방식의 손 감도와 버튼 도달 범위는 실제 이용자 검수가 필요하다. 엔진에서 이동하는 동안 조준점의 수평 거리를 함께 이동시켜, 작은 이동으로 조준 각도가 떠는 문제도 수정했다.

### 3. 작전의 호흡

기본 챕터를 3구간으로 확장한다. LAB과 기존 엔진 기본 실행은 단일 구간을 유지한다. `extended:true` 옵션으로 명시적으로 켠다.

1. 발견: 기존 코어 배치와 장치 역할 학습.
2. 재배치: 반대쪽 위치, 반대 속도 방향, 속도 1.12배. 기존 각도를 다시 계획.
3. 최종 해소: 위치 +95px(경계 안), 속도1.22배, 추가 소형 하중/재료 코어1개. 릴레이/보스는 여기서 진입.

각 구간은 실제 코어가 모두 해소된 후 전환한다. 1.1초간 해소 연출 후 다음 코어를 넣으며 장비·생명·점수·시간은 이어진다. 정지 중 전환 타이머도 멈춘다. 매 구간마다 상자나 준비창을 열지 않는다. 보상은 최종 승리 때만 기존 규칙에 따라 한 번 지급한다. 최고 기록은 3구간 `bestFlow`/`bestFlowTime`으로 별도 저장해 기존 단일 구간 기록과 비교하지 않는다.

현재 CH-01 기준 총 회수량은6→20으로 늘었다. 실제 인간 플레이 시간90~150초는 **목표**이며 측정 완료값이 아니다. 구간을 늘리는 것만으로 최종 재미를 확보했다고 선언하지 않는다. 후속 단계에서는 장치 조합별 대안 해법·명중 피드백과 실제 플레이의 피로도를 확인한다. 장시간 체류를 강제하는 대기·과금·출석 시스템은 넣지 않는다.

### 4. 결과의 쾌감과 정보

큰 점수와 브랜드 서명, 짧은 표어, 숙련 칩3개, 재도전/다음작전 두 행동을 우선 노출한다. 보상과 장비·경로는 펼칠 때 보는 기록 상세로 이동했다. 현장을 강한 블러로 덮지 않으며 결과창은 하단, 낮은 가로 화면은 우측에서 표시한다. 등장 모션은 reduced-motion을 존중한다. 구간 해소에 기존 FX 예산 안에서 확산 링과 스파크를 연결했다. 새 최종 음원이나 캐릭터 애니메이션을 제작했다고 주장하지 않는다.

## 검증·남은 품질 기준

- 순수 엔진: 질량/승리 조건3구간, 중간 승리 방지, 마지막 보스 생성, 정지 타이머, reset, LAB/기존 단일구간, 이동 각도 보존.
- 브라우저: 홈 세로/가로 스크롤과 잘림, 실제 링크→즉시 시작, 양손 동시 조작, 드래그 중 무발사/떼기 한 발, 각도 유지,3구간→결과→다음작전, 회전 버튼 경계.
- 기존 장비·충돌·보상·오프라인 저장 회귀 검사.
- 실기기: 손 도달·드래그 감도·체감속도,3분 혼잡 성능, 초보자 반사 성공률, 실제90~150초 플레이 시간.
- 미술/사운드: 장치 접촉·동작과 배경의 세대 일치, 회수의 최종 음향/무전 믹스. Final Art Lock과 운영 배포는 별도 판정.
