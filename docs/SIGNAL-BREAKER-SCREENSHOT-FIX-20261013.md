# 휴대폰 캡처 88814 기준 화면 정리

확인된 문제: 발생원 재발 알림·이동 조언·진전 없음 팁이 동시에 현장을 덮음. 이동 패드의 장식 라벨이 좁은 컨테이너에서 세로로 줄바꿈됨.

수정: 발생원 조치가 필요하면 HUD 아래 한 줄 안내를 우선한다. 조치가 끝나면 이동·조준 도움으로 전환한다. 해당 안내와 일반 팁은 동시에 띄우지 않는다. 발생원 이벤트의 중복 팝업과 같은 이동 조언의 반복 팝업을 억제한다. 짧은 획득·완료 알림은 잠시 행동 안내를 대신하며 만료 후 안내가 돌아온다. 내러티브 문구도 안내와 같은 위치에서 겹치지 않게 한다. 클릭 가능한 발생원/이동/직접 발사 조작은 유지한다.

이동 패드의 잘리는 장식 라벨만 제거하며 입력 영역·접근성 이름은 유지한다. 일반 휴대폰·짧은 세로 화면(393×720)·가로·태블릿·PC에서 검증한다. 캐시 0.46.2-guidance-cleanup을 적용한다. 게임 판정·해금·보상·자동발사 설정은 변경하지 않는다.

추가 원인: 세로 화면에서 보스 존재 여부 대신 항상 존재하는 카메라 속성으로 HUD를 배치해, 보스가 없는 첫 작전에도 보스용 중간 배치가 적용됐다. 실제 보스 존재로 배치를 구분하고 만료된 알림의 잔상을 행동 안내와 겹치지 않게 한다.
