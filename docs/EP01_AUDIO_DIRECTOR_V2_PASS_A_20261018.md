## 실제 반영

- EP01 본편 26/26 사건에 `src/app/episode01-audio-director.ts`의 연출 메타데이터 연결.
- 장면별 `sceneFadeMs`(850~1800ms), `scoreFadeMs`(1750~3200ms), `roomToneScale` 적용.
- 기존 `storySoundscape` 8개 배경·효과 자산을 그대로 참조. 특정 사건의 잔향을 한 번에 끊지 않고 2-deck 전환.
- 같은 배경음 ID라면 재시작하지 않으며, 볼륨 목표만 바뀌는 경우 별도 180~650ms 자동화로 연결.
- 표준 4개 검수 성우 음성, 26개 사건 ID, 선택지, 세이브, DAY02 브리지 데이터는 변경하지 않음.
- 이번 변경에서 음악 파일을 신설하거나 기존 오디오 마스터를 수정하지 않음.
